| |  |  | | --- | --- | | About design variables | | |  | | | |  | | --- | | Design variables are the entities that change during an optimization. Typically a design variable is linked to a property or an entity of the model.   * Design Variables | | |   Design Variables In topology optimization, the design variables denote the set of elements that might get removed during the optimization.  In a sizing optimization, the design variables are associated with the thickness of elements elements.  In shape and bead optimizations, the design variables are associated with node positions. |
