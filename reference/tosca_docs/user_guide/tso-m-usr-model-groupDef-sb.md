| |  |  | | --- | --- | | Group Definition (GROUP\_DEF, GROUP\_AUTO\_DEF) | | |  | | | |  | | --- | | The definition of groups is a very important function in SIMULIA Tosca Structure. For example, if one or more nodes should be assigned a specific attribute (for example, a restriction), the nodes are first assembled in an object node group. Then the attribute is assigned to the object node group.  In SIMULIA Tosca Structure different types of groups exist: node groups, element groups and generic groups. Groups can be defined manually using selection of objects or using lists in Tosca Structure.gui. Further, automatic node group definition is available to define groups following specific geometrical patterns like, for example, on surfaces of revolution. All groups from the FE input file(s) linked to the optimization task are also available for definitions in SIMULIA Tosca Structure. Groups are uniquely defined and addressed with their user-defined names (character string).
