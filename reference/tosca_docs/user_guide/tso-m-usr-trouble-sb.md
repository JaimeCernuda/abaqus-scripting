| |  |  | | --- | --- | | Troubleshooting | | |  | | | |  | | --- | | This section describes methods of identifying and correcting errors that occur when the program terminates prematurely during optimization.  The search of error messages is depending upon when the program stopped (see the figure in About Determining the Point of Program Termination), which can be identified using the main log file `TOSCA_OUT` in the job-directory (see also Logging). If a licensing problem is detected, the log file authorization.log might be of interest (see also Special Logfiles). In case that the FE-solver has not completed the analysis one must look into the respective FE-solvers log-files.  When the program terminates prematurely, all files required for the error search are moved to the subdirectory DB\_ERROR in the `jobname` directory (see Completion of the Optimization Process).
