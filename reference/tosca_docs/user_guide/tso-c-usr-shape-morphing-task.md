| |  |  | | --- | --- | | About the Morphing Task | | |  | | | |  | | --- | | This section gives information about the `MORPH` command.  * Control Output of Tosca for Morphing Tasks | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | MORPH | | MORPH\_AREA | |   Using the `MORPH` command, the single morphing areas (`MORPH_AREA`), the morphing parameter file and the optimization task are combined:   ``` MORPH   ID_NAME                 = <morph_name>   [string]   OPTIMIZE                = <optimization_name> [string]   MORPH_AREA              = <MORPH_AREA_name_1>   [string]   MORPH_AREA              = <MORPH_AREA_name_2>   [string]   MORPH_AREA              = …   MORPH_PARAM_FILE        = <morph_csv_file_name> [string]   NUMBER_OF_PARALLEL_JOBS = <number>   SMOOTHING               = YES|NO [string]   MAIN                    = AUTO | MIN | MAX | MINABS | MAXABS | SUM | CSV END_ ```   The parameter `NUMBER_OF_PARALLEL_JOBS` defines optionally a number of jobs which can be run in parallel. If omitted or =1, a sequential run is performed (default).  `SMOOTHING` is another optional parameter that switches off the surface mesh smoothing for the nodes in the morph areas. By default surface smoothing is omitted to gain the exact displacement as specified in the `csv-file`. However some manufacturing constraint might not work as expected in this case.  The `MAIN` criteria is a great help to gain control about the order in which the morph areas are processed. This is especially important if you work with overlapping morph areas.  * AUTO:   (Default, same behavior as in previous versions) Order as specified as in the csv file, but morph areas with zero displacement are processed last and thus being most important. * MIN: Morph areas with the smallest displacement specified in the csv file are processed last. * MINABS: Morph areas with the smallest absolute displacement (for example, 0) are processed last. * MAX: Morph areas with the greatest displacement are processed last. * MAXABS: Morph areas with the greatest absolute displacement are processed last. * SUM: If nodes are referenced in multiple morph areas, the displacements are summed up. * CSV: Order exactly as specified as in the csv file.  Control Output of Tosca for Morphing TasksBy default, Tosca generates results for all morphed variants. To suppress the generation of fe-solver results, use the command-line option `--morph_no_solve`. Morphed input files can be found in `SAVE.inp`/[n], where [n] corresponds to the row number in the morphing parameter file. |
