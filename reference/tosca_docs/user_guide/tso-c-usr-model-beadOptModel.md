| |  |  | | --- | --- | | Models for Bead Optimization | | |  | | | |  | | --- | | The basic idea of bead optimization with respect to model requirements is described. | | |   The design area for a bead optimization must be a shell type of structure, that is, shell or plate elements.  The mesh should be uniform in element size. The element size should be chosen such that six elements cover the wanted bead width. It is recommended to use linear elements, but not required. |
