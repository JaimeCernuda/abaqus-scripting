# Processing Results from Shape or Bead Optimization

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Processing Results from Shape or Bead Optimization | | |  | | | |  | | --- | | In the case of shape or bead optimization, Tosca Structure.SMOOTH generates the surface of the model with calculated optimization displacements. | | |   Therefore, the database containing the model and the optimization results should be specified in the parameter file, and the task should be set to surface:   ```     TASK = surface     DATABASE = "opt_res_database" ```   In Tosca Structure.gui (Tosca Structure.SMOOTH screen), select the `Create Surface with optimization displacements (Shape and Bead optimization)` option of the Task field.  In addition, there is the possibility to generate the surface of the input model, without applying the optimization displacements. This works for the models used in topology optimization as well. In this case, the `DATABASE` entry should be omitted in the parameter file; in the Tosca Structure.pre screen of Tosca Structure.gui, this is the case for the topology optimization, while for shape and bead optimization the surface with optimization displacements is always generated. In Tosca Structure.SMOOTH screen of Tosca Structure.gui, choose `Create Surface without optimization displacements` as the value of the `Task` field.  After the surface is generated, the data reduction can be performed; it is turned off by default. Both data reduction and the output in various formats are done in the same way as when processing the topology optimization results. |
