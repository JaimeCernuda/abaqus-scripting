These macros can be activated using the `INCLUDE` command in your parameter file. | | |   | Name of Macro | Description | Output Files | | --- | --- | --- | | report\_templates.mac | Standard report file for optimization results for any optimization type. Contains contour plot of optimization displacement (for bead and shape) and contour plot of material distribution (for topology and sizing) as well as plots of constraint and objective values (and other significant quantities if required). | `<jobname>_report.vtfx` | | smooth\_templates.mac | Standard smooth command for optimization results for any optimization type: Surface of result in vtfx-format | `default_bead_smooth.vtfx` | | stop\_1.mac | Stop condition: Variation of ctrl\_inp is smaller than 1% of start value or maximum optimization displacement is smaller than 1% of start displacement | no output, program stops | | stop\_2.mac | Stop condition: Variation of ctrl\_inp is smaller than 1% of start value | no output, program stops | | uf\_group\_onf.mac | Group information as `ONF` file | `GROUPS.onf` | | uf\_model\_onf.mac | Node and element information of the initial FE model in global Cartesian coordinates in `ONF` format | `MODEL_fem.onf` | | uf\_shape\_onf.mac | Shape optimization results in `ONF` format | `SHAPE_xxx.onf` | | uf\_topo\_onf.mac | Topology optimization results in `ONF` format | `TP_xxx.onf` | | uf\_bead\_onf.mac | Bead optimization results in `ONF` format | `BEAD_xxx.onf` | | uf\_sizing\_onf.mac | Sizing optimization results in `ONF` format | `SIZING_xxx.onf` | |
