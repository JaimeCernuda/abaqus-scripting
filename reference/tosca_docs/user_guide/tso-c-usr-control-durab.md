| |  |  | | --- | --- | | Durability Interface | | |  | | | |  | | --- | | Durability interface related topics are discussed within this section. | | |   Using the parameter `--life <life_solver_name>` the durability interface is specified. No damage calculation is carried out by default. The typical Tosca Structure call with a specific life-solver interface is:   ``` tosca --job <jobname> --solver <solvername> --life <lifesolvername> ```   Note, that durability can only be used with a Tosca Structure.durability license, contact Dassault Systèmes for more information. |
