First, the cyclic symmetry is enforced, and afterward the surface is modified to ensure plane symmetry in each segment. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | LINK\_SHAPE | |   | CLIENT / Applicable for | SHAPE\_CONTROLLER | SHAPE\_SENSITIVITY | | --- | --- | --- | | SURF\_CYCLIC\_PLANE\_SYM | OK | OK |  This link condition is a combination of cyclic rotational and planar symmetry. First, the cyclic symmetry is enforced, and afterward the surface is modified to ensure plane symmetry in each segment. The plane for each segment cuts the segment into two halves. The following parameters are required for the definition of the link condition:   ``` CLIENT           = SURF_CYCLIC_PLANE_SYM CLIENT_DIR       = <X_1>, <X_2>, <X_3> CS               = name_of_coord_system TOL              = tolerance_value ANGLE            = angle in degree CYCLIC_SYM_START = <X_1>, <X_2>, <X_3> ```   In comparison to the `SURF_CYCLIC_SYM` case, the `CYCLIC_SYM_START` point is really important here. As it defines the starting point of the partitioning process, this point directly influences the areas that are made plane symmetric. Its coordinates are given with reference to the global cartesian coordinate system.   |  | | --- | |  |  |  | | --- | |  |   The figure above shows the differences between the different `SURF_*_SYM` restrictions.
