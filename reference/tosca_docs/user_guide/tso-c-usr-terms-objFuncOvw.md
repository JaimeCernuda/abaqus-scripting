Remarks  * For controller-based shape optimization, the "reference value" has a special meaning and is very   important. See "Reference Stress" in the shape optimization section "Objective Function   for Controller-Based Shape Optimization." * For all other optimization approaches, the reference value and weight is only of limited importance.   A case for using weights in sensitivity-based optimization is when you use two different types of DRESPs   in the objective function and they might have very different value intervals. This is not recommended and   in most cases you have a better optimization setup using one type of DRESP in OBJ\_FUNC and   the others as constraints. |
