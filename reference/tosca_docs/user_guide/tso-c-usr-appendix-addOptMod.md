| |  |  | | --- | --- | | Additional Tosca Structure Optimization Modules | | |  | | | |  | | --- | | Tosca Structure offers modules for standard topology (Tosca Structure.topology), shape (Tosca Structure.shape), and bead (Tosca Structure.bead) optimization. Further functionalities for high-level optimization applications are available with the following modules:  This page discusses:   * Tosca Structure.durability * Tosca Structure.nonlinear * Tosca Structure.morph | | |   Tosca Structure.durability  * Shape optimization based on a durability analysis (see Shape Optimization Based on a Durability Analysis)  Tosca Structure.nonlinear  * Optimizations based on nonlinear results from the used solver   (independent to the optimization type) * Optimization of contact surfaces to homogenize the contact stress   for shape optimization * Shape optimization based upon a geometrically nonlinear analysis (see   Highly Nonlinear Shape Optimization) * Shape optimization using nonlinear materials (see Highly Nonlinear Shape Optimization) * Topology optimization based upon a geometrically nonlinear analysis * Topology optimization using nonlinear materials  Tosca Structure.morph  * Automatic generation of model variants and submission of analysis   runs for these models. |
