| |  |  | | --- | --- | | About Cluster Groups | | |  | | | |  | | --- | | For sensitivity-based topology optimization, elements can be clustered to have equal pseudo densities in certain areas during the optimization (`CHECK_TYPE = CLUSTER_GROUPS`). | | |   Define a cluster group as follows:   ``` DVCON_TOPO   ID_NAME    = DVCON_CLUSTER   EL_GROUP   = CLUSTER_1   EL_GROUP   = CLUSTER_2   EL_GROUP   = CLUSTER_3   EL_GROUP   = CLUSTER_4   ...   ...   EL_GROUP   = CLUSTER_143   EL_GROUP   = CLUSTER_144   CHECK_TYPE = CLUSTER_GROUPS END_ ```   Note: Elements within one referred element group have the same values for pseudo densities. But two different element groups have different values for pseudo densities.  Reference the `DVCON_TOPO` ID name in the `OPTIMIZE` command to activate this restriction:   ``` OPTIMIZE   ID_NAME = ...   ...   DVCON   = DVCON_CLUSTER   ... END_ ```   To give an example the following model is considered:   | Model | Displacements | Stresses | | --- | --- | --- | |  |  |  |   To obtain an extrudable profile as the optimization result cluster groups are utilized:   | Mesh | Clustering groups | | --- | --- | |  |  |   The corresponding optimized structures are shown in the following figures:   | Optimization without clustering | Optimization with clustering groups | | --- | --- | |  |  | |
