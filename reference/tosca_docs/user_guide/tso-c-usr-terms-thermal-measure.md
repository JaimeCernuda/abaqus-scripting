This page discusses:   * Analysis Types: Thermal Analysis * Remarks * Definition | | |   | Parameter Name | Formula | | --- | --- | | ENERGY\_THERMAL\_MEASURE | fgTTu−qTTgfg |   where fg is the defined external load, Tu the unknown field temperature field, q thermal reaction load at the boundary where the prescribed temperature is applied and Tg the prescribed temperature at the boundary.  Analysis Types: Thermal Analysis This is the total thermal energy stored in the system. It is a global measure that is used to define the conductivity of structures. Minimizing this response leads to the best conductivity in the structure. Because of the way it is implemented in SIMULIA Tosca Structure, there is no need to distinguish between external thermal loads or prescribed temperature conditions.  This response is easy to define and almost always results in stable optimizations with good convergence. This is analogous to energy\_stiffness\_measure in a structural optimization.
