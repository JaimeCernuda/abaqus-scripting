| |  |  | | --- | --- | | Defining a Shell Thickness Bound | | |  | | | |  | | --- | | Shell thicknesses can be controlled to vary between a lower or upper bound (`CHECK_TYPE = THICKNESS_BOUNDS`). For the definition of the thickness bounds, either an absolute or relative value for the upper and lower bound can be defined. In case of relative bounds a real number is specified for each bound, which is multiplied with the initial value for the shell thickness to get the absolute upper and lower bounds.  This task shows you how to:   * Define Thickness Bounds in Tosca Structure.gui * Parameter File | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | DVCON\_SIZING | |   Context:  Shell thicknesses can be controlled to vary between a lower or upper bound (`CHECK_TYPE = THICKNESS_BOUNDS`). For the definition of the thickness bounds, either an absolute or relative value for the upper and lower bound can be defined. In case of relative bounds a real number is specified for each bound, which is multiplied with the initial value for the shell thickness to get the absolute upper and lower bounds.  The parameter `MAGNITUDE` defines if the lower and upper bound are defined as absolute or relative values.    Define Thickness Bounds in Tosca Structure.gui 1. Choose Command > DVCON\_SIZING in Tosca Structure.pre    screen. 2. Apply an ID\_NAME and select the    element group that is to be frozen. If the element group is not already defined, it is required    to define it in advance using the `GROUP_DEF` command. 3. Choose Type = Thickness\_bounds and define a relative (REL)    or absolute (ABS) upper and lower value:  Parameter File The resulting command looks like: ``` DVCON_SIZING   ID_NAME     = dvcon_thickness_bounds   EL_GROUP    = my_group    CHECK_TYPE  = THICKNESS_BOUNDS   MAGNITUDE   = REL/ABS    LOWER_BOUND = …   UPPER_BOUND = … END_ ``` |
