This function depends on the results of the FE analysis. Therefore, the values of interest must be derived from the FE results to define an objective function and functional constraints. The results of the FE analysis (total displacement, energy, etc.) for determining the objective function and functional constraints are called ’design responses’. A single value from the design response must be specified for the definition of the objective function using the command `DRESP`(Design Response).  Objective Function Terms Tosca Structure.shape controller allows optimization on different stress hypotheses, strain formulations, and damage results. The most used equivalent stress is von Mises (`SIG_MISES`).
