| |  |  | | --- | --- | | Defining Frozen Areas | | |  | | | |  | | --- | | Sometimes it is required to maintain material in certain parts of the design area, such that they remain unchanged in the optimized model. Element groups describing these parts can be defined as frozen area.  This option is used to exclude the so-called frozen elements from being modified during the optimization, even though these elements are included in the design space. This is the case, for example, when the elements are used to fix the component and therefore should be preserved independently of their internal loads. The inclusion into the design space might be required, for example, to control the target volume. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | DVCON\_SIZING | |   1. Choose Command | DVCON\_SIZING in    Tosca Structure.pre    screen. 2. Apply an ID\_NAME and select the    element group that is to be frozen. If the element group is not already defined, it is required    to define it in advance using the `GROUP_DEF` command. 3. Choose Type = Frozen. |
