| |  |  | | --- | --- | | About Symmetry Conditions | | |  | | | |  | | --- | | Different symmetry conditions can be defined for an optimization in SIMULIA Tosca Structure. They can be used to obtain symmetrical results also for non-symmetrical meshes.
