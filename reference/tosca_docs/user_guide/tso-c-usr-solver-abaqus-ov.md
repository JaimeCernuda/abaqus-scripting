See also the flow diagram in Overview.  All FE input models (`.inp`) and FE results (`.odb, .fil or .sim`) are moved into their corresponding `SAVE` directory.  Abaqus must always be called in interactive mode within Tosca Structure. Thus, using Abaqus in background mode is not allowed.  It is highly recommended that you use the same main versions of Tosca and Abaqus. Versions of Abaqus later than 2025 are not supported by this release of Tosca. Earlier releases of Abaqus can be used with Tosca with the following restrictions:  * `SENS_CALC_MODE=SOLVER` is supported only if the main releases of   Abaqus and   Tosca match. It is highly recommended   that you also use the same Hot Fix version. * By default, `SENS_CALC_MODE=SOLVER` sets   `SOLVER_RUN_MODE=SIMULTANEOUS`, which offers better performance,   but does not store the `.odb` files of the simulation runs. In   order to save them during the optimization, define a SaveRule as explained in   Configurable Driver   commands. * Using MatrixFormats.SIM in sensitivity-based calculations with   `SENS_CALC_MODE=TOSCA` is supported only if the main releases of   Abaqus and Tosca match. It is highly recommended that you also use the same Hot Fix version.   If the versions do not match, MatrixFormats.FIL might work as a workaround, but   full functionality cannot be guaranteed. |
