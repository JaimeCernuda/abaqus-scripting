| |  |  | | --- | --- | | About Working with Tosca Structure | | |  | | | |  | | --- | | In this chapter, the general workflow with Tosca Structure is described.  Prior to starting Tosca Structure a FE model must exist of the part that needs to be optimized. The model must be analyzed at least once and the results checked. In Models for Optimization tips on model building for the required type of optimization are listed. How much the definition of the optimization problem can be simplified through entries made in the FE preprocessor is described in Postprocessing of Optimization Results for the relevant preprocessor.  It is recommended to control the whole optimization workflow using the classical Tosca Structure.gui. All steps of the optimization process (but not FE modeling and postprocessing) can be accessed from Tosca Structure.gui. Access to Tosca Structure from the command shell is described in Working with Tosca Structure in the Command Shell.   --- | | In this section:   * Working with the Graphical User Interface Tosca Structure.gui * Working with Tosca Structure in the Command Shell | | | |
