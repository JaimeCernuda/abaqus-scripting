| |  |  | | --- | --- | | Manufacturing Conditions and Geometrical Restrictions | | |  | | | |  | | --- | | For sizing with SIMULIA Tosca Structure, it is possible to define constraints (`DVCON_SIZING`) that have a direct influence on the individual design variables (`DV_SIZING`). This allows the manufacturing restrictions or geometrical design aspects to be taken into consideration in the sizing optimization.  The different restrictions are listed below:   * Frozen area   + Element fixing by     exclusion from the optimization group.   + Element fixing by     freezing elements (`CHECK_TYPE = FROZEN`). * Shell thickness control   + Upper and lower bounds     for shell thicknesses (`CHECK_TYPE = THICKNESS_BOUNDS`).   + Clustering of element     areas with the same shell thickness (`CHECK_TYPE = CLUSTER`) * Symmetry control   + Area linking (     `LINK_SIZING`)   + Symmetry restriction (     `LINK_SIZING`) * Member size control   + Minimum cluster width     control (`CHECK_TYPE = MIN_CLUSTER_WIDTH`)   + Maximum member size     control (`CHECK_TYPE = MAX_MEMBER`)   --- | | In this section:   * Defining Frozen Areas * Defining a Shell Thickness Bound * Defining Cluster Groups * Defining Width Control (Minimum Cluster Width) * Defining Symmetry Conditions * Tips on Defining Restrictions | | | |
