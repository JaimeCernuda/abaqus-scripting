| |  |  | | --- | --- | | Optimization Modules | | |  | | | |  | | --- | | The optimization loop runs in batch mode. After preprocessing, the solver, the `RES_TO_VTM` module, the optimization module (`TOSCA_OPT`), and `FEM_MODIF` module are started successively.  This page discusses:   * FEM\_MODIF * RES\_TO\_VTM * TOSCA\_OPT | | |   FEM\_MODIF The `FEM_MODIF` module generates the modified analysis model by combining the initial model with the instructions from `TOSCA_OPT`. The optimization database is updated in each iteration.  RES\_TO\_VTM The `RES_TO_VTM` module loads the results generated by the solver into the `VTM` (Virtual SIMULIA Tosca Structure Memory) database file.  TOSCA\_OPT The optimization module requires not only the result file from the previous calculation in `ONF` format, but also the loads as well as the required model and control information found in the optimization database. The optimization module is responsible for specifying the model modifications in `ONF` format. The optimization loop is completed when the optimization target is achieved or when a stop condition (for example, the maximum number of iterations) is fulfilled. |
