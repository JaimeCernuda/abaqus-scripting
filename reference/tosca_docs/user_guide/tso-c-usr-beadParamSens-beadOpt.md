# Optimizer Parameters

|  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Optimizer Parameters | | |  | | | |  | | --- | | The mathematical optimizer CSA is used to determine the new nodal positions.  This page discusses:   * Move Limit (NODAL\_MOVE) * CSA Asymptote Update (NODAL\_UPDATE) * Sensitivity Calculation (ONLY\_DES\_NODES) | | |   The following parameters might be set:  Move Limit (NODAL\_MOVE) A move limit adjusts the change in the nodal coordinates per iteration. The relative move limit of the node-based optimization displacement for each iteration is set by the optimization parameter.   ``` NODAL_MOVE = <real_value> ```   Default value is `NODAL_MOVE = 0.1`. The value must be between 0.0 and 1.0. The absolute move limit is the maximum possible optimization displacement times `NODAL_MOVE`.  CSA Asymptote Update (NODAL\_UPDATE) The optimization parameter `NODAL_UPDATE` can be used to control the update of asymptotes in CSA. The value of nodal update might be conservative (`NODAL_UPDATE = CONS`) which is default or normal (`NODAL_UPDATE = NORM`).  |  | | --- | | Important: Only advanced users should change this parameter. |  Sensitivity Calculation (ONLY\_DES\_NODES) Tosca Structure.bead calculates sensitivities only for design nodes:   ``` ONLY_DES_NODES = YES ```   In the opposite case (`ONLY_DES_NODES = NO`), Tosca Structure is forced to calculate sensitivities for `ALL_NODES`, which is not recommended.  |  | | --- | | Important: Only advanced users should change this parameter. | |
