| |  |  | | --- | --- | | About Overhang Restrictions | | |  | | | |  | | --- | | Overhang restrictions can be used to prevent overhangs in the model that exceed a critical angle. | | |   For some additive manufacturing processes it is beneficial if the model does not contain overhangs with high overhang angles, as shown in the picture below:   |  | | --- | |  |   Generally, overhangs with an angle greater than 45° are difficult to print and usually require the addition of support structures to be manufacturable. Support structures increase production time as well as material waste and require additional postprocessing. It is advisable to prevent overhangs in the model wherever possible to reduce manufacturing costs and time. In Tosca Structure this can be done by including the overhang manufacturing constraint directly in the topology optimization.  |  | | --- | | Tip: Usually, it is better to carry out the optimization without manufacturing restrictions first, and then to perform a second optimization with manufacturing restrictions. | |
