# Tips on Defining Restrictions

| |  |  | | --- | --- | | Tips on Defining Restrictions | | |  | | | |  | | --- | | * The element group for a certain restriction should be a subset of the   design element group. If this is not the case, SIMULIA Tosca Structure   stops the optimization. * The `DVCON_SIZING` `ID_NAME` must be referenced in the `OPTIMIZE`   command to activate the restriction. In Tosca Structure.gui,   the `DVCON_SIZING` entry must be activated in the `OPTIMIZE` mask.    ```   OPTIMIZE     ...     DVCON = name_of_dvcon_entry     ...   END_   ``` * Each geometrical restriction reduces the possibilities of the solution.   Thus, it is required to add only the restrictions required for solving   the problem. It is still possible to find a solution if too many restrictions   are defined, but the result is most probably suboptimal compared   to the optimal design. Therefore, the first step for the user is to perform   an optimization without restrictions to obtain knowledge about the restrictions   required for the specific problem. * It is impossible to combine all manufacturing constraints at random.   The user must be careful when combining conflicting restrictions. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | DVCON\_SIZING | | |
