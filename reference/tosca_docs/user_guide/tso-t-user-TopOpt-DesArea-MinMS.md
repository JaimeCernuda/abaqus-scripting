| |  |  | | --- | --- | | Defining a Minimum Truss Thickness (Minimum Member Size) | | |  | | | |  | | --- | | Thin trusses in the resulting structure are often undesirable, depending on the manufacturing process. You can define a minimum truss thickness to avoid the creation of small substructures in the final result. This task shows you how to:   * Define a Minimum Member Size Restriction in Tosca Structure.gui | | ---  Before you begin:   * It is impossible to ensure the accurate minimum thickness of the structures.   For some cases, the results contain parts with a diameter smaller than   the defined minimum member size. * The CPU-time for the calculation increases quadratically with the   minimum member size. To save calculation time, the restriction should   only be defined in the areas of the model where thin parts should be   avoided. To identify these areas, the first step is to perform an optimization   without restrictions. | | |  | | --- | | See Also | | About Member Size Control |  |  | | --- | |  | | In Other Guides | | DVCON\_TOPO | |       Define a Minimum Member Size Restriction in Tosca Structure.gui 1.
