| |  |  | | --- | --- | | Topology Optimization | | |  | | | |  | | --- | | At the beginning of the conventional design process, the design engineer often defines the shape and the topology of new components using the experience and the results gained from existing designs. This results in an evolution process that might lead to an optimum design after several manual design iterations and a long process development time. Nowadays, it is required to shorten the development process of new components, and at the same time develop fundamentally new designs. Therefore, optimization tools are required for replacing the natural evolution process by an automatic procedure. With SIMULIA Tosca Structure, it is possible to carry out topology and shape optimization in the existing CAE environment.
