| |  |  | | --- | --- | | Example: Minimizing Stresses in Objective Function | | |  | | | |  | | --- | | The task for this example is to minimize the maximum von Mises stress.  Note: Each design response definition of type `SIG_SENS_MISES` might only be applied once in either the objective or constraint definition. If stresses should be considered both in constraint or the objective (or several stresses should be combined) for each use one separate design response must be defined.  This task shows you how to:   * Define the von Mises Stress in Tosca Structure.gui * Tosca Structure   Parameter File | | |   Define the von Mises Stress in Tosca Structure.gui 1. Choose Command > DRESP. The DRESP menu appears. 2. Define the SIG\_SENS\_MISES    as design response in as shown in the following figure:  Tosca Structure Parameter File The design response for stresses for topology optimization is defined as follows: ``` DRESP   ID_NAME   = TOPO_STRESS_DESIGN_ELEMENTS   TYPE      = SIG_SENS_MISES   DEF_TYPE  = SYSTEM   EL_GROUP  = <element_group>   LC_SET    = <load cases> END_ ```   Response for stresses is applied in the objective function as the following:   ``` OBJ_FUNC   ID_NAME  = OBJ_FUNCTION_ID   DRESP    = SIG_SENS_MISES,<weight_fact_1>, <ref_stress_1>   ...........   TARGET = MIN END_ ``` |
