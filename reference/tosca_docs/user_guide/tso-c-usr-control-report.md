| |  |  | | --- | --- | | Tosca Structure.REPORT Run | | |  | | | |  | | --- | | Tosca Structure.REPORT related topics are discussed.   * Configuring Default Tosca Structure.REPORT Run | | |   Tosca Structure.REPORT is run automatically at the end of your optimization, but you can also run it manually after optimization. Use command-line parameter `post --report` to run the Tosca Structure.REPORT.   ``` tosca post -j <jobDir> --report [vtfx|sim] ```   The above command runs only the Tosca Structure.REPORT command requiring that an optimization job has successfully completed before this call. The resulting files are generated in the subdirectory `TOSCA_POST` of the job directory. Each time Tosca Structure.REPORT is called a new post-file is created (`<jobname>_ report(n).par`). Use overwrite (`--ow`) so that the post-file (`<jobname>_post.par`) is overwritten for each call.   |  | | --- | | Important:  Using `--ow` together with `--report` does not overwrite the job directory. |   Configuring Default Tosca Structure.REPORT Run In case no `REPORT` command is defined in the input files, Tosca Structure looks for the default `REPORT` macros that are found in the installation directory `<tosca>` in the directory macro:   * `<tosca>/macros/report_templates.mac` |
