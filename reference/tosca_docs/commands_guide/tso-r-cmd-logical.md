The direct definition of logical variables (`DEF_TYPE = BASE`) can be done by a comparison of two numerical variables or one numerical variable    and a fixed value. The numerical variables must already be defined. 2. Definitions relating to Boolean operations (`DEF_TYPE = BOOLEAN`) must include at least two already defined logical variables that are referenced.    A maximum of up to four logical variables might be combined.  Examples  ``` LOGICAL   ID_NAME  = my_logical_01   DEF_TYPE = BASE   OPER     = LT   VAR_A    = volume_part_a   FIX_VAL  = 100.0 END_ ``` |
