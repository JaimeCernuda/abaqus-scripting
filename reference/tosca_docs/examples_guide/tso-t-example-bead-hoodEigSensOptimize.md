| |  |  | | --- | --- | | Optimizing the Eigenfrequency of the Hood Model | | |  | | | |  | | --- | | In this example, you follow the workflow for a standard bead optimization task with eigenfrequency:  1. Define input data and design variables. 2. Define the Objective Function (DRESP, OBJ\_FUNC). 3. Activate the Boundary Conditions (DVCON\_BEAD) 4. Define the OPTIMIZE command. 5. (optional) Set additional settings (OPT\_PARAM). | | |   1. Define input data and Design Variables. ```    FEM_INPUT      ID_NAME      = INPUT_FILE      FILE         = hood_eig_sens.inp    END_     DV_BEAD      ID_NAME      = DESIGN_VARIABLES      ND_GROUP     = ALL_NODES    END_    ``` 2. For most applications, you want to avoid that the modes switch during optimization.    The easiest way to do this is to define a new Design Response (DRESP) based    on the Kreisselmeier-Steinhauser formulation. Here we assume that the first    mode never gets larger as the 5th mode. To define the Objective Function (OBJ\_FUNC)    for the first five eigenfrequency, do the following:    1. Create a Design Response (DRESP): ```       DRESP         ID_NAME      = dresp_kreis         TYPE         = DYN_FREQ_KREISSEL         DEF_TYPE     = SYSTEM         LC_SET       = ALL,ALL,1-5       END_       ```    2. Reference the Design Response in the Objective Function (OBJ\_FUNC) and maximize it: ```       OBJ_FUNC         ID_NAME      = maximize_eigenfrequency         DRESP        = dresp_kreis         TARGET       = MAX       END_       ```    3. Define the DVCON\_BEAD for the growth and shrink limits, respectively. ```       DVCON_BEAD         ID_NAME      = dvcon_max_disp         CHECK_BC     = NO         ND_GROUP     = ALL_NODES         CHECK_GROW   = 0.5         CHECK_SHRINK = 0.5       END_       ``` 3. Reference the Design Variables, Objective Function, and Constraints as well as DV\_CONs    in the OPTIMIZE command: ```    OPTIMIZE      ID_NAME       = BEAD_OPTIMIZATION      DV            = DESIGN_VARIABLES      OBJ_FUNC      = maximize_eigenfrequency      DVCON         = dvcon_max_disp      STRATEGY      = BEAD_SENSITIVITY    END_    ``` 4. (optional) Define the filter radius in the OPT\_PARAM command as well as the maximum number of iterations. ```    OPT_PARAM      ID_NAME            = OPT_PARAMS      OPTIMIZE           = BEAD_OPTIMIZATION      BEAD_FILTER_RADIUS = 1.5    END     STOP      ID_NAME       = global_stop      ITER_MAX      = 20    END_    ```      If you do not define the bead width, the system automatically determines a bead width.  The optimization result looks as follows:   The result is a final eigenvalue of 0.3558 (15%), which might even become higher if you let the optimization continue for more than 20 iterations. |
