| |  |  | | --- | --- | | Optimizing the Eigenfrequency of the Hood Model | | |  | | | |  | | --- | | In this example, you follow the workflow for a standard bead optimization task with eigenfrequency:  1. Define input data and design variables. 2. Define the Constraint of the optimization task (DRESP, CONSTRAINT). 3. Define the Objective Function (DRESP, OBJ\_FUNC). 4. Activate the Boundary Conditions (DVCON\_BEAD) 5. Define the OPTIMIZE command. 6. (optional) Set additional settings (OPT\_PARAM). | | |   1. Define input data and Design Variables. ```    FEM_INPUT      ID_NAME    = INPUT_FILE      FILE       = hood_eig.inp    END_     DV_BEAD      ID_NAME    = DESIGN_VARIABLES      ND_GROUP   = ALL_NODES    END_    ``` 2. Create a constraint for the bead height.    1. Define a Design Response (DRESP): ```       DRESP         ID_NAME    = dresp_bead_height         DEF_TYPE   = SYSTEM         ND_GROUP   = ALL_NODES         TYPE       = BEAD_HEIGHT         GROUP_OPER = MAX       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT): ```       CONSTRAINT         ID_NAME    = bead_height_constraint         DRESP      = dresp_bead_height         MAGNITUDE  = ABS         EQ_VALUE   = 0.5       END_       ``` 3. To define the Objective Function (OBJ\_FUNC) for the first eigenfrequency, do the following:    1. Create a Design Response (DRESP): ```       DRESP         ID_NAME    = dresp_eigenfrequency         DEF_TYPE   = SYSTEM         TYPE       = DYN_FREQ         LC_SET     = MODAL,ALL,1       END_       ```    2. Reference the Design Response in the Objective Function (OBJ\_FUNC) and maximize it: ```       OBJ_FUNC         ID_NAME    = maximize_eigenfrequency         DRESP      = dresp_eigenfrequency         TARGET     = MAX       END_       ``` 4. Reference the Design Variables, Objective Function, and Constraints as well as DV\_CONs    in the OPTIMIZE command: ```    OPTIMIZE      ID_NAME    = BEAD_OPTIMIZATION      DV         = DESIGN_VARIABLES      OBJ_FUNC   = maximize_eigenfrequency      CONSTRAINT = bead_height_constraint      STRATEGY   = BEAD_CONTROLLER    END_    ``` 5. (optional) Define the bead width and scale in the OPT\_PARAM command. ```    OPT_PARAM      ID_NAME    = OPT_PARAMS      OPTIMIZE   = BEAD_OPTIMIZATION      BEAD_WIDTH = 3.0      SCALE      = 1.0    END    ```      If you do not define the bead width, the system automatically determines a bead width.  The optimization result looks as follows:   The first eigenvalue is only slightly higher 0.3140 (1.3%) after the controller-based optimization. The eigenvalue does NOT become higher if you change the number of iterations. |
