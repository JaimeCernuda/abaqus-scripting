| |  |  | | --- | --- | | Optimizing the Shaft Model | | |  | | | |  | | --- | | This example shows how the rotational symmetry is maintained during the optimization of rotary symmetrical components. This task shows you how to:   * Define the Node Groups * Define the Link Conditions * Assign the Link Conditions | | |   Define the Node Groups Using the command GROUP\_AUTO\_DEF, nodes can be automatically searched for, starting with a parent group of nodes.  1. To define the parent node group, create a Group Definition (GROUP\_DEF) that contains all nodes in the length of    the shaft: ```    GROUP_DEF     ID_NAME = parent     TYPE    = NODE     FORMAT  = LIST     LIST_BEGIN     16, 177-1717:140    END_    ``` 2. To find all nodes in a circumferential direction (360° of the    global cylindrical coordinate system CS\_1), use the GROUP\_AUTO\_DEF    command: ```    GROUP_AUTO_DEF     ND_GROUP    = parent     CS          = CS_1     TOL         = 0.1,0.1,0.1     SEARCH_TYPE = CONTINUOUS     SEARCH_DIR  = +2     SEARCH_LEN  = 360    END_    ```      With this command, you also define new groups with the name    of the parent group as the name prefix. For every node of the parent group, a new    group is defined with indices (parent\_1, paren\_2,.., parent\_13). 3. (optional) To check if the processing was done correctly, you can check the TOSCA.OUT file: ```     --------------------------------------------------------------------------    | Data output of GROUP_AUTO_DEF command                                    |      --------------------------------------------------------------------------      GROUP_AUTO_DEF (temporary data) :       ND_GROUP      : PARENT       CS            : CYL       TOL           :  0.100    ,  0.100    ,  0.100       SEARCH_TYPE   : CONTINUOUS       SEARCH_DIR    : +2   (positive second coordinate of CS)       SEARCH_LEN    :   360.     Remark :       Only the selected nodes will be considered (see SELECT command).          NODE_GROUP NAME: PARENT_1     int. No.:       10      Number of Nodes:       30   Min_No.:        287   Max_No.:        345      287  288  291  293  295  297  299  301  303  305  307  309  311      313  315  317  319  321  323  325  327  329  331  333  335  337      339  341  343  345     -----------------------------------------------------------     .....    ```  Define the Link Conditions To maintain the rotational symmetry, each node of a link group (parent\_\*) must have the same absolute displacement (in the cylindrical coordinate system CS\_1) as the main nodes of the link group. The main node is determined by the 'MAX'-criterion (that is, the node with the largest stress is the main node).  Define a link condition (LINK\_SHAPE) as follows: ``` LINK_SHAPE  ID_NAME = link_length  MAIN  = MAX  CLIENT  = LENGTH  CS      = CS_1  TOL     = 0.1,0.1,0.1 END_ ```  Assign the Link Conditions The link conditions must be assigned to the individual node groups using the command DVCON\_SHAPE. As the definition of node groups occurs automatically and a lot of node groups are generated in large models, SIMULIA Tosca Structure also has the functionality to provide automatic generation. The command DVCON\_AUTO\_SHAPE allows the automatic definition of DVCON\_SHAPE entries for all groups that have a certain name prefix (in this case parent\_).  1. To automatically define DVCON\_SHAPE entries, create a Design Variable Constraint (DVCON\_AUTO\_SHAPE): ```    DVCON_AUTO_SHAPE     ID_NAME         = dvcon_link_*     ND_GROUP_FAMILY = parent_*     CHECK_LINK      = link_length    END_    ``` 2. (optional) To check if the processing was done correctly, you can check the TOSCA.OUT file: ```     --------------------------------------------------------------------------    | Information about the command DVCON_AUTO_SHAPE                           |     --------------------------------------------------------------------------     In the following some DVCON_SHAPE commands will be submitted automatically.     The syntax of these commands will be as follows:       DVCON_SHAPE         ID_NAME    = DVCON_LINK_*         ND_GROUP   = PARENT_*         CHECK_LINK = LINK_LENGTH       END_     The strings * result from the complements to     the full names of the existing node groups.     --------------------------------------------------------------------------    | Data output of DVCON_SHAPE entries                                       |     --------------------------------------------------------------------------     DVCON_SHAPE (database extraction):       ID_NAME            : DVCON_LINK_1       ND_GROUP           : PARENT_1       CHECK_ELGR_BLOCKING: BOTH       CHECK_LINK         : LINK_LENGTH       TOLERANCE          :  0.994666E-02     --------------------------------------------------------------------------    | Data output of DVCON_SHAPE entries                                       |     --------------------------------------------------------------------------     DVCON_SHAPE (database extraction):       ID_NAME            : DVCON_LINK_2       ND_GROUP           : PARENT_2       CHECK_ELGR_BLOCKING: BOTH       CHECK_LINK         : LINK_LENGTH       TOLERANCE          :  0.994666E-02     --------------------------------------------------------------------------    | Data output of DVCON_SHAPE entries                                       |     --------------------------------------------------------------------------     DVCON_SHAPE (database extraction):       ID_NAME            : DVCON_LINK_3       ND_GROUP           : PARENT_3       CHECK_ELGR_BLOCKING: BOTH       CHECK_LINK         : LINK_LENGTH       TOLERANCE          :  0.994666E-02     .....    ``` 3.
