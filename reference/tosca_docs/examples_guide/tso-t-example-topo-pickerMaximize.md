Filter(min) value defines the       limit for the soft elements (that is, elements with a relative material value lower       than Filter(min)are not shown).    2. In Tosca Structure.REPORT,       select View Report to visualize the VTFX file with the optimization result. 3. To further process the result, you have 2 options:    1. Define a smooth command int the parameter file and start a new optimization run.    2.
