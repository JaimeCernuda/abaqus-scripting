| |  |  | | --- | --- | | About the Temperature Loading Example | | |  | | | |  | | --- | | The present example shows that the topology optimization by Tosca Structure is also able to consider the temperature loading. This example can be done using the CAE solvers Abaqus and MSC Nastran®. This page discusses:   * About the Model * Procedure Summary: | | |   About the Model The model has three load cases:  a) Load case 1 is combined of a static external force and a constant temperature loading. b) Load case 2 consists strictly of external static forces. c) Load case 3 consists strictly of a constant temperature loading.  Procedure Summary: |  |  | | --- | --- | | Model: | temperature.ext | | Design Area: | All elements | | Objective Approach 1: | Maximize stiffness (minimize compliance) | | Objective Approach 2: | Minimize the absolute displacement in the y-axis direction of the load introduction nodes | | Constraint: | Relative volume of 40 % (less or equal constraint) | | Settings Approach 1: | AUTO\_FROZEN is set to OFF | | Settings Approach 2: | AUTO\_FROZEN is set to LOAD | |
