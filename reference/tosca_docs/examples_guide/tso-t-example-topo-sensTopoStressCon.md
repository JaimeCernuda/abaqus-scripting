To define the stress constraint, do the following:    1. Create a Design Response (DRESP) as follows: ```       DRESP         ID_NAME  = TOPO_STRESS_DESIGN_ELEMENTS         TYPE     = SIG_SENS_MISES         DEF_TYPE = SYSTEM         EL_GROUP = DESIGN_AREA       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT): ```       CONSTRAINT         ID_NAME   = CON_STRESS         MAGNITUDE = ABS         LE_VALUE  = 70000.         DRESP     = TOPO_STRESS_DESIGN_ELEMENTS       END_       ``` 2. To define the Objective Function, do the following:    1. Create a Design Response (DRESP) as follows: ```       DRESP         ID_NAME    = DRESP_VOL_TOPO         TYPE       = VOLUME         DEF_TYPE   = SYSTEM         GROUP_OPER = Sum         EL_GROUP   = DESIGN_AREA       END_       ```    2. Reference the Design Response in the Objective Function (OBJ\_FUNC): ```       OBJ_FUNC         ID_NAME = MY_OBJ_FUNC         TARGET  = MIN         DRESP   = DRESP_VOL_TOPO       END_       ```  The result looks as follows: |
