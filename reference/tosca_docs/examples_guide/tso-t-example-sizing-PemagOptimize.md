Define the Design Area. 2. Define the Objective Function. 3. Define the volume constraint. 4. Set the Optimization Task. | | |   1. Define the Design Area (DV\_SIZING): ```    DV_SIZING      ID_NAME  = Abaqus_Contact_Sizing_MPC_DESIGN_AREA_      EL_GROUP = my_elem_group    END_    ``` 2. To define the Objective Function, do the following:    1. Define a Design Response (DRESP) for the plastic strain magnitude (PEMAG) of the plate. ```       DRESP         ID_NAME    = PEMAG         LIST       = NO_LIST         DEF_TYPE   = SYSTEM         TYPE       = PEMAG         EL_GROUP   = beam-1_pemag_set         GROUP_OPER = SUM       END_       ```    2. Reference the Design Response in the Objective Function       (OBJ\_FUNC) and set the TARGET to MIN: ```       OBJ_FUNC         ID_NAME = MIN_PEMAG         DRESP   = PEMAG, 1.         TARGET  = MIN       END_       ``` 3. To define the volume constraint, do the following:    1. Define a Design Response (DRESP) that contains the sum of the       total volume of the optimization group: ```       DRESP         ID_NAME    = VOL         LIST       = NO_LIST         DEF_TYPE   = SYSTEM         TYPE       = VOLUME         EL_GROUP   = my_elem_group         GROUP_OPER = SUM       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT)       and restrict it to 90% of initial volume: ```       CONSTRAINT         ID_NAME   = VOLUMECONST         DRESP     = VOL         MAGNITUDE = REL         LE_VALUE  = 1.0       END_       ``` 4. To define the volume constraint, do the following:    1. Define the thickness bounds of the shells: ```       DVCON_SIZING         ID_NAME     = DVC_BOUNDS         EL_GROUP    = _PickedSet32         CHECK_TYPE  = THICKNESS_BOUNDS         MAGNITUDE   = REL         LOWER_BOUND = 0.7         UPPER_BOUND = 1.5       END_       ```    2. Define a symmetry constraint: ```       LINK_SIZING         ID_NAME = PLANE_SYMMETRY         TYPE    = PLANE_SYM, AXIS_1         CS      = CS_0       END_        DVCON_SIZING         ID_NAME    = DVC_SYM         EL_GROUP   = my_elem_group         CHECK_TYPE = LINK_SIZING         CHECK_LINK = PLANE_SYMMETRY       END_       ```    3. Define the minimum width of sheet patches: ```       DVCON_SIZING         ID_NAME    = DVC_WIDTH         EL_GROUP   = my_elem_group         CHECK_TYPE = MIN_CLUSTER_WIDTH         WIDTH      = 0.02       END_       ``` 5. Set up the optimization.    1. Reference the Design Variables, Objective Function, and       constraints in the OPTIMIZE command: ```       OPTIMIZE         ID_NAME    = Abaqus_Contact_Sizing_MPC         DV         = Abaqus_Contact_Sizing_MPC_DESIGN_AREA_         OBJ_FUNC   = MIN_VOL         DVCON      = DVC_BOUNDS         DVCON      = DVC_SYM         DVCON      = DVC_WIDTH         CONSTRAINT = PEMAG_CONST         STRATEGY   = SIZING_SENSITIVITY       END_       ``` 6. 1.
