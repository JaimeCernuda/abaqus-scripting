| |  |  | | --- | --- | | Tracking the Modes in Eigenfrequency Optimization | | |  | | | |  | | --- | | The present example shows that the topology optimization by Tosca Structure is also capable of performing mode tracking on dynamic frequency analysis. The setup compared to a standard eigenfrequency analysis is the same. Except for the use of the mode tracking option, causing the optimizer to maintain the initial mode order even thought mode switching occurs. | | |  | | --- | | See Also | | About Checking the Quality of the Optimization Result | |   1. Define the design space by excluding the frozen part:    1. To get the design space, subtract the frozen group from all elements: ```       GROUP_DEF         ID_NAME 	= DESIGN_SPACE         TYPE    	= ELEM         FORMAT  	= LIST_SUBTRACT_GROUP         LIST_BEGIN         ALL_ELEMENTS, FROZEN       END_       ```    2. To set the design space as design variables: ```       DV_TOPO         ID_NAME        = MY_DV_TOPO         EL_GROUP       = DESIGN_SPACE       END_       ``` 2. Define the objective function (minimize volume):    1. Define a design response (DRESP) of type volume: ```       DRESP         ID_NAME        = DRESP_VOL         DEF_TYPE       = SYSTEM         TYPE           = VOLUME         EL_GROUP       = DESIGN_SPACE       END_       ```    2. Define the objective function (OBJ\_FUNC) and reference the design response: ```       OBJ_FUNC         ID_NAME        = MY_OBJ_FUNC         TARGET         = MIN         DRESP          = DRESP_VOL       END_       ``` 3. Define the constraint that restricts the second eigenfrequency:    1. Define a design response (DRESP) of type DYN\_FREQ for the second eigenfrequency: ```       DRESP         ID_NAME        = DRESP_FREQX         DEF_TYPE       = SYSTEM         TYPE           = DYN_FREQ         LC_SET         = MODAL,ALL,2       END_       ```    2. Define a greater equal constraint (CONSTRAINT) that references the design response and constraints its value to a minimum value relative to the original frequency: ```       CONSTRAINT         ID_NAME        = MY_CONSTRAINT         MAGNITUDE      = REL         DRESP          = DRESP_FREQ2         GE_VALUE       = 1.78       END_       ``` 4. Define the mode tracking settings (MODETRACKING, MODETRACK\_REFERENCE, MODENUMBERS) in the optimization parameter block (OPT\_PARAM) as follows: ```    OPT_PARAM      ID_NAME              = MY_PARAMETERS      OPTIMIZE             = MY_OPTIMIZATION_TASK      MODETRACKING         = ON      MODETRACK_REFERENCE  = INITIAL      MODENUMBERS          = 10    END_    ```  The result looks as follows:    In the figure above, the left side shows the result without mode tracking. The right side keeps the modes tracked, which results in a better solution.  The tracked modes can be monitored in the TOSCA.OUT file of the optimization with mode tracking.
