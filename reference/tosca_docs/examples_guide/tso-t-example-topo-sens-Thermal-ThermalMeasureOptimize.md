| |  |  | | --- | --- | | Minimizing Energy Thermal Measure and Energy Stiffness Measure of the CPU Cooler Example | | |  | | | |  | | --- | | Shows how to set up a static-thermal optimization for a CPU cooler with an energy thermal measure as objective. | | |  | | --- | | See Also | | About Checking the Quality of the Optimization Result | |   1. Define input data and Design Variables: ```    FEM_INPUT      ID_NAME  = MY_INPUT_FILES      FILE     = topo_thermal_cpu_thmeasure_thermal.inp      FILE     = topo_thermal_cpu_thmeasure_static.inp    END_     DV_TOPO      ID_NAME  = MY_DV_TOPO      EL_GROUP = ALL_ELEMENTS    END_    ``` 2. Define additional groups for left and right side elements: ```    GROUP_DEF      ID_NAME = right_elements      TYPE    = ELEM      FORMAT  = LIST      LIST_BEGIN    12001, ...    END_     GROUP_DEF      ID_NAME = left_elements      TYPE    = ELEM      FORMAT  = LIST      LIST_BEGIN    11801, ...    END_    ``` 3. To use the energy thermal measure and energy stiffness measure in the objective, define a Design Response (DRESP) as follows: ```    DRESP      ID_NAME        = ENERGY_THERMAL_MEASURE_DRESP      DEF_TYPE       = SYSTEM      TYPE           = ENERGY_THERMAL_MEASURE      EL_GROUP       = ALL_ELEMENTS      LC_SET         = ALL, 1,,    END_     DRESP      ID_NAME        = ENERGY_STIFF_MEASURE_DRESP      DEF_TYPE       = SYSTEM      TYPE           = ENERGY_STIFF_MEASURE      EL_GROUP       = ALL_ELEMENTS      LC_SET         = ALL, 10001,,    END_    ``` 4. Define the Objective Function (OBJ\_FUNC) as follows: The weighting for energy stiffness measure is required to have    both design responses in a similar magnitude      ```    OBJ_FUNC      ID_NAME        = ENERGY_THERMAL_MEASURE_OBJ_FUNC      TARGET         = MIN      DRESP          = ENERGY_THERMAL_MEASURE_DRESP      DRESP          = ENERGY_STIFF_MEASURE_DRESP, 3e7    END_    ``` 5. Create a constraint for the volume.    1. Define a Design Response with the volume (DRESP): ```       DRESP         ID_NAME        = VOLUME_DRESP         TYPE           = VOLUME         DEF_TYPE       = SYSTEM         GROUP_OPER     = Sum         EL_GROUP       = ALL_ELEMENTS       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT) and constrain it to a maximum of 40%: ```       CONSTRAINT         ID_NAME        = VOLUME_CONSTRAINT         MAGNITUDE      = REL         DRESP          = VOLUME_DRESP         LE_VALUE       = 0.4       END_       ``` 6. Define the casting, stamp, symmetry and frozen DVCONs: ```    LINK_TOPO      ID_NAME        = MY_LINK_TOPO      CS             = CS_0      TYPE           = PLANE_SYM, AXIS_1    END_     DVCON_TOPO      ID_NAME        = SYMMETRY      CHECK_TYPE     = LINK_TOPO      EL_GROUP       = ALL_ELEMENTS      CHECK_LINK     = MY_LINK_TOPO    END_     DVCON_TOPO      ID_NAME        = CASTING1      MID_PLANE      = NONE      CHECK_GROUP    = ALL_ELEMENTS      PULL_DIR       = -2, 0, 1.78571      CHECK_TYPE     = CAST      EL_GROUP       = left_elements    END_     DVCON_TOPO      ID_NAME        = CASTING3      MID_PLANE      = NONE      CHECK_GROUP    = ALL_ELEMENTS      PULL_DIR       = 2, 0, 1.78571      CHECK_TYPE     = CAST      EL_GROUP       = right_elements    END_     DVCON_TOPO      ID_NAME        = CASTING2      MID_PLANE      = STAMP      CHECK_GROUP    = ALL_ELEMENTS      PULL_DIR       = 0, 1, 0      CHECK_TYPE     = CAST      EL_GROUP       = ALL_ELEMENTS    END_     DVCON_TOPO      ID_NAME        = DVCON_TOPO_Frozen      CHECK_TYPE     = FROZEN      EL_GROUP       = FROZEN_ELEMENTS    END_    ``` 7. Reference the Objective Function, Design Variables and Constraint as well as DVCON in the OPTIMIZE command: ```    OPTIMIZE      ID_NAME        = MY_OPTIMIZATION_TASK      OBJ_FUNC       = ENERGY_THERMAL_MEASURE_OBJ_FUNC      DV             = MY_DV_TOPO      CONSTRAINT     = VOLUME_CONSTRAINT      STRATEGY       = TOPO_SENSITIVITY      DVCON          = CASTING1      DVCON          = CASTING2      DVCON          = CASTING3      DVCON          = DVCON_TOPO_Frozen      DVCON          = SYMMETRY    END_     OPT_PARAM      ID_NAME             = MY_PARAMETERS      OPTIMIZE            = MY_OPTIMIZATION_TASK      TOPO_FILTER_RADIUS  = 5    END_    ```  The optimization result looks as follows: |
