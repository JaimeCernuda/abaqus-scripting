| |  |  | | --- | --- | | Optimizing the Clip Model | | |  | | | |  | | --- | | This example illustrates a plastic clip that is used to fix a variety of objects. | | |   1. Define the 3 coordinate systems as follows:    1. Define the coordinate system (CS\_DEF) in the center of the clip: ```       CS_DEF        ID_NAME      = 1        CS_TYPE      = RECTANGULAR        DEF_TYPE     = LOCAL        CS_REF       = CS_0        ORIGIN_123   = 0,0,0        ROTATION_321 = 45,0,0       END_       ```    2. Define the cylindrical coordinate system (CS\_DEF) in the tip of the left clip: ```       CS_DEF        ID_NAME    = CS_CYL_LEFT        CS_TYPE    = CYLINDRICAL        DEF_TYPE   = LOCAL        CS_REF     = 1        ORIGIN_123 = 23,23,0       END_       ```    3. Define cylindrical coordinate system (CS\_DEF) in the tip of the right clip: ```       CS_DEF        ID_NAME    = CS_CYL_RIGHT        CS_TYPE    = CYLINDRICAL        DEF_TYPE   = LOCAL        CS_REF     = 1        ORIGIN_123 = 23,-23,0       END_       ```        You can now use the coordinate systems to define the cylindrical frozen areas in       the tips of the clip: 2. To define the cylindrical areas, create 2 solids as follows: ```    SOLID     ID_NAME    = SOLID_CYL_LEFT     SOLID_PROP = RESTRICTED     CS         = CS_CYL_LEFT     VAL_1_MIN  = 0     VAL_1_MAX  = 7     VAL_2_MIN  = 0     VAL_2_MAX  = 360     VAL_3_MIN  = -100     VAL_3_MAX  = 100    END_    ```     ```    SOLID     ID_NAME    = SOLID_CYL_RIGHT     SOLID_PROP = RESTRICTED     CS         = CS_CYL_RIGHT     VAL_1_MIN  = 0     VAL_1_MAX  = 7     VAL_2_MIN  = 0     VAL_2_MAX  = 360     VAL_3_MIN  = -100     VAL_3_MAX  = 100    END_    ```      The solids are assigned the attribute "RESTRICTED" so that they function as restricted bodies. 3. To define both solids as the frozen areas, reference the solids in a Design Variable Constraint (DVCON\_SHAPE): ```    DVCON_SHAPE     ID_NAME     = dvcon_solid     ND_GROUP    = DV_NODES     CHECK_SOLID = SOLID_CYL_LEFT     CHECK_SOLID = SOLID_CYL_RIGHT     CHECK_SPC   = NO     CHECK_DOF   = CS_0,FREE,FREE,FIX    END_    ```      Up to six solids can be referenced in a DVCON\_SHAPE definition. 4. To view the stresses outside the design area, the stress in the node group    ALL\_NODES must be determined in a Design Response (DRESP): ```    DRESP     ID_NAME    = DRESP_MAX_MISES     DEF_TYPE   = SYSTEM     TYPE       = SIG_MISES     ND_GROUP   = ALL_NODES     GROUP_OPER = MAX    END_    ```  The result looks as follows: |
