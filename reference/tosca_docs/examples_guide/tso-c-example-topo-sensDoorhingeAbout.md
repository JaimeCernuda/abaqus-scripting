This page discusses:   * About the Model * Procedure Summary | | |   About the Model The example model is part of the opening mechanism of a gull-winged car door, as can be seen in the image below. It is fully fixed at the center hole (c, green), and loads are applied at the four outer bearing holes (b, red). The stiffness of the structure should be maximized while reducing the overall mass to around 32.5%. Since the model should be produced using additive layer manufacturing, the setup contains an overhang restriction. It limits the angle of overhanging structures to around 45° in the chosen printing direction (blue). In addition, the optimization includes a plane symmetry restriction (c, yellow) and five frozen regions (gray).
