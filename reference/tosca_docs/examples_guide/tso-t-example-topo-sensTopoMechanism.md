| |  |  | | --- | --- | | Maximizing the Displacement of a Node for the Mechanism Model | | |  | | | |  | | --- | | The present example shows that the topology optimization by SIMULIA Tosca Structure is also capable of performing a mechanism design. The object function is now different, here opposite, from the classic compliance formulation. The objective is now to maximize the displacement of a node for a given actuator force. | | |  | | --- | | See Also | | About Checking the Quality of the Optimization Result | |   1. Define a Design Response (DRESP) as follows: ```    DRESP      ID_NAME  = DRESP_NODE_X      TYPE     = DISP_X      DEF_TYPE = SYSTEM      LC_SET   = STATIC,1,ALL      NODE     = 2    END_    ``` 2. Define the Objective Function (OBJ\_FUNC) as follows: ```    OBJ_FUNC      ID_NAME = MIN_DISP      DRESP   = DRESP_NODE_X, 1.0, 0.0      TARGET  = MIN    END_    ``` 3. Define the Volume Constraint and the Frozen Area as specified in the Procedure Summary.
