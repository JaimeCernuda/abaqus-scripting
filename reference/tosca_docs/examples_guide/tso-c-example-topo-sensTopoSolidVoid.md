This page discusses:   * About the Model * Procedure Summary | | |   About the Model The input model describes a pendulum clamped at the front and a frozen geometry at the rear end. The optimization setup is a volume minimization objective function with a relative frequency constraint for the second mode with a value of greater equal than 150%. This leads to a result with a large amount of intermediate densities. This can be improved with the use of the `SOLID_VOID_POST_STRATEGY`:  Procedure Summary |  |  | | --- | --- | | Model: | solidvoid.ext | | Design Area: | All elements except frozen regions | | Objective: | Minimize the volume of the design space | | Constraint: | Second eigenfrequency is greater equal than 150% | | Iterations: | 100 | | Settings: | Mode tracking; Solid Void Post Strategy | |
