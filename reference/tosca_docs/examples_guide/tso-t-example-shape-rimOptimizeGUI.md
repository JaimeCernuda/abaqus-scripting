| |  |  | | --- | --- | | Optimizing the Rim Model (Tosca Structure.gui) | | |  | | | |  | | --- | | This example illustrates controller-based shape optimization of a rim. This task shows you how to:   * Create the Node Groups * Setup the Optimization | | |   Create the Node Groups You need to define node groups for the:  1. Design Area 2. Stamp Restriction 3. Turn Restriction 4. Frozen Area  1. To define the Design Area, create the DESIGN\_NODES\_ALL node group, which contains the design    nodes. The group should contain    all nodes of the rim holes: 2. Create 6 more node groups containing each hole separately (HOLE\_1    ... HOLE\_6). These group definitions are required for the stamp    restrictions (SURF\_STAMP) on the holes. 3. Create 2 node groups containing the nodes of the inner    (TURN\_INNER) and the outer rim surface (TURN\_OUTER), required for the    CHECK\_SLIDE restriction: 4. The MESH\_SMOOTH command can cause the undesirable displacement    of some nodes on the inner and outer turn surface of the rim. Therefore, some nodes need    to be fixed. Create a group with the fix nodes (FIX\_NODES):  Setup the Optimization 1. Start Tosca Structure.pre to define the optimization task. 2. Import the analysis model rim.ext (ext=inp, bdf, dat...). If no groups are defined in    the analysis input (for example, for MSC Nastran®input), import the groups from the file groups.bdf, which can be found in the same    directory as the analysis input. For more details, refer to the Tosca Structure Getting Started manual. 3. Create the design variable area. The group DESIGN\_NODES contains    the design elements. 4. To view the stresses outside the design area, the stress in the node group    ALL\_NODES must be determined in a Design Response (DRESP): Create a LINK\_SHAPE condition with client type SURF\_STAMP to set a    stamp restriction to the rim holes. Specify the positive global y    axis as client direction. For each rim hole, create a DVCON\_SHAPE    using the node groups HOLE\_1 ... HOLE\_6. Assign the link condition    above to the DVCON\_SHAPE items. 5. Create a LINK\_SHAPE condition with client type ROTATION\_SYM to set a rotation symmetry to    the design area. Specify a 60° symmetry around the global y axis. Choose a tolerance value of    0.01 for each axis that matches the Tosca Structure default tolerance value. Assign the link    condition to a DVCON\_SHAPE item selecting the design group. 6. Create a LINK\_SHAPE condition with client type SURF\_TURN, which is used for the    definition of the slide surface (Fig. 104). Set the node group TURN\_OUTER as the main    criterion for the outer rim surface. Specify the positive global y axis as client    direction. Assign the link condition to a DVCON\_SHAPE item selecting the same node    group. To specify a slide surface, activate the link condition in the field CHECK\_SLIDE.    After that repeat the whole definition for the inner rim surface (node group    TURN\_INNER). 7. Define a DVCON\_SHAPE item to fix some nodes on the outer rim turning    surface. The nodes are assembled in the group FIX\_NODES. Fix the    displacements of the node group in all global directions. 8. Create the design responses. Add a design response for the volume as a    sum of all design elements volumes. Create design responses for the    maximal von Mises stress in the design area for both load cases. 9. Define the objective function to minimize the maximal von Mises stress    from both load cases (MINMAX). 10. Define a volume constraint with a relative value of 1.0. Thus the initial     weight of the rim remains unchanged. 11. Define a MESH\_SMOOTH area that contains four element layers starting with the     DESIGN\_NODES group. 12. Compose the optimization task (OPTIMIZE) and select the predefined     definitions. Choose the SHAPE\_CONTROLLER optimization strategy. Make     sure to reference all defined DVCON\_SHAPE items in the OPTIMIZE     command. 13. Start the complete Tosca Structure optimization using the start option type     = all. 14.
