| |  |  | | --- | --- | | Optimizing the Beam Symmetry Model | | |  | | | |  | | --- | | This example shows how to add symmetry conditions to a standard stiffness optimization. The symmetry condition is defined using the command LINK\_SIZING. This definition specifies the type of symmetry (point, plane, cyclic,...), the reference to the applied coordinate system and the type of coupling. The LINK\_SIZING command is referenced in the DVCON\_SIZING command which completes the assignment of the element group.  Several definitions of symmetry restrictions are given in the example file in the installation manual but only the plane symmetry definition is activated. All other types of symmetries can be activated by changing the parameter file, but only one symmetry condition can be activated at the same time. | | |   1. Define the Coordinate System (CS\_DEF): ```    !COORDINATE SYSTEM IN THE CENTRE OF THE BEAM    CS_DEF     ID_NAME      = CS_local     CS_TYPE      = RECTANGULAR     DEF_TYPE     = LOCAL     CS_REF       = CS_0     ORIGIN_123   = 125.0, 50.0,0     ROTATION_321 = 0,0,0    END_    ``` 2. Define a plane symmetry regarding the X-Z plane with the LINK\_SIZING command: ```    !DEFINE PLANE SYMMETRY    !SYMMETRY PLANE: X-Z PLANE OF CENTER_CS    LINK_SIZING     ID_NAME = my_link_plane     TYPE    = PLANE_SYM, AXIS_1     CS      = CS_local    END_    ``` 3. Reference the symmetry in a Design Variable Constraint (DVCON\_SIZING): ```    DVCON_SIZING     ID_NAME    = dvcon_plane     EL_GROUP   = ALL_ELEMENTS     CHECK_TYPE = LINK_SIZING     CHECK_LINK = my_link_plane    END_    ``` 4. To activate the restriction, reference the DVCON\_SIZING command in the OPTIMIZE command: ```    OPTIMIZE     ID_NAME    = SIZING     DV         = design_variables     OBJ_FUNC   = maximize_stiffness     DVCON      = dvcon_sizing     CONSTRAINT = volume_constraint     ! Link sizing Constraint     ! DVCON = dvcon_sizing     ! Plane Symmetry     DVCON = dvcon_plane     ! Rotation Symmetry     ! DVCON = dvcon_rotation     ! Cyclic Symmetry     ! DVCON = dvcon_cyclic    END_    ```      For rotational and cyclic symmetry, we recommend the activation of a    minimum cluster width (of 20 for this model) to get more    discernible effects. Further, the outer layer of elements (element    group FROZEN) can be frozen.
