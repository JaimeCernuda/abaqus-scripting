| |  |  | | --- | --- | | About the Mode Tracking Example | | |  | | | |  | | --- | | The present example shows that the topology optimization by Tosca Structure is also capable of performing mode tracking on dynamic frequency analysis. The setup compared to a standard eigenfrequency analysis is the same. Except for the use of the mode tracking option, causing the optimizer to maintain the initial mode order even thought mode switching occurs. This page discusses:   * About the Model * Procedure Summary | | |   About the Model The input model describes a pendulum clamped at the front with a frozen geometry at the rear end. The optimization setup is a volume minimization with a relative frequency constraint for the second mode with a value of greater equal than 178%.
