| |  |  | | --- | --- | | Optimizing the Beam2D Model | | |  | | | |  | | --- | | The actual model shows the main parts of a sizing optimization task: Definition of design variables, constraints, and objective function.  1. Define the Design Area. 2. Define the thickness bounds. 3. Define the Objective Function. 4. Define the volume constraint. 5. Set the Optimization Task. 6. (optional) Define clustering elements. | | |   1. Define the Design Areas (DV\_SIZING): ```    DV_SIZING     ID_NAME  = design_variables     EL_GROUP = ALL_ELEMENTS    END_    ``` 2. Define the thickness bounds for the shell thicknesses in a Design    Variable Constraint (DVCON\_SIZING): ```    DVCON_SIZING     ID_NAME     = DVCON_SIZING     EL_GROUP    = P1     CHECK_TYPE  = THICKNESS_BOUNDS     MAGNITUDE   = ABS     LOWER_BOUND = 0.1     UPPER_BOUND = 2.0    END_    ```      The lower and upper bounds for the shell thicknesses are defined    as absolute values (MAGNITUDE = ABS. 3. To define the Objective Function, do the following:    1. Define a Design Response (DRESP) with the compliance for the       model: ```       DRESP        ID_NAME    = DRESP_SUM_ENERGY        DEF_TYPE   = SYSTEM        TYPE       = STRAIN_ENERGY        EL_GROUP   = ALL_ELEMENTS        GROUP_OPER = SUM       END_       ```    2. Reference the Design Response in the Objective Function       (OBJ\_FUNC) and set the TARGET to minimize: ```       OBJ_FUNC        ID_NAME = maximize_stiffness        DRESP   = DRESP_SUM_ENERGY        TARGET  = MIN       END       ```         The response is minimized and the stiffness is maximized. 4. To define the volume constraint, do the following:    1. Define a Design Response (DRESP) that contains the sum of the       total volume of the optimization group: ```       DRESP         ID_NAME    = DRESP_VOL_SIZING         DEF_TYPE   = SYSTEM         TYPE       = VOLUME         EL_GROUP   = ALL_ELEMENTS         GROUP_OPER = SUM       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT)       and restrict it to 50 % of initial volume: ```       CONSTRAINT        ID_NAME   = volume_constraint        DRESP     = DRESP_VOL_SIZING        MAGNITUDE = REL        LE_VALUE  = 0.5       END_       ``` 5. Reference the Design Variables, Objective Function, and constraints in the OPTIMIZE    command: ```    OPTIMIZE     ID_NAME    = SIZING     STRATEGY   = SIZING     DV         = DESIGN_VARIABLES     OBJ_FUNC   = MAXIMIZE_STIFFNESS     CONSTRAINT = VOLUME_CONSTRAINT     DVCON      = DVCON_SIZING    END_    ```      The optimization task above performs a free change of each single shell thickness.  The optimization result shows a varying shell thickness over the model. This can be used as    a hint for clustering (that is, where to create borders between single sheets of the same    thickness): 6. (optional) If you want to enforce certain areas to obtain the    same shell thickness, you can cluster the elements in these areas. To define    clustering areas, do the following:    1. Define an element group (EL\_SET\_1, EL\_SET\_2,... (predefined       in the example model)) for each of the clustering areas and assign them to a       clustering design variable constraint as follows: ```       DVCON_SIZING        ID_NAME    = CLUSTERING        EL_GROUP   = EL_SET_1        EL_GROUP   = EL_SET_2        EL_GROUP   = EL_SET_3        EL_GROUP   = EL_SET_4        EL_GROUP   = EL_SET_5        CHECK_TYPE = CLUSTER       END_       ```    2. Reference the new Design Response in the OPTIMIZE command: ```       OPTIMIZE        ID_NAME = SIZING        ...        DVCON   = CLUSTERING       END_       ```         The optimization result shows a very uniform thickness       distribution: |
