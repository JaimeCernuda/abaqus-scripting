This page discusses:   * About the Model * Procedure Summary | | |   About the ModelIn this model, a rectangular plate lying on a rigid mold comes into contact with a rigid punch and deform accordingly. The punch experiences a displacement-controlled (3.5mm) load at first to get into contact with the plate and then a force-controlled load (3000N), both through a reference point and in negative Y-direction.   The sizing optimization task is to minimize the compliance while using 90% of the initial volume. By default, the shell element thicknesses are allowed to change up to 25% of the initial thickness.
