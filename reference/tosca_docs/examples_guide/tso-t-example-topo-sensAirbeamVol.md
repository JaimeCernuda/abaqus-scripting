| |  |  | | --- | --- | | Minimizing the Volume of the AirbeamVol Model | | |  | | | |  | | --- | | This section shows the main components of the AirbeamVol setup. | | |   1. To define the objective of minimizing the volume, do the following:    1. Define a Design Response (DRESP) of type volume: ```       DRESP         ID_NAME    = DRESP_VOL_TOPO         DEF_TYPE   = SYSTEM         TYPE       = VOLUME         EL_GROUP   = ALL_ELEMENTS         GROUP_OPER = SUM       END_       ```    2. Define the Objective Function (OBJ\_FUNC) and reference the Design Response: ```       OBJ_FUNC         ID_NAME    = min_vol         DRESP      = DRESP_VOL_TOPO         TARGET     = MIN       END_       ``` 2. To define the displacement constraint, do the following:    1. Define a Design Response (DRESP) that refers to the absolute displacement of node 110. ```       DRESP         ID_NAME    = DRESP_DISP1_ABS_MAX         TYPE       = DISP_Y_ABS         DEF_TYPE   = SYSTEM         NODE       = 110       END_       ```    2. Define a less equal constraint (CONSTRAINT) that references the Design Response and constrains its value to a maximum displacement of 0.06mm. ```       CONSTRAINT         ID_NAME    = DISP_constraint         DRESP      = DRESP_DISP1_ABS_MAX         MAGNITUDE  = ABS         LE_VALUE   = 0.06       END_       ``` 3. To avoid a checkerboard effect and to enforce a minimum member size, increase the    default filter radius with the OPT\_PARAM command: ```    OPT_PARAM      ID_NAME             = OPT_PARAMS      OPTIMIZE            = TOPOLOGY_OPTIMIZATION      TOPOO_FILTER_RADIUS = 2.5    END_    ```      Setting the filter radius this way has the same effect as using a minimum member size    restriction.
