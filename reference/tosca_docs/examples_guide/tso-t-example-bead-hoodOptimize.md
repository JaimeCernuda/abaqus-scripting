| |  |  | | --- | --- | | Optimizing the Hood Model | | |  | | | |  | | --- | | Nodes of the boundary are not a part of the design variables as in the plate example. The remaining nodes are design variables for the bead optimization. | | |   1. Create two Design Responses (DRESP) for the load cases: ```    DRESP     ID_NAME    = dresp_compliance_1     DEF_TYPE   = SYSTEM     EL_GROUP   = ALL_ELEMENTS     TYPE       = STRAIN_ENERGY     GROUP_OPER = SUM     LC_SET     = STATIC,1,ALL    END_     DRESP     ID_NAME    = dresp_compliance_2     DEF_TYPE   = SYSTEM     EL_GROUP   = ALL_ELEMENTS     TYPE       = STRAIN_ENERGY     GROUP_OPER = SUM     LC_SET     = STATIC,2,ALL    END_    ``` 2. Reference the Design Responses in the Objective Function (OBJ\_FUNC): ```    OBJ_FUNC     ID_NAME = minimize_compliance     DRESP   = dresp_compliance_1, 1.0     DRESP   = dresp_compliance_2, 1.0     TARGET  = MIN    END_    ```      Here the weight fraction for both design responses is 1.0. 3. Reference the Design Variables, Objective Function, and constraints in the OPTIMIZE    command: ```    OPTIMIZE     ID_NAME    = BEAD_OPTIMIZATION     DV         = DESIGN_VARIABLES     OBJ_FUNC   = minimize_compliance     DVCON      = dvcon_FIX_spc     CONSTRAINT = bead_height_constraint     STRATEGY   = BEAD_CONTROLLER    END_    ```      The result looks as follows:    The optimization result is however not symmetric. 4. To enforce plane symmetry, do the following:    1. Define a coordinate system (CS\_DEF) on the symmetry plane: ```       CS_DEF        ID_NAME      = MY_CS        DEF_TYPE     = LOCAL        CS_TYPE      = RECTANGULAR        CS_REF       = CS_0        ORIGIN_123   = 5.0, 0.0, 10.0        ROTATION_321 = 0.0, 0.0, 0.0       END_       ```    2. The normal of the symmetry plane is the 3rd axis of the coordinate system. Thus, define the following link condition (LINK\_BEAD): ```       LINK_BEAD        ID_NAME    = my_link_plane        TYPE       = PLANE_SYM        CLIENT_DIR = 0., 0., 1.        CS         = MY_CS       END_       ```    3. Reference the link condition in a Design Variable Constraint (DVCON\_BEAD): ```       DVCON_BEAD        ID_NAME    = my_dvcon        CHECK_LINK = my_link_plane        ND_GROUP   = all_nodes       END_       ``` 5.
