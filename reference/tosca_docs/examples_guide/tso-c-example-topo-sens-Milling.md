| |  |  | | --- | --- | | About the Milling Example | | |  | | | |  | | --- | | This example shows the basic workflow for a sensitivity-based topology optimization with milling restrictions. This page discusses:   * About the Model * Procedure Summary | | |   About the Model The considered model is a simplified version of a suspension upright of a car. Because of the number of constraints, the optimization might take more time to finish when not using Abaqus as a solver.  The initial model of the block is loaded at various points with single forces and one moment, while the large center hole is fixed.  Multiple regions are considered frozen during the optimization. Target of the optimization is the volume minimization of the block for given constraints of stress and displacements.
