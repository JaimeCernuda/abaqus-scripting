This page discusses:   * About the Model * Procedure Summary | | |   About the ModelThe hood is a simple shell structure that is subjected to two load cases. Although one of the load cases is unsymmetrical, the final design should be symmetric.   The hood is loaded with a vertical pull and a shear force. It is fixed in the two upper corners. Dimensions: Height 15.0, width 20.0, and depth 15.0.
