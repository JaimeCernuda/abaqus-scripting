This page discusses:   * About the Model * Procedure Summary * See Also | | |   About the ModelIn this model, a clustered plate is encastered on the left side with a load of L = 100 N in the negative Y-direction on the right side. The plate is also fixed in Z-direction to prevent (for example, out of plane buckling motion).    In this example, it is shown how differences between elastic and elastic-plastic material affect the optimization results. The sizing optimization task is to minimize the volume of the plate while using von Mises stress constraints. By default, the shell thicknesses are allowed to change up to 25% of the initial thickness and are changed for each element cluster. Within a cluster, the elements have the same thickness.
