| |  |  | | --- | --- | | Maximizing the First Natural Frequency of the Plate Model | | |  | | | |  | | --- | | The setup includes the definition of the frequency objective. Loading the model and definition of design area, objective function and constraint can be done as described in the Getting Started Manual. | | |  | | --- | | See Also | | About Checking the Quality of the Optimization Result | |   1. Define a Design Response (DRESP) as follows: ```    DRESP      ID_NAME  = DRESP_FREQ      DEF_TYPE = SYSTEM      TYPE     = DYN_FREQ_KREISSEL      LC_SET   = Modal, 1, 1-5    END_    ``` 2. Define the Objective Function (OBJ\_FUNC) as follows: ```    OBJ_FUNC      ID_NAME = maximize_first_eigenfrequency      DRESP   = DRESP_FREQ      TARGET  = MAX    END_    ``` 3. To define the volume constraint, do the following:    1. Define a Design Response (DRESP) that refers to the initial volume of the design.       The initial volume is the sum of all elements. ```       DRESP         ID_NAME    = DRESP_VOL_TOPO         DEF_TYPE   = SYSTEM         TYPE       = VOL_FILL         EL_GROUP   = ALL_ELEMENTS         GROUP_OPER = SUM       END_       ```    2. Define a less equal constraint (CONSTRAINT) that references the Design Response and constrains it to 30 % of its initial volume. ```       CONSTRAINT         ID_NAME   = volume_constraint         DRESP     = DRESP_VOL_TOPO         MAGNITUDE = REL         LE_VALUE  = 0.3       END_       ``` 4. Define one of the displacement constraints as absolute constraint (CONSTRAINT): ```    CONSTRAINT      ID_NAME   = DISP_constraint_1      DRESP     = DRESP_DISP1_ABS_1      MAGNITUDE = ABS      LE_VALUE  = 1.3    END_    ``` 5. To avoid a checkerboard effect, activate the smoothing filter with the OPT\_PARAM command: ```    OPT_PARAM      ID_NAME            = KREISSELMEIER_FREQ_SETTINGS      OPTIMIZE           = TOPOLOGY_OPTIMIZATION      TOPO_FILTER_RADIUS = 25.    END_    ```      The radius must be chosen in such a way that the value is about twice the average element edge length in the    model (approx. 12.5). A value of 25 has been used in this example.
