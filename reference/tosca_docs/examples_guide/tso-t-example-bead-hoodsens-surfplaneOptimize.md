Enable reading all boundary conditions from the FE file: ```    OPTIONS      READ_BC = ALL    END_    ``` 2. Select the respective FE file and define design variables: ```    FEM_INPUT      ID_NAME  = OPTIMIZATION_MODEL      FILE     = hood.inp    END_     DV_BEAD      ID_NAME  = DESIGN_VARIABLES      ND_GROUP = ALL_NODES    END_    ``` 3. Create two Compliance Design Responses (DRESP) for the load cases: ```    DRESP     ID_NAME    = dresp_compliance_1     DEF_TYPE   = SYSTEM     EL_GROUP   = ALL_ELEMENTS     TYPE       = STRAIN_ENERGY     GROUP_OPER = SUM     LC_SET     = STATIC,1,ALL    END_     DRESP     ID_NAME    = dresp_compliance_2     DEF_TYPE   = SYSTEM     EL_GROUP   = ALL_ELEMENTS     TYPE       = STRAIN_ENERGY     GROUP_OPER = SUM     LC_SET     = STATIC,2,ALL    END_    ``` 4. Reference the Design Responses in the Objective Function (OBJ\_FUNC): ```    OBJ_FUNC     ID_NAME = minimize_compliance     DRESP   = dresp_compliance_1, 1.0     DRESP   = dresp_compliance_2, 1.0     TARGET  = MIN    END_    ```      Here the weighting for both design responses is 1.0. 5. Define a DVCON\_BEAD for the growths limits of the beads: ```    DVCON_BEAD      ID_NAME      = dvcon_bead_height      CHECK_BC     = NO      ND_GROUP     = ALL_NODES      CHECK_GROW   = 0.5      CHECK_SHRINK = 0.5    END_    ``` 6. Accept all boundary conditions read from the FE file with a DVCON\_BEAD: ```    DVCON_BEAD      ID_NAME  = dvcon_fix_spc      ND_GROUP = ALL_NODES      CHECK_BC = YES    END_    ``` 7. Reference the Design Variables, Objective Function, and Constraints in the OPTIMIZE    command: ```    OPTIMIZE      ID_NAME  = BEAD_OPTIMIZATION      DV       = DESIGN_VARIABLES      OBJ_FUNC = minimize_compliance      DVCON    = dvcon_fix_spc      DVCON    = dvcon_bead_height      STRATEGY = BEAD_SENSITIVITY    END_    ```      The result looks as follows:    The optimization result is however not symmetric in the center and at the top. 8. To enforce plane symmetry, do the following:    1. Define a coordinate system (CS\_DEF) on the symmetry plane: ```       CS_DEF        ID_NAME      = MY_CS        DEF_TYPE     = LOCAL        CS_TYPE      = RECTANGULAR        CS_REF       = CS_0        ORIGIN_123   = 5.0, 0.0, 10.0        ROTATION_321 = 0.0, 0.0, 0.0       END_       ```    2. The normal of the symmetry plane is the 3rd axis of the coordinate system. Thus, define the following link condition (LINK\_BEAD): ```       LINK_BEAD         ID_NAME    = link_bead_plane_sym         TYPE       = PLANE_SYM         CLIENT_DIR = 0., 0., 1.         CS         = SYM_CS       END_       ```    3. Reference the link condition in a Design Variable Constraint (DVCON\_BEAD): ```       DVCON_BEAD         ID_NAME    = dv_plane_sym         ND_GROUP   = ALL_NODES         CHECK_LINK = link_bead_plane_sym       END_       ``` 9.
