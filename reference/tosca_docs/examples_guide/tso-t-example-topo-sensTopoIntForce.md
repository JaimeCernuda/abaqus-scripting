To define the Objective Function, do the following:    1. Define a Design Response (DRESP) as follows: ```       DRESP         ID_NAME    = DRESP_SUM_ENERGY         DEF_TYPE   = SYSTEM         TYPE       = STRAIN_ENERGY         EL_GROUP   = ALL_ELEMENTS         GROUP_OPER = SUM       END       ```    2. Reference the Design Response in the Objective Function (OBJ\_FUNC): ```       OBJ_FUNC         ID_NAME = MAXIMIZE_STIFFNESS         DRESP   = DRESP_SUM_ENERGY         TARGET  = MIN       END_       ``` In this way, the sum of strain energy is minimized for    obtaining a stiff structure. 6. To constrain the volume to 15 % compared to the existing model, do the following:    1.
