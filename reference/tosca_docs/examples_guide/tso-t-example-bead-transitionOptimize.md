| |  |  | | --- | --- | | Optimizing the Control Arm Model | | |  | | | |  | | --- | | This example shows a basic model containing a transition zone design variable constraint:  1. Define input data and choose design variables. 2. Define the objective function (DRESP, OBJ\_FUNC). 3. Define boundary conditions (DVCON\_BEAD). 4. Define the OPTIMIZE command. 5. Set maximum number of design cycles. | | |   1. Define input data and design variables. ```    FEM_INPUT      ID_NAME         = INPUT_FILE      FILE            = bead_transition_zone.inp    END_     DV_BEAD      ID_NAME        = globalDesignArea      ND_GROUP       = globalDesignRegion    END_    ``` 2. Define the Objective Function (OBJ\_FUNC) for minimizing the compliance: ```    DRESP      ID_NAME        = TASK_STIFFNESS      DEF_TYPE       = SYSTEM      TYPE           = ENERGY_STIFF_MEASURE      EL_GROUP       = ALL_ELEMENTS      GROUP_OPER     = SUM    END_     OBJ_FUNC      ID_NAME        = MY_OBJECTIVE      DRESP          = TASK_STIFFNESS      TARGET         = MIN    END_    ``` 3. Define boundary conditions (DVCON\_BEAD): ```    DVCON_BEAD      ID_NAME        = globalFixed      ND_GROUP       = globalFixedRegion      CHECK_DOF      = CS_0,FIX,FIX,FIX    END_     DVCON_BEAD      ID_NAME        = BeadWidthControl1      ND_GROUP       = globalDesignRegion      CHECK_TYPE     = FILTER      RADIUS         = 0.012    END_     DVCON_BEAD      ID_NAME        = checkGrowOrShrink_1      ND_GROUP       = globalDesignRegion      CHECK_GROW     = 0.005      CHECK_SHRINK   = 0.005    END_     DVCON_BEAD      ID_NAME        = dvcon_transition_zone      ND_GROUP       = TransitionNodes      CHECK_TYPE     = TRANSITION_ZONE      REFERENCE_NDGR = TransitionBorderEdgeNodes1      FUNCTION       = SMOOTH ! or LINEAR    END_    ``` 4. Reference the Design Variables, Objective Function as well as DVCONs    in the OPTIMIZE command. Set the Strategy to BEAD\_SENSITIVITY. ```    OPTIMIZE      ID_NAME        = Objective      STRATEGY       = BEAD_SENSITIVITY      DV             = globalDesignArea      DVCON          = checkGrowOrShrink_1      DVCON          = BeadWidthControl1      DVCON          = globalFixed      DVCON          = dvcon_transition_zone      OBJ_FUNC       = MY_OBJECTIVE    END_    ``` 5. Set maximum number of iterations to 40. ```    STOP      ID_NAME        = global_stop      ITER_MAX       = 40    END_    ```  Optimization results with smooth transition zone    Optimization results with linear transition zone    Optimization results without transition zone     |  | | --- | | Important: Note that using a different solver other than Abaqus might lead to different optimization results because of differences in the solver calculations. | |
