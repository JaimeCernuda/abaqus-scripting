| |  |  | | --- | --- | | Optimizing the Holder Model | | |  | | | |  | | --- | | Details about the optimization of the Holder Model This task shows you how to:   * Use Standard Settings * Use BEAD\_NODE\_SMOOTH * Use CURV\_SMOOTH | | |   Use Standard Settings Command in the parameter file: ``` OPT_PARAM   ID_NAME    = MY_PARAMETERS   OPTIMIZE   = BEAD_OPTIMIZATION   BEAD_WIDTH = 50.0 END_ ```  The following figure shows the optimized solution using BEAD\_WIDTH = 50.0 and BEAD\_HEIGHT = 10.0, but otherwise the standard settings from Tosca Structure.gui. The two areas of interest are circled and marked with "1" and "2" and are used in the following to explain the function of the two optional OPT\_PARAM: BEAD\_NODE\_SMOOTH(1) and CURV\_SMOOTH(2) settings.  Use BEAD\_NODE\_SMOOTH Command in the parameter file: ``` OPT_PARAM   ID_NAME          = MY_PARAMETERS   OPTIMIZE         = BEAD_OPTIMIZATION   BEAD_NODE_SMOOTH = 20.0   BEAD_WIDTH       = 50.0 END_ ```   BEAD\_NODE\_SMOOTH defines a distance that is the lowest possible in plane distance where the optimization displacement is allowed to vary from 0.0 to the defined bead height. The following figure shows the effect of BEAD\_NODE\_SMOOTH for different values.    a) The value 1.0 is smaller than the element edge length and there no smoothing is enforced from the nondesign to design area (see the model).  b) and c) The values are higher and it is seen from the figure that more elements are forced to be in the transition from nondesign to design area. The default value in Tosca Structure.bead is BEAD\_NODE\_SMOOTH = 0.25\*BEAD\_WIDTH and that is in this case shown in b).  Use CURV\_SMOOTH Command in the parameter file: ``` OPT_PARAM   ID_NAME          = MY_PARAMETERS   OPTIMIZE         = BEAD_OPTIMIZATION   CURV_SMOOTH      = 10.0   BEAD_NODE_SMOOTH = 20.0   BEAD_WIDTH       = 50.0 END_ ```   If BEAD\_NODE\_SMOOTH > 0.5\*BEAD\_WIDTH, the optimization stops with an error. CURV\_SMOOTH defines the radius in which the mesh effects of a curved surface can be reduced. The value depends on the average element edge length in the design domain and is default set to 5.0 times this length (see the following figure b).    The figure shows the effect of CURV\_SMOOTH for different values. It is important to notice the different element size in the bead.  a) the curvature of the initial structure squeezes the nodes together so that the elements become quite small. For even higher degrees of curvature and large bead heights, it is possible that the nodes "grow together", thus distorting the elements so much that the FE-analysis fails.  c) the smoothing radius is 10 times the average element edge length. The elements in the curved area are almost the same size as the elements in the nonoptimized areas and keeping a valid mesh. It should be noted that the high values of CURV\_SMOOTH results in a large computational effort. |
