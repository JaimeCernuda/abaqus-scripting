| |  |  | | --- | --- | | Optimizing the Rim Model | | |  | | | |  | | --- | | In this example, you are going to follow the workflow for a standard shape optimization task:  1. Define input data and design variables. 2. Define the Constraint of the optimization task (DRESP, CONSTRAINT). 3. Define the Objective Function (DRESP, OBJ\_FUNC). 4. Define manufacturing constraints (CD\_DEF, LINK\_SHAPE, DVCON\_SHAPE). 5. Define the OPTIMIZE command (OPTIMIZE). 6. Set stop condition (STOP).  This task shows you how to:   * Create the Node Groups * Setup the Optimization | | |   Create the Node Groups You need to define node groups for the:  1. Design Area 2. Stamp Restriction 3. Demold Restriction 4. Frozen Area  1. To define the Design Area, create the DESIGN\_NODES\_ALL node    group that contains the design nodes. The group should contain all nodes of the rim    holes: 2. Create 6 more node groups containing each hole separately (HOLE\_1 ... HOLE\_6). These group definitions are required for the stamp restrictions on the holes. 3. Create 2 node groups containing the nodes of the inner    (TURN\_INNER) and the outer rim surface (TURN\_OUTER), required for the    CHECK\_SLIDE restriction: 4. Create 2 more node groups for the demold restriction on    the outer surface of the rim holes (first group DEMOLD). 5. Extend the group by adding the nodes of the inner turn surface of    the rim to create the check group for the demold restriction    (CHECK\_DEMOLD). 6. The MESH\_SMOOTH command can cause the undesirable displacement of    some nodes on the outer turn surface of the rim. Therefore, some    nodes need to be fixed. Create a group with the fix nodes    (FIX\_NODES):  Setup the Optimization 1. Define input data, additional groups design variables. ```    FEM_INPUT     ID_NAME  = fem_input_name     FILE     = rim_pemag.inp    END_     GROUP_DEF     ID_NAME = TURN_OUTER     TYPE    = NODE     FORMAT  = LIST     LIST_BEGIN     [List of node IDs, separated by comma] (skipped here because of readibility)    END_     GROUP_DEF     ID_NAME = TURN_INNER     TYPE    = NODE     FORMAT  = LIST     LIST_BEGIN     [List of node IDs, separated by comma] (skipped here because of readibility)    END_     GROUP_DEF     ID_NAME = DESIGN_NODES_ALL     TYPE    = NODE     FORMAT  = LIST     LIST_BEGIN     [List of node IDs, separated by comma] (skipped here because of readibility)    END_     DV_SHAPE     ID_NAME  = DESIGN_AREA     ND_GROUP = DESIGN_NODES_ALL    END_    ``` 2. Create a constraint for the volume.    1. Define a Design Response with the volume (DRESP): ```       DRESP        ID_NAME    = DRESP_VOLUME        LIST       = NO_LIST        DEF_TYPE   = SYSTEM        EL_GROUP   = ALL_ELEMENTS        TYPE       = VOLUME        GROUP_OPER = Sum       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT) and constrain it to 100%. ```       CONSTRAINT        ID_NAME   = VOLUME_CONSTRAINT        DRESP     = DRESP_VOLUME        MAGNITUDE = REL        LE_VALUE  = 1.0       END_       ``` 3. To define the Objective Function (OBJ\_FUNC) for the plastic equivalent magnitude (PEMAG)    in the second load case, do the following:    1. Create a Design Response (DRESP). ```       DRESP        ID_NAME  = DRESP_PEMAG        DEF_TYPE = SYSTEM        TYPE     = PEMAG        EL_GROUP = ALL_ELEMENTS       END_       ```    2. Define the objective function. ```       OBJ_FUNC        ID_NAME = OBJ_FUNCTION        TARGET  = MIN        DRESP   = DRESP_PEMAG       END_       ``` 4. Define turning and rotational symmetry constraints.    1. Create a new coordinate system. ```       CS_DEF        ID_NAME      = CS_SYM        DEF_TYPE     = LOCAL        CS_TYPE      = RECTANGULAR        CS_REF       = CS_0        ORIGIN_123   = 0.0,-60.,0.        ROTATION_321 = 0.,0.,0.       END_       ```    2. Define the constraint in LINK\_SHAPE commands. ```       LINK_SHAPE        ID_NAME    = LINK_SHAPE_TURN_OUTER        CLIENT     = SURF_TURN        MAIN     = NDGR,TURN_OUTER        CLIENT_DIR = 0, 1, 0        CS         = CS_0       END_        LINK_SHAPE        ID_NAME    = LINK_SHAPE_TURN_INNER        CLIENT     = SURF_TURN        MAIN     = NDGR,TURN_INNER        CLIENT_DIR = 0, 1, 0        CS         = CS_0       END_        LINK_SHAPE        ID_NAME    = ROT_SYM_LINK        MAIN     = MAX        CLIENT     = SURF_CYCLIC_SYM        CLIENT_DIR = 0.,1.,0.        CS         = CS_SYM        TOL        = 0.1,0.1,0.1        ANGLE      = 60        CYCLIC_SYM_START = 1.,0.,0.       END_       ```    3. Reference the constraints in DVCON\_SHAPE commands. ```       DVCON_SHAPE        ID_NAME     = DVCON_SHAPE_SLIDE_OUTER        CHECK_BC    = NO        ND_GROUP    = TURN_OUTER        CHECK_SLIDE = LINK_SHAPE_TURN_OUTER       END_        DVCON_SHAPE        ID_NAME     = DVCON_SHAPE_SLIDE_INNER        CHECK_BC    = NO        ND_GROUP    = TURN_INNER        CHECK_SLIDE = LINK_SHAPE_TURN_INNER       END_        DVCON_SHAPE        ID_NAME        = ROT_SYM        ND_GROUP       = DESIGN_NODES_ALL        CHECK_LINK     = ROT_SYM_LINK        FEASIBLE_START = YES       END_       ``` 5. Reference the Design Variables, Objective Function, and Constraints as well as DV\_CONs in    the OPTIMIZE command. ```    OPTIMIZE     ID_NAME     = SHAPE_OPTIMIZATION     DV          = DESIGN_AREA     OBJ_FUNC    = OBJ_FUNCTION     CONSTRAINT  = VOLUME_CONSTRAINT     STRATEGY    = SHAPE_SENSITIVITY     DVCON       = ROT_SYM     DVCON       = DVCON_SHAPE_SLIDE_OUTER     DVCON       = DVCON_SHAPE_SLIDE_INNER     MESH_SMOOTH = MY_MESH_SMOOTH    END_    ``` 6. Set stop condition. ```    OPT_PARAM     ID_NAME  = "OPT_PARAM"     OPTIMIZE = SHAPE_OPTIMIZATION    END_     STOP     ID_NAME  = STOP_CONDITION     ITER_MAX = 10    END_    ```  The optimization result looks as follows:  The PEMAG distribution in the initial iteration looks as follows:  The optimized part has the following PEMAG distribution: |
