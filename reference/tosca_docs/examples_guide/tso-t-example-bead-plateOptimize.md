| |  |  | | --- | --- | | Optimizing the Plate Model | | |  | | | |  | | --- | | In this example, you are going to follow the workflow for a standard bead optimization task:  1. Import Boundary Conditions (OPTIONS). 2. Import the FEM-Model (FEM\_INPUT). 3. Activate the Boundary Conditions (DVCON\_BEAD) 4. Define the Constraint of the optimization task (DRESP, CONSTRAINT). 5. Define the Objective Function (DRESP, OBJ\_FUNC). 6. Define the OPTIMIZE command. 7. (optional) Set additional settings (OPT\_PARAM). | | |   1. Import the boundary conditions in an OPTIONS command: ```    OPTIONS     READ_BC = ALL    END_    ``` 2. Import the FEM-Model (FEM\_INPUT). 3. To activate the boundary conditions, create a Design Variable Constraint (DVON\_BEAD): ```    DVCON_BEAD     ID_NAME  = dvcon_fix_spc     ND_GROUP = ALL_NODES     CHECK_BC = YES    END_    ```      The parameter CHECK\_BC = YES ensures that all nodes with a fixation in the finite element model    are also fixed in the corresponding DOFs during the optimization procedure. 4. To define the height of the beads as the constraint of the optimization    problem, do the following:    1. Define a Design Response with the height of the beads (DRESP): ```       DRESP        ID_NAME    = DRESP_BEAD_HEIGHT        DEF_TYPE   = SYSTEM        ND_GROUP   = ALL_NODES        TYPE       = BEAD_HEIGHT        GROUP_OPER = MAX       END_       ```    2. Reference the Design Response in a constraint (CONSTRAINT) and constrain it to a maximum of 20 mm: ```       CONSTRAINT        ID_NAME   = bead_height_constraint        DRESP     = dresp_bead_height        MAGNITUDE = ABS        EQ_VALUE  = 20.0       END_       ``` 5. To define the Objective Function (OBJ\_FUNC), do the following:    1. Create a Design Response (DRESP) with the compliance of the model: ```       DRESP        ID_NAME    = DRESP_COMPLIANCE        DEF_TYPE   = SYSTEM        EL_GROUP   = ALL_ELEMENTS        TYPE       = STRAIN_ENERGY        GROUP_OPER = SUM        LC_SET     = STATIC,1,ALL       END_       ```    2. Reference the Design Response in the Objective Function (OBJ\_FUNC) and minimize it: ```       OBJ_FUNC        ID_NAME = MINIMIZE_COMPLIANCE        DRESP = DRESP_COMPLIANCE        TARGET = MIN       END_       ``` 6. Reference the Design Variables, Objective Function, and Constraints in the OPTIMIZE command: ```    OPTIMIZE     ID_NAME    = BEAD_OPTIMIZATION     DV         = DESIGN_VARIABLES     OBJ_FUNC   = MINIMIZE_COMPLIANCE     DVCON      = DVCON_BC     CONSTRAINT = BEAD_HEIGHT_CONSTRAINT    END_    ``` 7. (optional) Define the bead width in the OPT\_PARAM command ```    OPT_PARAM     ID_NAME    = MY_PARAMETERS     OPTIMIZE   = BEAD_OPTIMIZATION     VECTOR     = FIRST     SCALE      = 1.0     BEAD_WIDTH = 60    END    ```      If you do not define the bead width, the system automatically determines a bead    width.
