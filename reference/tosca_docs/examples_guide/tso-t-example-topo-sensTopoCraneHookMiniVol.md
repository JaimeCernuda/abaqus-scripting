| |  |  | | --- | --- | | Minimizing the Volume of the Crane Hook Model | | |  | | | |  | | --- | | Depending on the used solver, the analysis can be performed in one or two solver runs. | | |  | | --- | | See Also | | About Checking the Quality of the Optimization Result | |   1. Depending on your solver, you have two options to specify the input file:    1. If the solver supports the combined analysis, define the following FEM\_INPUT: ```       FEM_INPUT         ID_NAME = MY_INPUT_FILES         FILE    = cranehook_stat_freq.inp       END_       ```         The static load cases are the       load cases with       number 1 and 2. The frequency load case is then number 3.    2. If the solver does NOT support the combined analysis, the FEM\_INPUT       command contains two entries for the FILE item: ```       FEM_INPUT         ID_NAME = MY_INPUT_FILES         FILE    = cranehook_stat.ext         FILE    = cranehook_freq.ext       END_       ```         The referenced load case       numbers of the second file are then shifted by 10.000. Therefore, the       modal analysis must be referenced with the load case number       (boundary conditions set number) 10.001. 2. To use the volume in objective,    define a Design Response (DRESP) as follows: ```    DRESP      ID_NAME    = TOSCA_DRESP_1_VOLUME_TERM_1      LIST       = NO_LIST      DEF_TYPE   = SYSTEM      EL_GROUP   = ALL_ELEMENTS      TYPE       = VOLUME      GROUP_OPER = Sum    END_    ``` 3. Define the Objective Function (OBJ\_FUNC) as follows: ```    OBJ_FUNC      ID_NAME = OBJ_FUNC_1_OBJ_FUNC_ITEM_1      TARGET  = MIN      DRESP   = TOSCA_DRESP_1_VOLUME_TERM_1    END_    ``` 4. Define a Design Response for the displacement in Y-direction for a given node for each load case: ```    DRESP      ID_NAME    = TOSCA_DRESP_2_DISPLACEMENT_CONSTRAINT_1      LIST       = NO_LIST      DEF_TYPE   = SYSTEM      NODE       = 13298      TYPE       = DISP_ABS      GROUP_OPER = MAX      LC_SET     = STATIC,1,      CS_REF     = CS_0    END_     DRESP      ID_NAME    = TOSCA_DRESP_3_DISPLACEMENT_CONSTRAINT_2      IST        = NO_LIST      DEF_TYPE   = SYSTEM      NODE       = 13298      TYPE       = DISP_ABS      GROUP_OPER = MAX      LC_SET     = STATIC,2,      CS_REF     = CS_0    END_    ``` 5. Define the displacement constraints as absolute constraint (CONSTRAINT): ```    CONSTRAINT      ID_NAME   = DISPLACEMENT_CONSTRAINT_1      DRESP     = TOSCA_DRESP_2_DISPLACEMENT_CONSTRAINT_1      MAGNITUDE = ABS      LE_VALUE  = 0.8    END_     CONSTRAINT      ID_NAME   = DISPLACEMENT_CONSTRAINT_2      DRESP     = TOSCA_DRESP_3_DISPLACEMENT_CONSTRAINT_2      MAGNITUDE = ABS      LE_VALUE  = 0.8    END_    ``` 6. The geometrical restriction of frozen areas and demolding can be defined as follows: ```    DVCON_TOPO      ID_NAME    = DVCON_TOPO_1_FROZEN_AREA_1      EL_GROUP   = FROZEN      CHECK_TYPE = FROZEN    END_     DVCON_TOPO      ID_NAME           = DVCON_TOPO_2_DEMOLD_CONTROL_2      EL_GROUP          = ALL_ELEMENTS      CHECK_TYPE        = CAST      PULL_DIR          = 0.,0.,1.      CHECK_GROUP       = ALL_ELEMENTS      MID_PLANE         = STAMP      !MID_PLANE         = AUTO      PULL_CS           = CS_0      CREATE_PULL_GROUP = NO    END_    ``` 7. In addition, you could define constraints for the first and second eigenfrequencies from    the third load case to be above 250 and 500 Hz, respectively: ```    DRESP      ID_NAME   = DRESP_FREQ_1      TYPE      = DYN_FREQ      DEF_TYPE  = SYSTEM      LC_SET    = Modal,3,1    END_     DRESP      ID_NAME   = DRESP_FREQ_2      TYPE      = DYN_FREQ      DEF_TYPE  = SYSTEM      LC_SET    = Modal,3,2    END_     CONSTRAINT      ID_NAME   = DRESP_FREQ_1_CON      DRESP     = DRESP_FREQ_1      MAGNITUDE = ABS      GE_VALUE  = 250.0    END_     CONSTRAINT      ID_NAME   = DRESP_FREQ_2_CON      DRESP     = DRESP_FREQ_2      MAGNITUDE = ABS      GE_VALUE  = 500.0    END_    ``` 8. Activate MIMP material interpolation: ```    OPT_PARAM      ID_NAME           = MY_OPT_PARAM      OPTIMIZE          = OPTIMIZE_1_TOPOLOGY_OPTIMIZATION_SENSITIVITY      MAT_INTERPOLATION = MIMP    END_    ``` 9. Reference the Objective Function, Design Variables and constraints in the OPTIMIZE command: ```    OPTIMIZE      ID_NAME    = OPTIMIZE_1_TOPOLOGY_OPTIMIZATION_SENSITIVITY      DV         = DESIGN_AREA      OBJ_FUNC   = OBJ_FUNC_1_OBJ_FUNC_ITEM_1      DVCON      = DVCON_TOPO_1_FROZEN_AREA_1      DVCON      = DVCON_TOPO_2_DEMOLD_CONTROL_2      CONSTRAINT = DISPLACEMENT_CONSTRAINT_1      CONSTRAINT = DISPLACEMENT_CONSTRAINT_2      !CONSTRAINT = DRESP_FREQ_1_CON      !CONSTRAINT = DRESP_FREQ_2_CON    END    ```  The optimization result without the frequency constraints with stamping midplane looks as follows:       Adding the frequency constraints and changing to an auto midplane, you obtain: |
