This page discusses:   * About the Model * Procedure Summary | | |   About the Model The beam in this example is more finely meshed than in the previous example. The definition of the symmetry plane, of the symmetry point or of cyclic symmetry needs to include a reference coordinate system. This definition can be made with the CS\_DEF command. If the coordinate system is defined in the model it can be imported. The origin of the coordinate system is in the middle of the design area.
