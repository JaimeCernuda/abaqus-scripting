| |  |  | | --- | --- | | Purpose and Location of the Examples | | |  | | | |  | | --- | | This guide lists and describes examples of topology, shape, bead and sizing optimization that are provided with the installation. This page discusses:   * Purpose * Location | | |   Purpose The guide aids in creating a better understanding of the problems involved in finding a solution and also gives an understanding of the obtained solutions to the problems. The description covers the initial model with its boundary conditions and loads, as well as the most important attributes of the optimization model. The shown models usually have a low number of elements and nodes so the optimization of the examples is done and with little calculation efforts.  The examples give step-by-step instructions for Tosca Structure.gui.  Location The examples are available in the example directory of the SIMULIA Tosca Structure distribution:  ``` $<tosca>/SMATsoResources/<fe_solver>/examples/bead $<tosca>/SMATsoResources/<fe_solver>/examples/shape $<tosca>/SMATsoResources/<fe_solver>/examples/topo $<tosca>/SMATsoResources/<fe_solver>/examples/sizing $<tosca>/SMATsoResources/<life_solver>/examples/<fe_solver>/ ```  where  ``` $<tosca> = <installation_directory> ```  The parameter file of the optimization (\*.par), the analysis model for the FE analysis (\*.bdf, \*.inp, ...) and all the other required files that are important for defining the optimization problem can be found in each individual model directory. |
