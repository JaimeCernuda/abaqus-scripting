| |  |  | | --- | --- | | Solving the Temperature Load Problem | | |  | | | |  | | --- | | The present example shows that the topology optimization by Tosca Structure is also able to consider the temperature loading. This example can be done using the CAE solvers Abaqus and MSC Nastran®. This task shows you how to:   * First Approach: Minimizing the Strain Energy of Load Case 3 * Second Approach: Minimizing Global Displacement of Load Introduction Nodes Considering   load cases 1 and 2 | | |  | | --- | | See Also | | About Checking the Quality of the Optimization Result | |     First Approach: Minimizing the Strain Energy of Load Case 3 Note: If you use MSC Nastran®, you cannot define STRAIN\_ENERGY as DRESP when having temperature loading because MSC Nastran® is calculating the strain energy using a wrong principle.  1. To define the Objective Function (OBJ\_FUNC), do the following:    1. Define a Design Response (DRESP) as follows: ```       DRESP         ID_NAME    = SUM_ENERGY_LOADCASE_3         TYPE       = STRAIN_ENERGY         DEF_TYPE   = SYSTEM         LC_SET     = STATIC,3,         EL_GROUP   = ALL_ELEMENTS         GROUP_OPER = SUM       END_       ```    2. Reference the Design Response in the Objective Function (OBJ\_FUNC): ```       OBJ_FUNC         ID_NAME = TEMP_OBJ         DRESP   = SUM_ENERGY_LOADCASE_3         TARGET  = MIN       END_       ``` 2. Deactivate the AUTO\_FROZEN attribute in the OPT\_PARAM command: ```    OPT_PARAM      ID_NAME     = MY_PARAMETERS      OPTIMIZE    = TOPOLOGY_OPTIMIZATION      AUTO_FROZEN = OFF    END_    ```      This ensures that the elements attached to the nodes where the static external    load is applied are not frozen by default. 3. Do an optimization run. The result looks as follows: You see that basically all material is removed from the design domain. By removing all the material    the loading through the temperature loading is also removed. Thereby, the STRAIN\_ENERGY is    also close to zero. 4. Alternatively, you can try maximizing the strain energy as follows: ```    OBJ_FUNC      ID_NAME = TEMP_OBJ      DRESP   = STRAIN_ENERGY_LOAD_3      TARGET  = MAX    END_    ```      The result looks as follows:    You see that the structure is stiff in axial compression and the solution leads to high    reaction forces at the clamped boundary conditions and high stresses.  Second Approach: Minimizing Global Displacement of Load Introduction Nodes Considering load cases 1 and 2 The stiffness optimization aim is unclear using STRAIN\_ENERGY when having temperature loading. Consequently, you can define the stiffness optimization using displacements instead of STRAIN\_ENERGY. Secondly, the absolute displacements at the loaded nodes for load case 1 (a) and for load case 2 (b) are minimized, respectively  1. Create a Group Definition (GROUP\_DEF) for a node group as follows: ```    GROUP_DEF      ID_NAME = MY_GROUP      TYPE    = NODE      FORMAT  = LIST      LIST_BEGIN      3442,3443,3444    END_    ```      This group contains some of the nodes where the external    forces are applied. 2. Create a Design Response (DRESP) with the absolute displacements for load case 2: ```    DRESP      ID_NAME  = DISP_LOADCASE_2      TYPE     = DISP_Y_ABS      DEF_TYPE = SYSTEM      LC_SET   = STATIC,2,      ND_GROUP = MY_GROUP    END_    ``` 3. Reference the Design Response in the Objective Function (OBJ\_FUNC): ```    OBJ_FUNC      ID_NAME = TEMP_OBJ      DRESP   = DISP_LOADCASE_2      TARGET  = MIN    END_    ``` 4. Make sure that the OP\_PARAM command is not applied. 5. Make an optimization run. The result looks as follows: 6.
