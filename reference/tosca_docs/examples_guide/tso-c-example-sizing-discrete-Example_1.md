This page discusses:   * FE Model * Optimization Problem * Optimization Results | | |   FE Model The model is for the analysis of the sagging behavior of a car door. The Loads applied are, a moment load on the two hinges, which are constrained using boundary conditions and a concentrated load on the side opposite to the hinges (near the locking mechanism). The hinges and the locking area are excluded from the optimization domain. Clustering has been used to create mechanically sensible results.
