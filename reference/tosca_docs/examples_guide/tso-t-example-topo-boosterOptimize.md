| |  |  | | --- | --- | | Optimizing the Booster | | |  | | | |  | | --- | | This 2D example shows the optimization and postprocessing steps with Tosca Structure.SMOOTH. | | |   1. Define a Design Response (DRESP) for the compliance: ```    DRESP      ID_NAME    = TOSCA_DRESP_1_COMPLIANCE_TERM_1      LIST       = NO_LIST      DEF_TYPE   = SYSTEM      EL_GROUP   = ALL_ELEMENTS      TYPE       = STRAIN_ENERGY      GROUP_OPER = Sum    END_    ``` 2. Define the Objective Function (OBJ\_FUNC) with a MINMAX formulation: ```    OBJ_FUNC      ID_NAME = OBJ_FUNC_1_OBJ_FUNC_ITEM_1      TARGET  = MINMAX      DRESP   = TOSCA_DRESP_1_COMPLIANCE_TERM_1    END_    ``` 3. Define a Design Response (DRESP) for the volume: ```    DRESP      ID_NAME    = TOSCA_DRESP_2_VOLUME_CONSTRAINT_1      LIST       = NO_LIST      DEF_TYPE   = SYSTEM      EL_GROUP   = ALL_ELEMENTS      TYPE       = VOLUME      GROUP_OPER = Sum    END_    ``` 4. Define the Constraint of 30% of the initial volume: ```    CONSTRAINT      ID_NAME   = CONSTRAINT_1_VOLUME_CONSTRAINT_1      DRESP     = TOSCA_DRESP_2_VOLUME_CONSTRAINT_1      MAGNITUDE = REL      EQ_VALUE  = 0.3    END_    ``` 5. Reference the Design Variables, Objective Function and Constraints in the OPTIMIZE command: ```    OPTIMIZE      ID_NAME    = OPTIMIZE_1_TOPOLOGY_OPTIMIZATION_CONTROLLER      DV         = DESIGN_AREA      OBJ_FUNC   = OBJ_FUNC_1_OBJ_FUNC_ITEM_1      CONSTRAINT = CONSTRAINT_1_VOLUME_CONSTRAINT_1      STRATEGY   = TOPO_CONTROLLER    END_    ``` 6. Define the smooth command (SMOOTH). ```    SMOOTH      ID_NAME                = ISO_SMOOTHING_0_3      TASK                   = iso      ISO_VALUE              = 0.3      ELF_INTERSECTION_CHECK = runtime      SMOOTH_CYCLES          = 10      REDUCTION_RATE         = 100      REDUCTION_ANGEL        = 5.0      FORMAT                 = vtfx      FORMAT                 = stl      FORMAT                 = onf    END_    ```  The optimization result looks as follows: |
