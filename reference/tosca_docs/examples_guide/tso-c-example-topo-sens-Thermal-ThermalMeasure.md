This page discusses:   * About the Model * Procedure Summary | | |   About the Model The considered model is a CPU cooler for a static-thermal optimization.  The bottom section of the model represents the CPU, which is encastered and frozen during the optimization. It is subjected to a surface heat flux at the buttom and a gravity load. The convection coefficient is 0.0001 and the boundary temperature is set to 20.
