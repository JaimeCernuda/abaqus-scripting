| |  |  | | --- | --- | | Optimizing the Holeplate Model | | |  | | | |  | | --- | | This example illustrates a shape optimization of a hole in a plate placed under biaxial tension. Only a quarter of the plate is modeled because of a symmetric configuration. | | |   1. Before you define the FEM\_INPUT, fix the nodes on the symmetry edges: ```    OPTIONS     READ_BC = ALL    END_    ```      All    defined fixations in the FE model are loaded into SIMULIA Tosca Structure during    model loading. 2. To activate the fixation, create a Design Variable Constraint (DVCON\_SHAPE): ```    DVCON_SHAPE     ID_NAME  = dvcon_fix_spc     ND_GROUP = ALL_NODES     CHECK_BC = YES    END_    ```      By activating CHECK\_BC = YES all nodes of the ALL\_NODES node group,    which contain fixations in the FE model and which are in the area    MESH\_SMOOTH, are restricted in the same degrees of freedom as defined    by the fixations of the analysis model. The parameter FREE\_SF = FIX is set    in the command MESH\_SMOOTH to avoid any surface changes outside this    area.
