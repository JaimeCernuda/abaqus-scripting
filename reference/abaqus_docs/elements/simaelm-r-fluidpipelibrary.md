Nodal Coordinates Required 2D: X, Y  3D: X, Y, Z  Element Property Definition The fluid pipe elements FP2D2, FP2D2C, FP3D2, and FP3D2C are defined by two nodes, which cannot be coincident (a zero-length pipe is not allowed).  The thermal fluid pipe elements FP2D2T and FP3D2T have six nodes. Two nodes define the fluid pressure and temperature, and four nodes define the wall temperatures. The nodes that define the pipe wall are coincident with the nodes that define the pore pressure degrees of freedom.  The thermal-slurry fluid pipe elements FP2D2Q and FP3D2Q have six nodes. Two nodes define the fluid pressure, slurry, and temperature; and four nodes define the wall temperatures.The nodes that define the pipe wall are coincident with the nodes that define the pore pressure degrees of freedom.  The annular thermal fluid pipe elements FP2D2AT and FP3D2AT have eight nodes. Two nodes define the fluid pressure and temperature, and the remaining six nodes define the wall temperatures.  The annular thermal-slurry fluid pipe elements FP2D2AQ and FP3D2AQ have eight nodes. Two nodes define the fluid pressure, slurry, and temperature; and the remaining six nodes define the wall temperatures.  You must associate a fluid pipe section with a set of fluid pipe elements.
