| |  |  | | --- | --- | | Thermal Fluid Pipe Connector Elements | | |  | | | |  | | --- | | Thermal fluid pipe connector elements allow you to simulate discrete viscous pressure loss and discrete thermal loss terms in a fluid pipe network.  You can use thermal fluid pipe connector elements to simulate control valves, allowing you to reduce or increase the resistance to flow or, alternatively, to turn off the flow. Thermal fluid pipe connectors in Abaqus/Standard use a pure pressure formulation to model steady-state flow of a single-phase, incompressible fluid through a fully filled junction in a pipe network. Choosing an Appropriate Element Several thermal fluid pipe connector elements are available. They can be broadly classified as regular thermal fluid pipe connector elements or annular thermal fluid pipe connector elements. Element types FPC2D2T and FPC3D2T belong to the class of regular thermal fluid pipe connector elements. Element types FPC2D2AT and FPC3D2AT belong to the class of annular thermal fluid pipe connector elements that enable the modeling of the annulus region of a connector. For a detailed discussion of the differences between the two classes (regular versus annular) of thermal fluid pipe elements, see [Choosing an Appropriate Element](simaelm-c-thermalfluidpipe.md#simaelm-c-thermalfluidpipe-t-elemchoice1) in [Thermal Fluid Pipe Elements](simaelm-c-thermalfluidpipe.md). Similar considerations carry over for the corresponding connector elements. The nodes at each end are geometrically coincident. Even though the figures show these elements to have finite lengths, the geometric length of the connectors (based on the nodal coordinates of its two ends) is ignored in the pressure drop computations. Input File Usage  Use the following option to define an offset used to create the connector pipe wall nodes:   ``` [ELEMENT](.._SIMACAEKEYRefMap_simakey-r-element.md#simakey-r-element), OFFSET=number ```  Assigning a Material Definition to a Set of Thermal Fluid Pipe Connector Elements You must associate a material definition with each connector element section property.  The material that is defined for the thermal fluid pipe connector section refers to the fluid that is flowing through the connector. You must define the following properties for the fluid: fluid density and viscosity. For the viscosity definition, thermal fluid pipe connector elements support both Newtonian and non-Newtonian fluids. The following non-Newtonian fluid models are supported: power law, Bingham Plastic, and Herschel-Bulkley models (see [Viscosity](.._SIMACAEMATRefMap_simamat-c-viscosity.md)).  For the thermal fluid pipe connector elements, you must also specify the following thermal properties:  * Conductivity and specific heat for the fluid * Density, conductivity, and specific heat for the pipe wall  Input File Usage  Use the following options to specify the flow and thermal properties of the fluid:   ``` [FLUID PIPE CONNECTOR SECTION](.._SIMACAEKEYRefMap_simakey-r-fluidpipeconnectorsection.md#simakey-r-fluidpipeconnectorsection), MATERIAL=material name [MATERIAL](.._SIMACAEKEYRefMap_simakey-r-material.md#simakey-r-material), NAME=material name [VISCOSITY](.._SIMACAEKEYRefMap_simakey-r-viscosity.md#simakey-r-viscosity), DEFINITION=NEWTONIAN or POWER LAW or HERSCHEL-BULKLEY or BINGHAM PLASTIC [DENSITY](.._SIMACAEKEYRefMap_simakey-r-density.md#simakey-r-density), PORE FLUID [CONDUCTIVITY](.._SIMACAEKEYRefMap_simakey-r-conductivity.md#simakey-r-conductivity), PORE FLUID [SPECIFIC HEAT](.._SIMACAEKEYRefMap_simakey-r-specificheat.md#simakey-r-specificheat), PORE FLUID ```   In addition, use the following options to specify the thermal properties for the pipe wall connector:   ``` [DENSITY](.._SIMACAEKEYRefMap_simakey-r-density.md#simakey-r-density) [CONDUCTIVITY](.._SIMACAEKEYRefMap_simakey-r-conductivity.md#simakey-r-conductivity) [SPECIFIC HEAT](.._SIMACAEKEYRefMap_simakey-r-specificheat.md#simakey-r-specificheat) ```  Multiple Fluid Flow Abaqus allows the use of multiple fluids in an analysis, up to a maximum of four fluid types. This capability is useful in situations where the spatial distribution of the different fluid types is known (that is, precomputed) at all times during the analysis. In other words, the type of fluid at each node in the domain is known at all times during the analysis.  The definition of multiple fluids in an analysis involves associating each fluid with a unique integer and a specific predefined field variable. This integer acts as a fluid identifier. You can utilize this fluid identifier to specify the properties (for example, viscosity) of each fluid. The field variable associated with a fluid type allows you to predefine the fluid type at a node as a function of time using amplitude definitions, or as functions of both time and space utilizing user subroutine [UFIELD](.._SIMACAESUBRefMap_simasub-c-ufield.md) or [USDFLD](.._SIMACAESUBRefMap_simasub-c-usdfld.md).  You specify a value for each field variable, which is associated with a fluid identifier, at each node. It is recommended that you specify a value for the field variable (   F V ) such that,    0.0 ≤ F V ≤ 1.0 . Abaqus assigns the fluid type at an integration point to be the one for which the field variable has the maximum value at that point. If all field variables have the same numerical value at an integration point, the first fluid (fluid identifer 1) is assumed to be active.  Input File Usage   ``` [VISCOSITY](.._SIMACAEKEYRefMap_simakey-r-viscosity.md#simakey-r-viscosity), FLUID ID=Fluid Id number, DEFINITION=NEWTONIAN or POWER LAW or HERSCHEL-BULKLEY or BINGHAM PLASTIC [FLUID ID FIELD](.._SIMACAEKEYRefMap_simakey-r-fluididfield.md#simakey-r-fluididfield) Fluid Id number, field_id ```  Thermal Fluid Pipe Connector Equations The main governing equations for the fluid flow and pressure loss can be found in [Fluid Pipe Connector Equations](simaelm-c-fluidpipeconnector.md#simaelm-c-fluidpipeconnector-t-FluidPipeConnectorEquations-sma-topic2). The different options of defining discrete pressure loss can be found in [Specifying the Fluid Pipe Connector Geometry and Connector Loss](simaelm-c-fluidpipeconnector.md#simaelm-c-fluidpipeconnector-t-SpecifyingTheFluidPipeConnectorGeometryAndConnectorLoss-sma-topic3). You can also define a control valve behavior in thermal fluid pipe connector elements as described in [Specifying the Control Valve Behavior](simaelm-c-fluidpipeconnector.md#simaelm-c-fluidpipeconnector-t-SpecifyingTheControlValveBehavior-sma-topic7).  Specifying the Wall Diameters for Thermal Fluid Pipe Connector Elements You must define the geometry of the connector wall as a circular cross-section by specifying the inner and outer wall radii.  Input File Usage   ``` [FLUID PIPE CONNECTOR WALL](.._SIMACAEKEYRefMap_simakey-r-fluidpipeconnectorwall.md#simakey-r-fluidpipeconnectorwall) ```  Specifying the Thermal Loss in the Fluid You can define the thermal loss due to the fluid flow in the thermal fluid pipe connector elements.  Input File Usage   ``` [FLUID PIPE CONNECTOR THERMAL LOSS](.._SIMACAEKEYRefMap_simakey-r-fluidpipeconnectorthermalloss.md#simakey-r-fluidpipeconnectorthermalloss) ```  Specifying Initial and Prescribed Conditions You can define an initial temperature or field distribution over the nodes of the thermal fluid pipe connector elements.  Input File Usage  Use one or both of the following options:   ``` [INITIAL CONDITIONS](.._SIMACAEKEYRefMap_simakey-r-initialconditions.md#simakey-r-initialconditions), TYPE=TEMPERATURE [INITIAL CONDITIONS](.._SIMACAEKEYRefMap_simakey-r-initialconditions.md#simakey-r-initialconditions), TYPE=FIELD ```  Specifying Loads and Boundary Conditions Thermal fluid pipe connector elements allow for the specification of pressure boundary conditions and volumetric flow rates at the nodes. The flow rate must be a nonzero value. At a particular node, you can specify either a pressure or flow rate but not both. Because the thermal fluid pipe connector elements do not use the geometric length in the fluid equilibrium equations, gravity loads are not supported for these elements. You can specify boundary conditions on the temperature degree of freedom.  Input File Usage  Use the following option to specify the pressure at the inlet or outlet:   ``` [BOUNDARY](.._SIMACAEKEYRefMap_simakey-r-boundary.md#simakey-r-boundary) node or node set, 8, 8, magnitude ```   Use the following option to specify the flow rate at the inlet or outlet:   ``` [CFLOW](.._SIMACAEKEYRefMap_simakey-r-cflow.md#simakey-r-cflow) node or node set, , magnitude ```   Use the following option to specify the temperature at the inlet or outlet:   ``` [BOUNDARY](.._SIMACAEKEYRefMap_simakey-r-boundary.md#simakey-r-boundary) node or node set, 11, 11, magnitude ``` |
