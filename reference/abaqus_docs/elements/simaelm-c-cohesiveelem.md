However, for pore pressure, coupled thermal pore-pressure, and coupled slurry-thermal-pore pressure cohesive elements , there is an additional layer of nodes on the element’s middle face. For example, COH2D4P is a 6-node element, with four corner nodes and two additional nodes along the middle face. For pore pressure cohesive elements that model the transition from Darcy flow to Poiseuille flow, the first three letters for the elements' names are changed to COD.
