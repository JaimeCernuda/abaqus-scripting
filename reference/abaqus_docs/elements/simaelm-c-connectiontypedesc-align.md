Connection type ALIGN.   The ALIGN connection imposes kinematic constraints only. The local directions at node b are set equal to those at node a. If the local directions do not align initially, the ALIGN connection holds fixed the Cardan angles between the local orientation directions at node b,    {   e 1 b ,  e 2 b ,  e 3 b } , and those at node a,    {   e 1 a ,  e 2 a ,  e 3 a } . These fixed angular positions are the connector position output quantities. See connection type [CARDAN](simaelm-c-connectiontypedesc-cardan.md) for a definition of Cardan angles and for the constraint moment if the local directions do not align.  The constraint moment enforcing the alignment of the local directions is  m¯=m1⁢e1a+m2⁢e2a+m3⁢e3a.  In two-dimensional analysis m1=m2=0.
