Nodal Coordinates Required 2D: X, Y  3D: X, Y, Z  Element Property Definition The fluid pipe connector elements FPC2D2, FPC2D2C, FPC3D2, and FPC3D2C are defined by two nodes that can be coincident. If the nodes are not coincident, the length of the fluid pipe connector element is ignored in the viscous loss computations.  The thermal fluid pipe connector elements FPC2D2T and FPC3D2T have six nodes. Two nodes define the fluid pressure and temperature, and four nodes define the wall temperatures.The nodes that define the pipe wall are coincident with the nodes that define the pore pressure degrees of freedom.  The thermal-slurry fluid pipe connector elements FPC2D2Q and FPC3D2Q have six nodes. Two nodes define the fluid pressure, temperature, and slurry; and four nodes define the wall temperatures. The nodes that define the pipe wall are coincident with the nodes that define the pore pressure degrees of freedom.  The annular thermal fluid pipe connector elements FPC2D2AT and FPC3D2AT have eight nodes. Two nodes define the fluid pressure and temperature, and the remaining six nodes define the wall temperatures.  The annular thermal-slurry fluid pipe connector elements FPC2D2AQ and FPC3D2AQ have eight nodes. Two nodes define the fluid pressure, slurry, and temperature; and the remaining six nodes define the wall temperatures.  You must associate a fluid pipe connector section with a set of fluid pipe connector elements.
