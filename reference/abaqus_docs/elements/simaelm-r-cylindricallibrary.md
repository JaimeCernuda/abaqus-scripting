Element Output Output is in a fixed cylindrical system (1=radial, 2=axial, 3=circumferential) unless a local coordinate system is assigned to the element through the section definition ([Orientations](.._SIMACAEMODRefMap_simamod-c-orientation.md)) in which case output is in the local coordinate system (which rotates with the motion in large-displacement analysis). See [State storage](.._SIMACAETHERefMap_simathe-c-statestorage.md) for details.  Stress, Strain, and Other Tensor Components Stress and other tensors (including strain tensors) are available for elements with displacement degrees of freedom. All tensors have the same components. For example, the stress components are as follows:  S11  Local 11 direct stress.  S22  Local 22 direct stress.  S33  Local 33 direct stress.  S12  Local 12 shear stress.  S13  Local 13 shear stress.  S23  Local 23 shear stress.
