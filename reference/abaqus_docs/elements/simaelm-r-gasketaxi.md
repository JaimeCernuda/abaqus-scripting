Additional Solution Variables None.  Nodal Coordinates Required X , Y  Element Property Definition You must define the element's initial gap and initial void. In addition, for link elements you must define the element's width.  You can specify the thickness direction as part of the gasket section definition or by specifying a normal direction at the nodes; you can specify the element thickness as part of the gasket section definition. Otherwise, Abaqus/Standard will calculate the thickness direction and the thickness. For link elements the thickness direction is the direction from the first to the second node and the thickness is the distance between the nodes. For general elements the thickness direction is based on the midsurface of the element and the thicknesses at the integration points are based on the nodal positions. See [Defining the Gasket Element's Initial Geometry](simaelm-c-gasketinit.md) for more details.
