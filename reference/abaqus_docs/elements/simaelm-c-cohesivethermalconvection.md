| |  |  | | --- | --- | | Defining Thermal Convection for a Cohesive Element | | |  | | | |  | | --- | | You can define convective heat transfer with gap flow as well as thermal convection between the gap fluid and both the top and bottom surfaces of a coupled temperature-pore pressure cohesive element.  Thermal convection modeling using coupled temperature-pore pressure cohesive elements:   * can be performed in coupled pore fluid   diffusion/stress analyses ([Coupled Pore Fluid Diffusion and Stress Analysis](.._SIMACAEANLRefMap_simaanl-c-coupdiffstress.md#simaanl-c-coupdiffstress)); * can also involve convective heat transfer between   the gap fluid and both the top and bottom surfaces of a cohesive element; and * can be specified by a   material model. The energy equation is given by:  ρfcf(dθ),t+ρfcf∇⋅(dqθ)−∇⋅(dk∇θ)−ρfcf[ct(pi−pt)+cb(pi−pb)]−h(θ−θt)−h(θ−θb)=0,  where  ρf  is the fluid density,  cf  is the specific heat of the fluid,  k  is the conductivity of the fluid,  h  is the heat convection coefficient,  θ  is the temperature of the gap flow,  θt  is the temperature on the top surface, and  θb  is the temperature on the bottom surface. All of the other variables (such as q, d, pi, pt, pb, ct, and cb) are defined in [Defining the Constitutive Response of Fluid Transitioning from Darcy Flow to Poiseuille Flow](simaelm-c-cohesivefluidbehaviordarcy.md#simaelm-c-cohesivefluidbehaviordarcy).  Specifying Fluid Density You can define the gap fluid density.  Input File Usage   ``` [DENSITY](.._SIMACAEKEYRefMap_simakey-r-density.md#simakey-r-density), PORE FLUID ```   Abaqus/CAE Usage  Specifying the gap fluid density is not supported in Abaqus/CAE.  Specifying Specific Heat of the Fluid You can define the specific heat of the pore fluid in a porous medium.  Input File Usage   ``` [SPECIFIC HEAT](.._SIMACAEKEYRefMap_simakey-r-specificheat.md#simakey-r-specificheat), PORE FLUID ```   Abaqus/CAE Usage  Specifying the specific heat of the pore fluid in a porous medium is not supported in Abaqus/CAE.  Specifying Conductivity of the Fluid You can define the conductivity of the pore fluid in a porous medium.  Input File Usage   ``` [CONDUCTIVITY](.._SIMACAEKEYRefMap_simakey-r-conductivity.md#simakey-r-conductivity), PORE FLUID ```   Abaqus/CAE Usage  Specifying the conductivity of the pore fluid in a porous medium is not supported in Abaqus/CAE.  Specifying Heat Convection between the Fluid and Both the Top and Bottom Surfaces The heat convection coefficient is defined as  h=Nu2kd,  where Nu is the Nusselt number. You can specify the Nusselt number as a function of temperature and field variables.  Input File Usage  Use the following option to define a constant flux solution for convective heat transfer (Nu=8.235):   ``` [GAP CONVECTION](.._SIMACAEKEYRefMap_simakey-r-gapconvection.md#simakey-r-gapconvection), TYPE=FLUX ```   Use the following option to define a constant temperature solution for convective heat transfer (Nu=7.54):   ``` [GAP CONVECTION](.._SIMACAEKEYRefMap_simakey-r-gapconvection.md#simakey-r-gapconvection), TYPE=TEMPERATURE ```   Use the following option to specify the Nusselt number as a function of temperature and/or field variables:   ``` [GAP CONVECTION](.._SIMACAEKEYRefMap_simakey-r-gapconvection.md#simakey-r-gapconvection), TYPE=TABULAR ```   Abaqus/CAE Usage   ``` Property module: material editor: OtherPore FluidGap Convection: Type: FLUX, TEMPERATURE, or TABULAR ``` |
