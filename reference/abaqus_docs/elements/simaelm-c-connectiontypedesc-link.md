Connection type LINK.   The LINK connection constrains the position of node b, xb, to a constant distance from node a. The distance between the two nodes is  l=∥xb-xa∥  and is constant. The constraint force in the LINK connection acts along the line connecting the two nodes and is  f¯=f1⁢q,    where    q=1∥xb-xa∥⁢(xb-xa).
