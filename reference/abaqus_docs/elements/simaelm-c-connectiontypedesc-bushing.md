Connection type BUSHING.     Connection type BUSHING does not constrain any components of relative motion and uses local orientation definitions equivalent to combining connection types PROJECTION CARTESIAN and PROJECTION FLEXION-TORSION.  Limitation In Abaqus/Explicit, if the total flexion angle vanishes, connector motion cannot be applied to the flexion component of motion.
