Nodal Coordinates Required X, Y, Z required at each node and, optionally, Nx, Ny, Nz (direction cosines of the normal to the shell) at each node.  A user-defined normal definition (see [Normal Definitions at Nodes](.._SIMACAEMODRefMap_simamod-c-nodalnormals.md)) can also be used to specify Nx, Ny, Nz. If these are not specified, they are constructed as for all other shell elements—by averaging over the shell elements attached to each node.  Element Property Definition The only element property used is the thickness; the number of integration points is ignored, since the elements work on the basis of section properties. Element Output Nodes 1, 2, and 3 on the element define side B and nodes 4, 5, and 6 define side A (see [Figure 1](simaelm-r-linespringlibrary.md#simaelm-r-linespringlibrary-t-ldquoStrainsrdquo-subelemoutput1__simaelm-r-elinespring-strain-not)). The sign of the crack is defined by the surface of the shell from which the crack originates, which you identify when you define the depth of the crack (see [Line Spring Elements for Modeling Part-through Cracks in Shells](simaelm-c-linespring.md)). If the crack originates from the positive surface of the shell, sign(crack)=1.0; if the crack originates from the negative surface of the shell, sign(crack)=−1.0.  The vector q is defined by the right-hand rule from the cross product of the tangent, t, which is positive going from node 1 to node 3 of the element, and the normal, n, defined when the coordinates are given (or by a user-defined normal definition). For element type LS3S the vector q must point into the model (away from the symmetry plane). For element type LS6 the vector q must point from side A to side B.  “Strains” E11  Mode I opening displacement, (uB-uA)⋅q¯  E22  Mode I opening rotation, (ϕB-ϕA)⋅t×s⁢i⁢g⁢n⁢(crack)  The following strains exist only for LS6:  E33  Mode II through thickness shear, (uB-uA)⋅n  E12  Mode II rotation, (ϕB-ϕA)⋅n (this strain plays no role)  E13  Mode III antiplane shear, (uB-uA)⋅t×s⁢i⁢g⁢n⁢(crack)  E23  Mode III opening rotation, (ϕB-ϕA)⋅q  The conjugate forces and moments are available by requesting “stress” output.  The J-integral is provided at each integration point. If elastic-plastic material behavior is defined, the elastic and plastic parts of J are provided.
