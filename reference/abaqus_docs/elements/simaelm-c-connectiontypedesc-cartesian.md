Connection type CARTESIAN.   The CARTESIAN connection does not impose kinematic constraints. It defines three local directions {e1a,e2a,e3a} at node a and measures the change in position of node b along these local coordinate directions. The local directions at node a follow the rotation of node a.  The position of node b relative to node a is  x=e1a⋅(xb-xa);    y=e2a⋅(xb-xa);    and    z=e3a⋅(xb-xa).  The available components of relative motion are  u1=x-x0;    u2=y-y0;    and    u3=z-z0;  where x0, y0, and z0 are the initial coordinates of node b relative to the local coordinate system at node a. The connector constitutive displacements are  u1m⁢a⁢t=x-l1r⁢e⁢f;    u2m⁢a⁢t=y-l2r⁢e⁢f;    and    u3m⁢a⁢t=z-l3r⁢e⁢f.  The kinetic force is  fC⁢a⁢r⁢t=f1⁢e1a+f2⁢e2a+f3⁢e3a.  In two-dimensional analysis z=0, u3=0, u3m⁢a⁢t=0, and f3=0.
