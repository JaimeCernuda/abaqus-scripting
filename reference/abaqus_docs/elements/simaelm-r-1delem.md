They are specified as described in [Thermal Loads](.._SIMACAEPRCRefMap_simaprc-c-thermal.md). \*dflux  1. Load ID (\*DFLUX): BF 2. Body heat flux 3. JL−3 T−1 4. Heat body flux per unit volume.  1. Load ID (\*DFLUX): BFNU 2. Body heat flux 3. JL−3 T−1 4. Nonuniform heat body flux per unit volume with magnitude supplied via user subroutine [DFLUX](.._SIMACAESUBRefMap_simasub-c-dflux.md#simasub-c-dflux).  1. Load ID (\*DFLUX): S1 2. Surface heat flux 3. JL−2 T−1 4. Heat surface flux per unit area into the first end of the link (node 1).  1. Load ID (\*DFLUX): S2 2. Surface heat flux 3. JL−2 T−1 4. Heat surface flux per unit area into the second end of the link (node 2 or node 3).  1. Load ID (\*DFLUX): S1NU 2. Not supported 3. JL−2 T−1 4. Nonuniform heat surface flux per unit area into the first end of the link (node 1) with magnitude supplied via user subroutine [DFLUX](.._SIMACAESUBRefMap_simasub-c-dflux.md#simasub-c-dflux).  1. Load ID (\*DFLUX): S2NU 2. Not supported 3. JL−2 T−1 4. Nonuniform heat surface flux per unit area into the second end of the link (node 2 or node 3) with magnitude supplied via user subroutine [DFLUX](.._SIMACAESUBRefMap_simasub-c-dflux.md#simasub-c-dflux).  Film Conditions Film conditions are available for elements with temperature degrees of freedom. They are specified as described in [Thermal Loads](.._SIMACAEPRCRefMap_simaprc-c-thermal.md). \*film  1. Load ID (\*FILM): F1 2. Not supported 3. JL−2T−1θ−1 4. Film coefficient and sink temperature (units of θ) at the first end of the link (node 1).  1. Load ID (\*FILM): F2 2. Not supported 3. JL−2T−1θ−1 4. Film coefficient and sink temperature (units of θ) at the second end of the link (node 2 or node 3).  1. Load ID (\*FILM): F1NU 2. Not supported 3. JL−2T−1θ−1 4. Nonuniform film coefficient and sink temperature (units of θ) at the first end of the link (node 1) with magnitude supplied via user subroutine [FILM](.._SIMACAESUBRefMap_simasub-c-film.md#simasub-c-film).  1. Load ID (\*FILM): F2NU 2. Not supported 3. JL−2T−1θ−1 4. Nonuniform film coefficient and sink temperature (units of θ) at the second end of the link (node 2 or node 3) with magnitude supplied via user subroutine [FILM](.._SIMACAESUBRefMap_simasub-c-film.md#simasub-c-film).  Radiation Types Radiation conditions are available for elements with temperature degrees of freedom. They are specified as described in [Thermal Loads](.._SIMACAEPRCRefMap_simaprc-c-thermal.md). \*radiate  1. Load ID (\*RADIATE): R1 2. Surface radiation 3. Dimensionless 4. Emissivity and sink temperature (units of θ) at the first end of the link (node 1).  1. Load ID (\*RADIATE): R2 2. Surface radiation 3. Dimensionless 4. Emissivity and sink temperature (units of θ) at the second end of the link (node 2 or node 3).  Distributed Impedances Distributed impedances are available for elements with acoustic pressure degrees of freedom. They are specified as described in [Acoustic and Shock Loads](.._SIMACAEPRCRefMap_simaprc-c-acoustic.md). \*impedance  1. Load ID (\*IMPEDANCE): I1 2. Not supported 3. None 4. Name of the impedance property that defines the impedance at the first end of the link (node 1).  1. Load ID (\*IMPEDANCE): I2 2. Not supported 3. None 4. Name of the impedance property that defines the impedance at the second end of the link (node 2 or node 3).  Distributed Electric Current Densities Distributed electric current densities are available for coupled thermal-electrical elements. They are specified as described in [Coupled Thermal-Electrical Analysis](.._SIMACAEANLRefMap_simaanl-c-jouleheating.md). \*decurrent  1. Load ID (\*DECURRENT): CBF 2. Body current 3. CL−3T−1 4. Volumetric current source density.  1. Load ID (\*DECURRENT): CS1 2. Surface current 3. CL−2T−1 4. Current density at the first end of the link (node 1).  1. Load ID (\*DECURRENT): CS2 2. Surface current 3. CL−2T−1 4. Current density at the second end of the link (node 2 or node 3).  Element Output Heat Flux Components Available for elements with temperature degrees of freedom. Electrical Current Density Components Available for coupled thermal-electrical elements.  ECD1  Electrical current density along the element axis.
