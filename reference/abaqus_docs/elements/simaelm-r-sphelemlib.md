Element Output Output is in global directions unless a local coordinate system is assigned to the element through the section definition ([Orientations](.._SIMACAEMODRefMap_simamod-c-orientation.md)), in which case output is in the local coordinate system (which rotates with the motion in large-displacement analysis). S13  X⁢Z, shear stress.  S23  Y⁢Z, shear stress.  Note: the order shown above is not the same as that used in user subroutine [VUMAT](.._SIMACAESUBRefMap_simasub-c-vumat.md#simasub-c-vumat).
