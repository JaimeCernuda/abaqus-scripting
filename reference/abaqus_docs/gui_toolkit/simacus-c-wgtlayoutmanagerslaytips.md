# Tips for specifying layout hints

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Tips for specifying layout hints | | |  | | | |  | | --- | | This section provides tips for specifying layout hints supported by the layout managers in the Abaqus GUI Toolkit. | | |   * Do not over specify layout hints. In many cases the default values are   what you want, and you do not need to specify the hints. * Think in terms of simple rows and columns, and use horizontal or vertical   frames whenever possible. * To avoid building up excessive padding, set the padding to zero in nested   layout managers. * Layout hints are described in detail in   [Layout hints](simacus-c-apxlayouthints.md). |
