| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Editing | | |  | | | |  | | --- | | By default, no items in a table are editable. To make all items in a table editable, you must specify AFXTABLE\_EDITABLE in the table constructor. | | |   To change the editability of some items in a table, you can use the following table methods:   * setColumnEditable(column, True|False) * setItemEditable(row, column, True|False) |
