# Selection options

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Selection options | | |  | | | |  | | --- | | The  Selection Options dialog box is automatically available in any pick step. | | |   The available options in the Selection Options dialog box are automatically configured, based on the types of entities that the user is picking. For example, if the user is picking only faces, only  Faces appears in the combo box in the dialog box. Similarly, if the user is picking a single entity, the drag shape and drag scope buttons are not available. As a result, procedures generally do not need to set the available selection options explicitly. If you need to set these options, you can use the procedure's setSelectionOptions method. You must set the procedure selection options prior to creating the first pick step. For more information, see the [Abaqus GUI Toolkit Reference Guide](.._SIMACAEGUIRefHtml_simagui-c-ov.md).  Normally a procedure will set these options only at the start of the procedure. However, during the procedure the user may change the settings, and the modified settings will be retained from step to step during the rest of the procedure. |
