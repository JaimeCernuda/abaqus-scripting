| |  |  | | --- | --- | | About the Results File | | |  | | | |  | | --- | | The Abaqus results file is the medium through which analysis results can be carried over into other software, such as postprocessing programs.  This page discusses:   * [Writing Information to the Results File](#simaout-c-resultsover-t-WritingInformationToTheResultsFile-sma-topic1) * [Accessing Information in the Results File](#simaout-c-resultsover-t-AccessingInformationInTheResultsFile-sma-topic2) | | |     Writing Information to the Results File The following types of output can be written to the results file:   * element output, nodal output, energy output, modal output, contact   surface output, and section output (see   [Output to the Data and Results Files](simaout-c-printfile.md)) * element matrix output (see   [Element Matrix Output in Abaqus/Standard](simaout-c-output.md#simaout-c-output-elemmatrix)) * substructure matrix output (see   [Writing the Recovery Matrix, Reduced Stiffness Matrix, Mass Matrix, Load Case Vectors, and Gravity Vectors to a File](.._SIMACAEANLRefMap_simaanl-c-superelementdef.md#simaanl-c-superelementdef-output)) * cavity radiation view factor matrices (see   [Writing the View Factor Matrices to the Results File](.._SIMACAEITNRefMap_simaitn-c-cavityradiation.md#simaitn-c-cavityradiation-viewfactoroutput))   [About Output](simaout-c-output.md) describes the general format of the results file.  An Abaqus model can be defined in terms of an assembly of part instances (see [Assembly Definition](.._SIMACAEMODRefMap_simamod-c-partassy.md)). However, the results file is not organized by part; it contains internal node and element numbers (see [About Output](simaout-c-output.md)). A map between the original numbers and part instance names and the internal numbers is written to the data file.  Accessing Information in the Results File This chapter contains technical descriptions of the results file and is intended to be read by users or programmers who need to write programs that use the results file.   * [Results File](simaout-c-format.md)   describes the format of the individual records in the results file. * [Accessing the Results File Information](simaout-c-accessinfo.md)   describes the subroutine calls required to read the file output, contains an   example of a program written to use the   Abaqus   results file, and shows how you can write (or modify) a results file using the   Abaqus   file format. * [Utility Routines for Accessing the Results File](simaout-c-results.md)   describes the utility subroutines that can be used to access the results file. |
