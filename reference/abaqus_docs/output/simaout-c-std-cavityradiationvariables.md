RADFL  Field: yes  History: yes  .fil: yes  .dat: yes   Radiation flux per unit area.  RADFLA  Field: yes  History: yes  .fil: yes  .dat: yes   Radiation flux over the facet.  RADTL  Field: yes  History: yes  .fil: yes  .dat: yes   Time integrated radiation per unit area.  RADTLA  Field: yes  History: yes  .fil: yes  .dat: yes   Time integrated radiation over the facet.
