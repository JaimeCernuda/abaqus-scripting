Record Format: Records Written for Any Section File Output Request 1580 Output request definition  1. Surface    section output (1). 2. Section name.  1581 Section output header record  1. Surface name. 2. System of coordinates used for    output (1–Global, 2–Local). 3. Flag to indicate whether or    not the local coordinate system and the output are updated during the analysis    (1–Yes, 2–No).  For All Analysis Types The following two records are generated only when section output is requested in a local coordinate system. In that case all components of forces and moments are given with respect to the local system. Only the first two directions of the local coordinate system are given; if needed, the third direction can be calculated as the cross product of the first two. 1582Global coordinates of the anchor point  1. First    coordinate. 2. Etc.  1583 Direction cosines of the local coordinate system  1. First component of the first direction. 2. Second component of the first direction. 3. Third component of the first direction. 4. First    component of the second direction. 5. Second component of    the second direction. 6. Third component of the second    direction.  1584 SOAREA Area of the defined section  1. Magnitude.  For Stress/Displacement Analyses 1585 SOF Total force in the section in the selected system  1. Magnitude. 2. First force component. 3. Etc.  1586 SOM Total moment in the section about the origin of the selected system  1. Magnitude. 2. First moment component. 3. Etc.  1587 SOCF Global coordinates of the center of the total force in the section   1. First coordinate. 2. Etc.  For Heat Transfer Analyses 1588 SOH Total heat flux across the section  1. Magnitude.  For Electrical Analyses 1589 SOE Total current across the section  1. Magnitude.  For Mass Diffusion Analyses 1590 SOD Total mass flow across the section  1. Magnitude.  For Coupled Pore Fluid Diffusion-Stress Analyses For coupled analyses the appropriate combination of records is available. For example, in a thermal-electrical analysis both SOH and SOE are valid output requests. 1591 SOP Total pore fluid volume flux across the section  1. Magnitude. |
