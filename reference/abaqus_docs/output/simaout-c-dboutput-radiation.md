Input File Usage   ``` [RADIATION OUTPUT](.._SIMACAEKEYRefMap_simakey-r-radiationoutput.md#simakey-r-radiationoutput) list of output variables ```  Selecting the Region of the Model for Which Radiation Output Is Required You can specify the cavity, element set, or surface for which radiation output is required. Each radiation output request can apply to only one type of region. If you do not specify a region of the model, radiation variables are output for all the cavities in the model.  Input File Usage  Use one of the following options:   ``` [RADIATION OUTPUT](.._SIMACAEKEYRefMap_simakey-r-radiationoutput.md#simakey-r-radiationoutput), CAVITY=cavity_name [RADIATION OUTPUT](.._SIMACAEKEYRefMap_simakey-r-radiationoutput.md#simakey-r-radiationoutput), ELSET=element_set_name [RADIATION OUTPUT](.._SIMACAEKEYRefMap_simakey-r-radiationoutput.md#simakey-r-radiationoutput), SURFACE=surface_name ```  Controlling the Output Frequency The frequency of radiation output is controlled as described in [Controlling the Frequency of Output to the Output Database](simaout-c-dboutput-frequency.md#simaout-c-dboutput-frequency).  Requesting Output You can request all radiation variables applicable to the current procedure. In this case any additional variables you specify are ignored.  Input File Usage   ``` [RADIATION OUTPUT](.._SIMACAEKEYRefMap_simakey-r-radiationoutput.md#simakey-r-radiationoutput), VARIABLE=ALL ``` |
