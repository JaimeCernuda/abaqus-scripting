This page discusses:   * [Parameter Table Type Definition](#sma-topic_68BB47D747FB4852AE53950E649B6B1A) * [Parameters](#sma-topic_9E22FD1EBDF04BC2B25B111A05E4F9C9) | | |  | | --- | | See Also | | [Coupled Thermal-Electrochemical Analysis](simaanl-c-coupthermalelecchem.md) | |   Products Abaqus/Standard  You must include a parameter table of type `"ABQ_EChemPET_Electrode_Particles"` in the material definition to specify a particle name and additional particle information. The particle name must be unique and is used in the labels of subsequent particle-specific material definitions. If you have multiple particles in a region, you can repeat the parameter table data lines.
