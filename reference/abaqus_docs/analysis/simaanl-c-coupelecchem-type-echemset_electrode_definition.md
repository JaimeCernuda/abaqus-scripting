| |  |  | | --- | --- | | ABQ\_EChemSET\_Electrode\_Definition | | |  | | | |  | | --- | | This parameter table type is used in modeling the solid state batteries with solid electrolytes to specify the material data for the electrode region.  This page discusses:   * [Parameter Table Type Definition](#simaanl-c-coupelecchem-type-echemset_electrode_definition-def) * [Parameters](#simaanl-c-coupelecchem-type-echemset_electrode_definition-param) | | |  | | --- | | See Also | | [Modeling Solid Electrolytes and Solid-State Batteries](simaanl-c-modelingsolidelectrolyte-batteries.md) | |   Products Abaqus/Standard  You must include a parameter table of type `"ABQ_EChemSET_Electrode_Definition"` in the material definition to specify the material data for the electrode region. The region name must be unique and is used in the labels of subsequent electrode material property definitions.    Parameter Table Type Definition ``` [PARAMETER TABLE TYPE](.._SIMACAEKEYRefMap_simakey-r-parametertabletype.md#simakey-r-parametertabletype), NAME="ABQ_EChemSET_Electrode_Definition", PARAMETERS=3  STRING, "  ", "Region Name", , ,  STRING, "  ", "Region Type", , "Anode|Cathode|Separator",  FLOAT, 0.0, "Unused", , , ```  Parameters Region Name  Unique name to identify the electrode region.  Region Type  Set to `“Anode”` to specify that the material definitions are for the anode region.  Set to `“Cathode”` to specify that the material definitions are for the cathode region.  Set to `“Separator”` to specify that the material definitions are for the separator region. |
