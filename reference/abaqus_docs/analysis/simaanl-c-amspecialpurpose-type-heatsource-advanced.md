If a table of this type is not present, default values are used. However, if a table is present, all fields must be explicitly defined. No field should be left blank.    Parameter Table Type Definition ``` [PARAMETER TABLE TYPE](.._SIMACAEKEYRefMap_simakey-r-parametertabletype.md#simakey-r-parametertabletype), NAME="ABQ_AM_MovingHeatSource_Advanced", PARAMETERS=7  STRING, "False", "Conserve Total Energy", , "True|False",  STRING, "False" , "Control Increment Size", , "True|False",  STRING, "Relative", "Offset Type", , "Absolute|Relative",  FLOAT , 0.0, "VectorX", , ,  FLOAT , 0.0, "VectorY", , ,  FLOAT , -1.0, "VectorZ", ,  FLOAT , 1.0, "Field Factor", , , ```  Parameters For reference, see [Figure 1](simaanl-c-amtoolpathmeshintersect-box-toolpath.md#simaanl-c-amtoolpathmeshintersect-box-toolpath-subsegment__fig-am-box-toolpath) in [Box Toolpath-Mesh Intersection](simaanl-c-amtoolpathmeshintersect-box-toolpath.md#simaanl-c-amtoolpathmeshintersect-box-toolpath).  Conserve Total Energy  Set to `“True”` to indicate that if part of the energy distribution along a path segment is outside the external mesh boundary, the power of the part of the energy distribution that is inside the mesh boundary is proportionally increased to keep the total energy conserved. If set to `“False”`, part of the energy distribution along a path segment outside the external mesh boundary is lost. Default value is `“False”`.  Control Increment Size  Unused. Should be set to `“False”`.  Offset Type  Set to `“Relative”` to indicate that the components of the offset vector defined in the table `"ABQ_AM_MovingHeatSource_Uniform"` are in terms of half of the box lengths in the local x-l, yl-, and zl-directions, respectively. Set to `“Absolute”` to indicate that the offset values are absolute.  VectorX  Global x-component of the local      z  1  vector for the box shape.  VectorY  Global y-component of the local      z  1  vector for the box shape.  VectorZ  Global z-component of the local      z  1  vector for the box shape.  Field Factor  Scaling factor that is multiplied to the first field of the event series. Default value is one. Only used if the energy distribution type is set to `“Goldak”` or `“Uniform”`. |
