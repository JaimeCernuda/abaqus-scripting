You must associate the inflator definition with a name. You specify the reference node of the fluid cavity that the inflator will fill with gas. A single fluid cavity can have any number of inflators.  Input File Usage   ``` [FLUID INFLATOR](.._SIMACAEKEYRefMap_simakey-r-fluidinflator.md#simakey-r-fluidinflator), NAME=name fluid_cavity_reference_node ```   Abaqus/CAE Usage   ``` Interaction module: Create Interaction: Fluid inflator, Name: name; Fluid cavity interaction: name ```   Input File Usage   ``` [FLUID INFLATOR](.._SIMACAEKEYRefMap_simakey-r-fluidinflator.md#simakey-r-fluidinflator), TYPE=COMBINED fluid_cavity_reference_node, Eulerian_material_instance inflator_nodes ```  Defining the Inflator Property The inflator property defines the mass flow rate and temperature as a function of inflation time either directly or by entering tank test data. It also defines the mixture of gases entering the fluid cavity. You must associate the inflator property with a name. This name can then be used to associate a certain property with an inflator definition.  Input File Usage  Use the following options:   ``` [FLUID INFLATOR](.._SIMACAEKEYRefMap_simakey-r-fluidinflator.md#simakey-r-fluidinflator), NAME=fluid_inflator_name, PROPERTY=property_name [FLUID INFLATOR PROPERTY](.._SIMACAEKEYRefMap_simakey-r-fluidinflatorproperty.md#simakey-r-fluidinflatorproperty), NAME=property_name ```   Abaqus/CAE Usage   ``` Interaction module: Create Interaction Property: Fluid inflator, Name: property_name ```  Specifying the Gas Temperature and Mass Flow Rate Directly The temperature and the mass flow rate of the gas entering the fluid cavity can be given directly as functions of inflation time. Enter a table of mass flow rate and temperature versus inflation time.  Input File Usage   ``` [FLUID INFLATOR PROPERTY](.._SIMACAEKEYRefMap_simakey-r-fluidinflatorproperty.md#simakey-r-fluidinflatorproperty), TYPE=TEMPERATURE AND MASS inflation time, inflator gas temperature, inflator mass flow rate ... ```   Abaqus/CAE Usage   ``` Interaction module: Create Interaction Property: Fluid inflator, Definition: Temperature and mass: Inflation Time, Inflator Gas Temperature, Inflator Mass Flow Rate ```  Using Tank Test Data The mass flow rate and the temperature of the gas entering the fluid cavity can be determined by the results of a tank test. The gas temperature in the inflator will be calculated by using the assumption of isentropic flow. The effective area must be specified. The discharge coefficient has a default value of 0.4.  Input File Usage   ``` [FLUID INFLATOR PROPERTY](.._SIMACAEKEYRefMap_simakey-r-fluidinflatorproperty.md#simakey-r-fluidinflatorproperty), TYPE=PRESSURE AND MASS, EFFECTIVE AREA=A, DISCHARGE COEFFICIENT=C inflation time, inflator pressure, inflator mass flow rate ... ```   Abaqus/CAE Usage   ``` Interaction module: Create Interaction Property: Fluid inflator, Definition: Inflator pressure and mass flow rate: Effective area: A, Discharge coefficient: C, Inflation Time, Inflator Pressure, Inflator Mass Flow Rate ```  Specifying the Gas Mixture To define the inflator gas mixture, specify the number of gas species used for the inflator, and enter a list of names of fluid behaviors and a table of the mass fraction or molar fraction of the species. The mass fraction or molar fraction of the species might be a function of inflation time. The sum of the mass fractions or molar fractions for the species should be equal to one at any given time.  Input File Usage  Use the following options to specify the gas mixture in terms of the mass fractions:   ``` [FLUID INFLATOR PROPERTY](.._SIMACAEKEYRefMap_simakey-r-fluidinflatorproperty.md#simakey-r-fluidinflatorproperty) [FLUID INFLATOR MIXTURE](.._SIMACAEKEYRefMap_simakey-r-fluidinflatormixture.md#simakey-r-fluidinflatormixture),  NUMBER SPECIES=k, TYPE=MASS FRACTION fluid_behavior_name_1, fluid_behavior_name_2, etc. inflation time, mass fraction 1, mass fraction 2, etc. ... ```   Use the following options to specify the gas mixture in terms of the molar fractions:   ``` [FLUID INFLATOR PROPERTY](.._SIMACAEKEYRefMap_simakey-r-fluidinflatorproperty.md#simakey-r-fluidinflatorproperty) [FLUID INFLATOR MIXTURE](.._SIMACAEKEYRefMap_simakey-r-fluidinflatormixture.md#simakey-r-fluidinflatormixture),  NUMBER SPECIES=k, TYPE=MOLAR FRACTION fluid_behavior_name_1, fluid_behavior_name_2, etc. inflation time, molar fraction 1, molar fraction 2, etc. ... ```   Abaqus/CAE Usage  Use the following options to specify the gas mixture in terms of the mass fractions:   ``` Interaction module: Create Interaction Property: Fluid Inflator Mixture, Type: Mass fraction ```   Use the following options to specify the gas mixture in terms of the molar fractions:   ``` Interaction module: Create Interaction Property: Fluid Inflator Mixture, Type: Molar fraction ```  Activating the Inflator Definition Inflation does occur unless the inflation definition is activated in an analysis step.  Input File Usage  Use the following options to activate a fluid inflator for a given analysis step:   ``` [FLUID INFLATOR](.._SIMACAEKEYRefMap_simakey-r-fluidinflator.md#simakey-r-fluidinflator), NAME=fluid_inflator_name [FLUID INFLATOR ACTIVATION](.._SIMACAEKEYRefMap_simakey-r-fluidinflatoractivation.md#simakey-r-fluidinflatoractivation) fluid_inflator_name ```   Abaqus/CAE Usage   ``` Interaction module: Create Interaction: Fluid inflator activation ```  Relating Inflation Time to Analysis Time Inflator property definition consists of specifying tables of gas variables versus inflation time. In Abaqus/Explicit the inflation time,    t  i ⁢ n , is related to the value of an amplitude curve    f ⁢  ( t )  by  t  i ⁢ n =   ∫ 0 t  f ⁢  ( t ) ⁢ d ⁢ t .  Typically the amplitude variation is a step function stepping from zero to one at the time the airbag should be deployed. This amplitude variation has the effect of offsetting the inflation time from the analysis time.  Input File Usage  Use the following options:   ``` [AMPLITUDE](.._SIMACAEKEYRefMap_simakey-r-amplitude.md#simakey-r-amplitude), NAME=amplitude_name [FLUID INFLATOR ACTIVATION](.._SIMACAEKEYRefMap_simakey-r-fluidinflatoractivation.md#simakey-r-fluidinflatoractivation), INFLATION TIME AMPLITUDE=amplitude_name ```   Abaqus/CAE Usage   ``` Interaction module: Edit Interaction: Fluid inflator activation, Inflation time amplitude: amplitude_name ```  Modifying the Mass Flow Rate If the mass flow rate is prescribed directly in the inflator property definition, you can modify it by specifying an amplitude definition during a step. However, if the mass flow rate is calculated using tank test data or the dual pressure method, the amplitude definition will be ignored.  Input File Usage  Use the following options:   ``` [AMPLITUDE](.._SIMACAEKEYRefMap_simakey-r-amplitude.md#simakey-r-amplitude), NAME=amplitude_name [FLUID INFLATOR ACTIVATION](.._SIMACAEKEYRefMap_simakey-r-fluidinflatoractivation.md#simakey-r-fluidinflatoractivation), MASS FLOW AMPLITUDE=amplitude_name ```   Abaqus/CAE Usage   ``` Interaction module: Edit Interaction: Fluid inflator activation, Mass flow amplitude: amplitude_name ```  Activation in Multiple Steps By default, when you modify the activation of a fluid inflator definition or activate a new fluid inflator definition, all existing fluid inflator activations in the step remain. When modifying an existing activation, all applicable parameters must be respecified.  Activated inflator definitions remain active in subsequent steps unless deactivated. You can choose to deactivate all fluid inflator definitions in the model and optionally reactivate new ones. If you deactivate any fluid inflator definition in a step, all fluid inflator definitions must be respecified.  Input File Usage  Use the following option to modify an existing fluid inflator activation or to specify an additional fluid inflator activation (default):   ``` [FLUID INFLATOR ACTIVATION](.._SIMACAEKEYRefMap_simakey-r-fluidinflatoractivation.md#simakey-r-fluidinflatoractivation), OP=MOD ```   Use the following option to deactivate all fluid inflator definitions in the model and optionally reactivate new ones:   ``` [FLUID INFLATOR ACTIVATION](.._SIMACAEKEYRefMap_simakey-r-fluidinflatoractivation.md#simakey-r-fluidinflatoractivation), OP=NEW ```   Abaqus/CAE Usage  Use the following option to modify an existing fluid inflator activation:   ``` Interaction module: Edit Interaction or Interaction Manager: Edit  specific fluid inflator activation interaction ```   Use the following option to deactivate all fluid inflator definitions in the model:   ``` Interaction module: Interaction Manager: Deactivate  specific fluid inflator activation interaction ```  References 1.
