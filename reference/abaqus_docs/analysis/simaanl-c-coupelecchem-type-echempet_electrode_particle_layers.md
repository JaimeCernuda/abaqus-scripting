This page discusses:   * [Parameter Table Type Definition](#sma-topic_68BB47D747FB4852AE53950E649B6B1A) * [Parameters](#sma-topic_9E22FD1EBDF04BC2B25B111A05E4F9C9) | | |  | | --- | | See Also | | [Coupled Thermal-Electrochemical Analysis](simaanl-c-coupthermalelecchem.md) | |   Products Abaqus/Standard  You must include a parameter table of type `"ABQ_EChemPET_Electrode_Particle_Layers"` in the material definition to specify the material layer name and the weight fraction for the layer. The layer name must be unique and is used in the labels of subsequent layer-specific material definitions.    Parameter Table Type Definition ``` [PARAMETER TABLE TYPE](.._SIMACAEKEYRefMap_simakey-r-parametertabletype.md#simakey-r-parametertabletype), NAME="ABQ_EChemPET_Electrode_Particle_Layers", PARAMETERS=2  STRING, " ", "Layer Name", , ,   FLOAT, , "Weight Fraction of Layer", , , ```  Parameters Layer Name  Unique name to identify the material region of the particle layer.  Weight Fraction of Layer  Set to `1.0` if only one layer is present in the particle. If multiple layers are present, set between `0.0` and `1.0`, depending on the weight ratio of each layer to the total weight of the particle. |
