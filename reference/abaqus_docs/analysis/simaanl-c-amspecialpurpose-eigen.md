In the trajectory-based method, the path of the movement of the laser spot is used to determine the time of activation of an element and the eigenstrain to apply to the element at the time of its activation. In the pattern-based method, a scan pattern, which represents an idealized motion of the laser, is used to determine the time of activation of an element and the eigenstrain to assign to that element (see [Scan Pattern–Mesh Intersection](simaanl-c-amtoolpathmeshintersect-scanpattern.md#simaanl-c-amtoolpathmeshintersect-scanpattern)).    Specifying Element Activation and Eigenstrain Using the Pattern-Based Method The following steps are required to use the pattern-based eigenstrain method:   * Create a table collection with a   name that begins with   `"ABQ_EIG"`. The table collection must contain a   parameter table of type   ["ABQ\_AM\_EigenStrain\_Method"](simaanl-c-amspecialpurpose-type-eigenstrainmethod.md#simaanl-c-amspecialpurpose-type-eigenstrainmethod) as well as the other   parameter tables listed below. * In the parameter table of type ["ABQ\_AM\_EigenStrain\_Method"](simaanl-c-amspecialpurpose-type-eigenstrainmethod.md#simaanl-c-amspecialpurpose-type-eigenstrainmethod), set the activation type   to `"PatternBased"`. * Define parameters of rectangular patches that make up a rectangular unit   cell (see   [Scan Pattern–Mesh Intersection](simaanl-c-amtoolpathmeshintersect-scanpattern.md#simaanl-c-amtoolpathmeshintersect-scanpattern)),   which is repeated to cover the cutting plane or a layer, in a parameter table   of type   ["ABQ\_AM\_EigenStrain\_PatternBased\_Define"](simaanl-c-amspecialpurpose-type-eigenstrain-activation-pattern-define.md#simaanl-c-amspecialpurpose-type-eigenstrain-activation-pattern-define). You can   define the following parameters: a local angle, φ;   the extents of a patch (xmin⁡,ymin⁡)   and (xmax⁡,ymax⁡);   and a label of the parameter table defining an eigenstrain to apply to this   patch. * Define the six eigenstrain components in a parameter table of type   ["ABQ\_AM\_EigenStrain\_Define"](simaanl-c-amspecialpurpose-type-eigenstrain-define.md#simaanl-c-amspecialpurpose-type-eigenstrain-define). * Define the parameters of the bounding box, inside which a particular   scan-pattern strategy is active, in a parameter table of type   ["ABQ\_AM\_EigenStrain\_PatternBased\_ScanStrategy\_Define"](simaanl-c-amspecialpurpose-type-eigenstrain-scan-strategy-define.md#simaanl-c-amspecialpurpose-type-eigenstrain-scan-strategy-define). * Define the build parameters (such as slice or layer thickness and build   coordinate system) in a parameter table of type   ["ABQ\_AM\_EigenStrain\_PatternBased\_Activation"](simaanl-c-amspecialpurpose-type-eigenstrain-activation-pattern.md#simaanl-c-amspecialpurpose-type-eigenstrain-activation-pattern). * Optionally, include a parameter table of type   ["ABQ\_AM\_EigenStrain\_Activation\_Advanced"](simaanl-c-amspecialpurpose-type-eigenstrain-activation-advanced.md#simaanl-c-amspecialpurpose-type-eigenstrain-activation-advanced) to specify   advanced options. * Refer to the table collection in   the progressive element activation.   A dedicated collection of parameter table, property table, and event series types is available to include all of the definitions required by special-purpose techniques for additive manufacturing. You can use the abaqus fetch utility to obtain the file containing all of the type definitions of parameter tables, property tables, and event series required by the special-purpose techniques for additive manufacturing as follows:  ``` abaqus fetch job=ABQ_am_special_purpose_types.inp ```  Input File Usage  Use the following options to define scan pattern parameters and eigenstrains:   ``` For a pattern-based eigenstrain analysis, the first two element solution-dependent field variables are internally set to the patch ID and scan region ID, respectively (see [Figure 1](simaanl-c-amspecialpurpose-eigen.md#simaanl-c-amspecialpurpose-vis-pattern__fig-simaanl-c-amspecialpurpose-visualize-scan-pattern)). For a trajectory-based eigenstrain analysis, the first element solution-dependent field variable is internally set to the rule ID. Specifying Element Activation and Eigenstrain Using the Trajectory-Based Method The following steps are required to use the trajectory-based method:   * Create a table collection with a name that begins with   `"ABQ_EIG"`. The table collection must contain a   parameter table of type   ["ABQ\_AM\_EigenStrain\_Method"](simaanl-c-amspecialpurpose-type-eigenstrainmethod.md#simaanl-c-amspecialpurpose-type-eigenstrainmethod) as well as the other   parameter tables listed below. * In the parameter table of type ["ABQ\_AM\_EigenStrain\_Method"](simaanl-c-amspecialpurpose-type-eigenstrainmethod.md#simaanl-c-amspecialpurpose-type-eigenstrainmethod), set the activation type   to `"TrajectoryBased"`. * Define parameters of the rectangular cross-section of the activation front (see [Figure 1](simaanl-c-amspecialpurpose-lded.md#simaanl-c-amspecialpurpose-lded-activation__fig-simaanl-c-amspecialpurpose-LDED-FDM) in [Thermomechanical Analysis of FDM- and LDED-Type Additive Manufacturing Processes](simaanl-c-amspecialpurpose-lded.md#simaanl-c-amspecialpurpose-lded)) and the name of the event series of type ["ABQ\_AM\_HeatSourceTrajectory\_RuleID"](simaanl-c-amspecialpurpose-type-eventseries-slm-heatsourcetrajectory-ruleid.md) that describe that laser spot motion   trajectory in a parameter table of type ["ABQ\_AM\_EigenStrain\_TrajectoryBased\_Activation"](simaanl-c-amspecialpurpose-type-trajectorybased.md#simaanl-c-amspecialpurpose-type-trajectorybased). * Define the six eigenstrain components in a parameter table of type   ["ABQ\_AM\_EigenStrain\_Define"](simaanl-c-amspecialpurpose-type-eigenstrain-define.md#simaanl-c-amspecialpurpose-type-eigenstrain-define). * Define a scan rule by including a parameter table of type ["ABQ\_AM\_EigenStrain\_TrajectoryBased\_Rule\_Define"](simaanl-c-amspecialpurpose-type-trajectory-rule-define.md#simaanl-c-amspecialpurpose-type-trajectory-rule-define) that   refers to a parameter table defining an eigenstrain. All the scan rules used in the   analysis must be listed in a parameter table of type ["ABQ\_AM\_EigenStrain\_TrajectoryBased\_Rules"](simaanl-c-amspecialpurpose-type-trajectory-rules.md#simaanl-c-amspecialpurpose-type-trajectory-rules). The   position index of the rule in this list is the rule ID number that is specified as the   first field in the event series of type ["ABQ\_AM\_HeatSourceTrajectory\_RuleID"](simaanl-c-amspecialpurpose-type-eventseries-slm-heatsourcetrajectory-ruleid.md). * Optionally, include a parameter table of type   ["ABQ\_AM\_EigenStrain\_Activation\_Advanced"](simaanl-c-amspecialpurpose-type-eigenstrain-activation-advanced.md#simaanl-c-amspecialpurpose-type-eigenstrain-activation-advanced) to specify   advanced options.
