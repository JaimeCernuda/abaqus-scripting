Specifying Progressive Element Activation for Material Removal The removal of material is simulated using progressive element activation in a structural or a thermal analysis. The cross-section of the bead of the material being removed is assumed to be rectangular. The following steps are required to define the removal process completely:   * Define the motion of the nozzle in an event   series. The event series must have a least one field that defines the “on/off” state of   the tool. Optionally, the event series can also define the varying height and width of the   cutting operation, and the local direction vector        z    1   , that defines the orientation of the tool, in five additional   fields. * Create a table collection with a name that   begins with "ABQ\_AM". The table collection must contain parameter tables of types ["ABQ\_AM\_MaterialRemoval"](simaanl-c-amspecialpurpose-type-matremoval.md)   and ["ABQ\_AM\_MaterialRemoval\_Bead"](simaanl-c-amspecialpurpose-type-matremoval-bead.md). * In the parameter table of type ["ABQ\_AM\_MaterialRemoval"](simaanl-c-amspecialpurpose-type-matremoval.md),   include a reference to the event series for the cutting tool motion. * In the parameter table of type ["ABQ\_AM\_MaterialRemoval\_Bead"](simaanl-c-amspecialpurpose-type-matremoval-bead.md), define the process parameters, such as the height   and width of the bead. If the height and the width are both set to zero, Abaqus assumes the height to be equal to the average height of a finite element in the   element set referenced from the progressive element activation and the width is large   enough to cover the entire element set. * Optionally, add a parameter table of type ["ABQ\_AM\_MaterialRemoval\_VariableBeadSize"](simaanl-c-amspecialpurpose-type-matremoval-variablebeadsize.md) to define the field positions in the   event series that define the height and the width of the material removal tool’s   cross-section. * Optionally, add a parameter table of type ["ABQ\_AM\_MaterialRemoval\_5AxisStrategy"](simaanl-c-amspecialpurpose-type-matremoval-5axisstrategy.md) to define the field positions in the   event series that define the three components of the local direction vector        z    1    of the tool. * Optionally, define a parameter table of type ["ABQ\_AM\_MaterialRemoval\_Advanced"](simaanl-c-amspecialpurpose-type-matremoval-advanced.md), to specify advanced settings for the element   deactivation process. * Refer to the table collection in the   progressive element activation.   A dedicated collection of parameter table, property table, and event series types is available to include all of the definitions required by special-purpose techniques for additive manufacturing. You can use the abaqus fetch utility to obtain the file containing all of the type definitions of parameter tables, property tables, and event series required by the special-purpose techniques for additive manufacturing as follows:  ``` abaqus fetch job=ABQ_am_special_purpose_types.inp ```  Input File Usage  Use the following options to define element removal (in this example, a user-defined event series type is used `MaterialRemoval_5AxisStrategy`):   ``` [*EVENT SERIES TYPE](.._SIMACAEKEYRefMap_simakey-r-eventseriestype.md), FIELDS=4, NAME=MaterialRemoval_5AxisStrategy "On and Off", Dimensionless, "ES field ID for normal vector componet x", L "ES field ID for normal vector componet y", L "ES field ID for normal vector componet z", L [EVENT SERIES](.._SIMACAEKEYRefMap_simakey-r-eventseries.md#simakey-r-eventseries), NAME=event series name, TYPE=MaterialRemoval_5AxisStrategy t1, x1, y1, z1, 1, Z11x, Z11y, Z11z t2, x2, y2, z2, 1, Z12x, Z12y, Z12z ...
