Parameter Table Type Definition ``` [PARAMETER TABLE TYPE](.._SIMACAEKEYRefMap_simakey-r-parametertabletype.md#simakey-r-parametertabletype), NAME="ABQ_AM_ThermoMech_PatternBased_Advanced", PARAMETERS=2  STRING, "SWEEP", "Activation Technique", , "SWEEP|LAYERBYLAYER",  INTEGER, 1, "Number of Slices per Time Increment", , , ```  Parameters Activation Technique  Set to `"LAYERBYLAYER"` to apply heat energy to all elements of a layer/slice simultaneously. Set to `"SWEEP"` to apply heat energy to elements following the scan pattern. This option has an effect only when the increment size is less than the time taken to complete printing one layer.  Number of Slices per Time Increment  Set to the number of layers that will be completed within one increment by automatically adjusting the time increment size. If you set this value to 0 the layer-by-layer time control will be disabled and the standard Abaqus automatic time control will be used. |
