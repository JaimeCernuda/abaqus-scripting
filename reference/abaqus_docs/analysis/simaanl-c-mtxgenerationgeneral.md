This mathematical abstraction serves various purposes. For example, you can use these matrices to exchange model data with other users, vendors, or software packages without exchanging mesh or material information. You can also use these matrices in techniques such as model order reduction. This abstraction can also be extended to transient nonlinear problems, which can be treated as a series of piecewise linear models constructed from matrix data at discrete times.  Matrix generation from nonlinear analyses accounts for all current boundary conditions, loads, and material responses in the model. The generated matrices are stored in a SIM document named jobname\_STATICn.sim and jobname\_THERMn.sim for static and heat transfer analyses, respectively. Here jobname is the name of the input file or analysis job, and n is the number of the Abaqus static or heat transfer step that generates the matrices. Generating Assembled or Element-by-Element Matrices Matrices are written to the SIM document in assembled or element-by-element forms.  Input File Usage  Use the following option to write matrices in assembled form:   ``` [*OPERATOR OUTPUT](.._SIMACAEKEYRefMap_simakey-r-operatoroutput.md#simakey-r-operatoroutput), OPERATOR=ASSEMBLED ```   Use the following option to write matrices in element-by-element form:   ``` [*OPERATOR OUTPUT](.._SIMACAEKEYRefMap_simakey-r-operatoroutput.md#simakey-r-operatoroutput), OPERATOR=ELEMENT BY ELEMENT ```  Specifying the Matrix Type You can generate matrices representing the following model features:   * Stiffness * Mass * Heat capacity * Thermal conductivity * Loads * Solutions * Free body response   The thermal conductivity matrix has an unsymmetric contribution if the thermal conductivity property is temperature dependent. This term is taken into account only if the unsymmetric solver has been activated in the step definition (see [Defining an Analysis](simaanl-c-over.md)).  The load matrix in uncoupled heat transfer analysis contains either the nodal external flux vector or the net flux vector corresponding to the loading defined in the heat transfer step. Matrices for a Part of the Model By default, matrices are generated for all supported element types in the model. You can request that Abaqus/Standard generate matrices for a part of the model defined by an element set.  Input File Usage   ``` [*OPERATOR OUTPUT](.._SIMACAEKEYRefMap_simakey-r-operatoroutput.md#simakey-r-operatoroutput), ELSET=element set name ```  Specifying the Frequency of Matrix Generation By default, matrices are generated for every increment in the step in which it is requested. You can request that Abaqus/Standard generate matrices at a specified frequency.  Input File Usage   ``` Use one of the following mutually exclusive options: ```  ``` [*OPERATOR OUTPUT](.._SIMACAEKEYRefMap_simakey-r-operatoroutput.md#simakey-r-operatoroutput), FREQUENCY=output frequency ```  ``` [*OPERATOR OUTPUT](.._SIMACAEKEYRefMap_simakey-r-operatoroutput.md#simakey-r-operatoroutput), NUMBER INTERVAL=number of intervals ```  Initial Conditions Matrix generation occurs in a general analysis procedure. Therefore, the generated matrices include the effect of initial conditions when applicable.  Boundary Conditions Prescribed boundary conditions are either imposed or not imposed on the generated matrices and load vectors, based on user-defined requests.  Loads All types of loads supported in static analysis and uncoupled heat transfer analysis can be used for matrix generation. For more information on applying loads, see [About Loads](.._SIMACAEPRCRefMap_simaprc-c-loading.md). For uncoupled heat transfer analysis, load types that are functions of temperature (such as film and radiation) contribute additional “load stiffness” terms to the thermal conductivity matrix.  Predefined Fields All types of predefined fields can be specified for matrix generation. For more information on specifying predefined fields, see [Predefined Fields](.._SIMACAEPRCRefMap_simaprc-c-fields.md).  Material Options All types of materials that are available in Abaqus/Standard for static and uncoupled heat transfer analyses can be used for matrix generation.  Elements All element types are supported in matrix generation for static analysis.  Only continuum diffusive heat transfer elements and thermal contact elements are supported for thermal matrix generation. Thermal matrices are written to the SIM document only for supported elements.  Output The generated matrices are written to the output SIM document in either element-by-element or assembled form. For efficiency, only nonzero matrix entries are stored in the SIM document. If the matrix is symmetric, only the nonzero entries in the upper triangular portion of the matrix are stored. You can use the matrix assembly utility ([Element Matrix Assembly Utility](.._SIMACAEEXCRefMap_simaexc-c-mtxassemblyutil.md)) to assemble element matrices in the SIM document and/or write assembled matrices to text files.  Limitations Constraints that are implemented using the degree-of-freedom elimination technique (such as tie constraints) are not processed for thermal matrix output. In addition, cavity radiation effects are not considered for thermal matrix output.
