Parameter Table Type Definition ``` [PARAMETER TABLE TYPE](.._SIMACAEKEYRefMap_simakey-r-parametertabletype.md#simakey-r-parametertabletype), NAME="ABQ_AM_BladeInterference", PARAMETERS=2 FLOAT, , "Powder Thickness", , , FLOAT, , "Risk Factor", , , ```  Parameters Powder Thickness  Thickness of the powder layer. If the value is zero, the thickness comes from the toolpath-mesh intersection module; otherwise, this value is used.  Risk Factor  Risk factor representing the powder blade flexibility. A value of zero indicates that the blade cannot move above the powder layer thickness. A value of one indicates that the blade can move up a distance equal to the powder layer thickness. |
