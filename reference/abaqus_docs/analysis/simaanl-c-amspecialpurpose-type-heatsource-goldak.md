Parameters defined in this table indicate parameters used in the Goldak expression of laser energy distribution (see [Figure 3](simaanl-c-amspecialpurpose-powderbed.md#simaanl-c-amspecialpurpose-powderbed-goldak__fig-special-goldak) in [Thermomechanical Analysis of Powder Bed–Type Additive Manufacturing Processes Using the Trajectory-Based Method](simaanl-c-amspecialpurpose-powderbed.md#simaanl-c-amspecialpurpose-powderbed)). It is assumed that material is deposited below the laser path defined by the event series; therefore, you must choose `“Below”` as the deposition position in the table of type `"ABQ_AM_MaterialDeposition_Bead"` for a bead-type material deposition method.
