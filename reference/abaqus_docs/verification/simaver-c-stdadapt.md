Problem description The verification problems are either slender beam-like structures that are loaded by gravity parallel to the length or cubical structures indented by a rigid punch.  The verification problems also test user subroutine [UMESHMOTION](.._SIMACAESUBRefMap_simasub-c-umeshmotion.md#simasub-c-umeshmotion), which provides user-prescribed mesh motion.  Results and discussion The verification of the adaptive mesh capability is done by comparing the results of the problems with and without adaptive mesh options.  The verification of user subroutine [UMESHMOTION](.._SIMACAESUBRefMap_simasub-c-umeshmotion.md#simasub-c-umeshmotion) consists of checking the nodal output to ensure correct application of the user-prescribed mesh motion.
