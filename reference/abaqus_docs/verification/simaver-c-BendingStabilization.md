Problem description Each model consists of three elements that are subjected to the same imposed displacement field. The constitutive responses for all three elements are assumed to be hyperelastic with identical material properties. However, they differ in the manner in which the material model is defined. One of the elements uses a built-in hyperelastic response. The other two elements use the same hyperelastic response but defined using user subroutines [UHYPER](.._SIMACAESUBRefMap_simasub-c-uhyper.md#simasub-c-uhyper) and [UMAT](.._SIMACAESUBRefMap_simasub-c-umat.md#simasub-c-umat), respectively. The imposed displacement field results in a nonhomogenous deformation field within the element.  Three separate models are tested with the above basic setup. In the first model, the bending stabilization is specified to be active. In the second model, the bending stabilization is specified to be inactive. In the third model, the default behavior for the bending stabilization is used  Model: The model consists of three C3D8H elements, each of dimensions 1 × 1 × 1.  Material: Hyperelasticity: Mooney-Rivlin  C  10  = 80.0  C  01  = 0.0  D  1  = 2.013E−4  Boundary conditions: Each element type is loaded in displacement control to generate a nonhomogeneous deformation field.  Results and discussion When bending stabilization is specified to be active, the elements that use user-defined materials yield the same nodal reaction forces as the element that uses the built-in material. The nodal reaction forces change identically for all three elements when the bending stabilization is specified to be inactive. For the default case, the nodal forces for the elements with the built-in hyperelastic material are identical to the case with active bending stabilization, while the nodal forces for the elements that use user-defined materials are identical to the case with inactive bending stabilization.
