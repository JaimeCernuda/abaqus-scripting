Problem description This set of verification problems tests many of the variables that are passed into [UVAREL](.._SIMACAESUBRefMap_simasub-c-uvarel.md#simasub-c-uvarel), as well as integration point quantities that are read by utility subroutine getElMPtVar. Most of the tests are single-element cases that set user-defined element output variables directly equal to output quantities such as stresses and section forces. These tests also verify that the user-defined output variables are transferred properly to the solution process.  Results and discussion The results verify that user subroutine [UVAREL](.._SIMACAESUBRefMap_simasub-c-uvarel.md#simasub-c-uvarel) picks up the correct variables and transfers them properly to the output files.
