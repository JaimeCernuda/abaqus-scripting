Problem description In each of the tests a user-defined coordinate system is used to define the material point orientation as shown in [Figure 1](simaver-c-orientation.md#simaver-c-orientation-t-probdescr1__simaver-c-verorient-model). Figure 1. Material point orientation.  Material: Linear elastic, Young's modulus = 3.0 × 106, Poisson's ratio = 0.3.  Boundary conditions: ux = uy = uz = 0 at nodes 11 and 14, ϕz = 0 for all the nodes.  Loading: Concentrated forces of 1000 are applied to nodes 12 and 13 at an angle of 45° to the x-axis.  Remarks Local coordinate directions are used in the input file [xorisrdc.inp](../SIMAINPRefResources/xorisrdc.inp).
