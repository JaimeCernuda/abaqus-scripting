A series of simple, 2-node connector elements simulating a damped spring-mass system verify the connections described in [Table 1](simaver-c-ststsinusoid.md#simaver-c-ststsinusoid-t-probdescr1__simaver-c-sinusoid-contypes). The kinetic behavior in the connector elements is modeled using the connector elasticity, connector damping, and connector friction behaviors.  In Abaqus/Standard a direct-integration implicit dynamic step is used with a small- or large-displacement formulation. In Abaqus/Explicit the usual explicit dynamic procedure is used with the default large-displacement formulation. The spring-mass system in each case is driven by assigning a connector element load.
