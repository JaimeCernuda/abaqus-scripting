Boundary conditions: End A is clamped.  Loading: Fx=​ 25.0 at end B.  General: Initial curvature is defined by specifying the direction cosines of the normals at the two ends.  Gauss integration is used for the shell cross-section for the S4R elements.  Reference solution Reference results are generated from models consisting of 20 B33 cubic beam elements. (Since only one element is used for modeling, if the direction cosines of the normals are not used, the solution will correspond to straight beam theory.) The reference tests use SECTION=RECT, SECTION=I, or SECTION=PIPE. These sections correspond to regular beams and shells, open section beams, and pipes, respectively. Only pipe elements are verified in Abaqus/Explicit.
