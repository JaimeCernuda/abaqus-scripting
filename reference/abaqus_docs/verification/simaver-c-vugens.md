This page discusses:   * [Elements tested](#simaver-c-vugens-t-elementstested1) * [Features tested](#simaver-c-vugens-t-featurestested1) * [Problem description](#simaver-c-vugens-t-probdescr1) * [Results and discussion](#simaver-c-vugens-t-resultssect1) * [Input files](#simaver-c-vugens-t-inputfiles1) | | |   Products Abaqus/Explicit  Elements tested S4R  Features tested User subroutine to define the mechanical behavior of a shell section in terms of generalized section quantities. The subroutine returns the section forces and moments as well as the section stiffness matrix of the element.  Problem description To verify user subroutine [VUGENS](.._SIMACAESUBRefMap_simasub-c-vugens.md), the data line input option is used to specify the shell section stiffness and thickness of the shell elements (passed into [VUGENS](.._SIMACAESUBRefMap_simasub-c-vugens.md) by array PROPS).  ver\_prystructdcoup\_vugens.inp  S4R elements with user subroutine [VUGENS](.._SIMACAESUBRefMap_simasub-c-vugens.md) are used to model a pair of surfaces connected by a spot weld using the [FASTENER](.._SIMACAEKEYRefMap_simakey-r-fastener.md#simakey-r-fastener) definition. A fixed boundary condition is applied to the nodes of one surface, and concentrated forces are applied to the nodes of the other surface. For comparison purposes, a duplicate pair of surfaces modeled by S4R elements without using user subroutine [VUGENS](.._SIMACAESUBRefMap_simasub-c-vugens.md) is included to provide a reference solution.  Results and discussion The verification compares results between models using a general shell section with and without user subroutine [VUGENS](.._SIMACAESUBRefMap_simasub-c-vugens.md). In each case, the results were identical.
