The sequence of tests involves transferring results from Abaqus/Standard to Abaqus/Explicit and then back into Abaqus/Standard.  Verification tests are also included for some first-order reduced-integration elements with enhanced hourglass control.  The material properties are the same as those used in [Fitting of elastomeric foam test data](.._SIMACAEBMKRefMap_simabmk-c-foamdatafitting.md).  Results and discussion The results demonstrate that the hyperfoam material model is transferred successfully between Abaqus/Explicit and Abaqus/Standard.
