Problem description In this verification test all the nodes of each element are fixed, and the reaction forces generated at the nodes as a result of the load application are used to verify the element load calculations. In addition, the effect of thermal loading is verified by allowing each element to deform freely in the thickness direction with the change in temperature. The resulting thermal strains in the thickness direction are compared with the analytical results.
