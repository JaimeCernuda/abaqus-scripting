The TSAIWU and MAX STRESS damage initiation criterion are tested for this model with a number of different element types. The off-axis angle is set to −45° The material is linear elastic, and the elastic constants and the failure strength are the same as those used in [LaRC05 criterion](simaver-c-damagefrm.md#simaver-c-damagefrm-t-DamageInitiationAndDamageEvolution-abqversubsect12).  Results and discussion The damage initiation criterion output variables TSAIWUCRT, MSTRESSCRT, TSAIWUFI, and MSTRESSFI are reviewed. The numerical results match the results obtained by hand calculations, based on the formula presented in [Generalized Damage Initiation Criteria for Anisotropic Materials](.._SIMACAEMATRefMap_simamat-c-damageinitgeneral.md).  Plane stress orthotropic failure measures are also specified in the material when shell elements are used. In addition, stress-based theories are used. The failure index output variables MSTRS and TSAIW are compared with the damage initiation failure index output variables TSAIWUFI and MSTRESSFI, as shown in [Figure 1](#simaver-c-damageaniso-results__simaver-c-damageaniso-figtsaiwu) and [Figure 2](#simaver-c-damageaniso-results__simaver-c-damgeaniso-maxstressfig). The results match as expected. The match is observed only because the loading is monotonic. Otherwise, differences are expected because the plane stress failure measures are evaluated only at the output frame, while the damage initiation failure indices are the maximum values over the entire loading history.
