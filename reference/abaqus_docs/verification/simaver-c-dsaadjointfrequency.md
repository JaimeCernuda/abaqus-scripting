This page discusses:   * [Elements tested](#elementstested_nmg_xcr_lpb) * [Features tested](#featurestested_scx_gdr_lpb) * [Problem description](#simaver-c-dsaadjointfrequency-desc) * [Results and discussion](#simaver-c-dsaadjointfrequency-resultsect) * [Input files](#inputfiles_np4_vdr_lpb) | | |   Products Abaqus/Standard  Elements tested * B31 * C3D8  Features tested This section includes a general set of simple tests to verify the adjoint design sensitivity analysis techniques for beam and solid continuum element types for a frequency step. A full range of design variables are used, including those related to the topology relative material density, the lattice beam element radius, and nodal shape sensitivities. Sensitivities for multiple eigenfrequencies, as well as for models including special features such as model change, are tested.  Problem description All tests use constitutive elastic material properties. The design parameters are either the relative material density, beam element radius, or nodal positions.  Results and discussion All adjoint sensitivity results are verified by comparing them to results obtained using finite difference calculations.
