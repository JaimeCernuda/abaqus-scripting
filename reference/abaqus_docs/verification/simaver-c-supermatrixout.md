Features tested The output and input of substructure matrices and load case vectors are tested.  Problem description These tests verify that the matrices and load vectors written out by the substructure matrix output option are valid and that they can be input into an analysis and used again. The validity of the results is tested by an analysis that uses the generated matrices and load vectors to solve a linear problem.  Results and discussion xsmon2so.inp, xsmon2su.inp  Input files [xsmon2so.inp](../SIMAINPRefResources/xsmon2so.inp) and [xsmon2su.inp](../SIMAINPRefResources/xsmon2su.inp) use the substructure and the associated matrices generated by the substructure generation analysis defined in input file [xsmon2so\_gen1.inp](../SIMAINPRefResources/xsmon2so_gen1.inp). In the model defined in [xsmon2so.inp](../SIMAINPRefResources/xsmon2so.inp), a single substructure element is used and the generated substructure loads are activated. In the model defined in [xsmon2su.inp](../SIMAINPRefResources/xsmon2su.inp), a single linear user element is defined using the stiffness matrix output from the generation job [xsmon2so\_gen1.inp](../SIMAINPRefResources/xsmon2so_gen1.inp) and the model is loaded with a system of concentrated loads. Both runs yield identical displacement fields. The maximum displacement of −2.0 × 10−4 occurs at node 3 in both the runs.  xsmop1so.inp, xsmop1su.inp  Input files [xsmop1so.inp](../SIMAINPRefResources/xsmop1so.inp) and [xsmop1su.inp](../SIMAINPRefResources/xsmop1su.inp) use the substructure and the associated matrices generated by the substructure generation analysis defined in input file [xsmop1so\_gen1.inp](../SIMAINPRefResources/xsmop1so_gen1.inp). In the model defined in [xsmop1so.inp](../SIMAINPRefResources/xsmop1so.inp), a single substructure element is used and the generated substructure loads are activated. In the model defined in [xsmop1su.inp](../SIMAINPRefResources/xsmop1su.inp), a single linear user element is defined using the stiffness matrix output from the generation job [xsmop1so\_gen1.inp](../SIMAINPRefResources/xsmop1so_gen1.inp) and the model is loaded with a system of concentrated loads. Both runs yield identical displacement fields. The maximum displacement of −2.0 × 10−4 occurs at node 3 in both the runs.  Input files Output of substructure matrices and loads: [xsmon2so\_gen1.inp](../SIMAINPRefResources/xsmon2so_gen1.inp)  A substructure made up of one C3D8 element with distributed loads in one [SUBSTRUCTURE LOAD CASE](.._SIMACAEKEYRefMap_simakey-r-substructureloadcase.md#simakey-r-substructureloadcase) and concentrated loads in another.  [xsmop1so\_gen1.inp](../SIMAINPRefResources/xsmop1so_gen1.inp)  A substructure made up of one C3D8 element with concentrated loads applied in a preloading step (for demonstration purpose) and distributed loads applied in a [SUBSTRUCTURE LOAD CASE](.._SIMACAEKEYRefMap_simakey-r-substructureloadcase.md#simakey-r-substructureloadcase).  Using substructures and substructure loads: [xsmon2so.inp](../SIMAINPRefResources/xsmon2so.inp)  This file uses the substructure matrix and load vectors generated using [xsmon2so\_gen1.inp](../SIMAINPRefResources/xsmon2so_gen1.inp). A static step is used to test the matrix and load vectors.  [xsmop1so.inp](../SIMAINPRefResources/xsmop1so.inp)  This file uses the substructure matrix and load vectors generated using [xsmop1so\_gen1.inp](../SIMAINPRefResources/xsmop1so_gen1.inp). A static step is used to test the matrix and load vectors. Using equivalent user elements: [xsmon2su.inp](../SIMAINPRefResources/xsmon2su.inp)  The user element is created using the substructure matrix generated using [xsmon2so\_gen1.inp](../SIMAINPRefResources/xsmon2so_gen1.inp). A static step is used to test the matrix when the load vectors are applied.  [xsmop1su.inp](../SIMAINPRefResources/xsmop1su.inp)  The user element is created using the substructure matrix generated using [xsmop1so\_gen1.inp](../SIMAINPRefResources/xsmop1so_gen1.inp). A static step is used to test the matrix when the load vectors are applied. |
