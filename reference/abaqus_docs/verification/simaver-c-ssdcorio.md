A four-step direct-solution steady-state dynamic procedure is performed on a unit length rod for trusses, on a unit square plate for two-dimensional solids, and on a unit cube for three-dimensional solids. Two elements are used for the triangular and prism element shapes, five elements are used for the tetrahedral element shapes, and one element is used for all other element shapes. The elements are constrained at all nodes and displaced in one degree of freedom: degree of freedom 1 in Steps 1 and 2 and degree of freedom 2 in Steps 3 and 4. Coriolis loading is activated in Steps 2 and 4, and the resulting additional reaction forces and phase shifts are verified by comparing them to analytical values. One representative element type is tested for all solid and truss element classes that can be used in steady-state dynamic analyses and that support Coriolis loading. The use of this feature with submodeling is verified by performing a global and a submodel analysis with CPE4 elements.
