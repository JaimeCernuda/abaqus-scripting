Problem description Generation files [psupreb1\_gen1.inp](../SIMAINPRefResources/psupreb1_gen1.inp), [psupreb2\_gen1.inp](../SIMAINPRefResources/psupreb2_gen1.inp), [psupreb3\_gen1.inp](../SIMAINPRefResources/psupreb3_gen1.inp), and [psupreb4\_gen1.inp](../SIMAINPRefResources/psupreb4_gen1.inp) are made up of single elements, with each element being treated as a substructure for the purposes of this problem. For the hoop tests a substructure load case is used to define a pressure load acting on the surface of the shell, and a uniform pressure is subsequently applied at the usage level. For the radial rebar tests a substructure load case is used to define a concentrated load, and it is applied at the usage level at the outer edge of the shell.  Generation files [psupreb5\_gen1.inp](../SIMAINPRefResources/psupreb5_gen1.inp), [psupreb6\_gen1.inp](../SIMAINPRefResources/psupreb6_gen1.inp), [psupreb7\_gen1.inp](../SIMAINPRefResources/psupreb7_gen1.inp), [psupreb8\_gen1.inp](../SIMAINPRefResources/psupreb8_gen1.inp), [psupreb10\_gen1.inp](../SIMAINPRefResources/psupreb10_gen1.inp), [psupreb11\_gen1.inp](../SIMAINPRefResources/psupreb11_gen1.inp), [psupreb12\_gen1.inp](../SIMAINPRefResources/psupreb12_gen1.inp), and [psupreb13\_gen1.inp](../SIMAINPRefResources/psupreb13_gen1.inp) are made up of five elements each, all five elements being combined to form a single substructure. In input files [psupreb5.inp](../SIMAINPRefResources/psupreb5.inp), [psupreb6.inp](../SIMAINPRefResources/psupreb6.inp), [psupreb10.inp](../SIMAINPRefResources/psupreb10.inp), and [psupreb11.inp](../SIMAINPRefResources/psupreb11.inp) the substructure model is subjected to axial tension. In input files [psupreb7.inp](../SIMAINPRefResources/psupreb7.inp), [psupreb8.inp](../SIMAINPRefResources/psupreb8.inp), [psupreb12.inp](../SIMAINPRefResources/psupreb12.inp), and [psupreb13.inp](../SIMAINPRefResources/psupreb13.inp) a two-step loading is applied, with axial tension applied in the first step and a torsional moment in the second. Both loadings are applied by using the substructure loading.  Generation files [psupreb9\_gen1.inp](../SIMAINPRefResources/psupreb9_gen1.inp) and [psupreba\_gen1.inp](../SIMAINPRefResources/psupreba_gen1.inp) are made up of five elements each, all five elements being combined to form a single substructure. The substructure model is subjected to an axial tension applied.  Results and discussion The results from the substructure analysis exactly match the results that are obtained when substructures are not used.
