Elements tested F2D2  SPRING1  Features tested User subroutine to define fluid density and fluid compliance for an ideal gas.  Problem description The fluid is modeled using a two-dimensional fluid block that measures 1 × 1 with unit thickness. The user-defined fluid is modeled as an ideal gas with the following properties:   |  | | --- | | Ambient pressure, pA = 14.7 | | Absolute zero temperature, θZ = −460. | | Reference density, ρR = 10.0 | | Reference pressure for density, pR = 0. | | Reference temperature for density, θR = 200. |  Loading: The following five steps are executed:   1. Load the fluid to induce a pressure of 100.0 units. 2. Increase fluid temperature to 300.0. 3. Add prescribed amount of fluid. 4. Remove prescribed amount of fluid. 5. Decrease fluid temperature to 200.0.  Results and discussion The results match the exact solution.  Input files [ufluidxx.inp](../SIMAINPRefResources/ufluidxx.inp)  Input file for this analysis.
