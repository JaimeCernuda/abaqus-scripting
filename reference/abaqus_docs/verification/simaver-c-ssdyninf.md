Problem description The model consists of a single infinite element connected to one regular continuum finite element. The model is subjected to a plane wave and a shear wave. The results from this analysis are compared with a reference solution obtained from a model in which the infinite element is replaced by dashpots attached to the regular continuum element at points A and B. The damping coefficient corresponding to a plane wave, dp, is computed as dp=ρcp, where cp    =    λ    + 2⁢Gρ is the plane wave speed. Similarly, the damping coefficient corresponding to a shear wave, ds, is computed as ds=ρcs, where cs    =    Gρ is the shear wave speed.  Material: Young's modulus = 1.0, Poisson's ratio = 0.1, density = 0.01.  Boundary conditions: Plane wave: uy = 1.0 × 10−4 along edge CD, ux = 0 throughout the model.  Shear wave: ux = 1.0 × 10−4 along edge CD, uy = 0 throughout the model.  Results and discussion The results are confirmed by comparing them to a direct-solution steady-state dynamic analysis of the model in which the infinite elements are replaced by dashpots.
