Problem description These tests verify the correctness of the thermal strains computed by Abaqus/Standard. Each test consists of a set of elements to which the same elastic-plastic material is assigned. The properties of the material are listed in [Table 1](#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-elastic), [Table 2](#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-plastic), [Table 3](#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-iso-cte), [Table 4](#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-transversely-iso-cte), [Table 5](#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-ortho-cte), and [Table 6](#simaver-c-simpleexpansion-t-exatablesect1__table_hxl_xkf_bbcsimaver-c-table-simpleexpan-aniso-cte). The initial temperature in the material is 0°, and it is linearly increased during the analysis to the value of 100°, which generates thermal strains in the models.  Results and discussion The thermal strain results agree very well with the exact analytical solutions.
