This page discusses:   * [Elements tested](#simaver-c-uhyper_stretch-elemstested) * [Problem description](#simaver-c-uhyper_stretch-probdesc) * [Results and discussion](#simaver-c-uhyper_stretch-resultssect) * [Input files](#simaver-c-uhyper_stretch-inputfiles) | | |   Products Abaqus/Standard  Elements tested * C3D8 * C3D8RH * CPE4 * CPS4 * CPS4R  Problem description This set of verification problems tests the correctness of the results obtained using user subroutine [UHYPER\_STRETCH](.._SIMACAESUBRefMap_simasub-c-uhyper_stretch.md#simasub-c-uhyper_stretch) for various element types and loading paths. In addition, it tests the variables passed into [UHYPER\_STRETCH](.._SIMACAESUBRefMap_simasub-c-uhyper_stretch.md#simasub-c-uhyper_stretch) and the usage of the property table in [UHYPER\_STRETCH](.._SIMACAESUBRefMap_simasub-c-uhyper_stretch.md#simasub-c-uhyper_stretch).  Each test consists of two coincident elements. Both elements use the same material model and are subject to identical load histories. One of the elements is a reference element with the hyperelastic behavior specified using either a native Abaqus hyperelastic model (neo-Hookean or polynomial [N=2] model) or user subroutine [UHYPER](.._SIMACAESUBRefMap_simasub-c-uhyper.md#simasub-c-uhyper). The same material response is specified in the second element using user subroutine [UHYPER\_STRETCH](.._SIMACAESUBRefMap_simasub-c-uhyper_stretch.md#simasub-c-uhyper_stretch). Four different sets of material data are used. All the materials and their coefficients are chosen such that they can be expressed in the Valanis-Landel form (see [Valanis-Landel Form](.._SIMACAEMATRefMap_simamat-c-hyperelastic.md#simamat-c-hyperelastic-valanis-landel)), which is the required form by user subroutine [UHYPER\_STRETCH](.._SIMACAESUBRefMap_simasub-c-uhyper_stretch.md#simasub-c-uhyper_stretch).
