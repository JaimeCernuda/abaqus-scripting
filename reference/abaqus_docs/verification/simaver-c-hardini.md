Problem description User subroutine [HARDINI](.._SIMACAESUBRefMap_simasub-c-hardini.md#simasub-c-hardini) is used to define initial conditions for the hardening variables ε¯p⁢l and α. These initial conditions are used to solve for the mechanical response of an M3D4 element with rebar in uniaxial tension. The problem definition is the same as in the verification file [mplchi3nt1.inp](../SIMAINPRefResources/mplchi3nt1.inp) ([Rate-independent plasticity](simaver-c-rateindepplast.md)), where the initial conditions are specified. This input file verifies that initial conditions are assigned correctly using user subroutine [HARDINI](.._SIMACAESUBRefMap_simasub-c-hardini.md#simasub-c-hardini).  Results and discussion The results match the verified results of [mplchi3nt1.inp](../SIMAINPRefResources/mplchi3nt1.inp).
