Problem description A two-dimensional rectangular block of material, 10 × 2, has heat generated within its volume by user subroutine [HETVAL](.._SIMACAESUBRefMap_simasub-c-hetval.md#simasub-c-hetval). The value of the generated heat flux is r = 0.40483. The material has specific heat, c = 0.1431, and density, ρ = 0.2829. A transient thermal analysis with all edges of the volume insulated should give a temperature rate of  d⁢θd⁢t=rρ⁢c=10.
