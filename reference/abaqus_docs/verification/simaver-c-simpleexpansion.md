Problem description The verification tests consist of a set of single-element tests that include a combination of all the available elements with all the available materials. All elements are loaded by ramping up the temperature from an initial value of 0° to a final value of 100°. The undeformed meshes are shown in [Figure 1](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exafiguresect1__simaver-c-exxsimple-elastictest) for the elasticity models, [Figure 2](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exafiguresect1__simaver-c-exxsimple-plastictest) for the inelasticity models, and [Figure 3](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exafiguresect1__simaver-c-exxsimple-viscoelast-test) for the viscoelasticity models. Material properties are listed in [Table 1](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-elast) for the elastic materials and in [Table 2](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exatablesect1__simaver-c-table-simpleexpan-inelast) for the inelastic materials. The thermal expansion coefficient for all materials is 0.00005.  The degrees of freedom in the vertical direction are constrained for all the nodes, and deformation is allowed only in the horizontal direction. Nodes associated with elements C3D8R and C3D10M are constrained in the out-of-plane direction, which causes a plane strain condition to apply for these elements.  Results and discussion The time history plots for isotropic elasticity, Mises plasticity, and viscoelasticity for all of the elements are shown in [Figure 4](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exafiguresect1__simaver-c-exxsimple-isotropic), [Figure 5](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exafiguresect1__simaver-c-exxsimple-mises), and [Figure 6](simaver-c-simpleexpansion.md#simaver-c-simpleexpansion-t-exafiguresect1__simaver-c-exxsimple-viscoelast), respectively, except for pipe elements, whose results are consistent with beam elements.
