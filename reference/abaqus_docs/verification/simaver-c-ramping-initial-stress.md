This method helps to reduce initial oscillations in the solution when the initial stress field is not in perfect equilibrium with the external loads. This capability is tested for different element types and materials.  Results and discussion Each test consists of two elements of the same type and with the same material definition (either hyperelastic or plastic). The ramping of initial stress is defined for one of the elements, and the stress history results are compared between the two elements. In each case, it is verified that the initial oscillations in the solution are reduced for the element that includes ramping of initial stresses.
