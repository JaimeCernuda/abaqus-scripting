GAPCYL with positive gap clearance GAP data: Initial clearance = 0.0208 (positive gap clearance).  X, Y, Z direction cosine of the cylinder axis = (1., 0., 0.).  Boundary conditions: node 11 is clamped, node 121 is fixed in the x-, y- and z-directions.  Loading: Step 1: Fy = 2.0 × 104 at node 16; Step 2: Fz = 3.0 × 104 at node 16.  GAPCYL with negative gap clearance GAP data: Initial clearance = −1.0 (negative gap clearance).  X, Y, Z direction cosine of the cylinder axis = (1., 0., 0.).  Boundary conditions: nodes 11 and 12 are clamped, uy = −5.0 at node 22.  GAPSPHER with positive gap clearance GAP data: Initial clearance = 0.2080.  Boundary conditions: nodes 11 and 121 are clamped.  Loading case 1: Fy = 2.0 × 104 and Fz = 3.0 × 104 at node 21; Loading case 2: Fy = 4.0 × 104 and Fz = 6.0 × 104 at node 21.
