This page discusses:   * [Elements tested](#elementstested_dkn_mfr_lpb) * [Features tested](#featurestested_ohl_4fr_lpb) * [Problem description](#adjointimplicittransientdynamic-probdesc) * [Results and discussion](#adjointimplicittransientdynamic-results) * [Input files](#inputfiles_vsg_jgr_lpb) | | |   Products Abaqus/Standard  Elements tested * CPS4 * C3D8 * S4  Features tested This section includes a general set of simple tests to verify the adjoint design sensitivity analysis techniques for shell and solid continuum elements for an implicit transient dynamic step. Geometric nonlinearity, contact (with friction), and multi-point constraints are used for the models. A full range of design variables are used, including those related to topology and sizing sensitivities.  Problem description All tests use elastic constitutive material properties. The design parameters are either relative material density or shell element thickness. Design responses are defined at a number of time points.  Results and discussion All adjoint sensitivity results are verified by comparing them to results obtained using finite difference calculations.
