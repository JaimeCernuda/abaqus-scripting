A B21 and a B31 element are subjected to combined monotonically increasing loads. The analysis consists of a sequential transfer from Abaqus/Standard to Abaqus/Explicit and back to Abaqus/Standard. Nonlinear inelastic section behavior is defined by setting the nonlinear generalized cross section property and omitting the linear and elastic parameters from the options defining axial, bending, and torsional behavior of a general beam section.
