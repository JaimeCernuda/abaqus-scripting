This page discusses:   * [Elements tested](#simaver-c-vuviscosity-t-elementstested1) * [Features tested](#simaver-c-vuviscosity-t-featurestested1) * [Problem description](#simaver-c-vuviscosity-t-probdescr1) * [Results and discussion](#simaver-c-vuviscosity-t-resultssect1) * [Input files](#simaver-c-vuviscosity-t-inputfiles1) | | |   Products Abaqus/Explicit  Elements tested C3D8RT  CPS4RT  S4RT  Features tested User subroutine [VFILM](.._SIMACAESUBRefMap_simasub-c-vfilm.md#simasub-c-vfilm) to define a film coefficient and sink temperature for an Abaqus/Explicit heat transfer analysis.  Problem description The tests verify that the user-defined nonuniform film coefficient and sink temperature in user subroutine [VFILM](.._SIMACAESUBRefMap_simasub-c-vfilm.md#simasub-c-vfilm) transferred properly to the solution process. The finite element models consist of element-based ([FILM](.._SIMACAEKEYRefMap_simakey-r-film.md#simakey-r-film)), surface-based ([SFILM](.._SIMACAEKEYRefMap_simakey-r-sfilm.md#simakey-r-sfilm)), and node-based ([CFILM](.._SIMACAEKEYRefMap_simakey-r-cfilm.md#simakey-r-cfilm)) film convection loads. The film coefficient and sink temperature are implemented as user-defined values. For comparison purposes, a duplicate set of tests with the film coefficient and sink temperature directly defined in input files is also included to provide reference solutions.  Results and discussion In each case the results for the cases using user subroutine [VFILM](.._SIMACAESUBRefMap_simasub-c-vfilm.md#simasub-c-vfilm) match the solutions in the reference tests.
