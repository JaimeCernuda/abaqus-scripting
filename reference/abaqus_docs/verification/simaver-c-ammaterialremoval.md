The simple model geometry was chosen to clearly depict the motion and orientation of the bead as it removes material. Model  The model is a 10 × 10 × 10 cube.  Mesh  A uniform 20 × 20 × 20 mesh of DC3D8 elements is used.  Material  All cubes have the same constant thermal properties.   |  |  | | --- | --- | | Conductivity | k  = 5.70496e-3 | | Density | ρ  = 4.43e-09 | | Specific heat | c  p = 543917000 |   (The units are not important.)  Boundary conditions  Each cube is insulated on all faces. An initial temperature of 300° is prescribed for all elements.  Loading  No loads are applied.  Results and discussion In all cases, the material removal patterns are as expected. The volume fraction output variable (EACTIVE) is used to track the material removal.
