Problem description This set of verification problems ensures that the subroutine [URDFIL](.._SIMACAESUBRefMap_simasub-c-urdfil.md#simasub-c-urdfil) is called properly for the various procedure types. In each problem the utility routine `POSFIL` is called from within [URDFIL](.._SIMACAESUBRefMap_simasub-c-urdfil.md#simasub-c-urdfil). Use is made of the `LSTOP` and `LOVRWRT` parameters such that the results file differs from that which would be produced by the same analysis without [URDFIL](.._SIMACAESUBRefMap_simasub-c-urdfil.md#simasub-c-urdfil).  Results and discussion The results file can be checked to ensure that [URDFIL](.._SIMACAESUBRefMap_simasub-c-urdfil.md#simasub-c-urdfil) and `POSFIL` are functioning correctly for the various procedures.
