Problem description Two test cases are included. The purpose of both tests is to show that the initial conditions of the solution-dependent state variables are interpreted correctly and to show that the solution-dependent state variables can be updated in another user subroutine.  In the first test case six solution-dependent state variables are initialized in user subroutine [SDVINI](.._SIMACAESUBRefMap_simasub-c-sdvini.md#simasub-c-sdvini) and are subsequently updated in user subroutine [UMAT](.._SIMACAESUBRefMap_simasub-c-umat.md#simasub-c-umat). The problem is a trivial linear elastic, static analysis of a single plane stress element. The analysis is repeated for a plane stress gasket element, and identical results are obtained.  In the second test case two solution-dependent state variables are initialized in user subroutine [SDVINI](.._SIMACAESUBRefMap_simasub-c-sdvini.md#simasub-c-sdvini) and are subsequently updated in user subroutine [FRIC](.._SIMACAESUBRefMap_simasub-c-fric.md#simasub-c-fric). The expected solution-dependent state variable settings are confirmed in the step-1, increment-1 call to [FRIC](.._SIMACAESUBRefMap_simasub-c-fric.md#simasub-c-fric).  Results and discussion The solution-dependent state variables defined in [SDVINI](.._SIMACAESUBRefMap_simasub-c-sdvini.md#simasub-c-sdvini) are made available properly in the other user subroutines.
