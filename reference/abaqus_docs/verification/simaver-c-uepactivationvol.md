Problem description The model consists of 10 elements that are activated during the analysis. The activation of elements is defined either at specified step times or at specified increments. This feature is tested with static and heat transfer analysis procedures.  Results and discussion The elements in all cases were activated at the times and increments specified in the user subroutines.
