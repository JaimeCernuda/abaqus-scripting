All tests consist of four elements subjected to uniaxial tension. The same isotropic linearly elastic material definition is used in all cases, and three different methods are used to specify the plastic material properties used for the evaluation of the plasticity corrections: Ramberg-Osgood, tabular, and Mises yield surface. When the Ramberg-Osgood or the tabular method is used, Abaqus evaluates plasticity corrections in both general and static perturbation procedures. However, if an elastic-plastic material with Mises yield surface is used, the plasticity corrections are evaluated only in static perturbation procedures.
