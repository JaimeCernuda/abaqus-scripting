Problem description These tests are related to hydaulic-driven crack propagation. The finite element model for each test case consists of two steps. In the first step, the fluid is injected into the crack mouth so that the crack will propagate and its opening will increase. In the second step, injection of the fluid is stopped. Due to fluid leakoff to the surrounding media, the crack will close. Using user subroutine [UCOHESIVEOFFSET](.._SIMACAESUBRefMap_simasub-c-ucohesiveoffset.md#simasub-c-ucohesiveoffset), we can hold the crack opening to either a constant offset height or its maximum opening height as achieved in the previous step.  Results and discussion The results match the expected results well.
