Elements tested C3D8  C3D8H  C3D8R  CPEG4  CPE4H  CPE4R  CPE8R  Problem description This set of verification problems is primarily intended to test the variables that are passed into [UANISOHYPER\_INV](.._SIMACAESUBRefMap_simasub-c-uanisohyper_inv.md#simasub-c-uanisohyper_inv) in Abaqus/Standard or [VUANISOHYPER\_INV](.._SIMACAESUBRefMap_simasub-c-vuanisohyper_inv.md#simasub-c-vuanisohyper_inv) in Abaqus/Explicit. These tests also verify that the derivatives of the strain energy function defined by the user are transferred properly to the solution process. In each test the material properties are specified using the user strain energy potential for the testing elements, for which the strain energy function and the associated derivatives are defined in user subroutines [UANISOHYPER\_INV](.._SIMACAESUBRefMap_simasub-c-uanisohyper_inv.md#simasub-c-uanisohyper_inv) and [VUANISOHYPER\_INV](.._SIMACAESUBRefMap_simasub-c-vuanisohyper_inv.md#simasub-c-vuanisohyper_inv). Each test contains one reference element with material properties specified with anisotropic hyperelasticity, which provides the reference solution. Three different sets of material data are used, as described below.
