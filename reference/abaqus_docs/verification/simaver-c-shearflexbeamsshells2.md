Material: Linear elastic, Young's modulus = 30 × 106, Poisson's ratio = 0.3.  Boundary conditions: ϕx=ϕy=ϕz=0 at end A, ux=uy=uz=0 at end B.  Loading: Mx=My=Mz=​ 100.0 at end B. Only My is applied for shell models.  General: Analogous problems are modeled in Abaqus/Explicit using linear beam and pipe elements. Unit density is prescribed for the material, and the solution is computed for unit time. Loads are applied smoothly for a quasi-static solution, similar to that from static analysis. The results using pipe elements are consistent to that using beam elements, both of which match the static analysis.
