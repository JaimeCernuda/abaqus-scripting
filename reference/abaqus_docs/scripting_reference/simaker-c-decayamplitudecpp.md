| |  |  | | --- | --- | | DecayAmplitude object | | |  | | | |  | | --- | | The DecayAmplitude object defines an amplitude curve using an exponential decay.  The DecayAmplitude object is derived from the [Amplitude](simaker-c-amplitudecpp.md) object.  This page discusses:   * [Access](#simaker-c-decayamplitudecpp__simaker-c-decayamplitudecpp-s-cppaccess1) * [DecayAmplitude(...)](#simaker-decayamplitudedecayamplitudecpp) * [setValues(...)](#simaker-decayamplitudesetvaluescpp) * [Members](#simaker-c-decayamplitudecpp-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-decayamplitudecpp-t-pykeywordsect1) | | |   Access  ``` amplitudeApi.amplitudes()[name] ```  DecayAmplitude(...) This method creates a DecayAmplitude object.  Path  ``` amplitudeApi.DecayAmplitude ```  Prototype  ``` odb_DecayAmplitude& DecayAmplitude(const odb_String& name,                double initial,                double maximum,                double start,                double decayTime,                const odb_String& timeSpan); ```  Required arguments name  An odb\_String specifying the repository key.  initial  A Double specifying the constant A0.  maximum  A Double specifying the coefficient A.  start  A Double specifying the starting time t0. Possible values are non-negative numbers.  decayTime  A Double specifying the decay time td. Possible values are non-negative numbers.  Optional arguments timeSpan  An odb\_String specifying the time span of the amplitude. Possible values are "STEP" and "TOTAL". The default value is "STEP".  Return value A DecayAmplitude object.  Exceptions InvalidNameError and RangeError.  setValues(...) This method modifies the DecayAmplitude object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [DecayAmplitude](simaker-c-decayamplitudecpp.md#simaker-decayamplitudedecayamplitudecpp) method, except for the name argument.  Return value None.  Exceptions RangeError.  Members The DecayAmplitude object has members with the same names and descriptions as the arguments to the [DecayAmplitude](simaker-c-decayamplitudecpp.md#simaker-decayamplitudedecayamplitudecpp) method.
