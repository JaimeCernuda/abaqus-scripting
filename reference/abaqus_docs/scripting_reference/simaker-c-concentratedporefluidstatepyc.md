# ConcentratedPoreFluidState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | ConcentratedPoreFluidState object | | |  | | | |  | | --- | | The ConcentratedPoreFluidState object stores the propagating data of a concentrated pore fluid flow load in a step. One instance of this object is created internally by the [ConcPoreFluid](simaker-c-concporefluidpyc.md) object for each step. The instance is also deleted internally by the [ConcPoreFluid](simaker-c-concporefluidpyc.md) object.  The ConcentratedPoreFluidState object has no constructor or methods.  The ConcentratedPoreFluidState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-concentratedporefluidstatepyc__simaker-c-concentratedporefluidstatepyc-s-pyaccess1) * [Members](#simaker-c-concentratedporefluidstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-concentratedporefluidstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The ConcentratedPoreFluidState object has the following members:  magnitude  A Float specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [CLOAD](.._SIMACAEKEYRefMap_simakey-r-cload.md#simakey-r-cload) (degree of freedom: 8) |
