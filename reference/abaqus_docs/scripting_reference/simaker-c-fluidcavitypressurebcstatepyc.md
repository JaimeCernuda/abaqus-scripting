# FluidCavityPressureBCState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | FluidCavityPressureBCState object | | |  | | | |  | | --- | | The FluidCavityPressureBCState object stores the propagating data for a fluid cavity pressure boundary condition in a step. One instance of this object is created internally by the [FluidCavityPressureBC](simaker-c-fluidcavitypressurebcpyc.md) object for each step. The instance is also deleted internally by the [FluidCavityPressureBC](simaker-c-fluidcavitypressurebcpyc.md) object.  The FluidCavityPressureBCState object has no constructor or methods.  The FluidCavityPressureBCState object is derived from the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-fluidcavitypressurebcstatepyc__simaker-c-fluidcavitypressurebcstatepyc-s-pyaccess1) * [Members](#simaker-c-fluidcavitypressurebcstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-fluidcavitypressurebcstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].boundaryConditionStates[name] ```  Members The FluidCavityPressureBCState object has the following members:  magnitude  A Float specifying the fluid cavity pressure magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the fluid cavity pressure magnitude. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude reference. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * PROPAGATED\_FROM\_BASE\_STATE * MODIFIED\_FROM\_BASE\_STATE * DEACTIVATED\_FROM\_BASE\_STATE * BUILT\_INTO\_MODES  amplitude  A String specifying the name of the amplitude reference. The String is empty if the boundary condition has no amplitude reference.
