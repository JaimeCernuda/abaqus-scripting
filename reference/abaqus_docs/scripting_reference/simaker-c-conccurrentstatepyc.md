# ConcCurrentState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | ConcCurrentState object | | |  | | | |  | | --- | | The ConcCurrentState object stores the propagating data of a concentrated current in a step. One instance of this object is created internally by the [ConcCurrent](simaker-c-conccurrentpyc.md) object for each step. The instance is also deleted internally by the [ConcCurrent](simaker-c-conccurrentpyc.md) object.  The ConcCurrentState object has no constructor or methods.  The ConcCurrentState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-conccurrentstatepyc__simaker-c-conccurrentstatepyc-s-pyaccess1) * [Members](#simaker-c-conccurrentstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-conccurrentstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The ConcCurrentState object has the following members:  magnitude  A Float specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [CECURRENT](.._SIMACAEKEYRefMap_simakey-r-cecurrent.md#simakey-r-cecurrent) |
