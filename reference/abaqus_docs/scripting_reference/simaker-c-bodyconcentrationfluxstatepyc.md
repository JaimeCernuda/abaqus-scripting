# BodyConcentrationFluxState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | BodyConcentrationFluxState object | | |  | | | |  | | --- | | The BodyConcentrationFluxState object stores the propagating data for a [BodyConcentrationFlux](simaker-c-bodyconcentrationfluxpyc.md) object in a step. One instance of this object is created internally by the [BodyConcentrationFlux](simaker-c-bodyconcentrationfluxpyc.md) object for each step. The instance is also deleted internally by the [BodyConcentrationFlux](simaker-c-bodyconcentrationfluxpyc.md) object.  The BodyConcentrationFluxState object has no constructor or methods.  The BodyConcentrationFluxState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-bodyconcentrationfluxstatepyc__simaker-c-bodyconcentrationfluxstatepyc-s-pyaccess1) * [Members](#simaker-c-bodyconcentrationfluxstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-bodyconcentrationfluxstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The BodyConcentrationFluxState object has the following members:  magnitude  A Float specifying the body concentration flux magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the body concentration flux magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [CFLUX](.._SIMACAEKEYRefMap_simakey-r-cflux.md#simakey-r-cflux) |
