Section definitions that contain the same number of section points or integration points are grouped together. To access data for a particular section definition, use the individual [Section](simaker-c-sectioncpp.md) objects in the output database. For more information, see [Beam Section profile commands](simaker-m-BpfPyc-sb.md) and [Section commands](simaker-m-SctPyc-sb.md). Path odb.SectionCategory  Prototype  ``` odb_SectionCategory& SectionCategory(const odb_String& name, const odb_String& description); ```  Required arguments name  An odb\_String specifying the name of the category.  description  An odb\_String specifying the description of the category.
