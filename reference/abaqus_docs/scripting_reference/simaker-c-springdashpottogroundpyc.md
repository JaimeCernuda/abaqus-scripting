Path  ``` mdb.models[name].parts[name].engineeringFeatures.SpringDashpotToGround mdb.models[name].rootAssembly.engineeringFeatures\ .SpringDashpotToGround ```  Required arguments name  A String specifying the repository key.  region  A [Region](simaker-c-regionpyc.md) object specifying the region to which the springs and/or dashpots are applied.  dof  An Int specifying the degree of freedom associated with the spring and dashpot behaviors.  Optional arguments orientation  None or a [DatumCsys](simaker-c-datumcsyspyc.md) object specifying the local directions for the spring and/or dashpot. If orientation=None, the spring and/or dashpot data are defined in the global coordinate system. The default value is None.  springBehavior  A Boolean specifying whether to apply spring behavior to the selected points. The default value is OFF.  At least one of the arguments springBehavior=ON or dashpotBehavior=ON must be specified.  dashpotBehavior  A Boolean specifying whether to apply dashpot behavior to the selected points. The default value is OFF.  At least one of the arguments springBehavior=ON or dashpotBehavior=ON must be specified.  springStiffness  A Float specifying the force per relative displacement for the spring. The default value is 0.0.  dashpotCoefficient  A Float specifying the force per relative velocity for the dashpot. The default value is 0.0.  Return value A SpringDashpotToGround object.
