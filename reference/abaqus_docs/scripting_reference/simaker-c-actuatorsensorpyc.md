| |  |  | | --- | --- | | ActuatorSensor object | | |  | | | |  | | --- | | The ActuatorSensor object defines a single point actuator where the actuation is determined by a user subroutine ([UEL](.._SIMACAESUBRefMap_simasub-c-uel.md#simasub-c-uel)). The subroutine senses the data at the same point as the actuator.  The ActuatorSensor object is derived from the [Interaction](simaker-c-interactionpyc.md) object.
