| |  |  | | --- | --- | | LeafFromInstanceNodeLabels object | | |  | | | |  | | --- | | The LeafFromInstanceNodeLabels object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are used to specify the items in a display group. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands.  The LeafFromInstanceNodeLabels object is derived from the [Leaf](simaker-c-leafpyc.md) object.  This page discusses:   * [Access](#simaker-c-leaffrominstancenodelabelspyc__simaker-c-leaffrominstancenodelabelspyc-s-pyaccess1) * [LeafFromInstanceNodeLabels(...)](#simaker-leaffrominstancenodelabelsleaffrominstancenodelabelpyc) * [Members](#simaker-c-leaffrominstancenodelabelspyc-t-pymembersect1) | | |   Access  ``` import displayGroupMdbToolset ```  LeafFromInstanceNodeLabels(...) This method creates a [Leaf](simaker-c-leafpyc.md) object from a sequence of Strings specifying the node labels. Leaf objects specify the items in a display group.  Path  ``` LeafFromInstanceNodeLabels ```  Required arguments nodeLabels  A sequence of sequences specifying node labels. Each inner sequence consists of a [PartInstance](simaker-c-partinstancepyc.md) object followed by a sequence of Strings specifying node labels.  Optional arguments None.  Return value A LeafFromInstanceNodeLabels object.  Exceptions None.  Members The LeafFromInstanceNodeLabels object has the following member:  leafType  A SymbolicConstant specifying the leaf type. Possible values are EMPTY\_LEAF, DEFAULT\_MODEL, ALL\_ELEMENTS, ALL\_NODES, and ALL\_SURFACES. |
