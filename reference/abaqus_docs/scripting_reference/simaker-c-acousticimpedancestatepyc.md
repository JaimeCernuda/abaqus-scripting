# AcousticImpedanceState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | AcousticImpedanceState object | | |  | | | |  | | --- | | The AcousticImpedanceState object stores the propagating data of an [AcousticImpedance](simaker-c-acousticimpedancepyc.md) object in a step. One instance of this object is created internally by the [AcousticImpedance](simaker-c-acousticimpedancepyc.md) object for each step. The instance is also deleted internally by the [AcousticImpedance](simaker-c-acousticimpedancepyc.md) object.  The AcousticImpedanceState object has no constructor or methods.  The AcousticImpedanceState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-acousticimpedancestatepyc__simaker-c-acousticimpedancestatepyc-s-pyaccess1) * [Members](#simaker-c-acousticimpedancestatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-acousticimpedancestatepyc-t-pykeywordsect1) | | |   Access  ``` import interaction mdb.models[name].steps[name].interactionStates[name] ```  Members The AcousticImpedanceState object has the following members:  interactionPropertyState  A SymbolicConstant specifying the propagation state of the interactionProperty member. Possible values are UNSET, SET, UNCHANGED, and FREED.  interactionProperty  A String specifying the name of the [AcousticImpedanceProp](simaker-c-acousticimpedanceproppyc.md) object associated with this interaction.  status  A SymbolicConstant specifying the propagation state of the [InteractionState](simaker-c-interactionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  Corresponding analysis keywords * [SIMPEDANCE](.._SIMACAEKEYRefMap_simakey-r-simpedance.md#simakey-r-simpedance) |
