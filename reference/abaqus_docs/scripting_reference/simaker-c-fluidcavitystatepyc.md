| |  |  | | --- | --- | | FluidCavityState object | | |  | | | |  | | --- | | The FluidCavityState object stores the propagating data for an [FluidCavity](simaker-c-fluidcavitypyc.md) object. One instance of this object is created internally by the [FluidCavity](simaker-c-fluidcavitypyc.md) object for each step. The instance is also deleted internally by the [FluidCavity](simaker-c-fluidcavitypyc.md) object.  The FluidCavityState object has no constructor or methods.  The FluidCavityState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.
