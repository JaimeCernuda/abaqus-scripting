Path  ``` sectionApi.AcousticInterfaceSection ```  Prototype  ``` odb_AcousticInterfaceSection& AcousticInterfaceSection(const odb_String& name,                          double thickness); ```  Required arguments name  An odb\_String specifying the repository key.
