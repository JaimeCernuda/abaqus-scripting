# Title object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Title object | | |  | | | |  | | --- | | The Title object is used to store the display attributes of the XYPlot title.  A Title object is automatically created when creating a [XYPlot](simaker-c-xyplotpyc.md) object.  This page discusses:   * [Access](#simaker-c-titlepyc__simaker-c-titlepyc-s-pyaccess1) * [setValues(...)](#simaker-titlesetvaluespyc) * [Members](#simaker-c-titlepyc-t-pymembersect1) | | |   Access  ``` import visualization session.defaultPlot.title session.xyPlots[name].title ```  setValues(...) This method modifies the Title object.  Required arguments None.  Optional arguments title  A Title object from which attributes are to be copied.  text  A String specifying the text to appear as a title. By default the title is set to the [XYPlot](simaker-c-xyplotpyc.md) object name. The default value is an empty string.  area  An [Area](simaker-c-areapyc.md) object specifying the area of the title.  useDefault  A Boolean specifying whether to show the default title. The default value is OFF.  style  A [TextStyle](simaker-c-textstylepyc.md) object specifying the text properties used to display the legend title.  Return value None.  Exceptions None.  Members The Title object can have the following members:  useDefault  A Boolean specifying whether to show the default title. The default value is OFF.  area  An [Area](simaker-c-areapyc.md) object specifying the area of the title.  text  A String specifying the text to appear as a title. By default the title is set to the [XYPlot](simaker-c-xyplotpyc.md) object name. The default value is an empty string.  style  A [TextStyle](simaker-c-textstylepyc.md) object specifying the text properties used to display the legend title. |
