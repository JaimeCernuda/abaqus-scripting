# FluidInflatorState object

|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | FluidInflatorState object | | |  | | | |  | | --- | | The FluidInflatorState object stores the propagating data for a FluidInflator object. One instance of this object is created internally by the [FluidInflator](simaker-c-fluidinflatorpyc.md) object for each step. The instance is also deleted internally by the [FluidInflator](simaker-c-fluidinflatorpyc.md) object. The FluidInflatorState object has no constructor or methods.  The FluidInflatorState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE |
