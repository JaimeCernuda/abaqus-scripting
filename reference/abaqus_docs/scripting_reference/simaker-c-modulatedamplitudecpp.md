This method creates a ModulatedAmplitude object.  Path  ``` amplitudeApi.ModulatedAmplitude ```  Prototype  ``` odb_ModulatedAmplitude& ModulatedAmplitude(const odb_String& name,                    double initial,                    double magnitude,                    double start,                    double frequency1,                    double frequency2,                    const odb_String& timeSpan); ```  Required arguments name  An odb\_String specifying the repository key.  initial  A Double specifying the constant A0.  magnitude  A Double specifying the coefficient A.  start  A Double specifying the starting time t0. Possible values are non-negative numbers.  frequency1  A Double specifying the circular frequency 1 (ω1). Possible values are positive numbers.  frequency2  A Double specifying the circular frequency 2 (ω2). Possible values are positive numbers.  Optional arguments timeSpan  An odb\_String specifying the time span of the amplitude. Possible values are "STEP" and "TOTAL". The default value is "STEP".  Return value A ModulatedAmplitude object.  Exceptions InvalidNameError and RangeError.  setValues(...) This method modifies the ModulatedAmplitude object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [ModulatedAmplitude](simaker-c-modulatedamplitudecpp.md#simaker-modulatedamplitudemodulatedamplitudecpp) method, except for the name argument.  Return value None.  Exceptions RangeError.  Members The ModulatedAmplitude object has members with the same names and descriptions as the arguments to the [ModulatedAmplitude](simaker-c-modulatedamplitudecpp.md#simaker-modulatedamplitudemodulatedamplitudecpp) method.
