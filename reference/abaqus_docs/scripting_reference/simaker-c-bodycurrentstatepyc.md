# BodyCurrentState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | BodyCurrentState object | | |  | | | |  | | --- | | The BodyCurrentState object stores the propagating data of a body current in a step. One instance of this object is created internally by the [BodyCurrent](simaker-c-bodycurrentpyc.md) object for each step. The instance is also deleted internally by the [BodyCurrent](simaker-c-bodycurrentpyc.md) object.  The BodyCurrentState object has no constructor or methods.  The BodyCurrentState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-bodycurrentstatepyc__simaker-c-bodycurrentstatepyc-s-pyaccess1) * [Members](#simaker-c-bodycurrentstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-bodycurrentstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The BodyCurrentState object has the following members:  magnitude  A Float specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DECURRENT](.._SIMACAEKEYRefMap_simakey-r-decurrent.md#simakey-r-decurrent) (load type label: CBF) |
