# FluidExchangeActivationState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | FluidExchangeActivationState object | | |  | | | |  | | --- | | The FluidExchangeActivationState object stores the propagating data for a FluidExchangeActivation object.  One instance of this object is created internally by the [FluidExchangeActivation](simaker-c-fluidexchangeactivationpyc.md) object for each step. The instance is also deleted internally by the [FluidExchangeActivation](simaker-c-fluidexchangeactivationpyc.md) object. The FluidExchangeActivationState object has no constructor or methods.  The FluidExchangeActivationState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-fluidexchangeactivationstatepyc__simaker-c-fluidinflatorstatepyc-s-pyaccess1) * [Members](#simaker-c-fluidinflatorstatepyc-t-pymembersect1) | | |   Access  ``` import interaction mdb.models[name].steps[name].interactionStates[name] ```  Members The FluidExchangeActivationState object has the following members:  exchangesState  A SymbolicConstant specifying the propagation state of the exchanges member. Possible values are UNSET, SET, UNCHANGED, and FREED.  exchanges  A String specifying the name of the [FluidExchange](simaker-c-fluidexchangepyc.md) object associated with this interaction.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitude  A String specifying the name of the [Amplitude](simaker-c-amplitudepyc.md) object associated with this interaction.  isBlockageState  A SymbolicConstant specifying the propagation state of the isBlockage member. Possible values are UNSET, SET, UNCHANGED, and FREED.  isBlockage  A Boolean specifying whether to consider vent and leakage area obstruction by contacted surfaces.  isOnlyOutflowState  A SymbolicConstant specifying the propagation state of the isOnlyOutflow member. Possible values are UNSET, SET, UNCHANGED, and FREED.  isOnlyOutflow  A Boolean specifying whether the flow of fluid is allowed only from the first fluid cavity to the second fluid cavity defined in the [FluidExchange](simaker-c-fluidexchangepyc.md) object.  deltaLeakageAreaState  A SymbolicConstant specifying the propagation state of the deltaLeakageArea member. Possible values are UNSET, SET, UNCHANGED, and FREED.  deltaLeakageArea  A Float specifying the ratio of the actual surface area over the initial surface area at which you want the fluid to leak.  status  A SymbolicConstant specifying the propagation state of the [InteractionState](simaker-c-interactionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE |
