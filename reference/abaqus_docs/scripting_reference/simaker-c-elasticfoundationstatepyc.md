# ElasticFoundationState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | ElasticFoundationState object | | |  | | | |  | | --- | | The ElasticFoundationState object stores the propagating data for an [ElasticFoundation](simaker-c-elasticfoundationpyc.md) object. One instance of this object is created internally by the [ElasticFoundation](simaker-c-elasticfoundationpyc.md) object for each step. The instance is also deleted internally by the [ElasticFoundation](simaker-c-elasticfoundationpyc.md) object.  The ElasticFoundationState object has no constructor or methods.  The ElasticFoundationState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-elasticfoundationstatepyc__simaker-c-elasticfoundationstatepyc-s-pyaccess1) * [Members](#simaker-c-elasticfoundationstatepyc-t-pymembersect1) | | |   Access  ``` import interaction mdb.models[name].steps[name].interactionStates[name] ```  Members The ElasticFoundationState object has the following members:  stiffness  A Float specifying the foundation stiffness per area.  stiffnessState  A SymbolicConstant specifying the propagation state of the stiffness member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [InteractionState](simaker-c-interactionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE |
