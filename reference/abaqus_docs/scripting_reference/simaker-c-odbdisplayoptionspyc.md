|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | OdbDisplayOptions object | | |  | | | |  | | --- | | The OdbDisplayOptions object stores the display options associated with an [OdbInstance](simaker-c-odbinstancepyc.md) object. This object does not have a constructor. Abaqus creates the OdbDisplayOptions object when an [OdbInstance](simaker-c-odbinstancepyc.md) object is created using the display options associated with the current viewport at the time of creation.
