# ConcentratedForceState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | ConcentratedForceState object | | |  | | | |  | | --- | | The ConcentratedForceState object stores the propagating data for a concentrated force in a step. One instance of this object is created internally by the [ConcentratedForce](simaker-c-concentratedforcepyc.md) object for each step. The instance is also deleted internally by the [ConcentratedForce](simaker-c-concentratedforcepyc.md) object.  The ConcentratedForceState object has no constructor or methods.  The ConcentratedForceState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-concentratedforcestatepyc__simaker-c-concentratedforcestatepyc-s-pyaccess1) * [Members](#simaker-c-concentratedforcestatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-concentratedforcestatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The ConcentratedForceState object has the following members:  cf1  A Float or a Complex specifying the concentrated force component in the 1-direction. Although cf1, cf2, and cf3 are optional arguments, at least one of them must be nonzero.  cf2  A Float or a Complex specifying the concentrated force component in the 2-direction.  cf3  A Float or a Complex specifying the concentrated force component in the 3-direction.  cf1State  A SymbolicConstant specifying the propagation state of the concentrated force component in the 1-direction. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  cf2State  A SymbolicConstant specifying the propagation state of the concentrated force component in the 2-direction. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  cf3State  A SymbolicConstant specifying the propagation state of the concentrated force component in the 3-direction. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [CLOAD](.._SIMACAEKEYRefMap_simakey-r-cload.md#simakey-r-cload) (degree of freedom: 1, 2, or 3) |
