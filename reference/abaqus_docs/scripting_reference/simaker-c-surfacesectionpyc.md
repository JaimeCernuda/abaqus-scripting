| |  |  | | --- | --- | | SurfaceSection object | | |  | | | |  | | --- | | The SurfaceSection object defines the properties of a surface section.  The SurfaceSection object is derived from the [Section](simaker-c-sectionpyc.md) object.  This page discusses:   * [Access](#simaker-c-surfacesectionpyc__simaker-c-surfacesectionpyc-s-pyaccess1) * [SurfaceSection(...)](#simaker-surfacesectionsurfacesectionpyc) * [Members](#simaker-c-surfacesectionpyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-surfacesectionpyc-t-pykeywordsect1) | | |   Access  ``` import section mdb.models[name].sections[name] import odbSection session.odbs[name].sections[name] ```  SurfaceSection(...) This method creates a SurfaceSection object.  Path  ``` mdb.models[name].SurfaceSection session.odbs[name].SurfaceSection ```  Required arguments name  A String specifying the repository key.  Optional arguments useDensity  A Boolean specifying whether or not to use the value of density. The default value is OFF.  density  A Float specifying the value of density to apply to this section. The default value is 0.0.  Return value A SurfaceSection object.  Exceptions RangeError and InvalidNameError.  Members The SurfaceSection object has members with the same names and descriptions as the arguments to the [SurfaceSection](simaker-c-surfacesectionpyc.md#simaker-surfacesectionsurfacesectionpyc) method.  In addition, the SurfaceSection object can have the following member:  rebarLayers  A [RebarLayers](simaker-c-rebarlayerspyc.md) object specifying reinforcement properties.
