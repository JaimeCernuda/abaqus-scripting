# RotationalBodyForceState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | RotationalBodyForceState object | | |  | | | |  | | --- | | The RotationalBodyForceState object stores the propagating data of a rotational body force in a step. One instance of this object is created internally by the [RotationalBodyForce](simaker-c-rotationalbodyforcepyc.md) object for each step. The instance is also deleted internally by the [RotationalBodyForce](simaker-c-rotationalbodyforcepyc.md) object.  The RotationalBodyForceState object has no constructor or methods.  The RotationalBodyForceState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-rotationalbodyforcestatepyc__simaker-c-rotationalbodyforcestatepyc-s-pyaccess1) * [Members](#simaker-c-rotationalbodyforcestatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-rotationalbodyforcestatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The RotationalBodyForceState object has the following members:  magnitude  A Float specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DLOAD](.._SIMACAEKEYRefMap_simakey-r-dload.md#simakey-r-dload) (load type labels: CENTRIF, ROTA) |
