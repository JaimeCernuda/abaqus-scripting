This method synchronizes the display options stored on the [OdbDisplay](simaker-c-odbdisplaypyc.md) object with the display options stored on the [DisplayGroupInstance](simaker-c-displaygroupinstancepyc.md) object.  Required arguments name  A String specifying the repository key.  Optional arguments updateInstances  A Boolean specifying whether to synchronize the display options on all the [DisplayGroupInstance](simaker-c-displaygroupinstancepyc.md) objects stored in the DisplayGroupInstanceRepository for which lockOptions is OFF. The default value of updateInstances is ON.  Return value None.  Exceptions None.  Members The DisplayGroupInstanceRepository object has no members. |
