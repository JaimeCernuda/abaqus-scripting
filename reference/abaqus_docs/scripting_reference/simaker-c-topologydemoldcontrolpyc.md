This method creates a TopologyDemoldControl object.  Path  ```           mdb.models[name].optimizationTasks[name].TopologyDemoldControl ```  Required arguments name  A String specifying the geometric restriction repository key.  region  A [Region](simaker-c-regionpyc.md) object specifying the region to which the geometric restriction is applied. When used with a [TopologyTask](simaker-c-topologytaskpyc.md), there is no default value. When used with a [ShapeTask](simaker-c-shapetaskpyc.md), the default value is MODEL.  Optional arguments csys  None or a [DatumCsys](simaker-c-datumcsyspyc.md) object specifying the local coordinate system of the pullDirection. If csys=None, the global coordinate system is used. When this member is queried, it returns an Int indicating the identifier of the [DatumCsys](simaker-c-datumcsyspyc.md). The default value is None.  draftAngle  A Float specifying the draft angle. The default value is 0.0.  collisionCheckRegion  The SymbolicConstant DEMOLD\_REGION or a [Region](simaker-c-regionpyc.md) object specifying the collision check region. If the value is DEMOLD\_REGION, then the value of region is used as both the demold region and the collision check region. The default value is DEMOLD\_REGION.  pointRegion  A [Region](simaker-c-regionpyc.md) object specifying the point on a plane perpendicular to the pull direction, used to specify the central plane when technique is POINT.  pullDirection  A [VertexArray](simaker-c-vertexpyc.md) object of length 2 specifying the demold pull direction. Instead of through a [Vertex](simaker-c-vertexpyc.md), each point may be specified through a tuple of coordinates.  technique  A SymbolicConstant specifying the demold technique. Possible values are AUTO, AUTO\_TIGHT, POINT, SURFACE, and STAMP. The default value is AUTO.  Return value A TopologyDemoldControl object.  Exceptions None.  setValues(...) This method modifies the TopologyDemoldControl object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [TopologyDemoldControl](simaker-c-topologydemoldcontrolpyc.md#simaker-topologydemoldcontroltopologydemoldcontrolpyc) method, except for the name argument.  Return value None.  Exceptions None.
