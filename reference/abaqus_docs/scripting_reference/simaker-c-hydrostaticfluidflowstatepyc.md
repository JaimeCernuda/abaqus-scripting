# HydrostaticFluidFlowState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | HydrostaticFluidFlowState object | | |  | | | |  | | --- | | The HydrostaticFluidFlowState object stores the propagating data for a concentrated HydrostaticFluidFlow object in a step. One instance of this object is created internally by the HydrostaticFluidFlow object for each step. The instance is also deleted internally by the HydrostaticFluidFlow object.  The HydrostaticFluidFlowState object has no constructor or methods.  The HydrostaticFluidFlowState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-hydrostaticfluidflowstatepyc__simaker-c-hydrostaticfluidflowstatepyc-s-pyaccess1) * [Members](#simaker-c-hydrostaticfluidflowstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-hydrostaticfluidflowstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The HydrostaticFluidFlowState object has the following members:  magnitude  A Float specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [FLUID FLUX](.._SIMACAEKEYRefMap_simakey-r-fluidflux.md#simakey-r-fluidflux) |
