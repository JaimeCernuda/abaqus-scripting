| |  |  | | --- | --- | | LeafFromOdbElementPlies object | | |  | | | |  | | --- | | The LeafFromOdbElementPlies object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are used to specify the items in a display group. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands.  The LeafFromOdbElementPlies object is derived from the [Leaf](simaker-c-leafpyc.md) object. This method creates a [Leaf](simaker-c-leafpyc.md) object from a sequence of Strings specifying ply names. Leaf objects specify the items in a display group.  Path  ``` LeafFromOdbElementPlies ```  Required arguments elementPlies  A sequence of Strings specifying element plies.  Optional arguments None.  Return value A LeafFromOdbElementPlies object.  Exceptions None.  Members The LeafFromOdbElementPlies object has the following member:  leafType  A SymbolicConstant specifying the leaf type.
