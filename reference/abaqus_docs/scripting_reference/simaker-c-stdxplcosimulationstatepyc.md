| |  |  | | --- | --- | | StdXplCosimulationState object | | |  | | | |  | | --- | | The StdXplCosimulationState object stores the propagating data for a [StdXplCosimulation](simaker-c-stdxplcosimulationpyc.md) object. One instance of this object is created internally by the [StdXplCosimulation](simaker-c-stdxplcosimulationpyc.md) object for each step. The instance is also deleted internally by the [StdXplCosimulation](simaker-c-stdxplcosimulationpyc.md) object.  The StdXplCosimulationState object has no constructor or methods.  The StdXplCosimulationState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.
