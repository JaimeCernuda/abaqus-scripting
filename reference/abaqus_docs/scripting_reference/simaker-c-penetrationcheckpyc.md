| |  |  | | --- | --- | | PenetrationCheck object | | |  | | | |  | | --- | | The PenetrationCheck object defines a penetration check geometric restriction.  The PenetrationCheck object is derived from the [GeometricRestriction](simaker-c-geometricrestrictionpyc.md) object. This method creates a PenetrationCheck object.  Path  ```           mdb.models[name].optimizationTasks[name].PenetrationCheck ```  Required arguments name  A String specifying the geometric restriction repository key.  penetrationCheckRegion  A [Region](simaker-c-regionpyc.md) object specifying the penetration check region.  region  A [Region](simaker-c-regionpyc.md) object specifying the region to which the geometric restriction is applied. When used with a [TopologyTask](simaker-c-topologytaskpyc.md), there is no default value. When used with a [ShapeTask](simaker-c-shapetaskpyc.md), the default value is MODEL.  Optional arguments presumeFeasibleRegionAtStart  A Boolean specifying whether to ignore the geometric restriction in the first design cycle. The default value is ON.  Return value A PenetrationCheck object.  Exceptions None.  setValues(...) This method modifies the PenetrationCheck object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [PenetrationCheck](simaker-c-penetrationcheckpyc.md#simaker-penetrationcheckpenetrationcheckpyc) method, except for the name argument.  Return value None.  Exceptions None.  Members The PenetrationCheck object has members with the same names and descriptions as the arguments to the [PenetrationCheck](simaker-c-penetrationcheckpyc.md#simaker-penetrationcheckpenetrationcheckpyc) method. |
