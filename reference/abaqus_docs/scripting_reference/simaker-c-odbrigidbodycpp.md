| |  |  | | --- | --- | | OdbRigidBody object | | |  | | | |  | | --- | | The Rigid body object is used to bind a set of elements and/or a set of nodes and/or an analytical surface with a reference node.  This page discusses:   * [Access](#simaker-c-odbrigidbodycpp__simaker-c-odbrigidbodycpp-s-cppaccess1) * [Members](#simaker-c-odbrigidbodycpp-t-pymembersect1) | | |   Access  ``` odb.parts()[name].rigidBodies(i) odb.rootAssembly().instances()[name].rigidBodies(i) odb.rootAssembly().rigidBodies(i) odb.steps()[name].frames(i).fieldOutputs()[name].values(i).instance()\ .rigidBodies(i) ```  Members The OdbRigidBody object can have the following members:  Prototype  ``` odb_Enum::odb_PositionEnum position() const; bool isothermal() const; odb_Set referenceNode() const; odb_Set elements() const; odb_Set tieNodes() const; odb_Set pinNodes() const; odb_AnalyticSurface analyticSurface() const; ```  position  An odb\_Enum::odb\_PositionEnum specifying the specific location of the OdbRigidBody reference node relative to the rest of the rigid body. Possible values are odb\_Enum::INPUT and odb\_Enum::CENTER\_OF\_MASS. The default value is odb\_Enum::INPUT.  isothermal  A Boolean specifying specify whether the OdbRigidBody can have temperature gradients or be isothermal. This is used only for fully coupled thermal-stress analysis The default value is true.  referenceNode  An [OdbSet](simaker-c-odbsetcpp.md) object specifying the reference node set associated with the rigid body.  elements  An [OdbSet](simaker-c-odbsetcpp.md) object specifying the element set whose motion is governed by the motion of rigid body reference node.  tieNodes  An [OdbSet](simaker-c-odbsetcpp.md) object specifying the node set which have both translational and rotational degrees of freedom associated with the rigid body.  pinNodes  An [OdbSet](simaker-c-odbsetcpp.md) object specifying the node set which have only translational degrees of freedom associated with the rigid body.  analyticSurface  An [AnalyticSurface](simaker-c-analyticsurfacecpp.md) object specifying the analytic surface whose motion is governed by the motion of rigid body reference node. |
