# FluidPressurePenetrationState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | FluidPressurePenetrationState object | | |  | | | |  | | --- | | The FluidPressurePenetrationState object stores the propagating data for a pressure in a step. One instance of this object is created internally by the [FluidPressurePenetration](simaker-c-fluidpressurepenetrationpyc.md) object for each step. The instance is also deleted internally by the [FluidPressurePenetration](simaker-c-fluidpressurepenetrationpyc.md) object. The FluidPressurePenetrationState object has no constructor or methods.  The FluidPressurePenetrationState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-fluidpressurepenetrationstatepyc__simaker-c-pressurestatepyc-s-pyaccess1) * [Members](#simaker-c-pressurestatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-pressurestatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The FluidPressurePenetrationState object has the following members:  magnitude  A Float specifying the pressure magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the pressure magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  criticalPressure  A Float specifying the critical contact interface pressure threshold at which fluid penetration starts to occur. The default value is 0.0.  criticalPressureState  A SymbolicConstant specifying the propagation state of the criticalPressure member. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  timePeriod  A Float specifying the time period over which the fluid pressure on the newly penetrated contact surface segments is ramped up to the current magnitude. The timePeriod argument applies only in Abaqus/Standard and is neglected in the linear perturbation analysis. The default value is 0.001.  timePeriodState  A SymbolicConstant specifying the propagation state of the timePeriod member. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  evolutionRegionMethod  A SymbolicConstant LOCAL or WETTING\_ADVANCE used for specifying the algorithm to control the evolution of the region exposed to the fluid pressure. The evolutionRegionMethod argument applies WETTING\_ADVANCE only in an Abaqus/Explicit analysis. The default value is LOCAL.  evolutionRegionMethodState  A SymbolicConstant specifying the propagation state of the evolutionRegionMethod member. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  wettedRegion  A [Region](simaker-c-regionpyc.md) object specifying the node or node set on the surface initially exposed to fluid pressure. The wettedRegion argument applies only when the evolutionRegionMethod argument has the value WETTING\_ADVANCE.  wettedRegionState  A SymbolicConstant specifying the propagation state of the wettedRegion member. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  Corresponding analysis keywords * [DSLOAD](.._SIMACAEKEYRefMap_simakey-r-dsload.md#simakey-r-dsload) * [DLOAD](.._SIMACAEKEYRefMap_simakey-r-dload.md#simakey-r-dload) |
