# ActuatorSensorState object

|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | ActuatorSensorState object | | |  | | | |  | | --- | | The ActuatorSensorState object stores the propagating data of an actuator sensor in a step. One instance of this object is created internally by the [ActuatorSensor](simaker-c-actuatorsensorpyc.md) object for each step. The instance is also deleted internally by the [ActuatorSensor](simaker-c-actuatorsensorpyc.md) object.  The ActuatorSensorState object has no constructor, methods, or members.  The ActuatorSensorState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE |
