This method creates a GapConductance object.  Path  ``` materialApi.materials()[name].GapConductance ```  Prototype  ``` odb_GapConductance& GapConductance(const odb_SequenceSequenceDouble& table, Float mainSurfaceEmissivity, Float secondarySurfaceEmissivity, ); ```  Required arguments mainSurfaceEmissivity  A Float specifying the Emissivity of main surface.  secondarySurfaceEmissivity  A Float specifying the Emissivity of the secondary surface.  table  An odb\_SequenceSequenceDouble specifying the items described below.  Table data The table data specify the following:   * Effective View Factor. * Gap Clearance. * Repeat this data line as often as necessary to define the dependence of the view   factor on gap clearance.  Return value A GapRadiation object.  Exceptions None.  Members The GapRadiation object has members with the same names and descriptions as the arguments to the [GapRadiation](simaker-c-gapradiationcpp.md#simaker-gapradiationgapradiationcpp) method.
