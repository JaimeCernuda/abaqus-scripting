# ShellEdgeLoadState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | ShellEdgeLoadState object | | |  | | | |  | | --- | | The ShellEdgeLoadState object stores the propagating data for a [ShellEdgeLoad](simaker-c-shelledgeloadpyc.md) object in a step. One instance of this object is created internally by the [ShellEdgeLoad](simaker-c-shelledgeloadpyc.md) object for each step. The instance is also deleted internally by the [ShellEdgeLoad](simaker-c-shelledgeloadpyc.md) object.  The ShellEdgeLoadState object has no constructor or methods.  The ShellEdgeLoadState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-shelledgeloadstatepyc__simaker-c-shelledgeloadstatepyc-s-pyaccess1) * [Members](#simaker-c-shelledgeloadstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-shelledgeloadstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The ShellEdgeLoadState object has the following members:  magnitude  A Float or a Complex specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.
