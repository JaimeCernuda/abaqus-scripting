# CoriolisForceState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | CoriolisForceState object | | |  | | | |  | | --- | | The CoriolisForceState object stores the propagating data of a coriolis force in a step. One instance of this object is created internally by the [CoriolisForce](simaker-c-coriolisforcepyc.md) object for each step. The instance is also deleted internally by the [CoriolisForce](simaker-c-coriolisforcepyc.md) object.  The CoriolisForceState object has no constructor or methods.  The CoriolisForceState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-coriolisforcestatepyc__simaker-c-coriolisforcestatepyc-s-pyaccess1) * [Members](#simaker-c-coriolisforcestatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-coriolisforcestatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The CoriolisForceState object has the following members:  magnitude  A Float specifying the load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the load magnitude. Possible values are UNSET, SET, UNCHANGED, and FREED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DLOAD](.._SIMACAEKEYRefMap_simakey-r-dload.md#simakey-r-dload) (load type label: CORIO) |
