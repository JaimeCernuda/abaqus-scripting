# SecondaryBaseBCState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | SecondaryBaseBCState object | | |  | | | |  | | --- | | The SecondaryBaseBCState object stores the propagating data for a secondary base boundary condition in a step. One instance of this object is created internally by the [SecondaryBaseBC](simaker-c-secondarybasebcpyc.md) object for each step. The instance is also deleted internally by the [SecondaryBaseBC](simaker-c-secondarybasebcpyc.md) object.  The SecondaryBaseBCState object has no constructor or methods.  The SecondaryBaseBCState object is derived from the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-secondarybasebcstatepyc__simaker-c-secondarybasebcstatepyc-s-pyaccess1) * [Members](#simaker-c-secondarybasebcstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-secondarybasebcstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].boundaryConditionStates[name] ```  Members The SecondaryBaseBCState object has the following members:  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude reference. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * PROPAGATED\_FROM\_BASE\_STATE * MODIFIED\_FROM\_BASE\_STATE * DEACTIVATED\_FROM\_BASE\_STATE * BUILT\_INTO\_MODES  amplitude  A String specifying the name of the amplitude reference. The String is empty if the boundary condition has no amplitude reference.  Corresponding analysis keywords * [BOUNDARY](.._SIMACAEKEYRefMap_simakey-r-boundary.md#simakey-r-boundary), BASE NAME |
