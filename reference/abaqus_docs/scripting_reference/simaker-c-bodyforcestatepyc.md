# BodyForceState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | BodyForceState object | | |  | | | |  | | --- | | The BodyForceState object stores the propagating data of a body force in a step. One instance of this object is created internally by the [BodyForce](simaker-c-bodyforcepyc.md) object for each step. The instance is also deleted internally by the [BodyForce](simaker-c-bodyforcepyc.md) object.  The BodyForceState object has no constructor or methods.  The BodyForceState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-bodyforcestatepyc__simaker-c-bodyforcestatepyc-s-pyaccess1) * [Members](#simaker-c-bodyforcestatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-bodyforcestatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The BodyForceState object has the following members:  comp1  A Float or a Complex specifying the body force component in the 1-direction.  comp2  A Float or a Complex specifying the body force component in the 2-direction.  comp3  A Float or a Complex specifying the body force component in the 3-direction.  comp1State  A SymbolicConstant specifying the propagation state of the body force component in the 1-direction. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  comp2State  A SymbolicConstant specifying the propagation state of the body force component in the 2-direction. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  comp3State  A SymbolicConstant specifying the propagation state of the body force component in the 3-direction. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DLOAD](.._SIMACAEKEYRefMap_simakey-r-dload.md#simakey-r-dload) (load type label: BX, BY, BZ, BR, BXNU, BYNU, BZNU, or BRNU) |
