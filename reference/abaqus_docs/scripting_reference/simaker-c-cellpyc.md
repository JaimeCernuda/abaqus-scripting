This method returns a Float indicating the volume of the cell.  Required arguments None.  Optional arguments printResults  A Boolean that determines whether a verbose output is to be printed. The default is True.  Return value A Float.  Exceptions None.  getFaces() This method returns a sequence consisting of the face IDs of the faces which bound the cell.  Arguments None.  Return value A tuple of integers.  Exceptions None.  getEdges() This method returns a sequence consisting of the edge IDs of the edges on the cell.  Arguments None.  Return value A tuple of integers.  Exceptions None.  getVertices() This method returns a sequence consisting of the vertex IDs of the vertices on the cell.  Arguments None.  Return value A tuple of integers.  Exceptions None.  getAdjacentCells() This method returns an array of cell objects that share at least one face of the cell.  Arguments None.  Return value A [CellArray](simaker-c-cellpyc.md) object which is a sequence of Cell objects.  Exceptions None.  getNodes() This method returns an array of node objects that are associated with the cell.  Arguments None.  Return value A [MeshNodeArray](simaker-c-meshnodepyc.md) object which is a sequence of [MeshNode](simaker-c-meshnodepyc.md) objects.  Exceptions None.  getElements() This method returns an array of element objects that are associated with the cell.  Arguments None.  Return value A [MeshElementArray](simaker-c-meshelementpyc.md) object which is a sequence of [MeshElement](simaker-c-meshelementpyc.md) objects.  Exceptions None.  getCADAttributes(...) This method returns an array of CAD attribute strings associated with the cell when the part was created from CAD data.  Arguments None.  Return value An array of String.  Exceptions None.  Members The Cell object has the following members:  index  An Int specifying the index of the cell in the CellArray.  isReferenceRep  A Boolean specifying whether the cell belongs to the reference representation of the Part or Instance.  pointOn  A tuple of Floats specifying the X-, Y-, and Z-coordinates of a point located on the cell.  featureName  A tuple of Floats specifying the name of the feature that created this cell.  instanceName  A tuple of Floats specifying the name of the part instance for this cell (if applicable). |
