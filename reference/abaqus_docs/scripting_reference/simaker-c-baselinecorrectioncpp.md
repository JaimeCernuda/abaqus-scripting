Path  ``` amplitudeApi.amplitudes()[name].BaselineCorrection ```  Prototype  ``` odb_BaselineCorrection& BaselineCorrection(const odb_SequenceDouble& intervals); ```  Required arguments None.  Optional arguments intervals  An odb\_SequenceDouble specifying the correction time interval end points. Possible values are positive and monotonically increasing Floats.
