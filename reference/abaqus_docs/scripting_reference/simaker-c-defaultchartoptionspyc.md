# DefaultChartOptions object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | DefaultChartOptions object | | |  | | | |  | | --- | | The DefaultChartOptions object is used to hold on default chart and axis attributes. The DefaultChartOptions object attributes are used whenever Chart or Axis are created. A DefaultChartOptions object is automatically created when opening a session.  This page discusses:   * [Access](#simaker-c-defaultchartoptionspyc__simaker-c-defaultchartoptionspyc-s-pyaccess1) * [setValues(...)](#simaker-defaultchartoptionssetvaluespyc) * [Members](#simaker-c-defaultchartoptionspyc-t-pymembersect1) | | |   Access  ``` import visualization session.defaultChartOptions ```  setValues(...) This method modifies the DefaultChartOptions object.  Required arguments None.  Optional arguments areaStyle  An [AreaStyle](simaker-c-areastylepyc.md) object specifying an [AreaStyle](simaker-c-areastylepyc.md) used to hold on to the default display properties for the chart area.  aspectRatio  A Float specifying the default aspect ratio of the grid area. A value of -1 specifies that the gridArea will take up all available space. The default value is −1.  defaultAxis1Options  An [Axis](simaker-c-axispyc.md) object specifying an [Axis](simaker-c-axispyc.md) object used to hold on to the default properties for direction 1 axes—the abscissa for a Cartesian chart.  defaultAxis2Options  An [Axis](simaker-c-axispyc.md) object specifying an [Axis](simaker-c-axispyc.md) object used to hold on to the default properties for direction 2 axes—the ordinate for a Cartesian chart.  gridArea  An [Area](simaker-c-areapyc.md) object specifying how to display the grid area by default.  legend  A [Legend](simaker-c-legendpyc.md) object specifying the default attributes for the legend of the chart.  majorAxis1GridStyle  A [LineStyle](simaker-c-linestylepyc.md) object specifying the default line properties to be used when drawing major gridlines along axis 1.  majorAxis2GridStyle  A [LineStyle](simaker-c-linestylepyc.md) object specifying the default line properties to be used when drawing major gridlines along axis 2.  minorAxis1GridStyle  A [LineStyle](simaker-c-linestylepyc.md) object specifying the default line properties to be used when drawing minor gridlines along axis 1.  minorAxis2GridStyle  A [LineStyle](simaker-c-linestylepyc.md) object specifying the default line properties to be used when drawing minor gridlines along axis 2.  tagAreaStyle  An [AreaStyle](simaker-c-areastylepyc.md) object specifying the default area properties to be used when creating tags.  tagBorder  A [LineStyle](simaker-c-linestylepyc.md) object specifying the default tag area border properties to be used when creating tags.  tagTextStyle  A [TextStyle](simaker-c-textstylepyc.md) object specifying the default text properties to be used when creating tags.  useQuantityType  A Boolean specifying whether to use the [QuantityType](simaker-c-quantitytypepyc.md) to associate curves with axes. The default value is ON.  Return value None.  Exceptions None.  Members The DefaultChartOptions object has members with the same names and descriptions as the arguments to the [setValues](simaker-c-defaultchartoptionspyc.md#simaker-defaultchartoptionssetvaluespyc) method. |
