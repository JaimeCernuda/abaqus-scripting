| |  |  | | --- | --- | | LeafFromOdbElementTypes object | | |  | | | |  | | --- | | The LeafFromOdbElementTypes object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are used to specify the items in a display group. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands.  The LeafFromOdbElementTypes object is derived from the [Leaf](simaker-c-leafpyc.md) object. This method creates a [Leaf](simaker-c-leafpyc.md) object from a sequence of Strings specifying element names. Leaf objects specify the items in a display group.  Path  ``` LeafFromOdbElementTypes ```  Required arguments elementTypes  A sequence of Strings specifying element Types.  Optional arguments None.  Return value A LeafFromOdbElementTypes object.  Exceptions None.  Members The LeafFromOdbElementTypes object has the following member:  leafType  A SymbolicConstant specifying the leaf type. Possible values are EMPTY\_LEAF, DEFAULT\_MODEL, ALL\_ELEMENTS, ALL\_NODES, and ALL\_SURFACES. |
