# TemperatureBCState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | TemperatureBCState object | | |  | | | |  | | --- | | The TemperatureBCState object stores the propagating data for a temperature boundary condition in a step. One instance of this object is created internally by the [TemperatureBC](simaker-c-temperaturebcpyc.md) object for each step. The instance is also deleted internally by the [TemperatureBC](simaker-c-temperaturebcpyc.md) object.  The TemperatureBCState object has no constructor or methods.  The TemperatureBCState object is derived from the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-temperaturebcstatepyc__simaker-c-temperaturebcstatepyc-s-pyaccess1) * [Members](#simaker-c-temperaturebcstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-temperaturebcstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].boundaryConditionStates[name] ```  Members The TemperatureBCState object has the following members:  magnitude  A Float specifying the temperature magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the temperature magnitude. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  dofState  A SymbolicConstant specifying the propagation state of the dof member. Possible values are SET and UNCHANGED.  dof  A tuple of Ints specifying the degrees of freedom to which the boundary condition is applied.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude reference. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * PROPAGATED\_FROM\_BASE\_STATE * MODIFIED\_FROM\_BASE\_STATE * DEACTIVATED\_FROM\_BASE\_STATE * BUILT\_INTO\_MODES  amplitude  A String specifying the name of the amplitude reference. The String is empty if the boundary condition has no amplitude reference.  Corresponding analysis keywords * [BOUNDARY](.._SIMACAEKEYRefMap_simakey-r-boundary.md#simakey-r-boundary) (degree of freedom: 11 for solids; 11, 12, etc. for shells) |
