# RigidBody object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | RigidBody object | | |  | | | |  | | --- | | The RigidBody object constrains all the degrees of freedom on the specified regions to the degree of freedom of its associated reference point.  The RigidBody object is derived from the [Constraint](simaker-c-constraintpyc.md) object.  This page discusses:   * [Access](#simaker-c-rigidbodypyc__simaker-c-rigidbodypyc-s-pyaccess1) * [RigidBody(...)](#simaker-rigidbodyrigidbodypyc) * [setValues(...)](#simaker-rigidbodysetvaluespyc) * [Members](#simaker-c-rigidbodypyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-rigidbodypyc-t-pykeywordsect1) | | |   Access  ``` import interaction mdb.models[name].constraints[name] ```  RigidBody(...) This method creates a RigidBody object.  Path  ``` mdb.models[name].RigidBody ```  Required arguments name  A String specifying the constraint repository key.  refPointRegion  A [Region](simaker-c-regionpyc.md) object specifying the reference point.  Optional arguments bodyRegion  None or a [Region](simaker-c-regionpyc.md) object specifying the elements constrained to the movement of the reference point. The default value is None.  tieRegion  None or a [Region](simaker-c-regionpyc.md) object specifying the nodes tied to the movement of the reference point. The default value is None.  pinRegion  None or a [Region](simaker-c-regionpyc.md) object specifying the nodes pinned to the movement of the reference point. The default value is None.  surfaceRegion  None or a [Region](simaker-c-regionpyc.md) object specifying the analytic surface constrained to the movement of the reference point. The default value is None.  refPointAtCOM  A Boolean specifying whether the analysis product should recompute the reference point position to be at the center of mass. The default value is OFF.  isothermal  A Boolean specifying whether the temperature degree of freedom should be constrained. The default value is OFF.  Return value A RigidBody object.  Exceptions None.  setValues(...) This method modifies the RigidBody object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [RigidBody](simaker-c-rigidbodypyc.md#simaker-rigidbodyrigidbodypyc) method, except for the name argument.  Return value None.  Exceptions None.  Members The RigidBody object has members with the same names and descriptions as the arguments to the [RigidBody](simaker-c-rigidbodypyc.md#simaker-rigidbodyrigidbodypyc) method.  In addition, the RigidBody object has the following member:  suppressed  A Boolean specifying whether the constraint is suppressed or not. The default value is OFF.
