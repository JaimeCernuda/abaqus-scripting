# BoltLoadState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | BoltLoadState object | | |  | | | |  | | --- | | The BoltLoadState object stores the propagating data of a bolt load in a step. One instance of this object is created internally by the [BoltLoad](simaker-c-boltloadpyc.md) object for each step. The instance is also deleted internally by the [BoltLoad](simaker-c-boltloadpyc.md) object.  The BoltLoadState object has no constructor or methods.  The BoltLoadState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-boltloadstatepyc__simaker-c-boltloadstatepyc-s-pyaccess1) * [Members](#simaker-c-boltloadstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-boltloadstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The BoltLoadState object has the following members:  boltMethod  A SymbolicConstant specifying the type of bolt load. Possible values are APPLY\_FORCE, ADJUST\_LENGTH, and FIX\_LENGTH.  boltMethodState  A SymbolicConstant specifying the propagation state of the bolt load type. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  magnitude  A Float specifying the bolt load magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the bolt load magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [CLOAD](.._SIMACAEKEYRefMap_simakey-r-cload.md#simakey-r-cload) (when boltMethod=APPLY\_FORCE) * [BOUNDARY](.._SIMACAEKEYRefMap_simakey-r-boundary.md#simakey-r-boundary) (when boltMethod=ADJUST\_LENGTH or FIX\_LENGTH) |
