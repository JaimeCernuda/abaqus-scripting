# CyclicSymmetryState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | CyclicSymmetryState object | | |  | | | |  | | --- | | The CyclicSymmetryState object stores the propagating data for a [CyclicSymmetry](simaker-c-cyclicsymmetrypyc.md) object. One instance of this object is created internally by the [CyclicSymmetry](simaker-c-cyclicsymmetrypyc.md) object for each step. The instance is also deleted internally by the [CyclicSymmetry](simaker-c-cyclicsymmetrypyc.md) object.  The CyclicSymmetryState object has no constructor or methods.  The CyclicSymmetryState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-cyclicsymmetrystatepyc__simaker-c-cyclicsymmetrystatepyc-s-pyaccess1) * [Members](#simaker-c-cyclicsymmetrystatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-cyclicsymmetrystatepyc-t-pykeywordsect1) | | |   Access  ``` import interaction mdb.models[name].steps[name].interactionStates[name] ```  Members The CyclicSymmetryState object has the following members:  extractedNodalDiameter  A SymbolicConstant specifying whether Abaqus should extract all possible nodal diameters or the nodal diameters between the user-specified values for lowestNodalDiameter and highestNodalDiameter. Possible values are ALL\_NODAL\_DIAMETER and SPECIFIED\_NODAL\_DIAMETER. The default value is ALL\_NODAL\_DIAMETER.  extractedNodalDiameterState  A SymbolicConstant specifying the propagation state of the extractedNodalDiameter member. Possible values are UNSET, SET, UNCHANGED, and FREED.  lowestNodalDiameter  An Int specifying the lowest nodal diameter to be used in the eigenfrequency analysis. The default value is 0.  lowestNodalDiameterState  A SymbolicConstant specifying the propagation state of the lowestNodalDiameter member. Possible values are UNSET, SET, UNCHANGED, and FREED.  highestNodalDiameter  An Int specifying the highest nodal diameter to be used in the eigenfrequency analysis. This argument value should be less than or equal to the half of the total number of sectors. The default value is 0.  highestNodalDiameterState  A SymbolicConstant specifying the propagation state of the highestNodalDiameter member. Possible values are UNSET, SET, UNCHANGED, and FREED.  excitiationNodalDiameter  An Int specifying the nodal diameter for which the modal-based steady-state dynamic analysis will be performed. This value should be greater than or equal to the lowest nodal diameter (specified in the lowestNodalDiameter parameter), and less than or equal to the highest nodal diameter (specified in the highestNodalDiameter parameter). The default value is 0.  excitiationNodalDiameterState  A SymbolicConstant specifying the propagation state of the excitiationNodalDiameter member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [InteractionState](simaker-c-interactionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  Corresponding analysis keywords * [CLOAD](.._SIMACAEKEYRefMap_simakey-r-cload.md#simakey-r-cload), CYCLIC MODE * [DLOAD](.._SIMACAEKEYRefMap_simakey-r-dload.md#simakey-r-dload), CYCLIC MODE * [DSLOAD](.._SIMACAEKEYRefMap_simakey-r-dsload.md#simakey-r-dsload), CYCLIC MODE * [SELECT CYCLIC SYMMETRY MODES](.._SIMACAEKEYRefMap_simakey-r-selectcyclicsymmetrymodes.md#simakey-r-selectcyclicsymmetrymodes) |
