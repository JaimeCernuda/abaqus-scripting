# TypeBCState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | TypeBCState object | | |  | | | |  | | --- | | The TypeBCState object stores the propagating data for a predefined boundary condition in a step. One instance of this object is created internally by the [TypeBC](simaker-c-typebcpyc.md) object for each step. The instance is also deleted internally by the [TypeBC](simaker-c-typebcpyc.md) object.  The TypeBCState object has no constructor or methods.  The TypeBCState object is derived from the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-typebcstatepyc__simaker-c-typebcstatepyc-s-pyaccess1) * [Members](#simaker-c-typebcstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-typebcstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].boundaryConditionStates[name] ```  Members The TypeBCState object has the following members:  typeName  A SymbolicConstant specifying the predefined boundary condition type. Possible values are XSYMM, YSYMM, ZSYMM, XASYMM, YASYMM, ZASYMM, PINNED, and ENCASTRE.  typeNameState  A SymbolicConstant specifying the propagation state of the predefined boundary condition type. The only possible value is UNCHANGED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude reference. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * PROPAGATED\_FROM\_BASE\_STATE * MODIFIED\_FROM\_BASE\_STATE * DEACTIVATED\_FROM\_BASE\_STATE * BUILT\_INTO\_MODES  amplitude  A String specifying the name of the amplitude reference. The String is empty if the boundary condition has no amplitude reference.  Corresponding analysis keywords * [BOUNDARY](.._SIMACAEKEYRefMap_simakey-r-boundary.md#simakey-r-boundary), TYPE=XSYMM, YSYMM, ZSYMM, XASYMM, YASYMM, ZASYMM, PINNED, or ENCASTRE |
