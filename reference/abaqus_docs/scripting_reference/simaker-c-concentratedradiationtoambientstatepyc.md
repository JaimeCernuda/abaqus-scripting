One instance of this object is created internally by the [ConcentratedRadiationToAmbient](simaker-c-concentratedradiationtoambientpyc.md) object for each step. The ConcentratedRadiationToAmbientState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.
