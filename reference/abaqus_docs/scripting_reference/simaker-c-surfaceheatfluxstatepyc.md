# SurfaceHeatFluxState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | SurfaceHeatFluxState object | | |  | | | |  | | --- | | The SurfaceHeatFluxState object stores the propagating data for a surface [SurfaceHeatFlux](simaker-c-surfaceheatfluxpyc.md) object in a step. One instance of this object is created internally by the [SurfaceHeatFlux](simaker-c-surfaceheatfluxpyc.md) object for each step. The instance is also deleted internally by the [SurfaceHeatFlux](simaker-c-surfaceheatfluxpyc.md) object.  The SurfaceHeatFluxState object has no constructor or methods.  The SurfaceHeatFluxState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-surfaceheatfluxstatepyc__simaker-c-surfaceheatfluxstatepyc-s-pyaccess1) * [Members](#simaker-c-surfaceheatfluxstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-surfaceheatfluxstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The SurfaceHeatFluxState object has the following members:  magnitude  A Float specifying the surface heat flux magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the surface heat flux magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DSFLUX](.._SIMACAEKEYRefMap_simakey-r-dsflux.md#simakey-r-dsflux) |
