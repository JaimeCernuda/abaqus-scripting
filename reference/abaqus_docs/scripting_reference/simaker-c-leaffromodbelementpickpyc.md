This method creates a [Leaf](simaker-c-leafpyc.md) object from a tuple containing machine readable, compact strings defining the elements picked for each part instance. Leaf objects specify the items in a display group. Return value A LeafFromOdbElementPick object.  Exceptions None.  Members The LeafFromOdbElementPick object has the following member:  leafType  A SymbolicConstant specifying the leaf type.
