| |  |  | | --- | --- | | LeafFromOdbNodePick object | | |  | | | |  | | --- | | The LeafFromOdbNodePick object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands. This method creates a [Leaf](simaker-c-leafpyc.md) object from a tuple containing machine readable, compact strings defining the nodes picked for each part instance. Leaf objects specify the items in a display group.  Path  ``` LeafFromOdbNodePick ```  Required arguments nodePick  A sequence of tuples of the form [part name, entity count, machine readable pick strings].  Optional arguments None.  Return value A LeafFromOdbNodePick object.  Exceptions None.  Members The LeafFromOdbNodePick object has the following member:  leafType  A SymbolicConstant specifying the leaf type. Possible values are EMPTY\_LEAF, DEFAULT\_MODEL, ALL\_ELEMENTS, ALL\_NODES, and ALL\_SURFACES. |
