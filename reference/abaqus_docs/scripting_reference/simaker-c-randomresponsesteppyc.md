| |  |  | | --- | --- | | RandomResponseStep object | | |  | | | |  | | --- | | The RandomResponseStep object is used to give the linearized response of a model to random excitation.  The RandomResponseStep object is derived from the [AnalysisStep](simaker-c-analysissteppyc.md) object.  This page discusses:   * [Access](#simaker-c-randomresponsesteppyc__simaker-c-randomresponsesteppyc-s-pyaccess1) * [RandomResponseStep(...)](#simaker-randomresponsesteprandomresponsesteppyc) * [setValues(...)](#simaker-randomresponsestepsetvaluespyc) * [Members](#simaker-c-randomresponsesteppyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-randomresponsesteppyc-t-pykeywordsect1) | | |   Access  ``` import step mdb.models[name].steps[name] ```  RandomResponseStep(...) This method creates a RandomResponseStep object.  Path  ``` mdb.models[name].RandomResponseStep ```  Required arguments name  A String specifying the repository key.  previous  A String specifying the name of the previous step. The new step appears after this step in the list of analysis steps.  freq  A [RandomResponseFrequencyArray](simaker-c-randomresponsefrequencypyc.md) object specifying frequencies over ranges of modes.  Optional arguments description  A String specifying a description of the new step. The default value is an empty string.  scale  A SymbolicConstant specifying the frequency scale. Possible values are LINEAR and LOG. The default value is LOG.  directDamping  A [DirectDamping](simaker-c-directdampingpyc.md) object.  compositeDamping  A [CompositeDamping](simaker-c-compositedampingpyc.md) object.  rayleighDamping  A [RayleighDamping](simaker-c-rayleighdampingpyc.md) object.  structuralDamping  A [StructuralDamping](simaker-c-structuraldampingpyc.md) object.  directDampingByFrequency  A [DirectDampingByFrequency](simaker-c-directdampingbyfrequencypyc.md) object.  rayleighDampingByFrequency  A [RayleighDampingByFrequency](simaker-c-rayleighdampingbyfrequencypyc.md) object.  structuralDampingByFrequency  A [StructuralDampingByFrequency](simaker-c-structuraldampingbyfrequencypyc.md) object.  maintainAttributes  A Boolean specifying whether to retain attributes from an existing step with the same name. The default value is False.  Return value A RandomResponseStep object.  Exceptions RangeError.  setValues(...) This method modifies the RandomResponseStep object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [RandomResponseStep](simaker-c-randomresponsesteppyc.md#simaker-randomresponsesteprandomresponsesteppyc) method, except for the name, previous, and maintainAttributes arguments.  Return value None.  Exceptions RangeError.  Members The RandomResponseStep object can have the following members:  name  A String specifying the repository key.  scale  A SymbolicConstant specifying the frequency scale.
