| |  |  | | --- | --- | | Layer object | | |  | | | |  | | --- | | Objects can be superimposed by displaying them in different layers of a viewport.  This page discusses:   * [Access](#simaker-c-layerpyc__simaker-c-layerpyc-s-pyaccess1) * [Layer(...)](#simaker-layerlayerpyc) * [moveBefore(...)](#simaker-layermovebeforepyc) * [moveAfter(...)](#simaker-layermoveafterpyc) * [Members](#simaker-c-layerpyc-t-pymembersect1) | | |   Access  ``` session.viewports[name].layers[name] ```  Layer(...) This method creates a Layer object in the Layer repository.  Path  ``` session.viewports[name].Layer ```  Required arguments name  A String specifying the repository key.  Optional arguments copyViewName  A String specifying the name of the layer to copy.  Return value A Layer object.  Exceptions None.  moveBefore(...) This method moves the layer object before another object in the layer repository.  Required arguments name  A String specifying the name of the other Layer object.  Optional arguments None.  Return value None.  Exceptions None.  moveAfter(...) This method moves the layer object after another object in the layer repository.  Required arguments name  A String specifying the name of the other Layer object.  Optional arguments None.  Return value None.  Exceptions None.  Members The Layer object has members with the same names and descriptions as the arguments to the [Layer](simaker-c-layerpyc.md#simaker-layerlayerpyc) method.  In addition, the Layer object can have the following members:  displayedObject  A Displayable object specifying the object to be displayed. The Displayable type is an abstract generalization. The concrete possible types are [Part](simaker-c-partpyc.md), [Assembly](simaker-c-assemblypyc.md), [ConstrainedSketch](simaker-c-constrainedsketchpyc.md), [Odb](simaker-c-odbpyc.md), or [XYPlot](simaker-c-xyplotpyc.md).  view  A [View](simaker-c-viewpyc.md) object specifying the object that controls viewing of the layer.  odbDisplay  An [OdbDisplay](simaker-c-odbdisplaypyc.md) object specifying the display options for the [Odb](simaker-c-odbpyc.md) object.  partDisplay  A [PartDisplayOptions](simaker-c-partdisplayoptionspyc.md) object specifying the display options for the [Part](simaker-c-partpyc.md) object.  assemblyDisplay  An [AssemblyDisplayOptions](simaker-c-assemblydisplayoptionspyc.md) object specifying the display options for the [Assembly](simaker-c-assemblypyc.md) object. |
