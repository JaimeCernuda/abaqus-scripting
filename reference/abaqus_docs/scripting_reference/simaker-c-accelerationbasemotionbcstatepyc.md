| |  |  | | --- | --- | | AccelerationBaseMotionBCState object | | |  | | | |  | | --- | | The AccelerationBaseMotionBCState object stores the propagating data for a velocity base motion boundary condition in a step. One instance of this object is created internally by the [AccelerationBaseMotionBC](simaker-c-accelerationbasemotionbcpyc.md) object for each step. The instance is also deleted internally by the [AccelerationBaseMotionBC](simaker-c-accelerationbasemotionbcpyc.md) object.  The AccelerationBaseMotionBCState object has no constructor or methods.  The AccelerationBaseMotionBCState object is derived from the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * PROPAGATED\_FROM\_BASE\_STATE * MODIFIED\_FROM\_BASE\_STATE * DEACTIVATED\_FROM\_BASE\_STATE * BUILT\_INTO\_MODES  amplitude  A String specifying the name of the amplitude reference.
