| |  |  | | --- | --- | | LeafFromDisplayGroup object | | |  | | | |  | | --- | | The LeafFromDisplayGroup object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are used to specify the items in a display group. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands.  The LeafFromDisplayGroup object is derived from the [Leaf](simaker-c-leafpyc.md) object. This method creates a [Leaf](simaker-c-leafpyc.md) object from a sequence of Display Group objects.  Path  ``` LeafFromDisplayGroup ```  Required arguments displayGroup  A [DisplayGroupArray](simaker-c-displaygrouppyc.md) object.  Optional arguments None.  Return value A LeafFromDisplayGroup object.  Exceptions None.  Members The LeafFromDisplayGroup object has members with the same names and descriptions as the arguments to the [LeafFromDisplayGroup](simaker-c-leaffromdisplaygrouppyc.md#simaker-leaffromdisplaygroupleaffromdisplaygrouppyc) method.  In addition, the LeafFromDisplayGroup object has the following member:  leafType  A SymbolicConstant specifying the leaf type. Possible values are EMPTY\_LEAF, DEFAULT\_MODEL, ALL\_ELEMENTS, ALL\_NODES, and ALL\_SURFACES. |
