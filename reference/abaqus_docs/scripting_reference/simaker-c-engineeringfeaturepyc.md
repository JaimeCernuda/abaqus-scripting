| |  |  | | --- | --- | | EngineeringFeature object | | |  | | | |  | | --- | | The EngineeringFeature object is a container for various specific engineering feature repositories.  The EngineeringFeature object has no explicit constructor or methods. This method creates a seam crack along an edge or a face.  Required arguments regions  A sequence of [Region](simaker-c-regionpyc.md) objects specifying the domain of the seam crack. The [Region](simaker-c-regionpyc.md) objects must be faces or edges.  Optional arguments None.  Return value None.  Exceptions None.  deleteSeam(...) This method deletes a seam crack.  Required arguments regions  A sequence of [Region](simaker-c-regionpyc.md) objects specifying the domain of the seam crack. The [Region](simaker-c-regionpyc.md) objects must be faces or edges.  Optional arguments None.  Return value None.  Exceptions None.  Members The EngineeringFeature object can have the following members:  inertias  A repository of [Inertia](simaker-c-inertiapyc.md) objects.  cracks  A repository of [Crack](simaker-c-crackpyc.md) objects.  fasteners  A repository of [Fastener](simaker-c-fastenerpyc.md) objects.  springDashpots  A repository of [SpringDashpot](simaker-c-springdashpotpyc.md) objects.  imperfections  A repository of [Imperfection](simaker-c-imperfectionpyc.md) objects. |
