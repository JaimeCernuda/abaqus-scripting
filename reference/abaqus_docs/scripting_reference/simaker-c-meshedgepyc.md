# MeshEdge object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | MeshEdge object | | |  | | | |  | | --- | | The MeshEdge object refers to an element edge. It has no constructor or members. A MeshEdge object can be accessed via a [MeshEdgeArray](simaker-c-meshedgepyc.md) or a repository on a part or part instance.  This page discusses:   * [Access](#simaker-c-meshedgepyc__simaker-c-meshedgepyc-s-pyaccess1) * [getElements()](#simaker-meshedgegetelementspyc) * [getElementsViaTopology()](#simaker-meshedgegetelementsviatopologypyc) * [getNodesViaTopology()](#simaker-meshedgegetnodesviatopologypyc) * [getElemFaces()](#simaker-meshedgegetelemfacespyc) * [getNodes()](#simaker-meshedgegetnodespyc) * [Members](#simaker-c-meshedgepyc-t-pymembersect1) | | |   Access  ``` import part mdb.models[name].parts[name].elemEdges[i] mdb.models[name].parts[name].elementEdges[i] import assembly mdb.models[name].rootAssembly.allInstances[name].elemEdges[i] mdb.models[name].rootAssembly.allInstances[name].elementEdges[i] mdb.models[name].rootAssembly.instances[name].elemEdges[i] mdb.models[name].rootAssembly.instances[name].elementEdges[i] ```  getElements() This method returns a tuple of elements that share the element edge.  Arguments None.  Return value A tuple of [MeshElement](simaker-c-meshelementpyc.md) objects.  Exceptions None.  getElementsViaTopology() This method returns an array of [MeshElement](simaker-c-meshelementpyc.md) objects that are obtained by recursively finding adjacent elements via topology.  Optional arguments domain  A MeshElementArray object specifying the domain to include in the search. By default, all elements in the mesh are included.  Return value A [MeshElementArray](simaker-c-meshelementpyc.md) object, which is a sequence of [MeshElement](simaker-c-meshelementpyc.md) objects.  Exceptions None.  getNodesViaTopology() This method returns an array of [MeshNode](simaker-c-meshelementpyc.md) objects that lie along element edges topologically in line with the element edge.  Optional arguments domain  A MeshElementArray object specifying the domain to include in the search. By default, all elements in the mesh are included.  Return value A [MeshNodeArray](simaker-c-meshelementpyc.md) object, which is a sequence of [MeshNode](simaker-c-meshelementpyc.md) objects.  Exceptions None.  getElemFaces() This method returns a tuple of unique [MeshFace](simaker-c-meshfacepyc.md) objects that share the element edge.  Arguments None.  Return value A tuple of [MeshFace](simaker-c-meshfacepyc.md) objects.  Exceptions None.  getNodes() This method returns a tuple of nodes on the element edge.  Arguments None.  Return value A tuple of [MeshNode](simaker-c-meshnodepyc.md) objects.  Exceptions None.  Members The MeshEdge object has no members. |
