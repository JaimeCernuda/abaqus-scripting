|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | LeafFromGeometry object | | |  | | | |  | | --- | | The LeafFromGeometry object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are used to specify the items in a display group. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands.  The LeafFromGeometry object is derived from the [Leaf](simaker-c-leafpyc.md) object. This method creates a Leaf object from a sequence of edge, face and cell geometry objects. Any combination of edge, face or cell arguments is allowed however the arguments must specify at least one object--it is not permissible to create an empty leaf.  Path  ``` LeafFromGeometry ```  Required arguments None.  Optional arguments edgeSeq  A sequence of geometry edges.  faceSeq  A sequence of geometry faces.  cellSeq  A sequence of geometry cells.  Return value A LeafFromGeometry object.  Exceptions If at least one of the sequences is not passed to this method:  Cannot define empty leaf.  Members The LeafFromGeometry object has the following member:  leafType  A SymbolicConstant specifying the leaf type. Possible values are EMPTY\_LEAF, DEFAULT\_MODEL, ALL\_ELEMENTS, ALL\_NODES, and ALL\_SURFACES. |
