| |  |  | | --- | --- | | LeafFromPartInstance object | | |  | | | |  | | --- | | The LeafFromPartInstance object can be used whenever a [Leaf](simaker-c-leafpyc.md) object is expected as an argument. [Leaf](simaker-c-leafpyc.md) objects are used to specify the items in a display group. [Leaf](simaker-c-leafpyc.md) objects are constructed as temporary objects, which are then used as arguments to [DisplayGroup](simaker-c-displaygrouppyc.md) commands.  The LeafFromPartInstance object is derived from the [Leaf](simaker-c-leafpyc.md) object. This method creates a [Leaf](simaker-c-leafpyc.md) object from a list of part instance names.  Path  ``` LeafFromPartInstance ```  Required arguments partInstanceName  A sequence of Strings specifying the names of the part instances.  Optional arguments None.  Return value A LeafFromPartInstance object.  Exceptions None.  Members The LeafFromPartInstance object has members with the same names and descriptions as the arguments to the [LeafFromPartInstance](simaker-c-leaffrompartinstancepyc.md#simaker-leaffrompartinstanceleaffrompartinstancepyc) method.  In addition, the LeafFromPartInstance object has the following member:  leafType  A SymbolicConstant specifying the leaf type. Possible values are EMPTY\_LEAF, DEFAULT\_MODEL, ALL\_ELEMENTS, ALL\_NODES, and ALL\_SURFACES. |
