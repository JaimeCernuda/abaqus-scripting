Path  ``` mdb.models[name].materials[name].MeanFieldHomogenization session.odbs[name].materials[name].MeanFieldHomogenization ```  Required arguments None.  Optional arguments angleSubdivision  An Int specifying the number of angle increments used for the discretization of the orientation space.  formulation  A SymbolicConstant specifying the type of homogenization model. Possible values are MT, REUSS, VOIGT, INVERSED\_MT, BALANCED, and UNSPECIFIED. The default value is MT.  isotropization  A SymbolicConstant specifying the type of isotropization method. Possible values are ALLISO, EISO, and PISO. The default value is ALLISO.  uniformMatrixStrain  A SymbolicConstant specifying whether the average strain in the matrix is uniform across all pseudo-grains. Possible values are NO and YES. The default value is NO.  Return value A MeanFieldHomogenization object.  Exceptions RangeError.  setValues(...) This method modifies the MeanFieldHomogenization object.  Required arguments None.
