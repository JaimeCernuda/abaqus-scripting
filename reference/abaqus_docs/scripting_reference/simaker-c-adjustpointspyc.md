# AdjustPoints object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | AdjustPoints object | | |  | | | |  | | --- | | The AdjustPoints constraint object is used to adjust points (nodes) to a surface.  The AdjustPoints object is derived from the [Constraint](simaker-c-constraintpyc.md) object.  This page discusses:   * [Access](#simaker-c-adjustpointspyc__simaker-c-adjustpointspyc-s-pyaccess1) * [AdjustPoints(...)](#simaker-adjustpointsadjustpointspyc) * [setValues(...)](#simaker-adjustpointssetvaluespyc) * [Members](#simaker-c-adjustpointspyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-adjustpointspyc-t-pykeywordsect1) | | |   Access  ``` import interaction mdb.models[name].constraints[name] ```  AdjustPoints(...) This method creates an AdjustPoints object.  Path  ``` mdb.models[name].AdjustPoints ```  Required arguments name  A String specifying the constraint repository key.  surface  A [Region](simaker-c-regionpyc.md) object specifying the surface to which the controlPoints are adjusted.  controlPoints  A [Region](simaker-c-regionpyc.md) object specifying the constraint control points.  Optional arguments None.  Return value An AdjustPoints object.  Exceptions None.  setValues(...) This method modifies the AdjustPoints object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [AdjustPoints](simaker-c-adjustpointspyc.md#simaker-adjustpointsadjustpointspyc) method, except for the name argument.  Return value None.  Exceptions None.  Members The AdjustPoints object has members with the same names and descriptions as the arguments to the [AdjustPoints](simaker-c-adjustpointspyc.md#simaker-adjustpointsadjustpointspyc) method.  In addition, the AdjustPoints object has the following member:  suppressed  A Boolean specifying whether the constraint is suppressed or not. The default value is OFF.
