This method creates a RuleResult with data for a [RemeshingRule](simaker-c-remeshingrulepyc.md) for a given adaptivity iteration.  Path  ``` mdb.adaptivityProcesses[name].iterations[i].RuleResult ```  Required arguments name  A String specifying the name of the Remeshing Rule to which these results correspond.  indicatorResults  A repository of [ErrorIndicatorResult](simaker-c-errorindicatorresultpyc.md) objects specifying the calculated results from the sizing function corresponding to the error indicator variables for the Remeshing Rule.  numElems  An Int specifying the number of elements before remeshing in the region of the Remeshing Rule.  minSizeElemCount  An Int specifying the number of elements that were constrained to the minimum element size by the Remeshing Rule.  Optional arguments satisfiedVars  A sequence of Strings specifying the error indicator variables that have satisfied the Remeshing Rule.  Return value A RuleResult object.  Exceptions AbaqusException.  Members The RuleResult object has members with the same names and descriptions as the arguments to the [RuleResult](simaker-c-ruleresultpyc.md#simaker-ruleresultruleresultpyc) method. |
