This method creates a TopologyRotationalSymmetry object.  Path  ```           mdb.models[name].optimizationTasks[name].TopologyRotationalSymmetry ```  Required arguments name  A String specifying the geometric restriction repository key.  angle  A Float specifying the repeating segment size, an angle in degrees.  region  A [Region](simaker-c-regionpyc.md) object specifying the region to which the geometric restriction is applied. When used with a [TopologyTask](simaker-c-topologytaskpyc.md), there is no default value. When used with a [ShapeTask](simaker-c-shapetaskpyc.md), the default value is MODEL.  Optional arguments axis  A SymbolicConstant specifying the axis of symmetry. Possible values are AXIS\_1, AXIS\_2, and AXIS\_3. The default value is AXIS\_1.  csys  None or a [DatumCsys](simaker-c-datumcsyspyc.md) object specifying the local coordinate system. If csys=None, the global coordinate system is used. When this member is queried, it returns an Int. The default value is None.  ignoreFrozenArea  A Boolean specifying whether to ignore frozen areas. The default value is OFF.  Return value A TopologyRotationalSymmetry object.  Exceptions None.  setValues(...) This method modifies the TopologyRotationalSymmetry object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [TopologyRotationalSymmetry](simaker-c-topologyrotationalsymmetrypyc.md#simaker-topologyrotationalsymmetrytopologyrotationalsymmetrpyc) method, except for the name argument.  Return value None.  Exceptions None.
