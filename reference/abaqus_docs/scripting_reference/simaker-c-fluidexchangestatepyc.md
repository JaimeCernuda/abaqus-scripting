| |  |  | | --- | --- | | FluidExchangeState object | | |  | | | |  | | --- | | The FluidExchangeState object stores the propagating data for an [FluidExchange](simaker-c-fluidexchangepyc.md) object. One instance of this object is created internally by the [FluidExchange](simaker-c-fluidexchangepyc.md) object for each step. The instance is also deleted internally by the [FluidExchange](simaker-c-fluidexchangepyc.md) object.  The FluidExchangeState object has no constructor or methods.  The FluidExchangeState object is derived from the [InteractionState](simaker-c-interactionstatepyc.md) object.
