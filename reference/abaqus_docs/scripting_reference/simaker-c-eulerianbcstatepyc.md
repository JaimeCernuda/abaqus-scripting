# EulerianBCState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | EulerianBCState object | | |  | | | |  | | --- | | The EulerianBCState object stores the propagating data for an Eulerian boundary condition in a step. One instance of this object is created internally by the [EulerianBC](simaker-c-eulerianbcpyc.md) object for each step. The instance is also deleted internally by the [EulerianBC](simaker-c-eulerianbcpyc.md) object.  The EulerianBCState object has no constructor or methods.  The EulerianBCState object is derived from the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-eulerianbcstatepyc__simaker-c-eulerianbcstatepyc-s-pyaccess1) * [Members](#simaker-c-eulerianbcstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-eulerianbcstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].boundaryConditionStates[name] ```  Members The EulerianBCState object has the following members:  definition  A SymbolicConstant specifying the material flow conditions to be defined. Possible values are INFLOW, OUTFLOW, and BOTH. The default value is INFLOW.  definitionState  A SymbolicConstant specifying the propagation state of the definition member. Possible values are UNSET, SET, and UNCHANGED.  inflowType  A SymbolicConstant specifying the material flow conditions to be defined. Possible values are FREE, NONE, and VOID. The default value is FREE.  inflowTypeState  A SymbolicConstant specifying the propagation state of the definition member. Possible values are UNSET, SET, and UNCHANGED.  outflowType  A SymbolicConstant specifying the material flow conditions to be defined. Possible values are ZERO\_PRESSURE, FREE, NON\_REFLECTING, and EQUILIBRIUM. The default value is ZERO\_PRESSURE.  outflowTypeState  A SymbolicConstant specifying the propagation state of the definition member. Possible values are UNSET, SET, and UNCHANGED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude reference. Possible values are UNSET, SET, UNCHANGED, FREED, and MODIFIED.  status  A SymbolicConstant specifying the propagation state of the [BoundaryConditionState](simaker-c-boundaryconditionstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * PROPAGATED\_FROM\_BASE\_STATE * MODIFIED\_FROM\_BASE\_STATE * DEACTIVATED\_FROM\_BASE\_STATE * BUILT\_INTO\_MODES  amplitude  A String specifying the name of the amplitude reference. The String is empty if the boundary condition has no amplitude reference.
