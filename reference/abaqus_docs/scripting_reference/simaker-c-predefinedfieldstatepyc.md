| |  |  | | --- | --- | | PredefinedFieldState object | | |  | | | |  | | --- | | The PredefinedFieldState object is the base object for the objects in the predefinedFieldState repository of the [Step](simaker-c-steppyc.md) object. The members of the PredefinedFieldState object are common to all objects derived from PredefinedFieldState.  The PredefinedFieldState object has no constructor or methods.  This page discusses:   * [Access](#simaker-c-predefinedfieldstatepyc__simaker-c-predefinedfieldstatepyc-s-pyaccess1) * [Members](#simaker-c-predefinedfieldstatepyc-t-pymembersect1) | | |   Access  ``` import load mdb.models[name].steps[name].predefinedFieldStates[name] ```  Members The PredefinedFieldState object has the following member:  status  A SymbolicConstant specifying the propagation state of the PredefinedFieldState object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * DEACTIVATED\_TO\_INITIAL * NO\_LONGER\_ACTIVE * RESET\_TO\_INITIAL * TO\_BE\_COMPUTED * PROPAGATED\_FROM\_COMPUTED * BUILT\_INTO\_BASE\_STATE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE   This member exists in all PredefinedFieldState objects, but different predefined fields use different subsets of the entire list of possible values depending on propagation rules. |
