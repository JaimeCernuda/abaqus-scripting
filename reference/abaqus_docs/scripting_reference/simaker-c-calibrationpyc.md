| |  |  | | --- | --- | | Calibration object | | |  | | | |  | | --- | | A Calibration object is the object used to specify a material calibration. The Calibration object stores the data that is used for specifying materials from test data. This method creates a Calibration object.  Path  ```           mdb.models[name].Calibration ```  Required arguments name  A String specifying the name of the new calibration.  Optional arguments None.  Return value A Calibration object.  Exceptions InvalidNameError.  Members The Calibration object has members with the same names and descriptions as the arguments to the [Calibration](simaker-c-calibrationpyc.md#simaker-calibrationcalibrationpyc) method.  In addition, the Calibration object can have the following members:  dataSets  A [DataSet](simaker-c-datasetpyc.md) object.  behaviors  A [Behavior](simaker-c-behaviorpyc.md) object. |
