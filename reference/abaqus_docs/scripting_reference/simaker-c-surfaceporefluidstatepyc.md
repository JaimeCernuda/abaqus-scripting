# SurfacePoreFluidState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | SurfacePoreFluidState object | | |  | | | |  | | --- | | The SurfacePoreFluidState object stores the propagating data for a [SurfacePoreFluid](simaker-c-surfaceporefluidpyc.md) object in a step. One instance of this object is created internally by the [SurfacePoreFluid](simaker-c-surfaceporefluidpyc.md) object for each step. The instance is also deleted internally by the [SurfacePoreFluid](simaker-c-surfaceporefluidpyc.md) object.  The SurfacePoreFluidState object has no constructor or methods.  The SurfacePoreFluidState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-surfaceporefluidstatepyc__simaker-c-surfaceporefluidstatepyc-s-pyaccess1) * [Members](#simaker-c-surfaceporefluidstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-surfaceporefluidstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The SurfacePoreFluidState object has the following members:  magnitude  A Float specifying the surface pore fluid flow magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the surface pore fluid flow magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DSFLOW](.._SIMACAEKEYRefMap_simakey-r-dsflow.md#simakey-r-dsflow) |
