# BodyHeatFluxState object

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | BodyHeatFluxState object | | |  | | | |  | | --- | | The BodyHeatFluxState object stores the propagating data for a Body [BodyHeatFlux](simaker-c-bodyheatfluxpyc.md) object in a step. One instance of this object is created internally by the [BodyHeatFlux](simaker-c-bodyheatfluxpyc.md) object for each step. The instance is also deleted internally by the [BodyHeatFlux](simaker-c-bodyheatfluxpyc.md) object.  The BodyHeatFluxState object has no constructor or methods.  The BodyHeatFluxState object is derived from the [LoadState](simaker-c-loadstatepyc.md) object.  This page discusses:   * [Access](#simaker-c-bodyheatfluxstatepyc__simaker-c-bodyheatfluxstatepyc-s-pyaccess1) * [Members](#simaker-c-bodyheatfluxstatepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-bodyheatfluxstatepyc-t-pykeywordsect1) | | |   Access  ``` import load mdb.models[name].steps[name].loadStates[name] ```  Members The BodyHeatFluxState object has the following members:  magnitude  A Float specifying the Body heat flux magnitude.  magnitudeState  A SymbolicConstant specifying the propagation state of the Body heat flux magnitude. Possible values are UNSET, SET, UNCHANGED, and MODIFIED.  amplitudeState  A SymbolicConstant specifying the propagation state of the amplitude member. Possible values are UNSET, SET, UNCHANGED, and FREED.  status  A SymbolicConstant specifying the propagation state of the [LoadState](simaker-c-loadstatepyc.md) object. Possible values are:   * NOT\_YET\_ACTIVE * CREATED * PROPAGATED * MODIFIED * DEACTIVATED * NO\_LONGER\_ACTIVE * TYPE\_NOT\_APPLICABLE * INSTANCE\_NOT\_APPLICABLE * BUILT\_INTO\_BASE\_STATE  amplitude  A String specifying the name of the amplitude reference. The String is empty if the load has no amplitude reference.  Corresponding analysis keywords * [DFLUX](.._SIMACAEKEYRefMap_simakey-r-dflux.md#simakey-r-dflux) |
