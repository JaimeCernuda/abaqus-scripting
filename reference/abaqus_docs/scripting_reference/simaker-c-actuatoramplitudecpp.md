This method creates a ActuatorAmplitude object.  Path  ``` amplitudeApi.ActuatorAmplitude ```  Prototype  ``` odb_ActuatorAmplitude& ActuatorAmplitude(const odb_String& name,                   const odb_String& timeSpan); ```  Required arguments name  An odb\_String specifying the repository key.  Optional arguments timeSpan  An odb\_String specifying the time span of the amplitude. Possible values are "STEP" and "TOTAL". The default value is "STEP".  Return value An ActuatorAmplitude object.  Exceptions InvalidNameError and RangeError.  setValues(...) This method modifies the ActuatorAmplitude object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [ActuatorAmplitude](simaker-c-actuatoramplitudecpp.md#simaker-actuatoramplitudeactuatoramplitudecpp) method, except for the name argument.  Return value None.  Exceptions RangeError.
