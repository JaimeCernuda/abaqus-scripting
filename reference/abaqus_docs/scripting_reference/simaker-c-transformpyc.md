| |  |  | | --- | --- | | Transform object | | |  | | | |  | | --- | | The MakeSketchTransform method creates a Transform object. The Transform object has no direct constructor. A Transform object is a 4×3 matrix of Floats that represents the transformation from sketch coordinates to assembly coordinates or to part coordinates.
