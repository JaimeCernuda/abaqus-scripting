This method creates a SizingPlanarSymmetry object.  Path  ```           mdb.models[name].optimizationTasks[name].SizingPlanarSymmetry ```  Required arguments name  A String specifying the geometric restriction repository key.  region  A [Region](simaker-c-regionpyc.md) object specifying the region to which the geometric restriction is applied.  Optional arguments axis  A SymbolicConstant specifying the axis of symmetry. Possible values are AXIS\_1, AXIS\_2, and AXIS\_3. The default value is AXIS\_1.  csys  None or a [DatumCsys](simaker-c-datumcsyspyc.md) object specifying the local coordinate system. If csys=None, the global coordinate system is used. When this member is queried, it returns an Int. The default value is None.  ignoreFrozenArea  A Boolean specifying whether to ignore frozen areas. The default value is OFF.  Return value A SizingPlanarSymmetry object.  Exceptions None.  setValues(...) This method modifies the sizingPlanarSymmetry object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [sizingPlanarSymmetry](simaker-c-sizingplanarsymmetrypyc.md#simaker-sizingplanarsymmetrysizingplanarsymmetrypyc) method, except for the name argument.  Return value None.  Exceptions None.
