| |  |  | | --- | --- | | FrozenArea object | | |  | | | |  | | --- | | The FrozenArea object defines a frozen area geometric restriction. This method creates a FrozenArea object.  Path  ```           mdb.models[name].optimizationTasks[name].FrozenArea ```  Required arguments name  A String specifying the geometric restriction repository key.  Optional arguments region  A [Region](simaker-c-regionpyc.md) object specifying the region to which the geometric restriction is applied. When used with a [TopologyTask](simaker-c-topologytaskpyc.md), there is no default value. When used with a [ShapeTask](simaker-c-shapetaskpyc.md), the default value is MODEL.  Return value A FrozenArea object.  Exceptions None.  setValues(...) This method modifies the FrozenArea object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [FrozenArea](simaker-c-frozenareapyc.md#simaker-frozenareafrozenareapyc) method, except for the name argument.  Return value None.  Exceptions None.  Members The FrozenArea object has members with the same names and descriptions as the arguments to the [FrozenArea](simaker-c-frozenareapyc.md#simaker-frozenareafrozenareapyc) method. |
