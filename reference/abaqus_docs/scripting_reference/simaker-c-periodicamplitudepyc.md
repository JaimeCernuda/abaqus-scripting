| |  |  | | --- | --- | | PeriodicAmplitude object | | |  | | | |  | | --- | | The PeriodicAmplitude object defines an amplitude curve using a Fourier series. This method creates a PeriodicAmplitude object.  Path  ``` mdb.models[name].PeriodicAmplitude session.odbs[name].PeriodicAmplitude ```  Required arguments name  A String specifying the repository key.  frequency  A Float specifying the circular frequency ω. Possible values are positive numbers.  start  A Float specifying the starting time t0. Possible values are positive numbers.  a\_0  A Float specifying the constant A0.  data  A sequence of pairs of Floats specifying Ai and Bi pairs.  Optional arguments timeSpan  A SymbolicConstant specifying the time span of the amplitude. Possible values are STEP and TOTAL. The default value is STEP.  Return value A PeriodicAmplitude object.  Exceptions InvalidNameError and RangeError.  setValues(...) This method modifies the PeriodicAmplitude object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [PeriodicAmplitude](simaker-c-periodicamplitudepyc.md#simaker-periodicamplitudeperiodicamplitudepyc) method, except for the name argument.  Return value None.  Exceptions RangeError.  Members The PeriodicAmplitude object has members with the same names and descriptions as the arguments to the [PeriodicAmplitude](simaker-c-periodicamplitudepyc.md#simaker-periodicamplitudeperiodicamplitudepyc) method.
