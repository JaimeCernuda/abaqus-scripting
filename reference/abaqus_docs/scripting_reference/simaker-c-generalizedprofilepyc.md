| |  |  | | --- | --- | | GeneralizedProfile object | | |  | | | |  | | --- | | The GeneralizedProfile object defines the properties of a profile via its area, moment of inertia, etc.  The GeneralizedProfile object is derived from the [Profile](simaker-c-profilepyc.md) object.  This page discusses:   * [Access](#simaker-c-generalizedprofilepyc__simaker-c-generalizedprofilepyc-s-pyaccess1) * [GeneralizedProfile(...)](#simaker-generalizedprofilegeneralizedprofilepyc) * [setValues(...)](#simaker-generalizedprofilesetvaluespyc) * [Members](#simaker-c-generalizedprofilepyc-t-pymembersect1) * [Corresponding analysis keywords](#simaker-c-generalizedprofilepyc-t-pykeywordsect1) | | |   Access  ``` import section mdb.models[name].profiles[name] import odbSection session.odbs[name].profiles[name] ```  GeneralizedProfile(...) This method creates a GeneralizedProfile object.  Path  ``` mdb.models[name].GeneralizedProfile session.odbs[name].GeneralizedProfile ```  Required arguments name  A String specifying the repository key.  area  A Float specifying the cross-sectional area for the profile.  i11  A Float specifying the moment of inertia for bending about the 1-axis, I11.  i12  A Float specifying the moment of inertia for cross bending, I12.  i22  A Float specifying the moment of inertia for bending about the 2-axis, I22.  j  A Float specifying the torsional constant, J.  gammaO  A Float specifying the sectorial moment, Γ0.  gammaW  A Float specifying the warping constant, ΓW.  Optional arguments None.  Return value A GeneralizedProfile object.  Exceptions RangeError.  setValues(...) This method modifies the GeneralizedProfile object.  Required arguments None.  Optional arguments The optional arguments to setValues are the same as the arguments to the [GeneralizedProfile](simaker-c-generalizedprofilepyc.md#simaker-generalizedprofilegeneralizedprofilepyc) method, except for the name argument.  Return value None.  Exceptions RangeError.  Members The GeneralizedProfile object has members with the same names and descriptions as the arguments to the [GeneralizedProfile](simaker-c-generalizedprofilepyc.md#simaker-generalizedprofilegeneralizedprofilepyc) method.  Corresponding analysis keywords * [BEAM GENERAL SECTION](.._SIMACAEKEYRefMap_simakey-r-beamgeneralsection.md#simakey-r-beamgeneralsection), SECTION=GENERAL or NONLINEAR GENERAL |
