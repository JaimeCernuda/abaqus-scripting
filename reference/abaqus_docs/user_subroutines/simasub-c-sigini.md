User subroutine [SIGINI](simasub-c-sigini.md#simasub-c-sigini):   * will be called for user-subroutine-defined initial stress fields at particular material   points (these are the effective stress values for soils analysis); * is called at the start of the analysis for each applicable material calculation point in   the model; and * can be used to define all active initial stress components at material points as   functions of coordinates, element number, integration point number, etc.  This page discusses:   * [Stress Components](#simasub-c-sigini-t-StressComponents-sma-topic1) * [Initial Stress Field Equilibrium](#simasub-c-sigini-t-InitialStressFieldEquilibrium-sma-topic2) * [Stress in Multiscale Material](#simasub-c-sigini-t-StressComponents-sma-multscale) * [User Subroutine Interface](#simasub-c-sigini-t-usersubinterface1) * [Variables to Be Defined](#simasub-c-sigini-t-vartodefine1) * [Variables Passed in for Information](#simasub-c-sigini-t-varforinfo1) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Initial Conditions](.._SIMACAEPRCRefMap_simaprc-c-initialcond.md) | | [\*INITIAL CONDITIONS](.._SIMACAEKEYRefMap_simakey-r-initialconditions.md#simakey-r-initialconditions) | |   Products Abaqus/Standard    Stress Components The number of stress components that must be defined depends on the element type for which this call is being made. [About the Element Library](.._SIMACAEELMRefMap_simaelm-c-general.md) describes the element stresses. The order in which the components must be defined is the same as in the element definition. For example, in three-dimensional continuum elements six stress components must be defined in the order      σ 11 ,  σ 22 ,  σ 33 ,  σ 12 ,  σ 13 ,  σ 23 .  Initial Stress Field Equilibrium You should ensure that the initial stress field is in equilibrium with the applied forces and distributed loads by using a static step or a geostatic step to check the equilibrium of the initial stress field before starting the response history. See [Geostatic Stress State](.._SIMACAEANLRefMap_simaanl-c-geostatstress.md) for a discussion of defining initial equilibrium conditions for problems that include pore fluid pressure.  Stress in Multiscale Material For multiscale material ([Mean-Field Homogenization](.._SIMACAEMATRefMap_simamat-c-meanfieldhomogenization.md)), you can define the stress components at either the composite level or at the constituent level. When defining the stresses at the constituent level, you should define stresses at all constituents to ensure that the stresses at the composite level are computed correctly through homogenization.  User Subroutine Interface ```       SUBROUTINE SIGINI(SIGMA,COORDS,NTENS,NCRDS,NOEL,NPT,LAYER,      1 KSPT,LFLAGS,NAMES) C       INCLUDE 'ABA_PARAM.INC' C       DIMENSION SIGMA(NTENS),COORDS(NCRDS),LFLAGS(2)       CHARACTER NAMES(3)*80         user coding to define SIGMA(NTENS)         RETURN       END ```  Variables to Be Defined SIGMA(1)  First stress component.  SIGMA(2)  Second stress component.  SIGMA(3)  Third stress component.  Etc.  Only NTENS stress values should be defined, where NTENS depends on the element type.  Variables Passed in for Information COORDS  An array containing the initial coordinates of this point.  NTENS  Number of stresses to be defined, which depends on the element type.  NCRDS  Number of coordinates.  NOEL  Element number.  NPT  Integration point number in the element.  LAYER  Layer number (for composite shells and layered solids).  KSPT  Section point number within the current layer.  LFLAGS(1)  Rebar flag. If LFLAGS(1)=1, the current integration point is associated with element rebar. Otherwise, LFLAGS(1)=0.  LFLAGS(2)  Constituent flag. If LFLAGS(2)=1, the current integration point is associated with a constituent in the multiscale material. Otherwise, LFLAGS(2)=0.  NAMES(1)  Name of the rebar to which the current integration point belongs, which is the name given in the rebar or rebar layer definition ([Defining Reinforcement](.._SIMACAEMODRefMap_simamod-c-rebarlayer.md) or [Defining Rebar as an Element Property](.._SIMACAEMODRefMap_simamod-c-rebar.md)). If no name was given in the rebar or rebar layer definition, this variable will be blank. This variable is relevant only when LFLAGS(1)=1.  NAMES(2)  Element type name (see [Abaqus/Standard Element Index](.._SIMACAEELMRefMap_simaelm-c-stdelementindex.md)).  NAMES(3)  Constituent name. This variable is relevant only when LFLAGS(2)=1. |
