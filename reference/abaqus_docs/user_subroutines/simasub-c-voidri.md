User subroutine [VOIDRI](simasub-c-voidri.md#simasub-c-voidri):   * will be called to define initial void ratio values at material calculation points of continuum elements (see [About the Element Library](.._SIMACAEELMRefMap_simaelm-c-general.md)) in a porous medium whenever a user-defined initial condition on void ratio is specified; and * can be used to define initial void ratio values as functions of material point coordinates and/or element numbers.
