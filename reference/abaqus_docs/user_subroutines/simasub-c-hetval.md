| |  |  | | --- | --- | | HETVAL | | |  | | | |  | | --- | | User subroutine to provide internal heat generation in heat transfer analysis. User subroutine [HETVAL](simasub-c-hetval.md#simasub-c-hetval):   * can be used to define a heat flux due to internal heat generation in a material, for example, as might be associated with phase changes occurring during the solution; * allows for the dependence of internal heat generation on state variables (such as the fraction of material transformed) that themselves evolve with the solution and are stored as solution-dependent state variables; * will be called at all material calculation points for which the material definition contains volumetric heat generation during heat transfer, coupled temperature-displacement, coupled thermal-electrical, or coupled thermal-electrical-structural analysis procedures; * can be useful if it is necessary to include a kinetic theory for a phase change associated with latent heat release (for example, in the prediction of crystallization in a polymer casting process); * can be used in conjunction with user subroutine [USDFLD](simasub-c-usdfld.md#simasub-c-usdfld) if it is desired to redefine any field variables before they are passed in; and  This page discusses:   * [User Subroutine Interface](#simasub-c-hetval-t-usersubinterface1) * [Variables to Be Defined](#simasub-c-hetval-t-vartodefine1) * [Variables That Can Be Updated](#simasub-c-hetval-t-varmayupdate1) * [Variables Passed in for Information](#simasub-c-hetval-t-varforinfo1) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Uncoupled Heat Transfer Analysis](.._SIMACAEANLRefMap_simaanl-c-heattransfer.md) | | [Fully Coupled Thermal-Stress Analysis](.._SIMACAEANLRefMap_simaanl-c-couptempdisp.md) | | [Fully Coupled Thermal-Electrical-Structural Analysis](.._SIMACAEANLRefMap_simaanl-c-coupthermalelecstruct.md) | | [\*HEAT GENERATION](.._SIMACAEKEYRefMap_simakey-r-heatgeneration.md#simakey-r-heatgeneration) | | [HETVAL](.._SIMACAEVERRefMap_simaver-c-hetval.md) | |   ProductsAbaqus/Standard    User Subroutine Interface ```       SUBROUTINE HETVAL(CMNAME,TEMP,TIME,DTIME,STATEV,FLUX,      1 PREDEF,DPRED) C       INCLUDE 'ABA_PARAM.INC' C       CHARACTER*80 CMNAME C       DIMENSION TEMP(2),STATEV(*),PREDEF(*),TIME(2),FLUX(2),      1 DPRED(*)         user coding to define FLUX and update STATEV         RETURN       END ```  Variables to Be Defined FLUX(1)  Heat flux, r (thermal energy per time per volume: JT−1L−3), at this material calculation point.  FLUX(2)  Rate of change of heat flux per temperature, ∂⁡r/∂⁡θ. This variable is nonzero only if the heat flux depends on temperature. It is needed to define a correct Jacobian matrix.  Variables That Can Be Updated STATEV(\*)  An array containing the user-defined solution-dependent state variables at this point.  In an uncoupled heat transfer analysis STATEV is passed into subroutine [HETVAL](simasub-c-hetval.md#simasub-c-hetval) as the values of these variables at the beginning of the increment. However, any updating of STATEV in user subroutine [USDFLD](simasub-c-usdfld.md#simasub-c-usdfld) will be included in the values passed into subroutine [HETVAL](simasub-c-hetval.md#simasub-c-hetval) since this routine is called before [HETVAL](simasub-c-hetval.md#simasub-c-hetval). In addition, if [HETVAL](simasub-c-hetval.md#simasub-c-hetval) is being used in a fully coupled temperature-displacement or coupled thermal-electrical-structural analysis and user subroutine [UEXPAN](simasub-c-uexpan.md#simasub-c-uexpan), user subroutine [CREEP](simasub-c-creep.md#simasub-c-creep), user subroutine [UMAT](simasub-c-umat.md#simasub-c-umat), or user subroutine [UTRS](simasub-c-utrs.md#simasub-c-utrs) is used to define the mechanical behavior of the material, those routines are called before this routine; therefore, any updating of STATEV done in [UEXPAN](simasub-c-uexpan.md#simasub-c-uexpan), [CREEP](simasub-c-creep.md#simasub-c-creep), [UMAT](simasub-c-umat.md#simasub-c-umat), or [UTRS](simasub-c-utrs.md#simasub-c-utrs) will be included in the values passed into this routine.  In all cases STATEV should be passed back from user subroutine [HETVAL](simasub-c-hetval.md#simasub-c-hetval) containing the values of the state variables at the end of the current increment.  Variables Passed in for Information CMNAME  User-specified material name, left justified.  TEMP(1)  Current temperature.  TEMP(2)  Temperature increment.  TIME(1)  Step time at the end of the increment.  TIME(2)  Total time at the end of the increment.  DTIME  Time increment.  PREDEF(\*)  An array containing the values of all of the user-specified field variables at this point (initial values at the beginning of the analysis and current values during the analysis).  DPRED(\*)  Array of increments of predefined field variables. |
