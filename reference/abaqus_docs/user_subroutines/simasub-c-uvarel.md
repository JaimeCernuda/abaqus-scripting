User subroutine [UVAREL](simasub-c-uvarel.md#simasub-c-uvarel):  * will be called at all elements for which the element user output variables are defined; * will be called for each converged increment in a step only once; * allows you to define output quantities that are functions of any of the available   integration point quantities listed in the Output Variable Identifiers table  ([Using Abaqus/Standard Output Variable Identifiers](.._SIMACAEOUTRefMap_simaout-m-stdoutputvar-sb.md#simaout-m-stdoutputvar-sb)); * allows you define whole element output variables   (UVARE) as well as integration point   output variables (UVARPT), * can be used with continuum solid, solid shell, conventional shell, and continuum shell   elements; * can call utility routine getElMPtVar to   access material point data for any material point within the element; * can call utility routine getSecVar to   access element section output variables; * can call utility routines   getUVarElMaterialName and   getUVarElOrientationName to access the   material name and the orientation name, respectively; * cannot be used with linear perturbation procedures; and * can be used only with procedures with mechanical degrees of freedom. The values of the material point data are recovered in the arrays ARRAY, JARRAY, and FLGRAY for floating point, integer, and character data, respectively. Floating point data are recovered as double-precision data.  Using Element User-Defined Output Variables You can use [UVAREL](simasub-c-uvarm.md#simasub-c-uvarm) to define both whole element as well as integration point output variables. The output identifiers for the user-defined output quantities are UVARE and UVARPT respectively. You access individual components with UVAREn (where    n =  1 , 2 , … , NUVARE) and UVARPTn (where    n =  1 , 2 , … , NUVARPT). You must specify the number of element user-defined output variables (NUVARE) and the number of user-defined output variables at the integration points (NUVARPT) for a given element to allocate space for each variable. You can use any number of user-defined output variables. Abaqus/Standard writes the user-defined output variables to the output database and restart files for contouring, printing, and X–Y plotting in Abaqus/CAE.  Output Precision Abaqus/Standard writes the data in single precision to the output database (.odb) file. Because you provide [UVAREL](simasub-c-uvarm.md#simasub-c-uvarm) output variables in double precision, numeric overflow errors related to output to the output database file might occur in cases where the output results exceed the capacity for single-precision representation even when no overflow errors occur in [UVAREL](simasub-c-uvarm.md#simasub-c-uvarm).  User Subroutine Interface ```        subroutine uvarel(uVarE, uVarPt, jOutput, time, dTime,       * nuUarE, nuVarPt, noel, nPt, nLayer, nSpt, nRebar, kStep,      * kInc, nDir, nShr, props, nProps, abqInternal)        include 'aba_param.inc'        dimension uVarE(nuVarE), uVarPt(nuVarPt,nPt), time(2),       *     nSpt(nLayer), props(nProps)        character*3 flgray(15)       dimension array(15), jarray(15)  c     The dimensions of the variables flgray, array, and jarray c     must be set equal to or greater than 15.         user coding to define uVarE or uVarPt         return       end ```  Variables to Be Defined uVarE(nuVarE)  Array containing the element user-defined output variables. These are passed in as the values at the beginning of the increment and must be returned as the values at the end of the increment.  uVarPt(nuVarPt,nPt)  Array containing the user-defined output variables at the integration points. These are passed in as the values at the beginning of the increment and must be returned as the values at the end of the increment.  Variables Passed in for Information jOutput  Output request flag  If jOutput=0, there is no output request at this increment.  If jOutput=1, there is an output request at this increment.  time(1)  Value of step time at the end of the current increment.  time(2)  Value of total time at the end of the current increment.  dTime  Time increment.  nuVarE  User-specified number of element user-defined output variables.  nuVarPt  User-specified number of user-defined output variables at the integration points.  noel  Element number.  nPt  Number of integration points.  nLayer  Number of layers (for composite shells and layered solids). 1 for all other elements.  nSpt(nLayer)  Array containing the number of section points per layer.  nRebar  Number of rebars.  kStep  Step number.  kInc  Increment number.  nDir  Number of direct stress components at this point.  nShr  Number of shear stress components at this point.  props(nProps)  User-specified array of constants associated with user-defined output variables.  nProps  Number of user-specified arrays of constants associated with user-defined output variables.  abqInternal  Variable that must be passed into the utility routines. |
