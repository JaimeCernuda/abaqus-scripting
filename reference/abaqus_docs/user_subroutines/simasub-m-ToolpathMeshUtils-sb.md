# Toolpath-Mesh Intersection Utility Routines

| |  |  | | --- | --- | | Toolpath-Mesh Intersection Utility Routines | | |  | | | |  | | --- | | Toolpath-mesh intersection utility routines are used to activate the toolpath-mesh intersection module and to access data computed by the module.  These utility routines are invoked from Abaqus/Standard user subroutines. Three types of utility routines are available:  * Setup utility routines that   are invoked at the beginning of an analysis step from user subroutines   [UEPACTIVATIONSETUP](simasub-c-uepactivationsetup.md#simasub-c-uepactivationsetup) and   [UMDFLUXSETUP](simasub-c-umdfluxsetup.md#simasub-c-umdfluxsetup). * A compute utility routine that   is invoked at the beginning of an increment from user subroutines   [UEPACTIVATIONSETUP](simasub-c-uepactivationsetup.md#simasub-c-uepactivationsetup) and   [UMDFLUXSETUP](simasub-c-umdfluxsetup.md#simasub-c-umdfluxsetup). * Data retrieval utility   routines that are invoked at the beginning of an increment after the call to a   compute routine from user subroutines   [UEPACTIVATIONSETUP](simasub-c-uepactivationsetup.md#simasub-c-uepactivationsetup) and   [UMDFLUXSETUP](simasub-c-umdfluxsetup.md#simasub-c-umdfluxsetup) and from within the element loop from user subroutines   [UEPACTIVATIONVOL](simasub-c-uepactivationvol.md#simasub-c-uepactivationvol),   [UEPACTIVATIONFACET](simasub-c-uepactivationfacet.md#simasub-c-uepactivationfacet), and   [UMDFLUX](simasub-c-umdflux.md#simasub-c-umdflux).  All toolpath-mesh intersection utility routine names use the prefix “Ptk."   --- | | In this section:   * [Setup Utility Routines](simasub-c-toolpathmesh-setuputils.md#simasub-c-toolpathmesh-setuputils) * [Compute Utility Routine](simasub-c-toolpathmesh-computeutils.md#simasub-c-toolpathmesh-computeutils) * [Data Retrieval Utility Routines](simasub-c-toolpathmesh-datautils.md#simasub-c-toolpathmesh-datautils) | | | |
