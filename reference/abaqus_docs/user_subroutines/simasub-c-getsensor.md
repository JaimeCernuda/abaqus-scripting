| |  |  | | --- | --- | | Obtaining Sensor Information | | |  | | | |  | | --- | | Given the user-defined name for a sensor, utility routines can be used to obtain the sensor ID or the sensor value using a computationally efficient searching technique. Utility routines IGETSENSORID and GETSENSORVALUE can be called only from Abaqus/Standard user subroutine [UAMP](simasub-c-uamp.md#simasub-c-uamp). Utility routines IVGETSENSORID and VGETSENSORVALUE can be called only from Abaqus/Explicit user subroutine [VUAMP](simasub-c-vuamp.md#simasub-c-vuamp). The calling user subroutine provides this variable.  sensorValues  Array containing the latest sensor values for all sensors in the model.  Variables Returned from the Utility Routine iMySensorID  Index in the sensorValues array for this sensor name.  dMySensorValue  Sensor value for this sensor name. |
