| |  |  | | --- | --- | | UFLUIDCONNECTORLOSS | | |  | | | |  | | --- | | User subroutine to define the loss coefficient for fluid flow in fluid pipe connector elements. User subroutine [UFLUIDCONNECTORLOSS](simasub-c-ufluidconnectorloss.md#simasub-c-ufluidconnectorloss):   * can be used to define the loss coefficient in a fluid pipe connector element; * corresponds to the Darcy-Weisbach equation for pressure loss; and * can be used with the fluid pipe connector elements.
