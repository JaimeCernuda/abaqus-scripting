| |  |  | | --- | --- | | VFILM | | |  | | | |  | | --- | | User subroutine to define nonuniform film coefficients and sink temperatures for heat transfer analysis. User subroutine [VFILM](simasub-c-vfilm.md#simasub-c-vfilm):   * can be used to define node-based, element-based, or surface-based nonuniform film   coefficients; * can be used to define sink temperatures as functions of position, time, temperature, field   variables, node number, element number, etc.; * will be called during procedures that allow heat transfer analysis at each node or surface   integration point of those surfaces and elements for which node-based, element-based, or   surface-based nonuniform film conditions are defined; and * uses the amplitude references for the sink temperature or film coefficient that may appear   with the associated nonuniform film definition only to modify the sink temperature or film   coefficient passed into the user subroutine. Units are JT−1L−2  θ −1. h is passed into the routine as the magnitude of the film coefficient specified as part of the node-based, element-based, or surface-based film condition definition. If the magnitude is not defined, h will be initialized to zero.  sink(nblock)  Sink temperature. sink is passed into the routine as the sink temperature specified as part of the node-based, element-based, or surface-based film condition definition. If the sink temperature is not defined, sink will be initialized to zero.  Variables Passed in for Information nblock  Number of points to be processed in this call to [VFILM](simasub-c-vfilm.md#simasub-c-vfilm).  ndim  Number of coordinate directions: two for two-dimensional models and three for three-dimensional models. The model is considered to be three-dimensional if any three-dimensional elements are defined.  kStep  Step number.  kIncr  Increment number.  stepTime  Value of time since the step began.  totalTime  Value of total time. The time at the beginning of the step is given by totalTime−stepTime  jElemUid  User-defined element numbers.  jNodeUid  User-defined node numbers.  numExfv  Number of field variables.  temp(nblock)  Current value of temperature at this integration point.  field(nblock,numExfv)  Current value of field variable at this integration point.  curCoords(nblock,ndim)  An array containing the coordinates of this point. These are the current coordinates if geometric nonlinearity is accounted for during the step (see [Defining an Analysis](.._SIMACAEANLRefMap_simaanl-c-over.md)); otherwise, the array contains the original coordinates of the point.  areaNode(nblock)  Array of nodal area for node-based films. areaNode is passed into the routine as the nodal area specified as part of the node-based film coefficient specification. This nodal area is not available for output purposes. This variable is passed in as blank for both element-based and surface-based films.  jltyp  Element face for which this call to [VFILM](simasub-c-vfilm.md#simasub-c-vfilm) is being made for an element-based film coefficient specification. This information is useful when several different nonuniform film conditions are being imposed on an element at the same time. See [About the Element Library](.._SIMACAEELMRefMap_simaelm-c-general.md) for element face identification. The key is as follows:   | JLTYP | Film type | | --- | --- | | 0 | Node-based or surface-based loading | | 11 | F1NU (FNEGNU for heat transfer shells) | | 12 | F2NU (FPOSNU for heat transfer shells) | | 13 | F3NU | | 14 | F4NU | | 15 | F5NU | | 16 | F6NU |  sname  Surface name for which this call to [VFILM](simasub-c-vfilm.md#simasub-c-vfilm) is being made for a surface-based film coefficient specification (JLTYP=0). This variable is passed in as blank for both node-based and element-based films. |
