# Obtaining the Material Name from User Subroutine UVAREL

|  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Obtaining the Material Name from User Subroutine UVAREL | | |  | | | |  | | --- | | Utility routine getUVarElMaterialName can be called from user subroutine UVAREL to obtain the name of the material. In the case of elements with composite sections, the utility routine can be called to obtain the material name for each layer.  This page discusses:   * [Utility Routine Interface](#simasub-c-uvarelmaterailname-interface) * [Variables to Be Provided to the Utility Routine](#simasub-c-getvrm-t-vartoprovide1) * [Variables Returned from the Utility Routine](#simasub-c-getnameutil-var-ret) | | |  | | --- | | See Also | | [UVAREL](simasub-c-uvarel.md) | |   Products Abaqus/Standard    Utility Routine Interface ``` character*80 cMatName ... call getUVarElMaterialName(kLayer, cMatName, jError, abqInternal) ... ```  Variables to Be Provided to the Utility Routine kLayer  Composite layer number. 1 for elements without a composite section.  abqInternal  Variable that must be passed into the getUVarElMaterialName utility routine. The calling user subroutine provides this variable.  Variables Returned from the Utility Routine cMatName  Character string with the name of the material.  jError  Return code (0 – no error, 1 – error). |
