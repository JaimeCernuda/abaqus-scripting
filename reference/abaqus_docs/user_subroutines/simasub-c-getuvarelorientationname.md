# Obtaining the Element Orientation Name from User Subroutine UVAREL

| |  |  | | --- | --- | | Obtaining the Element Orientation Name from User Subroutine UVAREL | | |  | | | |  | | --- | | Utility routine getUVarElOrientationName can be called from user subroutine UVAREL to obtain the name of the element orientation. In the case of elements with composite sections, the utility routine will return the section orientation associated with the element.  This page discusses:   * [Utility Routine Interface](#simasub-c-uvarelmaterailname-interface) * [Variables to Be Provided to the Utility Routine](#simasub-c-getvrm-t-vartoprovide1) * [Variables Returned from the Utility Routine](#simasub-c-getnameutil-var-ret) | | |  | | --- | | See Also | | [UVAREL](simasub-c-uvarel.md) | |   Products Abaqus/Standard    Utility Routine Interface ``` character*80 cOriName ... call getUVarElOrientationName(kLayer, cOriName, jError, abqInternal) ... ```  Variables to Be Provided to the Utility Routine kLayer  Composite layer number. 1 for elements without a composite section (currently not used).  abqInternal  Variable that must be passed into the getUVarElOrientationName utility routine. The calling user subroutine provides this variable.  Variables Returned from the Utility Routine cOriName  Character string with the name of the orientation.  jError  Return code (0 – no error, 1 – error). |
