| |  |  | | --- | --- | | UPOREP | | |  | | | |  | | --- | | User subroutine to define initial fluid pore pressure. User subroutine [UPOREP](simasub-c-uporep.md#simasub-c-uporep):   * allows for the specification of the initial pore pressure values of a porous medium; * can be used to define initial pore pressure values as functions of nodal coordinates and/or node numbers; and * will be called to define initial fluid pore pressure values at all nodes of a coupled pore fluid diffusion and stress analysis whenever user-defined initial pore pressure conditions are specified.
