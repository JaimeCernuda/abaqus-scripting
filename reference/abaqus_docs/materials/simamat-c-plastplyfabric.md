| |  |  | | --- | --- | | Plasticity Model for Bidirectional Fabric-Reinforced Composite Materials | | |  | | | |  | | --- | | The shear plasticity model provided in Abaqus/Explicit is intended for modeling the nonlinear in-plane shear behavior of the matrix of bidirectional fabric-reinforced composite materials. In Abaqus/Explicit the elastic behavior for bidirectional fabric-reinforced composites is assumed to be in the form of bilamina elasticity (see [Defining Orthotropic Elasticity in Plane Stress with Different Moduli in Tension and Compression](simamat-c-linearelastic.md#simamat-c-linearelastic-planestressbilamina)). This shear plasticity model can be used with the ply fabric damage initiation criterion (see [Ply Fabric Criterion](simamat-c-damageinitfibercomposite.md#simamat-c-damage-plyfabric)) to simulate progressive damage and failure for bidirectional fabric-reinforced composites. The hardening behavior and strain rate dependency are incorporated into the yield stress      σ  ¯  assuming this separable form:  σ ¯ ⁢  (    ε ¯  p ⁢ l ,    ε ¯ ˙  p ⁢ l ) =   σ 0 ⁢  (   ε ¯  p ⁢ l ) ⁢ R ⁢  (    ε ¯ ˙  p ⁢ l ) ,  where    σ 0  is the static yield stress, and    R  is a ratio, defined as    R = 1.0  at       ε ¯ ˙  p ⁢ l = 0.0 .
