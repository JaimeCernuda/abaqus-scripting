| |  |  | | --- | --- | | User-Defined Material Properties | | |  | | | |  | | --- | | User-defined material properties in Abaqus allow you to define property tables and parameter tables in material definitions and make these tables available automatically in all material-related user subroutines.  User-defined material properties:   * can be included in material definitions as property tables and   parameter tables; and * can be accessed from any material-related user subroutine that is   invoked for the material for which the properties are defined. Abaqus creates an internal table collection.  Input File Usage  Use the following options to define property tables and parameter tables:   ``` [MATERIAL](.._SIMACAEKEYRefMap_simakey-r-material.md#simakey-r-material), NAME=material_name [PROPERTY TABLE](.._SIMACAEKEYRefMap_simakey-r-propertytable.md#simakey-r-propertytable), TYPE=property_table_type [PARAMETER TABLE](.._SIMACAEKEYRefMap_simakey-r-parametertable.md#simakey-r-parametertable), TYPE=parameter_table_type ```  Accessing Material Properties You can access property tables and parameter tables from any material-related user subroutine that is invoked for the material for which the tables are defined. Abaqus activates an appropriate internal table collection. You can access these tables using the utility routines described in [Accessing Abaqus Table Collections](.._SIMACAESUBRefMap_simasub-c-tablecollection.md#simasub-c-tablecollection).  Elements User-defined material properties can be used with all elements in Abaqus/Standard. |
