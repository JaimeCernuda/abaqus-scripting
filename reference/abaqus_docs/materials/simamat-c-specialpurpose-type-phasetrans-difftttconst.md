# ABQ_PHASE_TRANS_Diffusional_TTT_Constants

| |  |  | | --- | --- | | ABQ\_PHASE\_TRANS\_Diffusional\_TTT\_Constants | | |  | | | |  | | --- | | You use this parameter table type to specify the constants for the time-temperature-transformation (TTT) diagram for a diffusional transformation.  This page discusses:   * [Parameter Table Type Definition](#simaanl-c-amspecialpurpose-type-phasetrans-difftttconst-def) * [Parameters](#simaanl-c-amspecialpurpose-type-phasetrans-difftttconst-params) | | |  | | --- | | See Also | | [Modeling Metallurgical Phase Transformations](simamat-c-specialpurpose-phasetrans.md) | |   Products Abaqus/Standard  You must include a parameter table of type `"ABQ_PHASE_TRANS_Diffusional_TTT_Constants"` in the material definition to specify the constants for the time-temperature-transformation (TTT) diagram for a diffusional transformation whose input option is set to `TTT` in the parameter table of type `"ABQ_PHASE_TRANS_Transformations"`.  The parameter table must have a unique label of `"ABQ_PHASE_TRANS_Trans_NameOfTransformation_TTT_Constants"`, where NameOfTransformation is the name of the transformation defined in the parameter table of type ["ABQ\_PHASE\_TRANS\_Transformations"](simamat-c-specialpurpose-type-phasetrans-trans.md).  The parameter table of type `"ABQ_PHASE_TRANS_Diffusional_TTT_Constants"` can define only one set of data.    Parameter Table Type Definition ``` [PARAMETER TABLE TYPE](.._SIMACAEKEYRefMap_simakey-r-parametertabletype.md#simakey-r-parametertabletype), NAME="ABQ_PHASE_TRANS_Diffusional_TTT_Constants", PARAMETERS=2  FLOAT, , "Starting Proportion", , ,  FLOAT, , "Ending Proportion", , , ```  Parameters Starting Proportion  Relative total volume fraction of child phases at the start of the transformation. This value must be between 0 and 1.  Ending Proportion  Relative total volume fraction of child phases at the end of the transformation. This value must be between 0 and 1. |
