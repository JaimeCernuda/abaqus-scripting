# Including volumetric heat flux due to internal heat generation

|  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Including volumetric heat flux due to internal heat generation | | |  | | | |  | | --- | | You can define a heat flux due to internal heat generation in conjunction with user subroutines.  User subroutine [HETVAL](.._SIMACAESUBRefMap_simasub-c-hetval.md#simasub-c-hetval) allows you to define a heat flux due to internal heat generation for heat transfer, coupled thermal-electric, or coupled temperature-displacement analyses. User subroutine [VHETVAL](.._SIMACAESUBRefMap_simasub-c-vhetval.md#simasub-c-vhetval) allows you to define a heat flux due to internal heat generation for coupled temperature-displacement analyses. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [HETVAL](.._SIMACAESUBRefMap_simasub-c-hetval.md#simasub-c-hetval) | | [VHETVAL](.._SIMACAESUBRefMap_simasub-c-vhetval.md#simasub-c-vhetval) | |   Context:  Abaqus/Standard calls user subroutine [HETVAL](.._SIMACAESUBRefMap_simasub-c-hetval.md#simasub-c-hetval) and Abaqus/Explicit calls [VHETVAL](.._SIMACAESUBRefMap_simasub-c-vhetval.md#simasub-c-vhetval) at each point for which the material definition includes a reference to the user subroutine.  1. From the menu bar in the Edit Material dialog    box, select ThermalHeat    Generation. (For information on displaying the Edit Material    dialog box, see    [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. Click OK to close the Edit    Material dialog box. Alternatively, you can select another material    behavior to define from the menus in the Edit Material    dialog box (for more information, see    [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md)). 3. Enter the    Job module    and display the job editor for the analysis job of interest. (For more    information, see    [Creating, editing, and manipulating jobs](simacae-m-AnaManagejob-sb.md).) 4. In the job editor, click the General tab, and    specify the file containing user subroutine    [HETVAL](.._SIMACAESUBRefMap_simasub-c-hetval.md#simasub-c-hetval) or    [VHETVAL](.._SIMACAESUBRefMap_simasub-c-vhetval.md#simasub-c-vhetval). For more information, see    [Specifying general job settings](simacae-c-anajobeditorotherbtn.md). Note:     You can specify only one user subroutine file in the job editor; if    your analysis involves more than one user subroutine, you must combine the user    subroutines into one file and then specify that file. |
