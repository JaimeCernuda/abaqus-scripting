# Using tabular report options

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Using tabular report options | | |  | | | |  | | --- | | You can customize tabular report characteristics such as the objects to include, report layout, and sort order. Select ReportXY, ReportField Output, or ReportFree Body Cut to customize and generate a tabular listing of X–Y data objects, field output variable values, or free body cuts, respectively. Select ToolsQuery to generate a tabular report of probe values. The following list identifies the tabular report characteristics that you can customize and the sections where you can find information. | | |   You can customize:   * The X–Y data objects or field output   variables to include in the report. See   [Selecting report data](simacae-m-ReportSelect-sb.md). * The free body cuts to include in the report.   Abaqus/CAE   includes all active free body cuts in the current output database in a free   body cut report. You can activate and suppress free body cuts from the   Free Body Cut Manager. See   [Displaying, hiding, and highlighting free body cuts](simacae-c-fbdhlpdisplay.md). * The probe values to include in the report. See   [Probing the model](simacae-m-Probe-sb.md). * The file name to which the report is written. See   [Specifying your report file name](simacae-t-reportfileframe.md). * The layout and width of the report. See   [Controlling report layout, width, format, and coordinate system](simacae-t-reportlayout.md). * How field output or probe values are sorted. For field output, see   [Sorting field output data](simacae-t-reportfieldsort.md);   for probe values, see   [Entering tabular data](simacae-c-intdialogspreadsheet.md). * The format and significant digits of report values. See   [Formatting report values](simacae-t-reportnumberformat.md). * Whether or not to include minimum and maximum value summaries or column   totals. See   [Reporting data values, minimums, maximums, and totals](simacae-t-reportdataframe.md). * The form of complex results in the report. See   [Controlling the form of complex results](simacae-t-rescomplexform.md). |
