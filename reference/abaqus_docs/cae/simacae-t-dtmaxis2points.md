# Creating a datum axis through two points

|  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Creating a datum axis through two points | | |  | | | |  | | --- | | You can position a datum axis by selecting any two points on the model through which the datum axis passes. | | |  | | --- | | See Also | | [Methods for creating a datum axis](simacae-c-dtmtoolaxis.md) | | [Datum creation techniques](simacae-m-DtmOverview-sb.md) | | [Controlling datum display](simacae-t-dspdynamicdatum.md) | |   Context:  The figure below shows an example of creating a datum axis through two points.  1. From the main menu bar, select    ToolsDatum. The Create Datum dialog box appears. The dialog    box outlines the types of datum geometry you can create.  Abaqus/CAE displays prompts    in the prompt area to guide you through the procedure.  |  |    | --- |    | Tip: You can also create a datum axis using the  tool, located in the module toolbox. For a diagram of the datum tools in the toolbox, see [Using the Datum toolset](simacae-c-dtmstart.md). | 2. From the list of types at the top of the dialog box, choose    Axis. The Method list indicates the methods you can    use to create a datum axis. 3. From the Method list, select 2    points. 4. If desired, select Make Independent from the    prompt area to create the datum as an independent feature. 5. From the part or assembly in the current viewport, select two points. The datum axis appears. You cannot modify a datum axis created with    this method; you must delete the old axis and create a new one. |
