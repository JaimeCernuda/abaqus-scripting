| |  |  | | --- | --- | | Specifying triaxial test data for a Drucker-Prager material model | | |  | | | |  | | --- | | Abaqus can use triaxial test data to calibrate the material parameters that define the Exponent Form of Drucker-Prager plasticity. See [General Exponent Model](.._SIMACAEMATRefMap_simamat-c-druckerprager.md#simamat-c-druckerprager-triaxial), for more information. | | |   1. Create a material model as described in [Defining a Drucker-Prager model](simacae-t-prpmechanicalplasticdruckerpragermodel.md).” 2. From the Suboptions menu in the Edit Material dialog box, select Triaxial Test Data. A Suboption Editor appears. 3. Enter values for Material constant a, Material constant b, and Material constant pt if they are known and held fixed at the input value. Alternatively, you can leave one or more of the fields blank if you want Abaqus to calibrate the values from the triaxial test data. 4. Enter the following data in the Data table: Confining Stress  Sign and magnitude of the confining stress, σ1=σ2.  Loading Dirn Stress  Sign and magnitude of the stress in the loading direction, σ3.  For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 5. Click OK to return to the Edit Material dialog box. |
