| |  |  | | --- | --- | | Renaming a feature | | |  | | | |  | | --- | | You can rename a feature by clicking mouse button 3 on the feature in the Model Tree and selecting Rename from the menu that appears. | | |  | | --- | | See Also | | [Using the Feature Manipulation toolset](simacae-c-ftsconcepts.md) | |   1.
