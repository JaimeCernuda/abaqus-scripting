# Methods for creating a datum point

|  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Methods for creating a datum point | | |  | | | |  | | --- | | When you choose Point from the Create Datum dialog box, the Method list displays the methods for creating a datum point. | | |  | | --- | | See Also | | [Creating datum points](simacae-m-DtmPoint-sb.md) | | [Controlling datum display](simacae-t-dspdynamicdatum.md) | |   The following methods are available:  Enter coordinates  Enter the X-, Y-, and Z-coordinates of the datum point, as shown in [Figure 1](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hptc). For detailed instructions, see [Creating a datum point by entering its coordinates](simacae-t-dtmpointcoord.md). Figure 1. Creating a datum point by entering coordinates.  Offset from point  Enter the location of the datum point in the form of the X-, Y-, and Z-coordinates of an offset from a selected point, as shown in [Figure 2](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hptop). For detailed instructions, see [Creating a datum point at an offset from a selected point](simacae-t-dtmpointoffset.md). Figure 2. Creating a datum point by offsetting from a point.  Midway between 2 points  Select two points on the model; Abaqus/CAE creates the datum point midway between the two selected points, as shown in [Figure 3](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hpmid). For detailed instructions, see [Creating a datum point midway between two points](simacae-t-dtmpointmidway.md). Figure 3. Creating a datum point by selecting two end points.  Offset from 2 edges  Select two edges on the model; and enter the distance from the datum point to each edge, as shown in [Figure 4](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hpted). For detailed instructions, see [Creating a datum point at a specified distance from two edges](simacae-t-dtmpointedges.md). Figure 4. Positioning a datum point a specified distance from two edges.  Enter parameter  Select an edge on the model, and enter the location of the datum point in the form of a parameter value that represents a percentage of the edge length. An arrow along the edge indicates the direction of increasing parameter value from the start vertex (corresponding to an edge parameter value of zero) to the end vertex (corresponding to a value of one), as shown in [Figure 5](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hpted2). For detailed instructions, see [Creating a datum point by entering an edge parameter](simacae-t-dtmpointedgeparam.md). Figure 5. Positioning a datum point a specified distance along an edge.  Project point on face/plane  Select a point and a face or plane on which to project the point. Abaqus/CAE creates the datum point where the face or plane intersects a line that is normal to it and passing through the selected point, as shown in [Figure 6](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hptpf). The datum point also marks the shortest distance between the selected point and the selected face or plane. For detailed instructions, see [Creating a datum point by projecting a point on a face or plane](simacae-t-dtmpointface.md). Figure 6. Creating a datum point by projecting a point onto a face.  Project point on edge/datum axis  Select a point on the model and an edge or datum axis on which to project the point. Abaqus/CAE creates the datum point where the edge or datum axis intersects a line that is normal to it and passing through the selected point, as shown in [Figure 7](simacae-c-dtmtoolpoint.md#simacae-c-dtmtoolpoint__simacae-c-dtm-hptpe). The datum point also marks the shortest distance between the selected point and the selected edge or datum axis. For detailed instructions, see [Creating a datum point by projecting a point on an edge or datum axis](simacae-t-dtmpointedge.md). Figure 7. Creating a datum point by projecting a point onto an edge. |
