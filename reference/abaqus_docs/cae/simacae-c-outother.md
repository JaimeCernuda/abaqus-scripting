| |  |  | | --- | --- | | Other | | |  | | | |  | | --- | | The Other page in the Job Diagnostics dialog box appears only when you select a Step from the Job History tree for an Abaqus/Standard analysis. It displays information about the matrix solver used for the analysis and the characteristic element length in the mesh. Depending on the procedure type, other pertinent information such as the mass of the model and the center of mass are also provided. This reference information can help you determine the possible cause or extent of a problem.
