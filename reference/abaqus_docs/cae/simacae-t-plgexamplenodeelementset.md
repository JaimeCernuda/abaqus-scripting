| |  |  | | --- | --- | | Creating node and element sets during postprocessing | | |  | | | |  | | --- | | You can create node and element sets in the Visualization module. Select ToolsCreate Set from the main menu bar. You can create and save sets only when the output database (.odb) file is opened with write privileges. In addition, the following rules apply:  * You can create sets only on the rootAssembly instance; however, the   instance cannot be named ASSEMBLY. * You cannot edit or delete the sets created in the output database. | | |  | | --- | | See Also | | [Opening a model database or an output database](simacae-t-dbsmdbopen.md#simacae-t-dbsmdbopen) | | [Using the angle and feature edge method to select multiple objects](simacae-c-picbyangle.md#simacae-c-picbyangle) | | [Using the topology method to select multiple elements](simacae-c-picbytopology.md#simacae-c-picbytopology) | |   1. From the main menu bar in    the Visualization module,    select ToolsCreate    Set. 2. In the Create Set dialog box that appears, do the    following:    1. Enter a name for the set.    2. Select Node or Element       as the set type.    3. Click Continue.    4. Select nodes or elements from the viewport. You can select the       nodes and elements individually, by angle, or by feature edge. You can also       select elements by topology.    5. Click Done. The newly created set appears in the    Results Tree. |
