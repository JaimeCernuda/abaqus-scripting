| |  |  | | --- | --- | | Filtering a design response for a shape optimization | | |  | | | |  | | --- | | You can apply a filter to a design response that will smooth out local peaks for a shape optimization. The filter is defined as Φj=∑i-1NΦi⁢Bi⁢j∑i-1NBi⁢j,  Bi⁢j=(rj-dj⁢i)p,  rj=rmax⁢e-0.5⁢(kmax⁢∫σ),  kmax=max⁡(|nj×nk|), where Φjis the filter function for node j. The main filter function, Bi⁢j, decreases with the distance, d, between nodes i and j. The maximum radius of influence, rm⁢a⁢x, defines the maximum distance from node j for the nodes i to influence the filter value. The local curvature, κm⁢a⁢x, is approximated by the vector product of the node normal, nj, and the neighboring nodes, nk. The curvature dependency, rj, defines a weight function that reduces the radius at higher local curvature. | | |  | | --- | | See Also | | [Creating and editing a design response](simacae-t-opzdesignresponseditor.md) | | [Selecting the data source of a design response](simacae-t-opzdesignresponsesource.md) | |   You can specify the following:   * The maximum radius of influence, rm⁢a⁢x. * The exponent, p, which defines the weight function that controls the influence of the distance between nodes i and j. The default value is 1.0. * The surface bending radius reduction, σ. The default value of σ is 0.2. A larger value of σ decreases the influence of the surface curvature. |
