| |  |  | | --- | --- | | The Sketch module | | |  | | | |  | | --- | | Sketches are two-dimensional profiles that are used to help form the geometry defining an Abaqus/CAE native part. You use the Sketch module to create a sketch that defines a planar part, a beam, or a partition or to create a sketch that might be extruded, swept, or revolved to form a three-dimensional part.
