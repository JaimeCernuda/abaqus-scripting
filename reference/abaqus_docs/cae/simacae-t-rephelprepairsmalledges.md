# Repairing small edges

|  |  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Repairing small edges | | |  | | | |  | | --- | | You can repair selected small edges from a part. Abaqus/CAE removes the small edges and repairs the adjoining edges and faces to create a closed geometry. The operation to repair small edges is stored as a feature of the part; therefore, you can use the Model Tree to delete or suppress the operation. | | |  | | --- | | See Also | | [Valid parts, precise parts, and tolerance](simacae-m-ImpConceptsPrecision-sb.md) | | [Methods for editing edges](simacae-c-repconcoverviewedges.md) | |   1. From the main menu bar, select ToolsGeometry Edit. Abaqus/CAE displays the Geometry Edit dialog box.      |  |    | --- |    | Tip: You can also repair small faces using the  tool, located with the edit tools in the Part module toolbox. For a diagram of the edit tools in the toolbox, see [Editing techniques](simacae-c-reptoolbox.md). | 2. From the dialog box, select the Edge category and the Repair small method. 3. Select the edges that you want to repair. You can select the edges from the viewport or select an existing set containing the edges. Note:     The default selection method is based on the selection method you most recently employed. To revert to the other method, click Select in Viewport or Sets on the right side of the prompt area.  You can use a combination of drag select, ShiftClick, CtrlClick, and the angle method to select more than one small edge to repair. For more information, see [Selecting objects within the current viewport](simacae-m-PicHelptopics-sb.md).      |  |    | --- |    | Tip: If you are unable to select the desired edges, you can use the Selection toolbar to change the selection behavior. For more information, see [Using the selection options](simacae-m-PicUsingoptions-sb.md). | 4. Click mouse button 2 to indicate that you have finished selecting small edges. Abaqus/CAE removes the selected small edges from the part and prompts you to update the validity of the part. 5. Do one of the following: * Click Yes to update the validity of the part. (You should update the validity of the part whenever you repair small edges.)    * Click No to skip the update and continue your repairs.    * Click Cancel to cancel the changes in the current repair operation.  You can also update the validity of a part at any time by clicking mouse button 3 on the part in the Model Tree and selecting Update validity from the menu that appears. |
