During mesh generation, Abaqus/CAE treats the combined edges as a single edge and ignores any vertices that were removed. | | |   1. From the Object field in the context bar, select a part or the assembly. 2. From the main menu bar, select ToolsVirtual TopologyCombine Edges. |  |    | --- |    | Tip: You can also combine edges using the  tool, located in the Mesh module toolbox. | 3. Select the edges that you want to combine. You can use a combination of drag-select, ShiftClick, CtrlClick, and the angle method to select more than one edge to combine. For more information, see [Selecting objects within the current viewport](simacae-m-PicHelptopics-sb.md).      |  |    | --- |    | Tip: If you are unable to select the desired edge, you can use the Selection toolbar to change the selection behavior. For more information, see [Using the selection options](simacae-m-PicUsingoptions-sb.md). |  Abaqus/CAE combines the selected edges. You can use the Model Tree or the Restore Entities tool to restore the selected edges.
