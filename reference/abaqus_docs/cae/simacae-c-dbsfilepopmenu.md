# Using the File menu

|  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Using the File menu | | |  | | | |  | | --- | | A variety of operations are available from the File menu. | | |  | | --- | | See Also | | [Understanding the files generated by creating and analyzing a model](simacae-c-dbsconcfilesgenerated.md) | | [Abaqus/CAE command files](simacae-m-DbsFilesCommand-sb.md) | |   Use the items under File on the main menu bar to do the following:   * Select FileNew Model   DatabaseWith Standard/Explicit   Model to create a new model database for an   Abaqus/Standard   or an   Abaqus/Explicit   analysis. You can also click    in the   File toolbar.   For more information, see   [Creating a new model database](simacae-c-dbsmdbnew.md). * Select FileNew Model   DatabaseWith Electromagnetic   Model to create a new model database for an   electromagnetic analysis. For more information, see   [Creating a new model database](simacae-c-dbsmdbnew.md). * Select   FileOpen   to open an existing model database or output database. You can also click    in the   File toolbar.   For more information, see   [Opening a model database or an output database](simacae-t-dbsmdbopen.md). * Select FileNetwork ODB   Connector to create a connection with a remote host   that you can use to read a remote output database. For more information, see   [Creating a network ODB connector](simacae-t-dbscreateremote.md). * Select FileClose   ODB to close an output database. For more   information, see   [Closing the current output database](simacae-t-dbsviwcloseodb.md). * Select FileSet Work   Directory to change the work directory. For more   information, see   [Setting the work directory](simacae-c-dbsmdbchangework.md). * Select   FileSave   to save the current model database. You can also click    in the   File toolbar.   For more information, see   [Saving the current model database](simacae-c-dbsmdbsave.md). * Select FileSave   As to save the current model database to a new file   with a different name. For more information, see   [Saving the current model database to a new file with a different name](simacae-c-dbsmdbsaveas.md). * Select FileCompress   MDB to compress the current model database. For more   information, see   [Compressing the file size of the current model database](simacae-c-dbsmdbcompress.md). * Select FileSave Display   Options to save your customized part, assembly, and   Visualization module display settings. For more information, see   [Understanding Abaqus/CAE GUI settings](simacae-c-intpreferences.md),   and   [Saving your display options settings](simacae-c-dsppreferences.md). * Select FileSave Session   Objects to save session-specific object definitions   such as view cuts, display groups, or paths to a file, model database, or   output database. For more information, see   [Managing session objects and session options](simacae-m-DbsSessionobjects-sb.md). * Select FileLoad Session   Objects to load previously saved session-specific   object definitions into the current session. For more information, see   [Managing session objects and session options](simacae-m-DbsSessionobjects-sb.md). * Select   FileImportSketch   to import a planar sketch. For more information, see   [Importing sketches](simacae-t-dbsimportsketch.md). * Select   FileImportPart   to import a part. For more information, see   [Importing parts](simacae-t-dbsimportpart.md). * Select   FileImportModel   to import a model. For more information, see   [Importing a model](simacae-t-impinputfilereader.md). * Select   FileExportSketch   to export the current sketch. For more information, see   [Exporting a sketch to an ACIS-, IGES-, or STEP-format file](simacae-t-dbsexportsketchacis.md). * Select   FileExportPart   to export the current part. For more information, see   [Exporting a part to an ACIS-, IGES-, STEP-, or VDA-format file](simacae-t-dbsexportpartacis.md). * Select   FileExportAssembly   to export the part instances in the assembly. For more information, see   [Exporting the assembly to an ACIS-format file](simacae-t-dbsexportassemblyacis.md). * Select   FileExportVRML   to export the current viewport to a   VRML-format file. For more information, see   [Exporting viewport data to a VRML-format file](simacae-t-dbsexportmodelvrml.md). * Select   FileExport3DXML   to export the current viewport to a 3D   XML-format file. For more information, see   [Exporting viewport data to a 3D XML-format file](simacae-t-dbsexportmodel3dxml.md). * Select   FileExportOBJ   to export the current viewport to an   OBJ-format file. For more information, see   [Exporting viewport data to an OBJ-format file](simacae-t-dbsexportmodelobj.md). * Select FileRun   Script to execute a file containing   Abaqus Scripting Interface   commands. For more information, see   [Replaying an Abaqus/CAE session](simacae-c-dbsfilesreplay.md),   and   [Creating and running your own scripts](simacae-c-dbsfilesscriptsrun.md). * Select FileMacro   Manager to store your actions in a macro file as a   sequence of   Abaqus Scripting Interface   commands. You can also run a macro and rename an existing macro. For more   information, see   [Creating and running a macro](simacae-c-dbsfilesscriptsmacro.md). * Select   FilePrint   to print all or selected viewports and annotations. You can also click    in the   File toolbar.   For more information, see   [Printing viewports](simacae-m-Pri-sb.md). * Select FileAbaqus   PDE to open the   Abaqus   Python development environment. The   Abaqus   PDE is a separate application used to create,   edit, test, and debug scripts. For more information, see   [About the Abaqus Python development environment](.._SIMACAECMDRefMap_simacmd-c-pdeover.md). * Select   FileExit   to exit the   Abaqus/CAE   session. For more information, see   [Exiting an Abaqus/CAE session](simacae-c-gststop.md). |
