See [Models for Metals Subjected to Cyclic Loading](.._SIMACAEMATRefMap_simamat-c-hardening.md), for more information. | | |   1. From the menu bar in the Edit Material dialog box, select MechanicalPlasticityPlastic. (For information on displaying the Edit Material dialog box, see [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. Click the arrow to the right of the Hardening field, and select Kinematic. 3. Toggle on Use temperature-dependent data to define behavior data that depend on temperature. A column labeled Temp appears in the Data table. 4. Enter the following data in the Data table: Yield Stress  The stress at which yield is initiated.  Plastic Strain  Plastic strain.  Temp  Temperature.  You may need to expand the dialog box to see all the columns in the Data table. For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 5. If desired, use the Suboptions menu to enter additional data. See the following sections for details: * [Defining anisotropic yield and creep](simacae-t-prpmechanicalplasticplasticpotential.md)”    * [Using the Oak Ridge National Laboratory (ORNL) constitutive model in plasticity and creep calculations](simacae-t-prpmechanicalplasticplasticornl.md)”    * [Specifying cycled yield stress data for the ORNL model](simacae-t-prpmechanicalplasticplasticcycledplastic.md)”    * [Specifying the annealing temperature of an elastic-plastic material](simacae-t-prpmechanicalplasticplasticanneal.md)” 6. Click OK to create the material and to close the Edit Material dialog box. Alternatively, you can select another material behavior to define from the menus in the Edit Material dialog box (see [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md), for more information). |
