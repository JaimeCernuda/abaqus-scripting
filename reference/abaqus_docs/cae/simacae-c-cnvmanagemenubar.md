# Managing viewports and viewport annotations from the main menu bar

|  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Managing viewports and viewport annotations from the main menu bar | | |  | | | |  | | --- | | Use the Viewport menu, located on the main menu bar, to create, delete, modify, link, or rearrange viewports and to create or edit viewport annotations—both those that you create and those generated by Abaqus/CAE. If you prefer, you can select ViewToolbarsViewport from the main menu bar to display a toolbar containing most of the functionality of the items in the Viewport menu. | | |  | | --- | | See Also | | [Managing viewports on the canvas](simacae-m-Cnv-sb.md) | |   The Viewport menu and toolbar allow you to do the following:   * [Create](simacae-t-cnvviewportbtn.md) a viewport. * [Edit](simacae-m-General-sb.md) options for generated viewport annotations (triad, legend, title block, and state block). * Create an [arrow](simacae-t-cnvarrowbtn.md) annotation. * Create a [text](simacae-t-cnvtextbtn.md) annotation. * Create a [combined arrow and text](simacae-t-cnvarrowtextcombo.md) annotation. * Edit [arrow](simacae-t-cnveditarrowanno.md) and [text](simacae-t-cnvedittextanno.md) annotations. * Open the Annotation Manager to manipulate arrow and text annotations.  Note:    The Annotation Manager provides several unique management functions; for more information, see [The Annotation Manager](simacae-c-cnvannotmgr.md). * Open the Viewport Annotation Options to show or hide all annotations and to manipulate the viewport annotations generated by Abaqus/CAE. * [Link](simacae-t-cnvlinkoptions.md) viewports.   In addition, the Viewport menu lists all the viewports in the session and allows you to delete the current viewport. |
