# Defining an equation of state

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Defining an equation of state | | |  | | | |  | | --- | | You can use the Edit Material dialog box to define a hydrodynamic material model in which the material's volumetric strength is determined by an equation of state.  For more information, see [Equation of State](.._SIMACAEMATRefMap_simamat-c-eos.md). | | |   1. From the menu in the Edit Material dialog box, select     Mechanical    Eos    . (For information on displaying the Edit Material dialog    box, see [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. Click the arrow to the right of the Type field, and select the type of equation of state that you want to define: * Select Ideal Gas to define an ideal gas equation of state. For more information, see [Ideal Gas Equation of State](.._SIMACAEMATRefMap_simamat-c-eos.md#simamat-c-eos-idealgas).    * Select JWL to define a Jones-Wilkins-Lee explosive equation of state. For more information, see [JWL High Explosive Equation of State](.._SIMACAEMATRefMap_simamat-c-eos.md#simamat-c-eos-jwl).    * Select Us-Up to define a linear Us − Up equation of state. For more information, see [Mie-Grüneisen Equations of State](.._SIMACAEMATRefMap_simamat-c-eos.md#simamat-c-eos-mg).    * Select Ignition and growth to define an equation of state that models shock initiation and detonation wave propagation. For more information, see [Ignition and Growth Equation of State](.._SIMACAEMATRefMap_simamat-c-eos.md#simamat-c-eos-ig).    * Select Tabular to define a tabulated equation of state linear in energy. For more information, see [Tabulated Equation of State](.._SIMACAEMATRefMap_simamat-c-eos.md#simamat-c-eos-tab). 3. If you selected Ideal Gas in Step 2, enter the following data in the Data table: Gas Constant  Gas constant, R. (Units of JM−1K−1.)  Ambient Pressure  The ambient pressure, pA (Units of FL−2).  For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 4. If you selected JWL in Step 2, enter the following data in the Data table: Detonation Wave Speed  Detonation wave speed, Cd. (Units of LT−1.)  A and B  Material constants A, and B. (Units of FL−2.)  omega, R1, and R2  Material constants ω, R1, and R2. (Dimensionless.)  Detonation Energy Dens  Detonation energy density, E0. (Units of JM−1.)  Pre-deton Bulk Modulus  Pre-detonation bulk modulus, Kp⁢d. (Units of FL−2.)  For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 5. If you selected Us-Up in Step 2, enter the following data in the Data table: c0  Reference sound speed, c0. (Units of LT−1.)  s  Slope of the Us − Up curve, s. (Dimensionless.)  Gamma0  Grüneisen ratio, Γ0. (Dimensionless.)  For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 6. If you selected Tabular in Step 2, enter the following data in the Data table. The volumetric strain values must be arranged in descending order (that is, from the most tensile to the most compressive states). f1  f1. (Units of FL−2.)  f2  f2. (Dimensionless.)  epsilon\_vol  Volumetric strain εvol. (Dimensionless.)  For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 7. If you selected Ignition and growth in Step 2, see [Defining an ignition and growth equation of state](simacae-t-prpmechanicalothereosignition.md) for detailed    instructions. 8. If you selected JWL in    Step 2, select Detonation Point from the    Suboptions menu to define detonation points for the    explosive material. For detailed instructions, see [Defining detonation points for an explosive material](simacae-t-prpmechanicalothereosdetonationpoints.md). 9. If you selected Us-Up or Tabular in    Step 2, you can select Eos Compaction from the    Suboptions menu to specify plastic compaction behavior    for a ductile porous material. For detailed instructions, see [Defining plastic compaction behavior for an equation of state](simacae-t-prpmechanicalothereoscompaction.md). 10. If you selected JWL,     Us-Up, or Tabular in Step 2, you     can select Tensile Failure from the     Suboptions menu to specify a tensile failure model and     criterion. For detailed instructions, see [Defining tensile failure for an equation of state](simacae-t-prpmechanicalothereostensilefailure.md). 11. Click OK to close the Edit Material dialog box. Alternatively, you can select another material behavior to define from the menus in the Edit Material dialog box (see [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md), for more information). |
