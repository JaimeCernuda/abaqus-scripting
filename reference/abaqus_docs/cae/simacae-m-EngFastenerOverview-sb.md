| |  |  | | --- | --- | | About fasteners | | |  | | | |  | | --- | | You use fasteners to model a point-to-point connection between two or more faces, such as a spot weld, a bolt, or a rivet. You can use the Attachment toolset to create attachments that help you define fasteners; for more information, see [Understanding attachment points and lines](simacae-c-attconcattachmethods.md). You can create point-based fasteners, discrete fasteners, or assembled fasteners. Both point-based and discrete fasteners can be modeled using connectors or beam MPCs. If you define connectors that use basic, assembled, or complex connection types, you can request output from your point-based or discrete fasteners through connector output variables. However, if you use beam MPCs, no output is available from your point-based or discrete fasteners.   --- | | In this section:   * [About point-based fasteners](simacae-c-engfasteneroverviewpoint.md) * [About discrete fasteners](simacae-c-engfasteneroverviewdiscrete.md) * [About assembled fasteners](simacae-m-EngFastenerOverviewAssm-sb.md) | | | |
