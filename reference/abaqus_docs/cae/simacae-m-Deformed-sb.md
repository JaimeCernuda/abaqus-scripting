| |  |  | | --- | --- | | Plotting the undeformed and deformed shapes | | |  | | | |  | | --- | | This section explains undeformed and deformed shape plotting and superimposed plots.  Immediately upon opening an output database, Abaqus/CAE displays the undeformed shape of your model. For general analysis steps an undeformed plot displays the shape of your model without any deformation. For linear perturbation steps an undeformed plot displays the base state of your model. The deformed plot shows the shape of your model according to the values of a nodal variable such as displacement. The undeformed and deformed shapes are also used to display each of the other plot states available in Abaqus/CAE.
