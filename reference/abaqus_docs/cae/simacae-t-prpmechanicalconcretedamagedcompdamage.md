| |  |  | | --- | --- | | Defining concrete compression damage | | |  | | | |  | | --- | | You can define the uniaxial compression damage variable, dc, as a tabular function of inelastic (crushing) strain. For more information, see [Defining Damage and Stiffness Recovery](.._SIMACAEMATRefMap_simamat-c-concretedamaged.md#simamat-c-concretedamaged-damage). | | |   1. Create a material model as described in [Defining a concrete damaged plasticity model](simacae-t-prpmechanicalplasticconcretedamagedmodel.md).” 2. From the Suboptions menu on the Compressive Behavior tabbed page, select Compression Damage. A Suboption Editor appears. 3. In the Tension recovery field, enter a value for the stiffness recovery factor wt, which determines the amount of tension stiffness that is recovered as the loading changes from compression to tension. If wt=1, the material fully recovers the tensile stiffness; if wt=0, there is no stiffness recovery. Intermediate values of wt (0≤wt≤1) result in partial recovery of the tensile stiffness. The default value is 0.0. 4. Toggle on Use temperature-dependent data to define data that depend on temperature. A column labeled Temp appears in the Data table. 5. Click the arrows to the right of the Number of field variables field to increase or decrease the number of field variables on which the data depend. 6. Enter the following data in the Data table: Damage Parameter  Compressive damage variable, dc.  Inelastic Strain  Inelastic (crushing) strain, ε~ci⁢n.  Temp  Temperature.  Field n  Predefined field variables. 7. Click OK to return to the Edit Material dialog box. |
