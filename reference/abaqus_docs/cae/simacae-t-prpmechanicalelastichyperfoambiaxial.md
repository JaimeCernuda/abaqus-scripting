Create a hyperelastic foam material model as described in [Providing test data to define a hyperelastic foam material model](simacae-t-prpmechanicalelastichyperfoamtestdata.md).” 2. From the Suboptions menu in the Edit Material dialog box, select Biaxial Test Data. A Test Data Editor appears. 3. In the Data table, enter the test data: Nominal Stress  Nominal stress, TL.  Nominal Strain  Nominal strain, ϵB.  Lateral Nominal Strain  Nominal transverse strain, ϵ3. This parameter is unnecessary if you have already entered a constant Poisson's ratio in the Edit Material dialog box.  You may need to expand the dialog box to see all the columns in the Data table. For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 4. Click OK to return to the Edit Material dialog box. |
