| |  |  | | --- | --- | | Controlling animation playback | | |  | | | |  | | --- | | During an object-based animation you can control the speed and repetition of playback, and you can stop, restart, and step through your animation.  Most industry-standard animation software supports the same functions for image-based animation, but the available options are based on the application that you choose. For object-based animations one additional option is available: you can display or suppress status information while the animation is playing.  If you are using multiple viewports to display animations, you can include or exclude individual viewports from the common animation time line. By default, each new viewport you create will be included in the synchronization.
