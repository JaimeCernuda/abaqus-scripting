| |  |  | | --- | --- | | Viewing load case output | | |  | | | |  | | --- | | Load case output is stored in separate frames in the output database (.odb). You use the Visualization module to view and manipulate load case output. The load case name is displayed in the state block for each frame containing load case output. For example, [Figure 1](simacae-c-advloadcaseoutput.md#simacae-c-advloadcaseoutput__simacae-advlcodb) shows the deformed plot for the `Pressure Load w End Load Up` load case of the cantilever beam model (see [Load case editors](simacae-c-advloadcaseeditors.md)). | | |  | | --- | | See Also | | [Creating and saving new field output](simacae-m-ResManaging-sb.md) | |   Figure 1. Results from a load case analysis.    In the Visualization module you can linearly combine output from several load cases to represent an actual loading environment. You can also obtain the minimum or maximum value of a selected field variable over some or all load cases.  For example, you can combine the output from the `End Load Only` and `Pressure Load Only` load cases for the cantilever beam model to create new field output with a load case name of `Both loads`, as shown in [Figure 2](simacae-c-advloadcaseoutput.md#simacae-c-advloadcaseoutput__simacae-advcreateoutput). Figure 2. Creating new field output by combining the output from two load cases (frames).    The new field output is contained in a frame of the session step and is available from the Field Output dialog box. [Figure 3](simacae-c-advloadcaseoutput.md#simacae-c-advloadcaseoutput__simacae-advlcodbboth) shows a plot of the combined deformation results. Figure 3. Combined deformation results from both load cases.    For detailed information on manipulating load case output, see [Combining results from several frames](simacae-c-rescombineframes.md). |
