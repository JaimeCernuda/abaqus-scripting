| |  |  | | --- | --- | | Defining a crush stress model | | |  | | | |  | | --- | | The crush stress can be thought of as the stress of the crushing body at the crushing interface. The crush stress is specified as a material property but does not directly influence the constitutive calculations associated with element integration points; rather, the crush stress limits the contact pressure magnitude at an actively crushing interface. See [CZone Analysis](.._SIMACAEANLRefMap_simaanl-c-czoneanalysis.md#simaanl-c-czoneanalysis) for more information. | | |   Context:  In the crush stress model, the composite material can be a constant or can vary as a function of the angle,    θ ,  between the local x-direction of the crushable element and the contact normal direction projected to the plane of the element.  1. From the menu bar in the Edit Material dialog box, select     Mechanical    Crush Stress    . (For information on displaying the Edit Material dialog    box, see [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. Toggle on Use temperature-dependent data to define data    that depend on temperature. A column labeled Temp appears in the    Data table. 3. Click the arrows to the right of the Number of field    variables field to increase or decrease the number of field    variables on which the data depend. 4. Enter the following data in the Data table: Crush Stress  Crush stress.  Material angle (degrees)  Material angle in degrees.  Temp  Temperature.  Field n  Predefined field variables.  You can expand the dialog box to see all the columns in the    Data table. For detailed information on how to enter    data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 5. Select Velocity Factor from the    Suboptions menu to define how the approach velocity at    a crushing interface influences a material's resistance to crushing (see [Defining crush stress velocity factor](simacae-t-prpmechanicalothercrushstressvelocityfactor.md#simacae-t-prpmechanicalothercrushstressvelocityfactor) for details). 6. Click OK to create the material and to close the    Edit Material dialog box. Alternatively, you can select    another material behavior to define from the menus in the Edit    Material dialog box (see [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md), for more information). |
