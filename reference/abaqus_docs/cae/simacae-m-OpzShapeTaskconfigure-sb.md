| |  |  | | --- | --- | | Configuring a shape optimization task | | |  | | | |  | | --- | | Shape optimization determines the displacement of each surface node in an effort to homogenize the stress on the surface and satisfy the objective function and any constraints. You can use the optimization task editor to customize various aspects of the shape optimization and to incorporate durability analysis into the optimization. You can specify a condition-based shape optimization (default) or a general (sensitivity-based) shape optimization. To locate the editor, select TaskEditoptimization task name from the main menu bar.
