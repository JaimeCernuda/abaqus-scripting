# Defining plastic compaction behavior for an equation of state

| |  |  | | --- | --- | | Defining plastic compaction behavior for an equation of state | | |  | | | |  | | --- | | If you define a linear Us − Up or tabulated equation of state (as described in [Defining an equation of state](simacae-t-prpmechanicalothereosdefine.md)”), you can use the Suboption Editor to specify plastic compaction behavior for a ductile porous material. For more information, see [P–alpha Equation of State](.._SIMACAEMATRefMap_simamat-c-eos.md#simamat-c-eos-compaction). | | |   1. Define a Us − Up or tabulated equation of state, as described in [Defining an equation of state](simacae-t-prpmechanicalothereosdefine.md).” 2. From the Suboptions menu in the Edit Material dialog box, select Eos Compaction. A Suboption Editor appears. 3. In the Reference sound speed in the porous material field, enter a value for ce. (Units of LT−1.) 4. In the Value of the porosity of the unloaded material field, enter a value for n0. (Dimensionless.) 5. In the Pressure required to initialize plastic behavior field, enter a value for pe. (Units of FL−2.) 6. In the Compaction pressure at which all pores are crushed field, enter a value for pS. (Units of FL−2.) 7. Click OK to return to the Edit Material dialog box. |
