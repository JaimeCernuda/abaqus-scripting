| |  |  | | --- | --- | | Generating tabular data reports | | |  | | | |  | | --- | | You can produce a tabular data report of X–Y data objects, field output results, probe values, or free body cuts. Abaqus/CAE writes the report to the file name of your choice. Generate a tabular report to save data values beyond the duration of the session or to print these values. In addition, you can use a tabular report as ASCII input in subsequent Abaqus/CAE sessions.
