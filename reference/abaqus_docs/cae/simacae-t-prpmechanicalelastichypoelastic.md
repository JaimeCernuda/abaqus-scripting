# Creating a hypoelastic material model

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Creating a hypoelastic material model | | |  | | | |  | | --- | | You can create a hypoelastic material definition to describe a nonlinear, small-strain elastic material. You have the option of either entering hypoelastic material parameters directly in the material editor or defining material parameters in user subroutine [UHYPEL](.._SIMACAESUBRefMap_simasub-c-uhypel.md#simasub-c-uhypel). User subroutine [UHYPEL](.._SIMACAESUBRefMap_simasub-c-uhypel.md#simasub-c-uhypel) allows you to specify temperature-dependent data. | | |   Context:  For more information, see the following sections:   * [Hypoelastic Behavior](.._SIMACAEMATRefMap_simamat-c-hypoelastic.md) * [UHYPEL](.._SIMACAESUBRefMap_simasub-c-uhypel.md)  1. From the menu bar in the Edit Material dialog box, select MechanicalElasticityHypoelastic. (For information on displaying the Edit Material dialog box, see [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. Select one of the following options for specifying material parameters: * Toggle on Use user subroutine UHYPEL.    * Enter material parameters in the Data area:  Young's Modulus  Instantaneous Young's modulus, E.  Poisson's Ratio  Instantaneous Poisson's ratio, ν.  I1  First strain invariant, I1.  I2  Second strain invariant, I2.  I3  Third strain invariant, I3.  You may need to expand the dialog box to see all the columns in the Data table. For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 3. Click OK to create the material and to close the Edit Material dialog box. Alternatively, you can select another material behavior to define from the menus in the Edit Material dialog box (see [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md), for more information). |
