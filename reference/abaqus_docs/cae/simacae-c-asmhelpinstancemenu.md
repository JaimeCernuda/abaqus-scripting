# Using the Instance menu

|  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Using the Instance menu | | |  | | | |  | | --- | | Use the Instance menu to do the following: | | |  | | --- | | See Also | | [Using the Assembly module toolbox](simacae-c-asmtoolbox.md) | | [The Assembly module](simacae-m-Asm-sb.md) | |   * [Create](simacae-t-asmcreateinstancebtn.md) instances of parts from the current model and add them to the assembly. You can also create instances of other models to add to the current assembly. * Create a [linear pattern](simacae-t-asmlinearpatternbtn.md) of part instances. * Create a [radial pattern](simacae-t-asmradialpatternbtn.md) of part instances. * [Translate](simacae-t-asmtranslateinstancebtn.md) selected part or model instances along a specified vector. * [Translate](simacae-t-asmconstraintcontactbtn.md) selected part or model instances along a specified vector until they are a specified distance from another instance. * [Rotate](simacae-t-asmrotateinstancebtn.md) selected part or model instances through a specified angle about a specified axis. * [Replace](simacae-t-asmreplaceinstancebtn.md) a part instance with a second part instance. * [Convert](simacae-t-asmconvconstbtn.md) any position constraints to an absolute position. * [Merge or cut](simacae-t-asmmergecutbtn.md) part instances.   You may find it more convenient to access the instance tools using the Assembly module toolbox. For a diagram of the tools in the Assembly toolbox, see [Using the Assembly module toolbox](simacae-c-asmtoolbox.md). |
