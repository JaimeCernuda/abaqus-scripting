| |  |  | | --- | --- | | Hosford-Coulomb damage | | |  | | | |  | | --- | | The Hosford-Coulomb damage initiation criterion is a special case of the ductile criterion in which the equivalent plastic strain at the onset of damage is a function of the stress triaxiality, material parameters, and strain rate. The Hosford-Coulomb criterion can be used in conjunction with the Mises, Johnson-Cook, Hill, and Drucker-Prager plasticity models. It can also be specified together with any other initiation criteria; each initiation criterion is treated independently. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Damage Initiation for Ductile Metals](.._SIMACAEMATRefMap_simamat-c-damageinitductile.md) | |   1.
