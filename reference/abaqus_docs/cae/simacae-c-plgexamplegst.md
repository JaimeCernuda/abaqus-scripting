# Running the Getting Started with Abaqus examples

| |  |  | | --- | --- | | Running the Getting Started with Abaqus examples | | |  | | | |  | | --- | | This plug-in allows you to run the examples described in [Getting Started with Abaqus/CAE](.._SIMACAEGSARefMap_simagsa-c-ov.md#simagsa-c-ov). The plug-in creates a model that reproduces each example. The plug-in also creates a job associated with the model; however, the plug-in does not submit the job for analysis. If desired, you can go to the Job module and submit the job for analysis. You can then can go to the Visualization module to view the results of the analysis.  The plug-in fetches files associated with the examples and places those files in the current directory. You can run the following examples from the plug-in:   * [Example: creating a model of an overhead hoist](.._SIMACAEGSARefMap_simagsa-m-AbsModel-sb.md#simagsa-m-AbsModel-sb) * [Example: connecting lug](.._SIMACAEGSARefMap_simagsa-m-CtmConnectlug-sb.md#simagsa-m-CtmConnectlug-sb) * [Example: skew plate](.._SIMACAEGSARefMap_simagsa-m-ShlExampleSkewplate-sb.md#simagsa-m-ShlExampleSkewplate-sb) * [Example: cargo crane](.._SIMACAEGSARefMap_simagsa-m-BmsExacargocrane-sb.md#simagsa-m-BmsExacargocrane-sb) * [Example: cargo crane under dynamic loading](.._SIMACAEGSARefMap_simagsa-m-DynExacargodyn-sb.md#simagsa-m-DynExacargodyn-sb) * [Example: skew plate](.._SIMACAEGSARefMap_simagsa-m-ShlExampleSkewplate-sb.md#simagsa-m-ShlExampleSkewplate-sb) * [Example: stress wave propagation in a bar](.._SIMACAEGSARefMap_simagsa-m-OvwExastresswave-sb.md#simagsa-m-OvwExastresswave-sb) * [Example: connecting lug](.._SIMACAEGSARefMap_simagsa-m-CtmConnectlug-sb.md#simagsa-m-CtmConnectlug-sb) * [Example: blast loading on a stiffened plate](.._SIMACAEGSARefMap_simagsa-m-MatExablastload-sb.md#simagsa-m-MatExablastload-sb) * [Example: axisymmetric mount](.._SIMACAEGSARefMap_simagsa-m-MatExaximount-sb.md#simagsa-m-MatExaximount-sb) * [Example: vibration of a piping system](.._SIMACAEGSARefMap_simagsa-m-StpExapipingsys-sb.md#simagsa-m-StpExapipingsys-sb) * [Abaqus/Standard 3D example: shearing of a lap joint](.._SIMACAEGSARefMap_simagsa-m-CntExalapjoint-sb.md#simagsa-m-CntExalapjoint-sb) * [Abaqus/Explicit example: circuit board drop test](.._SIMACAEGSARefMap_simagsa-m-CntCircuitboard-sb.md#simagsa-m-CntCircuitboard-sb) * [Example: forming a channel in Abaqus/Explicit](.._SIMACAEGSARefMap_simagsa-m-QsiExadeepdraw-sb.md#simagsa-m-QsiExadeepdraw-sb) | | | |
