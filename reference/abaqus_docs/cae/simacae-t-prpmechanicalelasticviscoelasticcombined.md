| |  |  | | --- | --- | | Specifying combined test data | | |  | | | |  | | --- | | You can use the Test Data Editor to specify simultaneously the normalized shear and bulk creep compliances or relaxation moduli as a function of time. For information on using combined test data to define viscoelastic material behavior, see [Time Domain Viscoelasticity](.._SIMACAEMATRefMap_simamat-c-timevisco.md), or [Frequency Domain Viscoelasticity](.._SIMACAEMATRefMap_simamat-c-freqvisco.md). | | |   1. Create a viscoelastic material model as described in [Defining time domain viscoelasticity](simacae-t-prpmechanicalelasticviscoelastictime.md)” or [Defining frequency domain viscoelasticity](simacae-t-prpmechanicalelasticviscoelasticfrequency.md).” 2. From the Test Data menu in the Edit Material dialog box, select Combined Test Data. A Test Data Editor appears. 3. In the Long-term normalized shear compliance or modulus field, enter either the long-term, normalized shear compliance, jS⁢(∞), for creep test data or the long-term, normalized shear modulus, gR⁢(∞), for relaxation test data. 4. In the Long-term normalized volumetric compliance or modulus field, enter either the long-term, normalized volumetric compliance, jK⁢(∞), for creep test data or the long-term, normalized volumetric modulus, kR⁢(∞), for relaxation test data. 5. In the Data table, enter the following data: js or gR  The normalized shear compliance, jS⁢(t), ( (jS⁢(t)≥1)) for creep test data or the normalized shear relaxation modulus, gR⁢(t), ( (0≤gR⁢(t)≤1)) for relaxation test data.  jK or kR  The normalized volumetric compliance, jK(t),(jK(t)≥1), for creep test data or the normalized volumetric modulus, kR(t),(0≤kR(t)≤1), for relaxation test data.  Time  Time, t. (t>0)  For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 6. Click OK to return to the Edit Material dialog box. |
