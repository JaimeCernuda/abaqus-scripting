# Producing a time history animation

|  |  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Producing a time history animation | | |  | | | |  | | --- | | Animating by time history produces a sequence of plots that vary over time according to actual analysis results. You can choose to animate a deformed shape, contour, symbol, or material orientation plot. | | |  | | --- | | See Also | | [Customizing the display of steps and frames in the results](simacae-m-ResActivestepsframesdb-sb.md) | | [Controlling animation playback](simacae-m-AnmPlayback-sb.md) | |   1. Use the File menu to open the [output database](simacae-t-dbsmdbopen.md) containing your analysis results. 2. To plot variables other than those Abaqus selects by default, use the Result menu. * For animation of a deformed or material orientation plot, select the [deformed field output variable](simacae-t-resdeformedtabbtn.md) for which Abaqus obtains values over time.    * For animation of a contour or symbol plot, select the [primary field output variable](simacae-t-resprimarytabbtn.md) or [symbol field output variable](simacae-t-ressymboltabbtn.md) to display. If you want to display your animating contour or symbol plot on the deformed shape, select the [deformed field variable](simacae-t-resdeformedtabbtn.md). For more information on field output variable selection, see [Selecting field output variables](simacae-t-resvisvariabledb.md). 3. To customize the steps and frames that Abaqus/CAE includes in the animation, locate the Active Steps/Frames dialog box. From the main menu bar, select ResultActive Steps/Frames. For more information about activating steps and frames, see [Customizing the display of steps and frames in the results](simacae-m-ResActivestepsframesdb-sb.md). 4. Use the Options and View menus to select the [customization options](simacae-c-conceptcustomization.md) that you want. These may include deformed, contour, symbol, orientation, and view options. 5. To initiate the animation, select AnimateTime History from the main menu bar. |  |    | --- |    | Tip: You can also produce a time history animation using the  tool in the toolbox. |  Animation begins in all animated viewports, and the animation controls appear in the right side of the context bar. Abaqus is now in the time history animation plot state. In this state Abaqus automatically refreshes your plot each time you click Apply or OK in the Results, Options, or View menu dialog boxes. All animated viewports remain in the time history animation state until you produce a plot in some other state, such as the undeformed or deformed state. To learn how to control the animation, see [Controlling animation playback](simacae-m-AnmPlayback-sb.md). |
