| |  |  | | --- | --- | | Reviewing and modifying detected contact pairs | | |  | | | |  | | --- | | This section discusses to review and modify the contact pair definitions.  After searching for contact pairs (described in [Specifying search criteria for contact detection](simacae-m-ItnHelpDetectionCriteria-sb.md) and [Searching for contact pairs](simacae-t-itnhelpdetectionsearch.md)), you have the opportunity to review the search results before creating interactions and tie constraints. The search results are presented in the contact pair candidates table: each contact pair comprises a row in the table; each column represents a parameter of the contact pair definition.
