| |  |  | | --- | --- | | Choosing the type of XFEM analysis | | |  | | | |  | | --- | | Abaqus provides the traction-separation cohesive behavior approach and the linear elastic fracture mechanics (LEFM) approach for studying crack initiation and propagation using XFEM. | | |   Traction-separation cohesive behavior  The traction-separation cohesive behavior approach is described in detail in [Modeling Moving Cracks with the Cohesive Segments Method and Phantom Nodes](.._SIMACAEANLRefMap_simaanl-c-enrichment.md#simaanl-c-enrichment-cohesive). You can specify the material properties that define the evolution of damage leading to eventual failure. You apply the material to the section that is assigned to the crack domain. You can choose to associate a normal behavior contact interaction property with the XFEM crack that defines the contact of cracked element surfaces. For detailed information, see [Specifying a contact interaction property for XFEM](simacae-t-enghelpxfemcontact.md). To assist convergence as the material fails, you can introduce localized damping using the viscous regularization technique. For more information, see [Damage stabilization](simacae-c-prpmechanicaldamagestabilization.md).  Linear elastic fracture mechanics (LEFM)  The linear elastic fracture mechanics (LEFM) approach uses the modified Virtual Crack Closure Technique (VCCT) to calculate the strain energy release rate at the crack tip. The approach is more appropriate for brittle fracture problems and is described in detail in [Applying the VCCT Technique to the XFEM-Based LEFM Approach](.._SIMACAEANLRefMap_simaanl-c-enrichment-xfem-based-lefm.md). To use this approach, you must create a fracture criterion contact interaction property, as described in [Specifying fracture criterion properties for crack propagation](simacae-t-itnhelppropcontactmechfracture.md). If you specify localized damping in the contact interaction property, Abaqus will use the viscous regularization technique to assist convergence as the material fails. For more information, see [Specifying fracture criterion properties for crack propagation](simacae-t-itnhelppropcontactmechfracture.md). |
