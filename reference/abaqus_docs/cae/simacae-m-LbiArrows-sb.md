| |  |  | | --- | --- | | Understanding symbols that represent prescribed conditions | | |  | | | |  | | --- | | This section explains how to interpret the symbols that represent prescribed conditions.  When you apply prescribed conditions to a region, you can choose to display symbols in the viewport that indicate the following:   * The regions to which you applied the prescribed condition. * The type of the prescribed condition. * If applicable, the degrees of freedom to which you applied the   prescribed condition. * If applicable, the direction (negative or positive) in which you   applied the prescribed condition. * If applicable, the spatial variation of the prescribed condition.
