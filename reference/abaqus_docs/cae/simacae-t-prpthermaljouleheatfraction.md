# Specifying a joule heat fraction

| |  |  | | --- | --- | | Specifying a joule heat fraction | | |  | | | |  | | --- | | Joule heating arises when the energy dissipated by an electrical current flowing through a conductor is converted into thermal energy. A joule heat fraction is the fraction of dissipated electrical energy released as heat in coupled thermal-electrical problems. | | |   Context:  See the following sections for more information:   * [Coupled Thermal-Electrical Analysis](.._SIMACAEANLRefMap_simaanl-c-jouleheating.md) * [Specifying the Amount of Thermal Energy Generated due to Electrical Current](.._SIMACAEANLRefMap_simaanl-c-jouleheating.md#simaanl-c-jouleheating-fraction)  1. From the menu bar in the Edit Material dialog box, select ThermalJoule Heat Fraction. (For information on displaying the Edit Material dialog box, see [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. In the Fraction field, enter the fraction of electrical energy released as heat, including any unit conversion factor. The default value is 1.0. 3. Click OK to close the Edit Material dialog box. Alternatively, you can select another material behavior to define from the menus in the Edit Material dialog box (see [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md), for more information). |
