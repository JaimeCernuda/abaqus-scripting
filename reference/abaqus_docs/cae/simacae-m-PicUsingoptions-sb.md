| |  |  | | --- | --- | | Using the selection options | | |  | | | |  | | --- | | Abaqus/CAE provides a set of tools that can make it easier and more efficient for you to select entities from the viewport. The selection tools are located in the Selection toolbar. The available options depend on the current selection procedure; some options can be used to preselect entities outside of a procedure.
