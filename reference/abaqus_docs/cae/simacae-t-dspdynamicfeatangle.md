[Figure 1](simacae-t-dspdynamicfeatangle.md#simacae-t-dspdynamicfeatangle__simacae-featanglepartassembly) shows a meshed part displayed at three different feature angles—0°, 5°, and 20°. Figure 1. Plots showing feature angles of 0°, 5°, and 20°.     Feature edges are defined as adjacent edges with normals that differ by more than the “feature angle.” You can customize the feature angle when you select Feature mesh edge visibility. Larger angles will reduce the number of feature edges; conversely, smaller angles will cause more edges to be visible. The default mesh feature angle is 20°.  1. Locate the feature angle option. From the main menu bar, select    ViewPart Display    Options or    ViewAssembly Display    Options. In the dialog box that appears, click the    General tab. 2. From the bottom of the dialog box, select Feature    edges from the list of mesh edges to show. Abaqus/CAE    displays an Angle data field to the right of    Feature. 3. Click the Angle data entry field, and enter the    desired feature angle. 4. Click OK to    implement your changes and to close the dialog box. Your changes are saved for the duration of the session. |
