# Methods for creating a datum axis

|  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Methods for creating a datum axis | | |  | | | |  | | --- | | When you choose Axis from the Create Datum dialog box, the Method list displays the methods for creating a datum axis. | | |  | | --- | | See Also | | [Creating datum axes](simacae-m-DtmAxis-sb.md) | | [Controlling datum display](simacae-t-dspdynamicdatum.md) | |   The following methods are available:  Principal axis  Select one of the three principal axes with which the datum axis must be colinear, as shown in [Figure 1](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-hapa). For detailed instructions, see [Creating a datum axis along a principal axis](simacae-t-dtmaxisprinc.md). Figure 1. Defining a datum axis as one of the three principal axes.  Intersection of 2 planes  Select two non-parallel planar surfaces. Abaqus/CAE creates the datum axis where the two planes (or extensions of the two planes) intersect, as shown in [Figure 2](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-haxn). For detailed instructions, see [Creating a datum axis along the intersection of two planes](simacae-t-dtmaxis2planes.md). Figure 2. Defining a datum axis as the intersection of two planes.  Straight edge  Select a straight edge on the model with which the datum axis must be colinear, as shown in [Figure 3](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-har). For detailed instructions, see [Creating a datum axis along a straight edge](simacae-t-dtmaxisedge.md). Figure 3. Defining a datum axis as a straight edge on the model.  2 points  Select any two points on the model through which the datum axis must pass, as shown in [Figure 4](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-ha2p). For detailed instructions, see [Creating a datum axis through two points](simacae-t-dtmaxis2points.md). Figure 4. Defining a datum axis by selecting two points.  Axis of cylinder  Select a cylindrical face on the model. Abaqus/CAE creates a datum axis that lies along the axis of the cylindrical face, as shown in [Figure 5](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-hacyl). For detailed instructions, see [Creating a datum axis along the axis of a cylinder](simacae-t-dtmaxiscylinder.md). Figure 5. Defining a datum axis as the axis of a cylinder.  Normal to plane, thru point  Select a plane and a point that is not on the plane. Abaqus/CAE creates a datum axis that is normal to the plane and passes through the point, as shown in [Figure 6](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-happ). For detailed instructions, see [Creating a datum axis normal to a plane and passing through a point](simacae-t-dtmaxisnormal.md). Figure 6. Defining a datum axis by selecting a point and a plane.  Parallel to line, thru point  Select an edge of the model and a point outside the edge. Abaqus/CAE creates a datum axis that is parallel to the edge and passes through the point, as shown in [Figure 7](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-halp). For detailed instructions, see [Creating a datum axis parallel to a line and passing through a point](simacae-t-dtmaxisparallel.md). Figure 7. Defining a datum axis by selecting a point and an edge.  3 points on circle  Select three points on the model that define a circle. Abaqus/CAE creates a datum axis along the axis of the circle, as shown in [Figure 8](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-hacir). For detailed instructions, see [Creating a datum axis running along the axis of a circle defined by three points](simacae-t-dtmaxiscircle.md). Figure 8. Defining a datum axis as the axis of a circle.  Rotate from line  Select an edge and an axis of rotation, and specify the angle through which the edge will be rotated. Abaqus/CAE creates a datum axis by rotating the edge about the axis through the specified angle, as shown in [Figure 9](simacae-c-dtmtoolaxis.md#simacae-c-dtmtoolaxis__simacae-c-dtm-harot). For detailed instructions, see [Creating a datum axis by rotating an existing edge through a specified angle](simacae-t-dtmaxisrotate.md). Figure 9. Defining a datum axis by rotating an edge through a specified angle. |
