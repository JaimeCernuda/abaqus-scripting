Display the concentrated pore fluid flow load editor using one of the    following methods: * To create a new concentrated pore fluid flow load, follow the      procedure outlined in      [Creating loads](simacae-t-lbihelptopicscreateload.md)      (Category: `Fluid`;      Types for Selected Step: `Concentrated pore      fluid`).    * To edit an existing concentrated pore fluid flow load using menus      or managers, see      [Editing step-dependent objects](simacae-t-intstepeditmenu.md).      To edit the region to which the load is applied, see      [Editing the region to which a prescribed condition is applied](simacae-t-lbihelptopicseditreg.md). 2. Click the arrow to the right of the Distribution    field, and select the option of your choice from the list that appears: * Select Uniform to define a load that is      uniform over the region.    * Select an analytical field to define a spatially varying load.      Only analytical fields that are valid for this load type are displayed in the      selection list. Alternatively, you can click      to create a new analytical field. (See      [The Analytical Field toolset](simacae-m-Fld-sb.md)      for more information.) 3. In the Magnitude field, enter the flow rate    (units L3T−1). A positive magnitude    indicates fluid flow out of the body at the vertex or node. 4. If desired, click the arrow to the right of the    Amplitude field, and select the amplitude of your choice    from the list that appears. Alternatively, you can click    to create a new amplitude. (See    [The Amplitude toolset](simacae-m-Amp-sb.md)    for more information.) 5. Click OK to save your data and to exit the    editor. |
