| |  |  | | --- | --- | | Using the pick midpoint/datum point method to partition an edge | | |  | | | |  | | --- | | You can partition a selected edge by selecting the midpoint of the edge or a datum point along the edge. | | |  | | --- | | See Also | | [Selecting objects within the viewport](simacae-m-Pic-sb.md) | | [Partitioning techniques](simacae-m-ParOverview-sb.md) | | [Methods for partitioning edges](simacae-c-paredgebtn.md) | |   Context:  The figure below shows an example of partitioning a selected edge by selecting the midpoint of the edge or a datum point along the edge.   You cannot directly modify a partition that was created by selecting an existing point. However, if you subsequently move the point, the partition will move along with the point.  1. From the main menu bar, select    ToolsPartition. The Create Partition dialog box appears.    Abaqus/CAE displays prompts    in the prompt area to guide you through the procedure.  |  |    | --- |    | Tip: You can also use the pick midpoint/datum point method to partition an edge using the  tool, located with the partition edge tools in the module toolbox. For a diagram of the partition tools in the toolbox, see [Using the Partition toolset](simacae-c-parstart.md). | 2. From the Type radio buttons at the top of the    dialog box, choose Edge. The Method list displays the methods that you    can use to partition an edge. 3. From the list of methods, select Select midpoint/datum    point. 4. Select the edge to partition. Abaqus/CAE    highlights the selected edge. 5. Select the midpoint of the edge or a datum point along the edge. Abaqus/CAE    highlights the location of the partition. 6. In the prompt area, click Create Partition. Abaqus/CAE    creates the partition. |
