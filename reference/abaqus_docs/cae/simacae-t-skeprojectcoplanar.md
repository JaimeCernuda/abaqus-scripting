# Limiting the projection of coplanar entities

|  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Limiting the projection of coplanar entities | | |  | | | |  | | --- | | When a sketch-based feature is created or edited, you can set a limit for the number of coplanar entities that Abaqus/CAE automatically projects from the background. By default, Abaqus/CAE automatically projects 300 coplanar entities. The limit you choose for projected coplanar entities applies to all sketches in the Abaqus/CAE session. | | |  | | --- | | See Also | | [Customizing the Sketcher](simacae-m-SkeCustomizing-sb.md) | | [How Sketcher customization options are initialized and saved](simacae-c-skecustom.md) | |   1. From the bottom of the Sketcher toolbox, select the customization tool . The Sketcher Options dialog box appears. 2. From the General tabbed page, enter a value in the Max coplanar entities to project text field. If this value is exceeded, a warning message is issued and no entities are automatically projected. 3. After you have chosen the desired customization options, click OK to apply your changes and to close the Sketcher Options dialog box. |
