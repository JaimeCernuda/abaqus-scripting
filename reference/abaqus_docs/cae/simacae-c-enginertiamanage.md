| |  |  | | --- | --- | | Managing inertia | | |  | | | |  | | --- | | The Inertia Manager allows you to create and manage inertia definitions. | | |  | | --- | | See Also | | [Suppressing and resuming objects](simacae-c-intstepsuppressresume.md) | | [Defining point mass and rotary inertia](simacae-t-enghelppmi.md) | | [Defining nonstructural mass](simacae-t-enghelpnonstructmass.md) | | [Defining heat capacitance](simacae-t-enghelpheatcap.md) | | [Editing the region to which inertia is applied](simacae-t-enghelpeditinertia.md) | |   The manager includes a list of the names and the types of inertia that you have defined.  The Create, Edit, Copy, Rename, and Delete buttons in the manager allow you to create new inertia definitions or to edit, copy, rename, and delete existing ones.  The icons in the column along the left side of the manager allow you to suppress and resume existing inertia definitions. You can also initiate these procedures using the  Special Inertia  menu from the main menu bar in the Property module or the Interaction module. After you select a management operation from the main menu bar, the procedure is the same as if you had clicked the corresponding button inside the manager dialog box. |
