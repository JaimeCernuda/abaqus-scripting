| |  |  | | --- | --- | | Configuring basic settings | | |  | | | |  | | --- | | You can configure a general topology optimization. | | |   1. In the optimization task editor, click the Basic    tab. 2. Choose whether to freeze load or boundary condition regions. It is recommended that you freeze regions to which prescribed    conditions are applied because you do not want these regions to be removed    during the optimization. Freezing these regions stabilizes the optimization and    often leads to a significantly lower number of iterations. |
