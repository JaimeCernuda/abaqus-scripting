For more information, see [Beam Section Behavior](.._SIMACAEELMRefMap_simaelm-c-beamsectionbehavior.md). | | |  | | --- | | See Also | | [Defining profiles](simacae-c-prppropprofile.md) | | [Defining sections](simacae-c-prppropsection.md) |  |  | | --- | |  | | In Other Guides | | [Using a General Beam Section to Define the Section Behavior](.._SIMACAEELMRefMap_simaelm-c-usingbeamgensect.md) | |   1. Display the Edit Profile dialog box, as described in [Choosing a profile type](simacae-t-prpsectionprofilescreate.md). 2. In the Area field, enter the area of the profile shape. 3. In the I11 field, enter the moment of inertia for bending about the 1-axis of the section. 4. In the I12 field, enter the moment of inertia for cross-bending. 5. In the I22 field, enter the moment of inertia for bending about the 2-axis of the section. 6. In the J field, enter the torsional constant. 7. If the profile describes an open-section beam, enter the following: * In the Gamma O field, enter the sectoral moment, Γ0.    * In the Gamma W field, enter the warping constant, ΓW. 8. Click OK to save the profile and to close the Edit Profile dialog box. |
