| |  |  | | --- | --- | | Using material orientation plot options | | |  | | | |  | | --- | | You can use the material orientation plot options to customize the appearance of material orientation triads. | | |  | | --- | | See Also | | [Customizing material orientation plot triads](simacae-t-matorienttriadcolor.md#simacae-t-matorienttriadcolor) | |   Select OptionsMaterial Orientation from the main menu bar or click  in the toolbox to access the Material Orientation Plot Options dialog box. Use the options in the dialog box to control the visibility, color, length, thickness, and arrow appearance of the material orientation triad axes.  Other options such as the render style, edge visibility, deformation scale factor, and translucency are located in the [Common Plot Options](simacae-c-defnavigating.md) dialog box. If you choose to plot material orientations on both the undeformed and the deformed shape, you can use the [Superimpose Plot Options](simacae-t-defshowundefbtn.md) to customize the appearance of the undeformed shape. For more information on customizing a superimposed plot, see [Superimposing deformed and undeformed model plots](simacae-t-defshowundefbtn.md). To learn how to customize the render style and other display characteristics of your material orientation plot, see [Customizing plot display](simacae-m-PlotDisplay-sb.md). For more information on selecting the results step, see [Selecting a specific results step and frame](simacae-t-resvisframedb.md). For more information on selecting section point locations, see [Selecting section point data by category](simacae-t-resvisvariableshelldb.md). |
