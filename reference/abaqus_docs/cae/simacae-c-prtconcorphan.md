# What are orphan nodes and elements?

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | What are orphan nodes and elements? | | |  | | | |  | | --- | | Orphan nodes and elements are components of a finite element mesh that exist without any associated geometry. In effect, the mesh information has been orphaned from its parent geometry. Orphan nodes and elements can be created in several ways; they can be: | | |   * Imported from an output database (for more information, see   [Importing a part from an output database](simacae-t-dbsimportpartodb.md)) * Imported from an   Abaqus   input file (for more information, see   [Importing a model](simacae-t-impinputfilereader.md)) * Created as a mesh part (for more information, see   [Creating a mesh part](simacae-t-mgnorphanmeshpart.md)   ) * Created in a bottom-up meshing procedure (for more information, see   [Bottom-up meshing](simacae-m-MgnConcBottomup-sb.md)) * Created by certain mesh editing operations, such as create element and   offset (for more information, see   [Using the mesh editing tools](simacae-c-edthelpoverview.md)) * Created by deleting the associativity with their parent geometry (for   more information, see   [Deleting mesh-geometry associativity](simacae-t-edthelpmesheditdeleteassoc.md)   )   The first three methods above create an orphan mesh feature as the base feature of a new part. The remaining methods are part of the Edit Mesh toolset; these methods edit the existing mesh and, therefore, do not exist as features of the part. For more information, see [The Edit Mesh toolset](simacae-m-Edt-sb.md).  You can select the face of an orphan element as the sketch plane to add geometric features. In addition, in the Mesh module you can change the element type assigned to orphan elements, and you can verify and edit the mesh. |
