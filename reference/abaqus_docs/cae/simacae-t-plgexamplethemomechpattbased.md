# Pattern-based thermomechanical process

| |  |  | | --- | --- | | Pattern-based thermomechanical process | | |  | | | |  | | --- | | You can use the additive manufacturing plug-in to simulate a pattern-based thermomechanical analysis. | | |   1. In the Create AM Model dialog box, select    Thermo-Mechanical as the analysis type. 2. For the process type, select Pattern-based powder bed    fabrication. 3. Specify the thermal and structural models for the simulation, and click    OK. A new AM model appears in the AM Modeler tree. If you expand the node for the    AM model, four subnodes display: Material Input,    Moving Heat Source, Cooling, and    Event Series. 4. From the Event Series subnode, select    Create/Edit from the mouse button 3 menu to specify any    kind of trajectory or path of the tools (such as laser beam or roller) used in    the additive manufacturing process. See [Event series](simacae-t-plgexampleameventseries.md) for more    information. 5. From the Material Input subnode, select    Create from the mouse button 3 menu to specify all the    structural inputs for modeling the additive manufacturing process. Abaqus/CAE populates the field with default values. Enter your desired values, and click    OK. 6. From the Moving Heat Source subnode, select    Create from the mouse button 3 menu to specify all the    thermal inputs for modeling the additive manufacturing process. Abaqus/CAE populates the field with default values. Enter your desired values, and click    OK. 7. From the Cooling subnode, select    Create from the mouse button 3 menu to specify thermal    interactions (such as radiation and convection) on the model. Abaqus/CAE populates the field with default values. You can define radiation and    convection cooling interaction. Enter your desired values, and click    OK. |
