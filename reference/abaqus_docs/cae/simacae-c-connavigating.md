| |  |  | | --- | --- | | Using contour plot options | | |  | | | |  | | --- | | You can use the contour plot options to customize the appearance of contour plots. | | |  | | --- | | See Also | | [Customizing a contour plot](simacae-m-ConCustomize-sb.md) | |   Select OptionsContour from the main menu bar or click in the toolbox to access the Contour Plot Options dialog box. Click the following tabs to customize the appearance of contour plots in the current viewport:   * Basic: Choose the contour type (including whether   to show tick marks for line elements), contour intervals, and contour method. * Color & Style: The Color &   Style page contains the following tabs:    + Model Edges: Control the color of model edges.   + Spectrum: Choose contour colors, and control     the order of the values displayed in the legend.   + Line: For line-type contours control the style     and thickness of each line.   + Banded / Isosurface: For banded- or     isosurface-type contours control the color, style, and thickness of contour     edges. * Limits: Control the computation of contour limits   and the display of annotations for the maximum and minimum contour values. * Other: Control tick mark plot display options, the   display of nodal averaged vector or tensor orientations, and the display of   section point or envelope plots.   Other options such as the render style, edge visibility, deformation scale factor, and translucency are located in the [Common Plot Options](simacae-c-defnavigating.md) dialog box. If you choose to plot contours on both the undeformed and the deformed shape, you can use the [Superimpose Plot Options](simacae-t-defshowundefbtn.md) to customize the appearance of the undeformed shape. See [Superimposing deformed and undeformed model plots](simacae-t-defshowundefbtn.md), for more information about superimpose plots. To learn how to customize the render style and underlying model of your contour plot, see [Customizing plot display](simacae-m-PlotDisplay-sb.md). For information on the computation of result values, see [Understanding how results are computed](simacae-c-resconceptcompute.md). |
