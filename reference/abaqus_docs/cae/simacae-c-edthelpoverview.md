# Using the mesh editing tools

|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | Using the mesh editing tools | | |  | | | |  | | --- | | This section is an overview of the tools that are available in the Edit Mesh toolset. | | |   You can access the tools from the main menu bar by selecting MeshEdit. Abaqus/CAE displays the Edit Mesh dialog box. You can also display the Edit Mesh dialog box using the  tool, located at the bottom of the Mesh module toolbox.  Node editing tools  The following tools are available for editing nodes:   * Create node. For more information, see   [Creating a node](simacae-t-edthelpmesheditcreatenode.md). * Edit node. For more information, see   [Editing the position of selected nodes](simacae-t-edthelpmeshediteditmultnodes.md). * Drag node. For more information, see   [Dragging nodes](simacae-t-edthelpmesheditdragnodes.md). * Project nodes. For more information, see   [Projecting nodes](simacae-t-edthelpmesheditprojectnodes.md). * Delete node. For more information, see   [Deleting nodes](simacae-t-edthelpmesheditdeletenode.md). * Merge nodes. For more information, see   [Merging nodes](simacae-t-edthelpmesheditmerge.md). * Adjust midside nodes. For more information, see   [Adjusting the position of midside nodes](simacae-t-edthelpmesheditmidsidenode.md). * Smooth external nodes. For more information, see   [Smoothing external nodes](simacae-t-edthelpmesheditsmoothnodes.md). * Renumber nodes. For more information, see   [Renumbering nodes](simacae-t-edthelpmesheditrenumber.md).  Element editing tools  The following tools are available for editing elements:   * Create element. For more information, see   [Creating an element](simacae-t-edthelpmesheditcreateelement.md). * Delete element. For more information, see   [Deleting elements](simacae-t-edthelpmesheditdeleteelement.md). * Flip normal. For more information, see   [Reversing the surface normal direction of shell elements](simacae-t-edthelpmesheditflipnormal.md). * Orient stack direction. For more information, see   [Orienting the stack direction](simacae-t-edthelpmesheditorientstack.md). * Collapse edge. For more information, see   [Collapsing an edge of a quadrilateral or triangular element](simacae-t-edthelpmesheditcollapseedges.md). * Split edge. For more information, see   [Splitting an edge of a quadrilateral or triangular element](simacae-t-edthelpmesheditsplitedge.md). * Swap diagonal. For more information, see   [Swapping the diagonal of a pair of adjacent triangular elements](simacae-t-edthelpmesheditswapdiagonal.md). * Split. For more information, see   [Splitting quadrilateral elements](simacae-t-edthelpmesheditsplitquad.md). * Combine. For more information, see   [Combining triangular elements](simacae-t-edthelpmesheditcombinetris.md). * Renumber elements. For more information, see   [Renumbering elements](simacae-t-edthelpmesheditrenumberelements.md).  Mesh editing tools  The following tools are available for editing the entire mesh:   * Offset solid. For more information, see   [Generating layers of solid elements offset from an existing mesh](simacae-t-edthelpmesheditoffsetsolid.md). * Offset shell. For more information, see   [Generating layers of shell elements offset from an existing mesh](simacae-t-edthelpmesheditoffsetshell.md). * Wrap. For more information, see   [Wrapping a mesh about the Z-axis](simacae-c-edthelpmesheditwrap.md). * Collapse. For more information, see   [Collapsing short edges of a linear orphan mesh](simacae-t-edthelpmesheditrefineclean.md). * Grow. For more information, see   [Growing short edges of a linear orphan mesh](simacae-t-edthelpmesheditrefinegrow.md). * Convert. For more information, see   [Converting a triangular shell mesh to a solid tetrahedral mesh](simacae-t-edthelpmesheditrefinetritotet.md),   and   [Converting a solid orphan mesh to a shell orphan mesh](simacae-t-edthelpmesheditrefinesolidtoshell.md). * Merge. For more information, see   [Merging elements](simacae-t-edthelpmesheditrefinemerge.md). * Subdivide. For more information, see   [Subdividing elements](simacae-t-edthelpmesheditrefinesubdivide.md). * Copy mesh pattern. For more information, see   [Copying a mesh pattern](simacae-t-edthelpmesheditpattern.md). * View and edit mesh-geometry associativity. For more information, see   [Viewing and editing mesh-geometry associativity](simacae-t-edthelpmesheditassociate.md). * Delete mesh-geometry associativity. For more information, see   [Deleting mesh-geometry associativity](simacae-t-edthelpmesheditdeleteassoc.md). * Insert cohesive seams. For more information, see   [Inserting cohesive seams](simacae-t-edthelpmesheditcohesiveseam.md).  Mesh refinement tools  The following tools are available for refining the mesh:   * Set size. * Remove size. * Remesh.   For more information, see [Editing and refining an orphan mesh](simacae-t-edthelpmesheditremesh.md).  Undo and redo for mesh edits  You can undo and redo multiple changes that you make using the tools in the Edit Mesh toolset, and control the number of available undo levels. For more information, see [Undoing or redoing a change in the Edit Mesh toolset](simacae-m-EdtHelpUndo-sb.md). |
