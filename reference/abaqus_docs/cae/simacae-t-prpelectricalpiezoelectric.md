# Defining piezoelectric properties

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Defining piezoelectric properties | | |  | | | |  | | --- | | You can define piezoelectric material properties by providing the stress coefficients, em⁢i⁢jφ, or the strain coefficients, dm⁢k⁢lφ. For more information, see [Piezoelectric Behavior](.._SIMACAEMATRefMap_simamat-c-piezoelect.md). | | |   1. From the menu bar in the Edit Material dialog box, select Electrical/MagneticPiezoelectric. (For information on displaying the Edit Material dialog box, see [Creating or editing a material](simacae-t-prpmaterialcreate.md).) 2. Toggle on Use temperature-dependent data to define piezoelectric properties as a function of temperature. A column labeled Temp appears in the Data table. 3. Click the arrows to the right of the Number of field variables field to increase or decrease the number of field variables on which the piezoelectric properties depend. 4. In the Data table, enter the piezoelectric stress or strain coefficient matrix. For more information, see [Specifying Piezoelectric Material Properties](.._SIMACAEMATRefMap_simamat-c-piezoelect.md#simamat-c-piezoelect-coefficients). Enter values for temperature and field variables if applicable. For detailed information on how to enter data, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 5. Click OK to close the Edit Material dialog box. Alternatively, you can select another material behavior to define from the menus in the Edit Material dialog box (see [Browsing and modifying material behaviors](simacae-c-prpmaterialbrowser.md), for more information). |
