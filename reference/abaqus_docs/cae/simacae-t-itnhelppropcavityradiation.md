| |  |  | | --- | --- | | Defining a cavity radiation interaction property | | |  | | | |  | | --- | | You can define the emissivity of cavity surfaces as a function of temperature and field variables. A cavity radiation interaction property can be referred to only by a cavity radiation interaction. For more information, see [Defining a cavity radiation interaction](simacae-m-ItnHelpCavityrad-sb.md). | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Cavity Radiation in Abaqus/Standard](.._SIMACAEITNRefMap_simaitn-c-cavityradiation.md) | |   1. From the main menu bar, select InteractionPropertyCreate. 2. In the Create Interaction Property dialog box that appears, do the following: * Name the interaction property. For more information about naming objects, see [Using basic dialog box components](simacae-c-intdialogbasic.md).    * Select the Cavity radiation type of interaction property. 3. Click Continue to close the Create Interaction Property dialog box. 4. Toggle on Use temperature-dependent data to define a cavity radiation property that varies with temperature. A column labeled Temp appears in the data table. 5. To define a cavity radiation property that depends on field variables, click the arrows to the right of the Number of field variables field to increase or decrease the number of field variables. Field variable columns appear in the data table. 6. In the data table, enter the emissivity, ϵ, as a function of temperature and field variables. You can enter data into the table using the keyboard. Alternatively, you can click mouse button 3 anywhere in the table to view a list of options for specifying tabular data. For detailed information on each option, see [Entering tabular data](simacae-c-intdialogspreadsheet.md). 7. Click OK to create the cavity radiation interaction property and to exit the editor. |
