| |  |  | | --- | --- | | Configuring a general bead optimization task | | |  | | | |  | | --- | | A general bead optimization is a flexible, sensitivity-based optimization that allows you to apply a range of constraints and objective functions to your model. The sensitivity-based algorithm does not implement a bead filter; therefore, the optimization may not generate a distinct bead pattern. You use the optimization task editor to customize various aspects of a bead optimization. To locate the editor, select TaskEditoptimization task name from the main menu bar.
