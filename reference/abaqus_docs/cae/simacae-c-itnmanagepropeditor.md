Once you have specified this information, click Continue in the Create Interaction Property dialog box to display the interaction property editor. | | |  | | --- | | See Also | | [Managing objects](simacae-m-IntMgr-sb.md) | | [Understanding modified step-dependent objects](simacae-c-intstepmodify.md) | |   The format of the interaction property editor depends on the type of interaction property you are defining. For example, the film condition and actuator/sensor property editors display data fields in which you can enter all of the information necessary to define the property. The film condition property editor is shown in [Figure 1](simacae-c-itnmanagepropeditor.md#simacae-c-itnmanagepropeditor__simacae-c-itn-propeditor). Figure 1. The film condition property editor.    The format of the contact property editor, on the other hand, is identical to the material editor in the Property module (see [Creating materials](simacae-c-prpeditormaterial.md), for more information). Like the material editor, the contact property editor contains menus from which you select options to include in the property definition, as shown in [Figure 2](simacae-c-itnmanagepropeditor.md#simacae-c-itnmanagepropeditor__simacae-c-prp-mechpropeditor). Figure 2. The contact property editor contains Mechanical and Thermal option menus.    When you select an option from a menu, the name of the option appears in the Contact Property Options list at the top of the editor, and the option becomes part of your interaction property definition. In addition, the option definition area in the lower half of the editor changes to provide fields in which you can specify information for the currently selected option.  For example, the Contact Property Options list in [Figure 3](simacae-c-itnmanagepropeditor.md#simacae-c-itnmanagepropeditor__simacae-c-prp-propoptions) reflects that the Tangential Behavior and Normal Behavior options (located in the Mechanical menu) have been included in the property definition. Tangential Behavior is currently selected, and the related parameters appear in the lower half of the editor. A mechanical contact property definition that includes the Tangential Behavior and Normal Behavior options.    You can display help on a particular feature of the editor by selecting HelpOn Context from the main menu bar and then clicking the feature of interest. For detailed instructions on creating properties, see [Creating interaction properties](simacae-t-itnhelptopiccreateprop.md), and [Using the interaction property editors](simacae-m-ItnPropertyeditors-sb.md). |
