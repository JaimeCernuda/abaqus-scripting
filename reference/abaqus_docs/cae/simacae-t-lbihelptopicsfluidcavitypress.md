| |  |  | | --- | --- | | Defining a fluid cavity pressure field | | |  | | | |  | | --- | | You can define the initial fluid cavity pressure for fluid-filled cavities (see [About Surface-Based Fluid Cavities](.._SIMACAEANLRefMap_simaanl-c-surfacebasedcavityover.md)). You can create or modify a fluid cavity pressure field only during the initial step. For more information, see [Initial Conditions](.._SIMACAEPRCRefMap_simaprc-c-initialcond.md). To modify fluid cavity pressure in a step other than the initial step, you must define a fluid cavity pressure boundary condition (for more information, see [Defining a fluid cavity pressure boundary condition](simacae-t-lbibceditorsfluidcavitypressure.md)). | | |  | | --- | | See Also | | [Creating predefined fields](simacae-t-lbihelptopicscreatefield.md) | | [Using analytical expression fields](simacae-m-FldUsing-sb.md) | | [Creating expression fields](simacae-t-fldhelp.md) |  |  | | --- | |  | | In Other Guides | | [About Surface-Based Fluid Cavities](.._SIMACAEANLRefMap_simaanl-c-surfacebasedcavityover.md) | |   1. Display the fluid cavity pressure field editor using one of the following methods: * To create a new fluid cavity pressure field, follow the procedure outlined in [Creating predefined fields](simacae-t-lbihelptopicscreatefield.md) (Category: `Other`; Types for Selected Step: `Fluid cavity pressure`). You can create a fluid cavity pressure field only during the initial step.    * To edit an existing fluid cavity pressure field using menus or managers, see [Editing step-dependent objects](simacae-t-intstepeditmenu.md). You can modify a fluid cavity pressure field only during the initial step. 2. Click the arrow to the right of the Fluid cavity interaction field, and select the interaction to which the fluid cavity pressure applies. 3. Enter the Fluid cavity pressure. 4. Click OK to create the fluid cavity pressure field and to close the dialog box. A green diamond appears at the fluid cavity reference point representing the initial fluid cavity pressure field that you just created. |
