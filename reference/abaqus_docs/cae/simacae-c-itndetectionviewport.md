| |  |  | | --- | --- | | Confirming search results in the viewport | | |  | | | |  | | --- | | As a visual aid, toggle on Highlight in viewport to highlight specified entities on your model in the viewport. | | |  | | --- | | See Also | | [Understanding contact and constraint detection](simacae-m-ItnAutoDetection-sb.md) | | [Using contact and constraint detection](simacae-m-ItnDetectioneditor-sb.md) | |   Select the entities you want to highlight:  Selected pairs  Highlights the surfaces involved in the contact pair or pairs that are currently selected in the contact pair candidates table. The main surface is highlighted in red; the secondary surface is highlighted in magenta. For axisymmetric or spherical surfaces, Abaqus/CAE also displays the axis of symmetry or spherical center for the surface; the axis or center point is used in surface smoothing calculations if they are applied (see [Modifying contact pair definitions](simacae-t-itndetectionmodifications.md)).  Selected main surfaces  Highlights the assigned main surfaces in the contact pair or pairs that are currently selected in the contact pair candidates table. For axisymmetric or spherical surfaces, Abaqus/CAE also displays the axis of symmetry or spherical center for the surface; the axis or center point is used in surface smoothing calculations if they are applied (see [Modifying contact pair definitions](simacae-t-itndetectionmodifications.md)).  Selected secondary surfaces  Highlights the assigned secondary surfaces in the contact pair or pairs that are currently selected in the contact pair candidates table. For axisymmetric or spherical surfaces, Abaqus/CAE also displays the axis of symmetry or spherical center for the surface; the axis or center point is used in surface smoothing calculations if they are applied (see [Modifying contact pair definitions](simacae-t-itndetectionmodifications.md)).  Search domain  Highlights the part instances in the model specified by the current Search domain field (see [Specifying general search options for contact detection](simacae-t-itndetectionsearch.md)).  Selected pairs + search domain  Highlights both the currently selected contact pairs and the entire search domain. |
