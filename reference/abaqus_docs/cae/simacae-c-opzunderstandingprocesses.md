# About optimization processes

|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | About optimization processes | | |  | | | |  | | --- | | You create optimization processes in the Job module. An optimization process reads an optimization task that you defined in the Optimization module and iteratively searches for an optimized solution based on the objective functions and constraints that you defined in the optimization task. For more information, see [What is an optimization process?](simacae-c-anaoptwhatis.md). You can use a view cut in the Visualization module to view the results of an optimization process. For more information, see [Cutting through a model](simacae-m-Cut-sb.md). | | | |
