# Creating homogeneous solid sections

|  |  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | Creating homogeneous solid sections | | |  | | | |  | | --- | | Homogeneous solid sections are used to define the section properties of two-dimensional, three-dimensional, and axisymmetric solid regions. For more information, see [Solid (Continuum) Elements](.._SIMACAEELMRefMap_simaelm-c-solidcont.md). | | |   1. From the main menu bar, select SectionCreate. A Create Section dialog box appears.      |  |    | --- |    | Tip: You can also click Create in the Section Manager or select the create section tool  in the Property module toolbox. | 2. Enter a section name. For more information on naming objects, see [Using basic dialog box components](simacae-c-intdialogbasic.md). 3. Select Solid as the section Category and Homogeneous as the section Type, and click Continue. The solid section editor appears. 4. Select a material for the solid section. If desired, click  to create a material; see [Creating or editing a material](simacae-t-prpmaterialcreate.md), for more information. 5. Enter a value for the section Plane stress/strain thickness. If the section will be used with a two-dimensional region, you must specify the section thickness. Abaqus/CAE ignores the thickness information if it is not needed for the region type. 6. Click OK to save your changes and to close the solid section editor. |
