# Importing a part from an Abaqus input file

|  |  |  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Importing a part from an Abaqus input file | | |  | | | |  | | --- | | You can import parts defined in an Abaqus input file in the form of orphan mesh parts. Select FileImportPart from the main menu bar to import parts defined in an Abaqus input file. If the input file contains multiple parts, Abaqus/CAE imports each part as a separate orphan mesh part. Only the orphan mesh part information is imported; properties that are assigned to the parts, such as sections and materials, are not imported. | | |  | | --- | | See Also | | [Using file selection dialog boxes](simacae-c-intdialogselection.md) | | [Using the File menu](simacae-c-dbsfilepopmenu.md) | |   1. From the main menu bar, select    FileImportPart. The Import Part dialog box appears. 2. From the File Filter menu at the bottom of the    Import Part dialog box, select Abaqus    Input File (\*.inp). Abaqus/CAE    lists all the files in the selected directory with an .inp    file extension. 3. Select the input file containing the parts to import, and click    OK. Abaqus/CAE    enters the    Part module    and imports the parts. The parts appear in the    Model Tree    and in the model's list of parts in the context bar. |
