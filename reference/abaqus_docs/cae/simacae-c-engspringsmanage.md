| |  |  | | --- | --- | | Managing springs and dashpots | | |  | | | |  | | --- | | The Springs/Dashpots Manager allows you to create and manage springs and dashpots. The manager includes a list of the names and types of springs and dashpots that you have defined. The Create, Edit, Copy, Rename, and Delete buttons in the manager allow you to create new springs and dashpots or to edit, copy, rename, and delete existing ones. The icons in the column along the left side of the manager allow you to suppress and resume existing springs and dashpots. You can also initiate these procedures using the SpecialSprings/Dashpots menu from the main menu bar in the Property module or the Interaction module.
