| |  |  | | --- | --- | | Using Sketcher customization options | | |  | | | |  | | --- | | Use the Sketcher customization options to control the appearance and behavior of the Sketcher. | | |  | | --- | | See Also | | [Customizing the Sketcher](simacae-m-SkeCustomizing-sb.md) | | [How Sketcher customization options are initialized and saved](simacae-c-skecustom.md) | |   Context:  The following options control the behavior of the Sketcher throughout the Abaqus/CAE session:   * Whether the cursor   [snaps](simacae-t-skesnapgridbtn.md) to the grid. * Whether   [preselection](simacae-t-skepreselectbtn.md) is active. * Whether dimensions are displayed. * Whether names or values of parameters are displayed. * Limiting the number of coplanar entities that are projected. * The types of dimensions and constraints available for use with the   Auto-Dimension and Auto-Constrain   tools. * The   [constraint solution   method](simacae-t-skeconstraintsframe.md) for use while editing or dragging objects. * Whether   [sketch constraints](simacae-t-skeconstraintsframe.md)   are displayed. * Whether implied constraints are added during entity creation. * Whether   [construction geometry](simacae-t-skeshowconsbtn.md) is   displayed. * Whether a   [background image](simacae-t-skeimageframe.md) is   displayed.   The following options are stored with each sketch; they control the behavior and appearance of the current sketch and new sketches that you create:   * The sheet size, the   [grid](simacae-t-skegridtext.md) spacing, and the   number of gridlines to display. * Whether the sheet size and grid spacing are controlled automatically. * Whether the grid is   [visible](simacae-t-skegridtext.md). * The text font size and the number of decimal places displayed in   [sketch dimensions](simacae-t-skedimensionsframe.md).   The origin of the sketch grid and the alignment of the X-axis are also stored with each sketch. However, the grid origin and alignment settings control only the behavior and appearance of the current sketch; they are reset to their default values for any new sketch that you create.  1. From the bottom of the Sketcher toolbox, select the Sketcher    customization tool    . The Sketcher Options dialog box appears. 2. Set the desired customization options on each of the tabbed pages. For    detailed help, request context-sensitive help on individual items in the dialog    box. |  |    | --- |    | Tip: You can also click Defaults to revert all Sketcher options to their default settings. | 3. Click OK to apply your changes and to close the    Sketcher Options dialog box. |
