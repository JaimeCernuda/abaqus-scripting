| |  |  | | --- | --- | | Using structured meshing near concave boundaries | | |  | | | |  | | --- | | When you mesh a region using any meshing technique, the nodes on the boundary of the mesh are always located on the boundary of the geometric region. However, when Abaqus/CAE creates a mesh using the structured meshing technique, it is possible for nodes in the interior of the mesh to fall outside the region's geometry, which results in a distorted, invalid mesh. This problem typically occurs near concave boundaries. | | |   For example, the region in [Figure 1](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concaveseed) has five sides; therefore, when Abaqus/CAE meshes this region using the structured meshing technique, it applies the mesh pattern for a regular pentagon to the region. Figure 1. The mesh pattern for a regular pentagon is applied to the region.     However, if you seed the region so that the number of elements is reduced, as shown in [Figure 2](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concave), a distorted mesh results due to the concavity at the highly curved edge. Nodes from the interior of the mesh pattern (indicated by closed circles in [Figure 3](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concaveprop)) fall outside the region's geometry, while nodes on the boundary of the mesh (indicated by open circles in [Figure 3](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concaveprop)) remain on the boundary of the region's geometry. Figure 2. Seeds prescribing a coarser mesh.     When interior nodes fall outside the region's geometry, you can try the following techniques to improve the mesh:   * Change the mesh seeds and remesh. For example, the number of elements   along the highly curved edge in   [Figure 1](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concaveseed)   is greater than in   [Figure 3](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concaveprop). Figure 3. Nodes from the interior of the mesh fall outside the region's   geometry. * Partition the part instance into smaller, more regularly shaped regions.   For example, the model was partitioned into three regions in   [Figure 4](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concavepart). Figure 4. Partition the region. * Select a different meshing technique. This option is most useful for   two-dimensional regions, where you can switch from structured meshing to free   meshing and still retain quadrilateral elements in the mesh. (Three-dimensional   free meshing is limited to tetrahedral elements. For more information, see   [Free meshing](simacae-m-MgnConcFree-sb.md).)   [Figure 5](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concavefree)   shows the region meshed using the free meshing technique. Figure 5. Mesh the region using the free meshing technique.         The mesh in   [Figure 5](simacae-c-mgnconcmappedconcave.md#simacae-c-mgnconcmappedconcave__simacae-c-mgn-concavefree)   is not symmetric, which is typical of free meshes. |
