This page discusses:   * [Overview](#simaexc-c-nasdmig__overview_y4t_lfz_m1c) * [Command Summary](#simaexc-c-nasabaproc-t-cmdsummary1) * [Command Line Options](#simaexc-c-nasabaproc-t-commandlineopts1) | | |  | | --- | | See Also | | [About Execution Procedures](simaexc-c-overview.md) | | [Translating an Abaqus Input File to a Partial Nastran Bulk Data Text File](simaexc-c-tonasabaproc.md) |  |  | | --- | |  | | In Other Guides | | [Importing a model from a Nastran input file](.._SIMACAECAERefMap_simacae-c-impnastran.md) | |   Products Abaqus/Standard Abaqus/Explicit  Overview You can specify that the translator create a SIM file of matrix data in addition to a text input file. The matrix data can be translated to:  * a SIM file structured as if it were created   from a [MATRIX GENERATE](.._SIMACAEKEYRefMap_simakey-r-matrixgenerate.md#simakey-r-matrixgenerate) step in an   Abaqus input file or * a SIM file equivalent to that resulting from an   Abaqus analysis with a [SUBSTRUCTURE GENERATE](.._SIMACAEKEYRefMap_simakey-r-substructuregenerate.md#simakey-r-substructuregenerate)   step.    Command Summary abaqus fromnastran    job  job-name   input  input-file   dmig2sim { GENERIC SUBSTRUCTURE }  Command Line Options job  This option is used to specify the name of the Abaqus input file to be output by the translator. It is also the default name of the file containing the Nastran data. Diagnostics created by the translator will be written to a file named job-name.log.  input  This option is used to specify the name of the file containing the Nastran data if it is different from job-name.  dmig2sim  This option is used to write DMIG matrix data to a binary SIM file for further processing by Abaqus.  If dmig2sim=GENERIC, a SIM file with a generic matrix system equivalent to that produced by a [MATRIX GENERATE](.._SIMACAEKEYRefMap_simakey-r-matrixgenerate.md#simakey-r-matrixgenerate) step is created.  If dmig2sim=SUBSTRUCTURE, a SIM file with a substructure matrix system equivalent to that produced by a [SUBSTRUCTURE GENERATE](.._SIMACAEKEYRefMap_simakey-r-substructuregenerate.md#simakey-r-substructuregenerate) step is created. |
