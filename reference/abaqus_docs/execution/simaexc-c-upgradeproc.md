| |  |  | | --- | --- | | Output Database Upgrade Utility | | |  | | | |  | | --- | | The abaqus upgrade utility will convert an output database file from earlier releases of Abaqus to the current release. Output database files from Abaqus 6.1 or later can be upgraded. The abaqus upgrade utility will generate a log file (job-name.log) that contains error, warning, diagnostic, and informational messages. You should carefully review the conversion log file to ensure that changes made to the older release output database file are appropriate. If no conversions are necessary, a message will be issued to the log file as well as to the screen.
