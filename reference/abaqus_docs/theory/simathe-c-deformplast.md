| |  |  | | --- | --- | | Deformation plasticity | | |  | | | |  | | --- | | Abaqus/Standard provides the deformation plasticity theory for fully plastic analysis of ductile metals, usually under small-displacement conditions, for fracture mechanics applications. The model is based on the Ramberg-Osgood relationship. In this section the detailed constitutive model is defined. The procedure for obtaining fully plastic solutions generally consists of incremental loading until the response is fully plastic. There is no “unloading” criterion (to allow recovery of the initial elastic stiffness immediately after a strain reversal), so that the model is only useful as a plasticity model in cases of continuous flow. It is, in fact, a nonlinear elastic model; but at a limit state when all of a specimen or structure is responding plastically, this model is a useful equivalent representation of the plastic response because it has such a simple form.    One-dimensional model The basic one-dimensional model is  (1)E⁢ε=σ+α⁢(|σ|σ0)n-1⁢σ,  where σ is the stress, ε is the mechanical strain, E is Young's modulus (defined as the slope of the stress-strain curve at zero stress), α is the “yield” offset (in the sense that, when σ=σ0, ε=(1+α)⁢σ0/E), and n is the hardening exponent for the “plastic” (nonlinear) term: n>1.  The material behavior described by this model is nonlinear at all stress levels, but for commonly used values of the hardening exponent (n∼5 or more) the nonlinearity becomes significant only at stress magnitudes approaching or exceeding σ0.  Multiaxial generalization A linear “elastic” relation is used to generalize the first term of [Equation 1](simathe-c-deformplast.md#simathe-c-deformplast-t-OnedimensionalModel-sma-topic1__simathe-c-deformplast-eq1); the nonlinear term is generalized to multiaxial stress states through the use of the Mises stress potential and associated flow law, giving the multiaxial model  (2)E⁢ε=(1+ν)⁢S-(1-2⁢ν)⁢p⁢I+32⁢α⁢(qσ0)n-1⁢S,  where  ε  is the strain tensor,  σ  is the stress tensor,  p=-13⁢σ:I  is the equivalent hydrostatic stress,  q=32⁢S:S  is the Mises equivalent stress,  S=σ+p⁢I  is the stress deviator, and  ν  is Poisson's ratio.  The linear part of the behavior may be compressible or incompressible depending on the value of Poisson's ratio, but the nonlinear part of the behavior is incompressible (because the flow is normal to the Mises stress potential). Since the model will generally be used for cases when the deformation is dominated by plastic flow, the use of selectively reduced integration elements or “hybrid” (mixed formulation) elements is recommended with this material model (except in plane stress).  Strain energy density The model is often used to obtain fully plastic solutions for fracture mechanics when the J-integral is needed. For evaluation of the J-integral the strain energy density is required. This is  W=∫σ:d⁢ε.  From [Equation 2](simathe-c-deformplast.md#simathe-c-deformplast-t-MultiaxialGeneralization-sma-topic2__simathe-c-deformplast-eq2) this may be obtained as  W=1+ν3⁢E⁢q2+32⁢1-2⁢νE⁢p2+nn+1⁢αE⁢σ0n-1⁢qn+1.  Stress solution During an analysis at each integration point the latest estimate of the kinematic solution is provided to the constitutive routines, which must provide the corresponding stress tensor calculated for the material model being used. Since this material model is nonlinear, we solve for the stresses by using the methods described below.  The uniaxial case (the only nonzero stress component is one direct stress) In this case  (3)E⁢ε=σ+α⁢(qσ0)n-1⁢σ,  where now q=|σ|.  We solve [Equation 3](simathe-c-deformplast.md#simathe-c-deformplast-t-TheUniaxialCasetheOnlyNonzeroStressComponentIsOneDirectStress-sma-topic4__simathe-c-deformplast-eq3) for σ using Newton's method. Writing cσ as the correction to σ, the Newton equations for [Equation 3](simathe-c-deformplast.md#simathe-c-deformplast-t-TheUniaxialCasetheOnlyNonzeroStressComponentIsOneDirectStress-sma-topic4__simathe-c-deformplast-eq3) are  [1+n⁢α⁢(qσ0)n-1]⁢cσ=E⁢ε-σ-α⁢(qσ0)n-1⁢σ,  σ=σ+cσ.  As an initial guess we use σ=E⁢|ε| if E⁢|ε|≤σ0 and σ=±[E⁢|ε|⁢σ0n-1/α]1/n (with the sign chosen as the same sign as ε) if E⁢|ε|>σ0.  In this case the material stiffness matrix is  ∂⁡σ∂⁡ε=E1+n⁢α⁢(q/σ0)n-1.  All strain components defined by the kinematic solution When all strain components are defined kinematically (that is, all cases except uniaxial and plane stress), projecting [Equation 2](simathe-c-deformplast.md#simathe-c-deformplast-t-MultiaxialGeneralization-sma-topic2__simathe-c-deformplast-eq2) onto I gives  p=-E3⁢(1-2⁢ν)⁢I:ε,  a linear relationship for the volumetric behavior. Defining the deviatoric strain as  e=ε-13⁢I⁢I:ε  and using [Equation 2](simathe-c-deformplast.md#simathe-c-deformplast-t-MultiaxialGeneralization-sma-topic2__simathe-c-deformplast-eq2) we find  (4)E⁢e=(1+ν+32⁢α⁢(qσ0)n-1)⁢S.  Defining the equivalent deviatoric strain as  (5)e¯=23⁢e:e  and using [Equation 4](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq4) we obtain the scalar equation  (6)E⁢e¯=23⁢(1+ν)⁢q+α⁢(qσ0)n-1⁢q.  This equation is solved for q using Newton's method:  [23⁢(1+ν)+n⁢α⁢(qσ0)n-1]⁢cq=E⁢e¯-23⁢(1+ν)⁢q-α⁢(qσ0)n-1⁢q,  q=q+cq.  As for the uniaxial case we will use the starting guesses:  q=32⁢E1+ν⁢e¯        if        32⁢E1+ν⁢e¯≤σ0,  and  q=(σ0n-1⁢E⁢e¯α)1/n        if        32⁢E1+ν⁢e¯>σ0.  [Equation 6](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq6) can also be used to define  1+ν+32⁢α⁢(qσ0)n-1=32⁢E⁢e¯q,  so that [Equation 4](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq4) becomes  (7)S=23⁢qe¯⁢e.  Thus, once q is known, S is defined; and, hence, σ is known as  σ=S-p⁢I.  The material stiffness is defined as follows. From [Equation 7](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq7) we have  (8)∂⁡S=23⁢qe¯⁢[∂⁡e+(∂⁡qq-∂⁡e¯e¯)⁢e];  and [Equation 6](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq6) gives  ∂⁡q=E23⁢(1+ν)+n⁢α⁢(q/σ0)n-1⁢∂⁡e¯;  and from [Equation 5](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq5)  ∂⁡e¯=23⁢ee¯:∂⁡e.  Using these results, [Equation 8](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq8) becomes  ∂⁡S=23⁢qe¯⁢[ℑ-23⁢e¯⁢{1e¯-1e¯+(n-1)⁢α⁢(q/σ0)n-1⁢(q/E)}⁢e⁢e]:∂⁡e.  Now  ∂⁡σ=∂⁡S-∂⁡p⁢I,  ∂⁡p=-E3⁢(1-2⁢ν)⁢I:∂⁡ε,  and  ∂⁡e=(ℑ-13⁢I⁢I):∂⁡ε.  Combining these results, we obtain the material stiffness as  ∂⁡σ=[23⁢qe¯⁢(ℑ-23⁢e¯⁢{1e¯-1e¯+(n-1)⁢α⁢(q/σ0)n-1⁢(q/E)}⁢ee)+13⁢(E1-2⁢ν-23⁢qe¯)⁢II]:∂⁡ε.  Plane stress For this case we obtain a solution for σ assuming that the material is fully incompressible. We then use this solution as a starting guess for a Newton loop to find σ. Finally, we compute the corresponding material stiffness matrix.  Incompressible approximation:  In this case ν=1/2 and ε33=-(ε11+ε22), so that e¯ is known and [Equation 6](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq6) can be solved as before for q. [Equation 7](simathe-c-deformplast.md#simathe-c-deformplast-t-AllStrainComponentsDefinedByTheKinematicSolution-sma-topic5__simathe-c-deformplast-eq7) then defines S, and the plane stress constraint requires that σ33=0, so  p=S33=-23⁢qe¯⁢(ε11+ε22);  and, hence, we obtain the initial estimate of the solution  σ11=23⁢qe¯⁢(2⁢ε11+ε22);  σ22=23⁢qe¯⁢(ε11+2⁢ε22),  and  σ12=q3⁢e¯⁢γ12.  Newton solution for the actual stresses:  [Equation 2](simathe-c-deformplast.md#simathe-c-deformplast-t-MultiaxialGeneralization-sma-topic2__simathe-c-deformplast-eq2) defines the stresses, where, for this case,  p=-13⁢(σ11+σ22),  S=σ+p⁢I,  and  q=32⁢S:S.  Therefore, [Equation 2](simathe-c-deformplast.md#simathe-c-deformplast-t-MultiaxialGeneralization-sma-topic2__simathe-c-deformplast-eq2) becomes  (9)E⁢ε=(1+ν+32⁢α⁢(qσ0)n-1)⁢σ+3⁢(ν+12⁢α⁢(qσ0)n-1)⁢p⁢I.  These equations are solved using Newton's method:  [(1+ν+32⁢α⁢(qσ0)n-1)⁢ℑ+94⁢α⁢(n-1)⁢(qσ0)n-1⁢Sq⁢Sq-(ν+12⁢α⁢(qσ0)n-1)⁢I⁢I]:cσ  ​=E⁢ε-(1+ν+32⁢α⁢(qσ0)n-1)⁢σ-3⁢(ν+12⁢α⁢(qσ0)n-1)⁢p⁢I,  σ=σ+cσ.  The material stiffness is directly available from [Equation 9](simathe-c-deformplast.md#simathe-c-deformplast-t-PlaneStress-sma-topic6__simathe-c-deformplast-eq9) as  E⁢[(1+ν+32⁢α⁢(qσ0)n-1)⁢ℑ+94⁢α⁢(n-1)⁢(qσ0)n-1⁢Sq⁢Sq-(ν+12⁢α⁢(qσ0)n-1)⁢I⁢I]-1. |
