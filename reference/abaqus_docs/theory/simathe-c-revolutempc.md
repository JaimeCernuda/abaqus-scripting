| |  |  | | --- | --- | | Revolute joint | | |  | | | |  | | --- | | A revolute joint is a joint between two nodes in which the rotations of the nodes differ by a relative rotation about an axis that is fixed in and, therefore, rotates with the joint.  A simple example is a hinge. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [General Multi-Point Constraints](.._SIMACAECSTRefMap_simacst-c-mpc.md) | |   ProductsAbaqus/StandardAbaqus/Explicit  A revolute joint is implemented in Abaqus/Standard as a multi-point constraint, defining the total rotation of the constrained (“secondary”) node (the first node of the MPC),    C ⁢  (  ϕ S ) , as the total rotation of the “main node” (the second node of the MPC),    C ⁢  (  ϕ M ) , followed by the relative rotation    ϕ J , about the axis of the joint   a :  C⁢(ϕS)=C⁢(ϕJ⁢a)⋅C⁢(ϕM).  The joint axis,   a , also rotates with the rotation of the main node:  a=C⁢(ϕM)⋅a|0.  The angular velocity of the secondary node is  ϕ˙S=ϕ˙M+ϕ˙J⁢a,  and the virtual variations of the rotations are, likewise,  (1)δ⁢ϕS=δ⁢ϕM+δ⁢ϕJ⁢a.  Thus, the joint imposes three constraints (each component of the angular velocity of the secondary node is constrained) but introduces an additional degree of freedom in the form of the relative rotation    ϕ J . This means the joint provides a total of two constraints to the model if    ϕ J  is not prescribed and three constraints if it is.  The virtual work contribution of the three nodes of the joint is  MS⋅δ⁢ϕS+MM⋅δ⁢ϕM+MJ⁢δ⁢ϕJ=0,  where MS is the total moment at node S, MM is the total moment at node M, and MJ is the moment in the joint. Applying the constraints ([Equation 1](simathe-c-revolutempc.md#simathe-c-revolutempc__simathe-c-revolutempc-eq1)), this is  (MS+MM)⋅δ⁢ϕM+(MS⋅a+MJ)⁢δ⁢ϕJ=0.  If there are no further constraints associated with the nodes of the joint, δ⁢ϕM and δ⁢ϕJ are independent variations, so the constrained virtual work equation implies that  MS=-MM  and that  MJ=-MS⋅a=MM⋅a.  Because the revolute is implemented in this manner, the relative rotation in the joint ϕJ appears as a degree of freedom in the model (degree of freedom 6 at the third node of the MPC). Thus, a moment, MJ, can be applied in the joint by specifying its value as a concentrated load; ϕJ can be given a prescribed variation in time by specifying a boundary condition; or stiffness and/or damping can be associated with relative rotation of the joint by attaching a spring and/or dashpot to ground to this degree of freedom (a spring or dashpot to ground is used because the variable is a relative rotation). |
