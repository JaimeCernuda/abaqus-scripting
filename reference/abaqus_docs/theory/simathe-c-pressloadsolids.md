| |  |  | | --- | --- | | Pressure load stiffness | | |  | | | |  | | --- | | In geometrically nonlinear analysis pressure loads are applied on the deformed structure.  Hence, the equivalent nodal loads are dependent on the nodal displacements. This dependency leads to additional contributions to the Jacobian in the solution procedure used in Abaqus/Standard.  This page discusses:   * [Pressure load stiffness on a surface in three-dimensional space](#simathe-c-pressloadsolids-t-PressureLoadStiffnessOnASurfaceInThreedimensionalSpace-sma-topic1) * [Pressure load stiffness on a surface in two-dimensional space](#simathe-c-pressloadsolids-t-PressureLoadStiffnessOnASurfaceInTwodimensionalSpace-sma-topic2) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Distributed Loads](.._SIMACAEPRCRefMap_simaprc-c-loaddistributed.md) | |   ProductsAbaqus/Standard  The external virtual work is  δ⁢WE=∫Aδ⁢u⋅p⁢n⁢d⁢A,  where A is the surface on which the pressure is applied; n is the normal to this surface, pointing into the material; δ⁢u is the virtual displacement field; and p is the pressure magnitude.    Pressure load stiffness on a surface in three-dimensional space The expression n⁢d⁢A can be rewritten as follows:  n⁢d⁢A=∂⁡x∂⁡g×∂⁡x∂⁡h⁢d⁢g⁢d⁢h,  where x are the current coordinates of a point on the surface, and the surface parametric coordinates (g, h) are chosen to give the correct sign to n through the cross product. The external virtual work is then given by  δ⁢WE=∫g,hp⁢δ⁢u⋅∂⁡x∂⁡g×∂⁡x∂⁡h⁢d⁢g⁢d⁢h,  and the load stiffness matrix is obtained from  -d⁢δ⁢WE=-∫g,hp⁢δ⁢u⋅(∂⁡d⁢u∂⁡g×∂⁡x∂⁡h+∂⁡x∂⁡g×∂⁡d⁢u∂⁡h)⁢d⁢g⁢d⁢h,  where, for a solid, d⁢x=d⁢u.  Pressure load stiffness on a surface in two-dimensional space Now  n⁢d⁢A=k×∂⁡x∂⁡g⁢t⁢d⁢g,  where k=(0,0,1) is a unit vector out of the plane of the model, t is the thickness of the two-dimensional solid (which is assumed to be constant), and the surface parametric coordinate g is chosen to give the correct sign to n through the cross product. The external work is then given by  δ⁢WE=∫gp⁢δ⁢u⋅k×∂⁡x∂⁡g⁢t⁢d⁢g,  and the load stiffness matrix is obtained from  -d⁢δ⁢WE=-∫gp⁢δ⁢u⋅k×∂⁡d⁢u∂⁡g⁢t⁢d⁢g. |
