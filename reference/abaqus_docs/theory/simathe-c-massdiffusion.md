| |  |  | | --- | --- | | Mass diffusion analysis | | |  | | | |  | | --- | | Abaqus/Standard provides for the modeling of the transient or steady-state diffusion of one material through another. For example, Abaqus/Standard provides for the modeling of the diffusion of hydrogen through a metal ([Crank (1956)](simathe-c-references.md#simathe-c-references__simathe-c-ref-crank), [deGroot and Mazur (1962)](simathe-c-references.md#simathe-c-references__simathe-c-ref-degroot)). The governing equations are an extension of Fick's equations, to allow for nonuniform solubility of the diffusing substance in the base material. This means that when the mesh includes dissimilar materials that share nodes, the normalized concentration is continuous across the interface between the different materials. Since ϕ is the square root of the partial pressure of the diffusing phase, the partial pressure is the same on both sides of the interface; Sievert's law is assumed to hold at the interface.    Governing equations The diffusion problem is defined from the requirement of mass conservation for the diffusing phase:  (1)∫Vd⁢cd⁢t⁢d⁢V+∫Sn⋅J⁢d⁢S=0,  where V is any volume whose surface is S, n is the outward normal to S, J is the flux of concentration of the diffusing phase, and n⋅J is the flux of concentration leaving S.  Using the divergence theorem,  ∫V(d⁢cd⁢t+∂∂⁡x⋅J)⁢d⁢V=0.  Because the volume is arbitrary, this provides the pointwise equation  d⁢cd⁢t+∂∂⁡x⋅J=0.  The equivalent weak form is  ∫Vδ⁢ϕ⁢(d⁢cd⁢t+∂∂⁡x⋅J)⁢d⁢V=0,  where δ⁢ϕ is an arbitrary, suitably continuous, scalar field.  This statement can be rewritten as  ∫V[δ⁢ϕ⁢(d⁢cd⁢t)+∂∂⁡x⋅(δ⁢ϕ⁢J)-J⋅∂⁡δ⁢ϕ∂⁡x]⁢d⁢V=0.  Using the divergence theorem again yields  (2)∫V[δ⁢ϕ⁢(d⁢cd⁢t)-∂⁡δ⁢ϕ∂⁡x⋅J]⁢d⁢V+∫Sδ⁢ϕ⁢n⋅J⁢d⁢S=0.  Constitutive behavior The diffusion is assumed to be driven by the gradient of a chemical potential, which gives the general behavior  (3)J=-s⁢D⋅[∂⁡ϕ∂⁡x+κs⁢∂∂⁡x⁢(ln⁡(θ-θZ))+κp⁢∂⁡p∂⁡x],  where D⁢(c,θ,f) is the diffusivity; s⁢(θ,f) is the solubility; κs⁢(c,θ,f) is the “Soret effect” factor, providing diffusion because of the temperature gradient; θ is the temperature; θZ is the absolute zero on the temperature scale used; κp⁢(c,θ,f) is the pressure stress factor, providing diffusion driven by the gradient of the equivalent pressure stress, p⁢=def-trace⁢(σ)/3; and f are any predefined field variables.  An example of a particular form of this constitutive model is the assumption made for hydrogen diffusion in a metal:  J=-D⁢cR⁢(θ-θZ)⋅∂⁡μ∂⁡x,  with the chemical potential, μ, defined as  μ=μ0+R⁢(θ-θZ)⁢ln⁡ϕ+p⁢V¯H,  where μ0 is a fixed datum, R is the universal gas constant, and V¯H is the partial molar volume of hydrogen in the solid solution. This form is similar to that used by [Sofronis and McMeeking (1989)](simathe-c-references.md#simathe-c-references__simathe-c-ref-sofronis) and results in a constitutive expression of the form  J=-s⁢D⋅[∂ϕ∂x+ϕ⁢ln⁡ϕ⁢∂∂x⁢(ln⁡(θ-θZ))+ϕ⁢V¯HR⁢(θ-θZ)⁢∂p∂x].  To implement this particular form, data for κs and κp must be calculated from the equations  κs=ϕ⁢ln⁡ϕ    and    κp=ϕ⁢V¯HR⁢(θ-θZ).  Changing variables (c=ϕ⁢s) and introducing the constitutive assumption of [Equation 3](simathe-c-massdiffusion.md#simathe-c-massdiffusion-t-ConstitutiveBehavior-sma-topic2__simathe-c-massdiffusion-eq3) into [Equation 2](simathe-c-massdiffusion.md#simathe-c-massdiffusion-t-GoverningEquations-sma-topic1__simathe-c-massdiffusion-eq2) yields  (4)∫V[δ⁢ϕ⁢(s⁢d⁢ϕd⁢t+ϕ⁢d⁢sd⁢θ⁢d⁢θd⁢t)+∂⁡δ⁢ϕ∂⁡x⋅s⁢D⋅(∂⁡ϕ∂⁡x+κs(θ-θZ)⁢∂⁡θ∂⁡x+κp⁢∂⁡p∂⁡x)]⁢d⁢V=∫Sδ⁢ϕ⁢q⁢d⁢S,  where  q⁢=def-n⋅J  is the concentration flux entering the body across S.  Discretization and time integration Equilibrium in a finite element model is approximated by a finite set of equations through the introduction of appropriate interpolation functions. Discretized quantities are indicated by uppercase superscripts (for example, ϕN). The summation convention is adopted for the superscripts. These represent nodal variables, with nodes shared between adjacent elements and appropriate interpolation chosen to provide adequate continuity of the assumed variation. The interpolation is based on material coordinates Si, i=1, 2, 3.  The virtual normalized concentration field is interpolated by  δ⁢ϕ=NN⁢δ⁢ϕN,  where NN⁢(Si) are interpolation functions. Then, the discretized equations are written as  (5)∫V[NN⁢(s⁢d⁢ϕd⁢t+ϕ⁢d⁢sd⁢θ⁢d⁢θd⁢t)+∂⁡NN∂⁡x⋅s⁢D⋅(∂⁡ϕ∂⁡x+κs(θ-θZ)⁢∂⁡θ∂⁡x+κp⁢∂⁡p∂⁡x)]⁢d⁢V=∫SNN⁢q⁢d⁢S.  Time integration in transient problems utilizes the backward Euler method (the modified Crank-Nicholson operator). Adopting the convention that any quantity not explicitly associated with a point in time is taken at t+Δ⁢t, we can drop the subscript t+Δ⁢t and write the integrated equations as  (6)∫V[NN⁢(s⁢(ϕ-ϕt)Δ⁢t+ϕ⁢d⁢sd⁢θ⁢d⁢θd⁢t)+∂⁡NN∂⁡x⋅s⁢D⋅(∂⁡ϕ∂⁡x+κs(θ-θZ)⁢∂⁡θ∂⁡x+κp⁢∂⁡p∂⁡x)]⁢d⁢V=∫SNN⁢q⁢d⁢S.  Jacobian contribution The Jacobian contribution from the conservation equation is obtained from the variation of [Equation 6](simathe-c-massdiffusion.md#simathe-c-massdiffusion-t-DiscretizationAndTimeIntegration-sma-topic3__simathe-c-massdiffusion-eq6) with respect to ϕ at time t+Δ⁢t. This yields  ∫V[NN(sΔ⁢tdϕ+d⁢sd⁢θd⁢θd⁢tdϕ)+∂⁡NN∂⁡x⋅s∂⁡D∂⁡ϕ⋅(∂⁡ϕ∂⁡x+κs(θ-θZ)∂⁡θ∂⁡x+κp∂⁡p∂⁡x)dϕ  +∂⁡NN∂⁡x⋅sD⋅(∂⁡d⁢ϕ∂⁡x+1(θ-θZ)∂⁡θ∂⁡x∂⁡κs∂⁡ϕdϕ+∂⁡p∂⁡x∂⁡κp∂⁡ϕdϕ)]dV.  Rearranging and using the interpolation d⁢ϕ=NN⁢d⁢ϕN, we obtain  ∫V[(sΔ⁢t+d⁢sd⁢θd⁢θd⁢t)NNNM+∂⁡NN∂⁡x⋅sD⋅∂⁡NM∂⁡x  + s   ∂ ⁡   N  N  ∂ ⁡ x ⋅   {   ∂ ⁡ D  ∂ ⁡ ϕ ⋅ (   ∂ ⁡ ϕ  ∂ ⁡ x +     κ  s  (  θ -   θ  Z )   ∂ ⁡ θ  ∂ ⁡ x +   κ  p   ∂ ⁡ p  ∂ ⁡ x ) + D ⋅  (   1  (  θ -   θ  Z )   ∂ ⁡ θ  ∂ ⁡ x   ∂ ⁡   κ  s  ∂ ⁡ ϕ +   ∂ ⁡ p  ∂ ⁡ x   ∂ ⁡   κ  p  ∂ ⁡ ϕ ) }   N  M ] d V .  Inspecting the above equation, we observe that the Jacobian becomes unsymmetric whenever the diffusivity, D; the temperature-driven diffusion coefficient, κs; or the pressure-driven diffusion coefficient, κp, is defined as a function of concentration. |
