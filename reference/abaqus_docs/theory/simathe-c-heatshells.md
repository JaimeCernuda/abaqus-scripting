| |  |  | | --- | --- | | Shell heat conduction | | |  | | | |  | | --- | | This section describes the formulation used in the shell heat conduction elements in Abaqus/Standard. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Three-Dimensional Conventional Shell Element Library](.._SIMACAEELMRefMap_simaelm-r-shellgeneral.md) | |   ProductsAbaqus/Standard  The basis of the elements is a combination of piecewise quadratic interpolation of temperature through the thickness of the shell and either linear interpolation (in elements DS3 and DS4) or quadratic interpolation (in elements DS6 and DS8) on the reference surface of the shell. The isoparametric interpolation functions for the shell reference surface are identical in form to those used for the solid quadrilateral and triangular elements and can be found in [Solid isoparametric quadrilaterals and hexahedra](simathe-c-solidisoquadhex.md) and [Triangular, tetrahedral, and wedge elements](simathe-c-tritetwedge.md), respectively. Nodal temperature values are stored at a set of points through the thickness (points P below) at each node of the element (nodes N below). For the purpose of numerical integration of the finite element equations, a 2 × 2 Gauss integration scheme with a 2 × 2 nodal integration scheme for the internal energy and specific heat term is used for the quadrilateral element DS4 and a 3 × 3 Gauss integration scheme is used for the quadrilateral element DS8. Three- and six-point integration schemes are used for the triangular elements DS3 and DS6, respectively, the details of which can be found in [Triangular, tetrahedral, and wedge elements](simathe-c-tritetwedge.md).  Let (ϕ1,ϕ2) be material coordinates of a point in the reference surface of the shell, and let s3 measure position through the thickness of the shell so that -h/2-z0≤s3≤h/2-z⁢0, where h is the thickness of the shell, z0 is the offset of the reference surface from the midsurface as discussed in [Transverse shear stiffness in composite shells and offsets from the midsurface](simathe-c-transshearshells.md). The position of any point in the shell is given by  x=xo⁢(ϕ1,ϕ2)+s3⁢n⁢(ϕ1,ϕ2),  where  xo  is the position of a point in the reference surface, and  n  is the unit normal to the reference surface of the shell.  The temperature interpolation can be written as  (1)θ=NN⁢(ϕ1,ϕ2)⁢MP⁢(s3)⁢θ¯N⁢P,  where  MP⁢(s3)  is a piecewise parabolic interpolation,  NN⁢(ϕ1,ϕ2)  is an interpolator in the reference surface, and  θ¯N⁢P  are nodal temperature values (at node N, point P through the thickness).  The basic heat energy balance is [Equation 3](simathe-c-uncoupledheat.md#simathe-c-uncoupledheat-t-SpatialDiscretization-sma-topic4__simathe-c-uncoupledheat-eq3), with the approximate Jacobian matrix for the Newton method based on  ∫Vρ⁢δ⁢θ⁢d⁢U˙d⁢θt+Δ⁢t⁢d⁢θ⁢d⁢V+∫V∂⁡δ⁢θ∂⁡x⋅k⋅∂⁡d⁢θ∂⁡x⁢d⁢V-∫Sδ⁢θ⁢∂⁡q∂⁡θt+Δ⁢t⁢d⁢θ⁢d⁢S,  where d⁢θ is the correction to the temperature solution at time t+Δ⁢t. The derivation of this form is discussed in [Uncoupled heat transfer analysis](simathe-c-uncoupledheat.md). The form of these terms for shell heat conduction elements is obtained by introducing the interpolator, [Equation 1](simathe-c-heatshells.md#simathe-c-heatshells__simathe-c-heatshells-eq1), and neglecting the change in area, with respect to s3, of surfaces parallel to the reference surface.  The internal energy rate term (the first term in [Equation 3](simathe-c-uncoupledheat.md#simathe-c-uncoupledheat-t-SpatialDiscretization-sma-topic4__simathe-c-uncoupledheat-eq3)) contributes, to the residual,  ∫A[NN∫-h/2h/2MPρU˙t+Δ⁢tds3]dA,  and to the Jacobian,  ∫A[NN⁢∫-h/2h/2MP⁢ρ⁢d⁢U˙d⁢θt+Δ⁢t⁢MQ⁢d⁢s3]⁢NM⁢d⁢A.  For the second term the temperature derivatives are taken with respect to a local orthogonal system (s1,s2,s3), where s1 and s2 measure distance along local base vectors e1 and e2, in the reference surface of the shell, set up according to the standard convention in Abaqus for such local systems in shells. The term is formed by first introducing an intermediate set of temperature values,  ⌊θP, ∂⁡θP∂⁡s1,    ∂⁡θP∂⁡s2⌋,  corresponding to each temperature value point through the thickness, at each section where integration through the thickness is performed. Since the number of temperature values on the section is the same as the number of integration points, MP is unity in the appropriate locations and zero everywhere else. Then we can interpolate to the section by  {θP∂θP∂s1∂θP∂s2}={βM}⁢θ¯M⁢P,  where  {βM}={NM∂NM∂s1∂NM∂s2}.  The piecewise quadratic interpolation through the thickness then gives  {∂⁡θ∂⁡s1∂⁡θ∂⁡s2∂⁡θ∂⁡s3}=[γP]⁢{θP∂⁡θP∂⁡s1∂⁡θP∂⁡s2},  where  [γP]=[0MP000MPd⁢MP/d⁢s300].  The conductivity term in the Jacobian then is  ∫A⌊βN⌋⁢[∫-h/2h/2[γP]T⁢[k]⁢[γQ]⁢d⁢s3]⁢{βM}⁢d⁢A,  where [k] is the local conductivity matrix and the same term multiplied by θt+Δ⁢tM⁢Q appears in the residual.  Finally, the external flux terms contribute  ∫ANN⁢∫-h/2h/2MP⁢r⁢d⁢s3⁢d⁢A+∫ANN⁢[IA⁢qA+IB⁢qB]⁢d⁢A  to the residual and  ∫ANN⁢[IA⁢d⁢qd⁢θ|t+Δ⁢t,A+IB⁢d⁢qd⁢θ|t+Δ⁢t,B]⁢NM⁢d⁢A  to the Jacobian, where  IA=1  at point A through the thickness  IA=0  at all other points through the thickness,  and points A and B are on the top and bottom surfaces of the shell. |
