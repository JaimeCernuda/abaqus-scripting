Figure 1. Typical unstable static response.    It is assumed that the loading is proportional—that is, that all load magnitudes vary with a single scalar parameter. In addition, we assume that the response is reasonably smooth—that sudden bifurcations do not occur. Several methods have been proposed and applied to such problems. Of these, the most successful seems to be the modified Riks method—see, for example, [Crisfield (1981)](simathe-c-references.md#simathe-c-references__simathe-c-ref-crisfield-1981), [Ramm (1981)](simathe-c-references.md#simathe-c-references__simathe-c-ref-ramm), and [Powell and Simons (1981)](simathe-c-references.md#simathe-c-references__simathe-c-ref-powell)—and a version of this method has been implemented in Abaqus. The essence of the method is that the solution is viewed as the discovery of a single equilibrium path in a space defined by the nodal variables and the loading parameter. Development of the solution requires that we traverse this path as far as required. The basic algorithm remains the Newton method; therefore, at any time there will be a finite radius of convergence. Further, many of the materials (and possibly loadings) of interest will have path-dependent response. For these reasons, it is essential to limit the increment size. In the modified Riks algorithm, as it is implemented in Abaqus, the increment size is limited by moving a given distance (determined by the standard, convergence rate-dependent, automatic incrementation algorithm for static case in Abaqus/Standard) along the tangent line to the current solution point and then searching for equilibrium in the plane that passes through the point thus obtained and that is orthogonal to the same tangent line. Here the geometry referred to is the space of displacements, rotations, and the load parameter mentioned above.    Basic variable definitions Let PN    (N=1,2,… = the degrees of freedom of the model) be the loading pattern, as defined with one or more of the loading options in Abaqus. Let λ be the load magnitude parameter, so at any time the actual load state is λ⁢PN, and let uN be the displacements at that time.  The solution space is scaled to make the dimensions approximately the same magnitude on each axis. In Abaqus this is done by measuring the maximum absolute value of all displacement variables, u¯, in the initial (linear) iteration. We also define P¯=(PN⁢PN)12. The scaled space is then spanned by   * load =λP~N,P~N=PN/P¯, * displacements =u~N=(uN/u¯);   and the solution path is then the continuous set of equilibrium points described by the vector (u~N;    λ) in this scaled space. All components of this vector will be of order unity. Modified Riks algorithm.    Suppose the solution has been developed to the point Ao=(u~oN;λo). The tangent stiffness, KoN⁢M, is formed, and we solve  KoN⁢M⁢voM=PN.  The increment size (Ao to A1 in [Figure 2](simathe-c-modifiedriks.md#simathe-c-modifiedriks-t-BasicVariableDefinitions-sma-topic1__simathe-c-stmmodified-riks-alg)) is chosen from a specified path length, Δ⁢l, in the solution space, so that  Δ⁢λo2⁢(v~oN; 1):(v~oN; 1)=Δ⁢l2,  and, hence,  Δ⁢λo=±Δ⁢l(v~oN⁢v~oN+1)12  (here v~oN is voN scaled by u¯). The value Δ⁢l is initially suggested by the user and is adjusted by the Abaqus/Standard automatic load incrementation algorithm for static problems, based on the convergence rate. The sign of Δ⁢λo—the direction of response along the tangent line—is chosen so that the dot product of Δ⁢λo⁢(v~oN; 1) on the solution to the previous increment, (Δ⁢u~-1N; Δ⁢λ-1), is positive:  Δ⁢λo⁢(v~oN; 1):(Δ⁢u~-1N;    Δ⁢λ-1)>0,  that is  Δ⁢λo⁢(v~oN⁢Δ⁢u~-1N+Δ⁢λ-1)>0.  It is possible that in some cases, where the response shows very high curvature in the (u~N;λ) space, this criterion will cause the wrong sign to be chosen—see, for example, [Figure 3](simathe-c-modifiedriks.md#simathe-c-modifiedriks-t-BasicVariableDefinitions-sma-topic1__simathe-c-stmincorrect-dlambda). Figure 3. Example of incorrect choice of sign for Δ⁢λ.    The wrong sign is rarely chosen in practical cases, unless the increment size is too large or the solution bifurcates sharply. To check for such cases is computationally expensive: one approach would be for the solution to be found at λo-ε⁢Δ⁢λ-1, 0<ε≪1, so that we obtain a vector that gives a close approximation of the directed tangent at Ao. Because the case is so rare, such a check is not included, and the simple dot product given above is used alone to determine the sign of Δ⁢λo. Thus, we have now found the point A1⁢(u~oN+Δ⁢λo⁢v~oN;λo+Δ⁢λo) in [Figure 2](simathe-c-modifiedriks.md#simathe-c-modifiedriks-t-BasicVariableDefinitions-sma-topic1__simathe-c-stmmodified-riks-alg). Form IN,    KN⁢M, the internal (stress) forces at the nodes,  IN=∫VβN:σ⁢d⁢V, and ⁢KN⁢M=∂⁡IN∂⁡uM,  at the state (uoN+Δ⁢uiN;    λo+Δ⁢λi)—that is, at Ai in [Figure 2](simathe-c-modifiedriks.md#simathe-c-modifiedriks-t-BasicVariableDefinitions-sma-topic1__simathe-c-stmmodified-riks-alg).   2. Check equilibrium:  RiN=(λo+Δ⁢λi)⁢PN-IN.  If all the entries in RiN are sufficiently small, the increment has converged. If not, we proceed.   3. Solve:  KN⁢M⁢{viM;ciM}={PN;RiN}.  That is, we solve simultaneously with two load vectors, PN and RN, and obtain two displacement vectors, viN and ciN.   4. Now scale the vector (v~iN;1), and add it to (c~iN;ρi) where ρi=RiN⁢PN/P¯2 is the projection of the scaled residuals onto P~N so that we move from Ai to Ai+1 in the plane orthogonal to (v~oN;1)—see [Figure 2](simathe-c-modifiedriks.md#simathe-c-modifiedriks-t-BasicVariableDefinitions-sma-topic1__simathe-c-stmmodified-riks-alg). This gives the equation  {(0;-ρi)+(c~iN;ρi)+μ⁢(v~iN;1)}:(v~oN;1)=0,  which simplifies to give  μ=-c~iN⁢v~oNv~iN⁢v~oN+1,  and the solution point is now Ai:  (uoN+Δ⁢uiN+ciN+μ⁢viN;λo+Δ⁢λi+μ).   5. Update for the next iteration,  Δ⁢ui+1N​=Δ⁢uiN+ciN+μ⁢viNΔ⁢λi+1​=Δ⁢λi+μi​=i+1,  and return to (a) above for the next iteration.   The implementation in Abaqus/Standard includes the additional update after each iteration:  voN=viN.  This causes the equilibrium search to be orthogonal to the last tangent, rather than to the tangent at the beginning of the increment. The main motivation for this additional modification comes from the use of the method in plasticity problems, where the first iteration of each increment uses the elastic material stiffness to establish the direction of straining and so provides a stiffness that is not representative of the tangent to the equilibrium path if active plasticity is occurring.  The total path length traversed is determined by the load magnitudes supplied by the user on the loading options; while the number of increments is determined by the user-specified time increment data, assisted by Abaqus/Standard's automatic incrementation scheme if that is chosen. |
