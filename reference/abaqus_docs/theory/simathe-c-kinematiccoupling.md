| |  |  | | --- | --- | | Kinematic coupling | | |  | | | |  | | --- | | A kinematic coupling constrains a group of secondary nodes to the translation and rotation of a main node in a customized manner; combinations of secondary node degrees of freedom are selected to participate in the constraint.  Since each secondary node has a separate relationship with the main node, the kinematic coupling constraint can be considered as the combination of general main-secondary constraints. These general constraints are described below. Each of these combinations is treated according to the appropriate theory employed in Abaqus/Standard. To implement these constraints, an additional node is created internally for each secondary node. For example, for revolute and universal constraints this additional node is used in a similar manner to the nodes required in the specification of the analog MPC types.  Translations The additional internal node, described above, also reflects the motion of the secondary node, relative to that of a fully constrained secondary node in the following manner. Let    X m  be the position of the main node and    X s  be the position of the secondary node in the reference configuration. The reference configuration position of the secondary node with respect to the main node is then  N=Xs-Xm.  Then, in the current configuration  x^s=xm+n,  where     x ^ s  is the fully constrained secondary node position and  n=C⁢(ϕm)⋅N,  where    C ⁢  (  ϕ m )  is the rotation matrix associated with the main node rotation,    ϕ m . The selectively constrained secondary node position can be described as  (1)xs=x^s+yi⁢ei,  where yi are the translation degrees of freedom at the additional node and ei are the current configuration base vectors, which rotate from the reference global Cartesian base vectors ei according to  ei=C⁢(ϕm)⋅ei.  This base vector rotation is made regardless of the choice of rotation constraint at the secondary node. Constraint or release of secondary node translation degree of freedom i can now be described as the constraint (    y i = 0 ) or release of translation degrees of freedom on the additional node. With these constraints on    y i , [Equation 1](simathe-c-kinematiccoupling.md#simathe-c-kinematiccoupling-t-Translations-sma-topic2__simathe-c-kinematiccoupling-eq1) can be used to define the constraint equations.
