| |  |  | | --- | --- | | Axisymmetric shell element allowing asymmetric loading | | |  | | | |  | | --- | | The Abaqus/Standard element library includes a family of nonlinear thin shell elements with axisymmetric reference geometry that allow asymmetric loading and deformation (SAXA1N and SAXA2N). This section provides their theoretical formulation. These elements encompass a broad range of practical applications from the bending/ovalization of variable diameter pipes to the bending of circular plates. The theoretical formulation of these elements is similar to the general finite-strain shell element described in [Finite-strain shell element formulation](simathe-c-finitestrainshells.md). Furthermore, this formulation is the shell counterpart to the continuum axisymmetric bending elements described in [Axisymmetric elements allowing nonlinear bending](simathe-c-axinonlinbend.md). Hence in-plane bending of the model is permitted, while deformations such as torsion about the axis of symmetry are precluded. The symmetries of the undeformed configuration and of the deformation are exploited through the assumption of particular displacement and rotation interpolations around the circumference of the shell. Specifically, Fourier series expansions are used in the θ or circumferential direction that preserve the plane of symmetry.    Geometric description Let (S,θ) be coordinate functions parametrizing the reference surface of the shell and let S3∈[-h/2,h/2] be the coordinate function in the thickness direction, where h is the shell's initial thickness. (For a detailed account of the geometric description of the finite-strain shell formulation, see [Finite-strain shell element formulation](simathe-c-finitestrainshells.md).) Then points in the reference or undeformed configuration are identified by the normal coordinates mapping  X⁢(S,θ,S3)=X¯⁢(S,θ)+S3⁢T3⁢(S,θ),  where X is the three-dimensional position of a material point, X¯ is the shell reference surface mapping, and T3 is the unit normal to the shell reference surface. The fact that T3 is a unit vector assumes that the reference configuration is (locally) of constant thickness. Owing to the axisymmetric reference configuration, X¯ can be given relative to a global Cartesian coordinate system as  X¯⁢(S,θ)={X1⁢(S,θ)X2⁢(S,θ)X3⁢(S,θ)}={r⁢(S)⁢cos⁡θr⁢(S)⁢sin⁡θz⁢(S)},  where r⁢(S) is the radius, z⁢(S) is the axial position, and (r,z,θ) are the cylindrical coordinates. (Note that the usual convention for cylindrical coordinates (r,θ,z) has been changed, which is consistent with the axisymmetric shell elements and the axisymmetric elements allowing nonlinear bending.) By definition the normal field to the shell reference surface is T3=X¯,S×X¯,θ/∥X¯,S×X¯,θ∥, which by direct computation yields  T3=1[(r′)2+(z′)2]12⁢{-z′⁢cos⁡θ-z′⁢sin⁡θr′}⁢     with    ∥X¯,S×X¯,θ∥=r⁢[(r′)2+(z′)2]12,  where r′=∂⁡r/∂⁡S and z′=∂⁡z/∂⁡S. Relative to the cylindrical coordinate system, T3=[(r′)2+(z′)2]-12⁢(-z′⁢er+r′⁢ez).  The basic kinematic assumption is that for any deformed configuration, the position of a point in the body can be identified by  (1)x⁢(S,θ,S3)=x¯⁢(S,θ)+S3⁢f¯33⁢(S,θ)⁢t3⁢(S,θ),  where x is the deformed position of the material point, x¯ is the deformed shell reference surface mapping, t3 is the deformed unit director field, and f¯33 is the thickness change parameter. Of critical importance for any shell formulation is the treatment of the rotation field; that is, the treatment of the director field t3. The geometric description and the incremental update procedure for the director field are given in detail below.  Under the kinematic assumption above, the deformed configuration of the shell is completely determined by the reference surface mapping x¯, the deformed director field t3 and the thickness parameter f¯33.  We define the following displacement quantities. Since x¯ is an element of a (linear) vector space, we can define the reference surface displacement vector u by the difference between the deformed reference surface and the undeformed reference surface; i.e.,  u⁢(S,θ)=x¯⁢(S,θ)-X¯⁢(S,θ).  The director field, however, is a unit vector field that is not a member of a linear vector space. The orientation of the director field is defined in terms of a rotation vector ϕ as  t3⁢(S,θ)=exp⁡[ϕ^⁢(S,θ)]⋅T3⁢(S,θ).  Here ϕ^ is the skew-symmetric matrix with axial vector ϕ, defined by the properties  ϕ^⋅ϕ=0⁢   and⁢    ϕ^⋅v=ϕ×v⁢ for all vectors  v  and exp⁡[ϕ^] is an orthogonal transformation given by the closed-form expression  exp⁡[ϕ^]=cos⁡∥ϕ∥⁢I+sin⁡∥ϕ∥∥ϕ∥⁢ϕ^+(1-cos⁡∥ϕ∥)∥ϕ∥2⁢ϕ⁢ϕ.  Alternatively, quaternion algebra can be used to specify the orientation of the deformed director field t3. In this case the orthogonal matrix exp⁡[ϕ^] is replaced by the quaternion parameter q=(q0,q), where  q0=cos⁡∥ϕ/2∥    and    q=sin⁡∥ϕ/2∥∥ϕ∥⁢ϕ.  The orientation of the unit director field then follows as  t3=(2⁢q02-1)⁢T3+2⁢q0⁢q×T3+2⁢(q⋅T3)⁢q.  Similarly, the orthogonal transformation exp⁡[ϕ^] can be extracted from the quaternion parameter as  exp⁡[ϕ^]=(2⁢q02-1)⁢I+2⁢q0⁢q^+2⁢qq.  Interpolations Displacement and rotation components are given relative to the cylindrical coordinate system (r,z,θ) with orthonormal basis vectors {er,ez,eθ} that are fixed in the reference or undeformed configuration. A general interpolation scheme for u=ur⁢er+uz⁢ez+uθ⁢eθ and ϕ=ϕr⁢er+ϕz⁢ez+ϕθ⁢eθ using a Fourier expansion in the θ variable is  ui⁢(S,θ)​=∑m=1MHm⁢(S)⁢(uim⁢0+∑p=1P(cos⁡(p⁢θ)⁢ui⁢cm⁢p+sin⁡(p⁢θ)⁢ui⁢sm⁢p))ϕi⁢(S,θ)​=∑m=1MHm⁢(S)⁢(ϕim⁢0+∑p=1P(cos⁡(p⁢θ)⁢ϕi⁢cm⁢p+sin⁡(p⁢θ)⁢ϕi⁢sm⁢p))}    (i=r,z,θ).  Here Hm⁢(S) are the polynomial interpolation functions along the generator lines of the axisymmetric reference configuration; uim⁢0, ui⁢cm⁢p, ui⁢sm⁢p, ϕim⁢0, ϕi⁢cm⁢p, ϕi⁢sm⁢p are the solution amplitude values (Fourier coefficients); M is the number of terms used in the interpolation along the generator lines; and P is the number of Fourier interpolation terms used around the circumference of the reference shell. Note that an axisymmetric deformation is obtained for the choice P=0.  The symmetry requirement in the r–z plane at θ=2⁢n⁢π, n=0,1,…, eliminates many of the above Fourier coefficients. For the displacement vector the only admissible terms are  {ur⁢(S,θ)uz⁢(S,θ)uθ⁢(S,θ)}=∑m=1MHm⁢(S)⁢({urm⁢0uzm⁢00}+∑p=1Pcos⁡(p⁢θ)⁢{ur⁢cm⁢puz⁢cm⁢p0}+∑p=1Psin⁡(p⁢θ)⁢{00uθ⁢sm⁢p}).  For the rotation components, symmetry requirements switch the role of the r and z components with the θ components:  {ϕr⁢(S,θ)ϕz⁢(S,θ)ϕθ⁢(S,θ)}=∑m=1MHm⁢(S)⁢({00ϕθm⁢0}+∑p=1Pcos⁡(p⁢θ)⁢{00ϕθ⁢cm⁢p}+∑p=1Psin⁡(p⁢θ)⁢{ϕr⁢sm⁢pϕz⁢sm⁢p0}).  For practical reasons the values of ur, uz, and ϕθ are often required at specific locations around the circumference of the shell. Therefore, displacement and rotation components urm⁢p, uzm⁢p, and ϕθm⁢p are used instead of the Fourier coefficients ur⁢cm⁢p, uz⁢cm⁢p, and ϕθ⁢cm⁢p. Furthermore, a negative sign is introduced in the interpolation for ϕθ for the following reason: The Abaqus convention for axisymmetric shell elements is that the axial tangent direction is drawn between nodes in ascending node number (the shell local 1-direction). The normal to the shell is then obtained by a 90° counter-clockwise rotation of the tangent (the shell local 3-direction). However, a positive rotation of the normal field (about the shell local 2-direction) is counterclockwise. This convention implies a left-handed shell local coordinate system. For the axisymmetric shell bending elements, a right-handed shell local coordinate system is required at the integration points; thus, the direction of positive rotation is reversed there.  Rearranging the Fourier series expansions and making the substitution uθ⁢sm⁢p↦uθm⁢p, the interpolations for the displacement components are  (2){ur⁢(S,θ)uz⁢(S,θ)uθ⁢(S,θ)}=∑m=1MHm⁢(S)⁢(∑p=1P+1Rp⁢(θ)⁢{urm⁢puzm⁢p0}+∑p=1Psin⁡(p⁢θ)⁢{00uθm⁢p}).  Similarly, replacing ϕr⁢sm⁢p and ϕz⁢sm⁢p with ϕrm⁢p and ϕzm⁢p respectively, the interpolation for the rotation components becomes  (3){ϕr⁢(S,θ)ϕz⁢(S,θ)ϕθ⁢(S,θ)}=∑m=1MHm⁢(S)⁢(∑p=1P+1Rp⁢(θ)⁢{00-ϕθm⁢p}+∑p=1Psin⁡(p⁢θ)⁢{ϕrm⁢pϕzm⁢p0}).  In the above interpolations, urm⁢p, uzm⁢p, and ϕθm⁢p are physical displacement and rotation components at θp=π⁢(p-1)/P and Rp⁢(θ) are trigonometric interpolation functions with the property that Rp(θq)={1,    p=q0,    p≠q defined by:  P=1: θ1=0, θ2=π,  R1⁢(θ)​=12⁢(1+cos⁡θ)R2⁢(θ)​=12⁢(1-cos⁡θ)  P=2: θ1=0, θ2=π/2, θ3=π,  R1⁢(θ)​=14⁢(1+2⁢cos⁡θ+cos⁡2⁢θ)R2⁢(θ)​=12⁢(1-cos⁡2⁢θ)R3⁢(θ)​=14⁢(1-2⁢cos⁡θ+cos⁡2⁢θ)  P=3: θ1=0, θ2=π/3, θ3=2⁢π/3, θ4=π,  R1⁢(θ)​=16⁢(1+2⁢cos⁡θ+2⁢cos⁡2⁢θ+cos⁡3⁢θ)R2⁢(θ)​=13⁢(1+cos⁡θ-cos⁡2⁢θ-cos⁡3⁢θ)R3⁢(θ)​=13⁢(1-cos⁡θ-cos⁡2⁢θ+cos⁡3⁢θ)R4⁢(θ)​=16⁢(1-2⁢cos⁡θ+2⁢cos⁡2⁢θ-cos⁡3⁢θ)  P=4: θ1=0, θ2=π/4, θ3=π/2, θ4=3⁢π/4, θ5=π,  R1⁢(θ)​=18⁢(1+2⁢cos⁡θ+2⁢cos⁡2⁢θ+2⁢cos⁡3⁢θ+cos⁡4⁢θ)R2⁢(θ)​=14⁢(1+2⁢cos⁡θ-2⁢cos⁡3⁢θ-cos⁡4⁢θ)R3⁢(θ)​=14⁢(1-2⁢cos⁡2⁢θ+cos⁡4⁢θ)R4⁢(θ)​=14⁢(1-2⁢cos⁡θ+2⁢cos⁡3⁢θ-cos⁡4⁢θ)R5⁢(θ)​=18⁢(1-2⁢cos⁡θ+2⁢cos⁡2⁢θ-2⁢cos⁡3⁢θ+cos⁡4⁢θ)  As with the continuum axisymmetric bending element, P=4 is the highest-order interpolation offered with respect to θ. The element becomes significantly more expensive as higher-order interpolations are used, and it is assumed that the general-purpose finite-strain shell is less expensive than using this element with P>4.  Virtual work The virtual work expression from the three-dimensional theory is  δ⁢Π=∫Vσi⁢j⁢δ⁢Ei⁢j⁢d⁢V,  where V is the current volume of the deformed body, σi⁢j are the curvilinear components of the Cauchy stress tensor, Ei⁢j are the components of the Lagrange strain tensor, and δ⁢Ei⁢j are the variational or linearized strain measure components. By definition the Lagrange strain tensor components are given by  Ei⁢j⁢=def⁢12⁢(∂⁡x∂⁡ξi⋅∂⁡x∂⁡ξj-∂⁡X∂⁡ξi⋅∂⁡X∂⁡ξj).  Note that in the statement of virtual work, no choice has thus far been made regarding the curvilinear coordinate functions ξi(i=1,2,3). Furthermore, the current volume measure d⁢V is given by the parametric relationship  d⁢V=j⁢d⁢ξ1⁢d⁢ξ2⁢d⁢ξ3,    where    j⁢=def⁢det⁡[∇⁡x]=∂⁡x∂⁡ξ1×∂⁡x∂⁡ξ2⋅∂⁡x∂⁡ξ3.  We now introduce the kinematic assumption [Equation 1](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-GeometricDescription-sma-topic1__simathe-c-axiasymmshells-eq1) into the definition of Ei⁢j to find  Eα⁢β=12(x¯,α⋅x¯,β-X¯,α⋅X¯,β)+12S3[x¯,α⋅(f¯33t3),β+x¯,β⋅(f¯33t3),α-X¯,α⋅T3,β-X¯,β⋅T3,α]+12(S3)​2[(f¯33t3),α⋅(f¯33t3),β-T3,α⋅T3,β],E3⁢α​=12⁢(f¯33⁢x¯,α⋅t3+S3⁢f¯33⁢f¯33,α),E33​=12⁢[(f¯33)2-1],  where differentiation is now with respect to the parametric coordinates, so that α,β∈{S,θ} and 3=S3. Define the following shell strain measure components and kinematic relationships:  ϵα⁢β=def⁢12⁢(x¯,α⋅x¯,β-X¯,α⋅X¯,β)κα⁢β=def⁢12⁢(x¯,α⋅t3,β+x¯,β⋅t3,α)-bα⁢β0γα=def⁢x¯,α⋅t3μ=def⁢ln⁡(f¯33)    membrane strain,bending strain,transverse shear,logarithmic stretch.  In the above, bα⁢β0⁢=def⁢X¯,α⋅T3,β=bβ⁢α0 are the components of the second fundamental form of the undeformed reference surface.  Substituting the above definitions into the virtual work expression, we find (after some manipulation) that the volume integral reduces to the following integral over the deformed reference surface  δ⁢Π=∫A[Nα⁢β⁢δ⁢ϵα⁢β+Mα⁢β⁢δ⁢κα⁢β+Qα⁢δ⁢γα+L3⁢δ⁢μ+M3⁢α⁢(δ⁢μ),α]⁢j¯⁢d⁢S⁢d⁢θ,  where δ⁢μ=δ⁢f¯33/f¯33 and the current reference surface Jacobian determinant is j¯=∥x¯,1×x¯,2∥. In the above virtual work expression, the (S3)2 term in Eα⁢β has been neglected. This term is O⁢(h2/R2)—where h is the thickness and R is some characteristic radius of curvature—and is negligible in light of the kinematic assumption [Equation 1](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-GeometricDescription-sma-topic1__simathe-c-axiasymmshells-eq1). The shell stress resultant components are defined by the following integrals through the thickness of the shell:  Nα⁢β​=1j¯⁢∫hσα⁢β⁢j⁢d⁢S3,Mα⁢β​=f¯33⁢1j¯⁢∫hS3⁢σα⁢β⁢j⁢d⁢S3,Qα​=f¯33⁢1j¯⁢∫h(σ3⁢α+S3⁢σα⁢β⁢μ,β)⁢j⁢d⁢S3,L3​=f¯33⁢1j¯⁢∫h[σ33⁢f¯33+σ3⁢α⁢γα+2⁢S3⁢σ3⁢α⁢f¯33,α+S3⁢σα⁢β⁢(κα⁢β+γα⁢μ,β)]⁢j⁢d⁢S3,M3⁢α​=f¯33⁢1j¯⁢∫hS3⁢(σ3⁢α⁢f¯33+σα⁢β⁢γβ)⁢j⁢d⁢S3.  For thin shells the Kirchhoff-Love approximation, which states that the deformed director field t3 is (approximately) the normal field to the deformed reference surface, is introduced along with the plane stress assumption σ33=0. Consistent with these approximations, we neglect all O⁢(h/R) terms and terms proportional to the gradient of the thickness parameter. Accordingly, we set  γα=0,    jj¯=f¯33    and    f¯33,α=μ,α=0 .  We can now summarize the virtual work expression for thin (Kirchhoff-Love) shells:  (4)δ⁢Π=∫A[Nα⁢β⁢δ⁢ϵα⁢β+Mα⁢β⁢δ⁢κα⁢β+Qα⁢δ⁢γα]⁢j¯⁢d⁢S⁢d⁢θ,  where the shell resultant components are defined in terms of the Cauchy stress tensor components by the integrals  Nα⁢β=f¯33⁢∫hσα⁢β⁢d⁢S3    and    Mα⁢β=(f¯33)2⁢∫hS3⁢σα⁢β⁢d⁢S3.  In the expression for δ⁢Π, Qα=(f¯33)2⁢∫hσ3⁢α⁢d⁢S3 is interpreted as a constraint stress that enforces that the director field remain normal to the reference surface. Two other contributions to the virtual work expression Mα⁢β⁢κα⁢β⁢δ⁢μ and M3⁢α⁢(δ⁢μ),α, where M3⁢α=(f¯33)2⁢∫hS3⁢σ3⁢α⁢d⁢S3 are O⁢(h/R) and, thus, neglected.  Orthonormal surface coordinate system and coordinate transformation It is desirable to define stress resultant quantities relative to an orthonormal basis in the deformed configuration. To do this, we define a normal coordinate system {n1,n2,n3}, where n1 and n2 are tangent to the deformed reference surface and n3 is the unit normal field.  Define the following notation. Let f¯αa(a=1,2) be the components of x¯,α relative to the basis {n1,n2}; that is  (5)∂⁡x¯∂⁡ξα=f¯αa⁢na.  Furthermore, let the inverse of the matrix of components [f¯αa] be given by [h¯aα], such that  f¯αa⁢h¯bα=δba    and    h¯aα⁢f¯βa=δβα.  Note that the basis vectors n1 and n2 induce distance measuring coordinates s1 and s2 such that  f¯αa=∂⁡sa∂⁡ξα    and    h¯aα=∂⁡ξα∂⁡sa.  It follows from [Equation 5](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-OrthonormalSurfaceCoordinateSystemAndCoordinateTransformation-sma-topic4__simathe-c-axiasymmshells-eq5) that the orthonormal tangent vectors are given by  na=h¯aα⁢x¯,α=∂⁡x¯∂⁡sa.  For the material calculations, it is important to express both the strain and stress quantities relative to the local orthonormal frame {n1,n2}. Accordingly, let Na⁢b=Nb⁢a and Ma⁢b=Mb⁢a be the membrane and bending stress resultant components relative to this local orthonormal basis. Thus, we can write  Nα⁢β=Na⁢b⁢h¯aα⁢h¯bβ    and    Mα⁢β=Ma⁢b⁢h¯aα⁢h¯bβ,  where we recall that h¯aα⁢=def⁢∂⁡ξα/∂⁡sa. Then the stress resultant contributions to the virtual work expression can be transformed as follows. First, the membrane contribution:  Nα⁢β⁢δ⁢ϵα⁢β​=Nα⁢β⁢x¯,α⋅(δ⁢x¯),β​=Na⁢b⁢h¯aα⁢h¯bβ⁢x¯,α⋅(δ⁢x¯),β​=Na⁢b⁢∂⁡x¯∂⁡sa⋅∂⁡(δ⁢x¯)∂⁡sb.  Recall, however, that by the definition of the coordinates sa, ∂⁡x¯/∂⁡sa=na. Thus,  Nα⁢β⁢δ⁢ϵα⁢β=Na⁢b⁢sym⁢[na⋅∂⁡(δ⁢x¯)∂⁡sb].  Similarly, the bending contribution is:  Mα⁢β⁢δ⁢κα⁢β​=Mα⁢β⁢[x¯,α⋅(δ⁢t3),β+t3⋅(δ⁢x¯),α]​=Ma⁢b⁢[na⋅∂⁡(δ⁢ϕ×t3)∂⁡sb+∂⁡t3∂⁡sb⋅∂⁡(δ⁢x¯)∂⁡sa].  Let eac be the two-dimensional alternator, such that e11=e22=0 and e12=-e21=1. Then t3×na=eac⁢nc and  Mα⁢β⁢δ⁢κα⁢β=Ma⁢b⁢[eac⁢nc⋅∂⁡(δ⁢ϕ)∂⁡sb+∂⁡t3∂⁡sb⋅(∂⁡(δ⁢x¯)∂⁡sa-δ⁢ϕ×na)].  Since the second term in the brackets is proportional to the bending curvature, we neglect this term relative to the first, yielding  Mα⁢β⁢δ⁢κα⁢β=Ma⁢b⁢sym⁢[eac⁢nc⋅∂⁡(δ⁢ϕ)∂⁡sb].  Strain displacement operators We now write the virtual work expression [Equation 4](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-VirtualWork-sma-topic3__simathe-c-axiasymmshells-eq4) in matrix operator notation. Define the following stress resultant component vectors:  N⁢=def⁢{N11N22N12}    and    M⁢=def⁢{M11M22M12}.  Define the matrix strain displacement operators as follows:  BN=[n1T⁢∂∂⁡s1n2T⁢∂∂⁡s2n1T⁢∂∂⁡s2+n2T⁢∂∂⁡s1|01×301×301×3]    and    BM=[01×301×301×3|n2T⁢∂∂⁡s1-n1T⁢∂∂⁡s2n2T⁢∂∂⁡s2-n1T⁢∂∂⁡s1],  where 01×3 is the column of zeros {000}T. Then the virtual work expression [Equation 4](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-VirtualWork-sma-topic3__simathe-c-axiasymmshells-eq4) is equivalently stated  δ⁢Π=∫A[N⋅BN⁢{δ⁢x¯δ⁢ϕ}+M⋅BM⁢{δ⁢x¯δ⁢ϕ}]⁢j¯⁢d⁢S⁢d⁢θ.  Corotational coordinate system Thus far n1 and n2 are any two orthonormal vectors in the tangent plane to the reference surface. We can uniquely choose these two vectors by requiring the matrix components of the incremental reference surface deformation gradient [Δ⁢f¯ba], where  Δ⁢f¯ba⁢=def⁢∂⁡s(t+Δ⁢t)⁢a∂⁡s(t)⁢b=f¯β(t+Δ⁢t)⁢a⁢h¯b(t)⁢β,  to be symmetric; i.e., Δ⁢f¯21=Δ⁢f¯12. Note that by definition f¯α(t+Δ⁢t)⁢a=Δ⁢f¯ba⁢f¯α(t)⁢b. This symmetry condition defines a corotational orthonormal basis in the deformed configuration. This orthonormal basis is calculated as follows.  Obtain the Abaqus convention pair of orthonormal surface vectors t^a. We then rotate these vectors in the tangent plane to the reference surface about the normal vector n3t+Δ⁢t by the angle Δ⁢ψ, where Δ⁢ψ is determined by the symmetry condition Δ⁢f¯21=Δ⁢f¯12. Thus, we define  (6)n1t+Δ⁢t​=cos⁡(Δ⁢ψ)⁢t^1+sin⁡(Δ⁢ψ)⁢t^2,n2t+Δ⁢t​=-sin⁡(Δ⁢ψ)⁢t^1+cos⁡(Δ⁢ψ)⁢t^2.  It follows by definition that  Δ⁢f¯ba=na(t+Δ⁢t)⋅∂⁡x¯(t+Δ⁢t)∂⁡s(t)⁢b.  Therefore, define the quantity  Δ⁢f^a⁢b⁢=def⁢t^a⋅∂⁡x¯(t+Δ⁢t)∂⁡s(t)⁢b.  The symmetry condition requires that  (cos⁡(Δ⁢ψ)⁢t^1+sin⁡(Δ⁢ψ)⁢t^2)⋅∂⁡x¯t+Δ⁢t∂⁡s(t)⁢2=(-sin⁡(Δ⁢ψ)⁢t^1+cos⁡(Δ⁢ψ)⁢t^2)⋅∂⁡x¯t+Δ⁢t∂⁡s(t)⁢1.  From this it can be determined that  Δ⁢ψ=tan-1⁡[Δ⁢f^21-Δ⁢f^12Δ⁢f^11+Δ⁢f^22],  and {n1t+Δ⁢t,n2t+Δ⁢t} are then determined by [Equation 6](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-CorotationalCoordinateSystem-sma-topic6__simathe-c-axiasymmshells-eq6).  Having determined the updated vectors nat+Δ⁢t, we can calculate the quantities required for coordinate transformation. First the incremental deformation gradient components and the Jacobian matrix components:  Δ⁢f¯ba≡Δ⁢f¯a⁢b=na(t+Δ⁢t)⋅∂⁡x¯(t+Δ⁢t)∂⁡s(t)⁢b    and    f¯α(t+Δ⁢t)⁢a=Δ⁢f¯ba⁢f¯α(t)⁢b.  Note that due to the symmetry of the incremental deformation gradient components, there is no ambiguity in writing Δ⁢f¯ba=Δ⁢f¯a⁢b. We can now calculate the inverse components  h¯a(t+Δ⁢t)⁢α=[f¯α(t+Δ⁢t)⁢a]-1=∂⁡ξα∂⁡s(t+Δ⁢t)⁢a.  Consistent linearization The iterative solution procedure requires the calculation of the consistent tangent stiffness. This stiffness has two parts, one resulting from the material model and the other resulting from the changing geometry. We denote the second variational quantities with d. Returning to [Equation 4](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-VirtualWork-sma-topic3__simathe-c-axiasymmshells-eq4), the virtual work expression can be written as  δ⁢Π=∫VJ⁢σa⁢b⁢δ⁢Ea⁢b⁢d⁢V0=∫A∫hJ⁢σa⁢b⁢δ⁢Ea⁢b⁢j0⁢d⁢S3⁢d⁢S⁢d⁢θ,  where J=j/j0, j0 is the Jacobian determinant of the reference configuration parametrization given by j0=det⁡[∇⁡X], and components are relative to the corotated frame with a,b∈{1,2}. We assume constitutive behavior such that  d⁢(J⁢σa⁢b)=J⁢Ca⁢b⁢c⁢d⁢d⁢Ec⁢d.  Thus, the variation of the virtual work expression yields  d(δΠ)=∫A[∫hjj¯⁢(δ⁢ϵa⁢b+f¯33⁢S3⁢δ⁢κa⁢b)⁢Ca⁢b⁢c⁢d⁢(d⁢ϵc⁢d+f¯33⁢S3⁢d⁢κc⁢d)⁢d⁢S3+Na⁢bd(δϵa⁢b)+Ma⁢bd(δκa⁢b)]j¯dSdθ.  The first term in the integrand forms the material stiffness, while the second two terms form the geometric stiffness. The second variation of the strain measure components are calculated in [Finite-strain shell element formulation](simathe-c-finitestrainshells.md). The second variation of the membrane strain is  d⁢(δ⁢ϵa⁢b)=sym⁢[∂⁡(δ⁢x¯)∂⁡sa⋅∂⁡(d⁢x¯)∂⁡sb-2⁢δ⁢ϵa⁢c⁢d⁢ϵc⁢b].  The second variation of the bending strain is zero; i.e.,  d⁢(δ⁢κa⁢b)=0 .  Incremental degrees of freedom: interpolations and configuration updates At the beginning of an increment we have the configuration at iteration k, denoted (x¯k,t3k). In the incremental solution procedure we solve for the incremental displacement field and the incremental rotation field in components relative to the reference cylindrical coordinate system:  (Δ⁢urm⁢p,Δ⁢uzm⁢p,Δ⁢uθm⁢p,Δ⁢ϕrm⁢p,Δ⁢ϕzm⁢p,Δ⁢ϕθm⁢p).  We use these incremental fields to update the configuration to iteration k+1.  1. Reference surface update: The displacement increments are interpolated using the same interpolation scheme as the total displacement vector in [Equation 2](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-Interpolations-sma-topic2__simathe-c-axiasymmshells-eq2):  Δ⁢u⁢(S,θ)={Δ⁢ur⁢(S,θ)Δ⁢uz⁢(S,θ)Δ⁢uθ⁢(S,θ)}=∑m=1MHm⁢(S)⁢(∑p=1P+1Rp⁢(θ)⁢{Δ⁢urm⁢pΔ⁢uzm⁢p0}+∑p=1Psin⁡(p⁢θ)⁢{00Δ⁢uθm⁢p}).  The reference surface position map is updated from the displacement increment by  x¯k+1⁢(S,θ)=x¯k⁢(S,θ)+Δ⁢u⁢(S,θ).  2. Rotation field update: The incremental rotation field is updated with the same interpolation scheme as the total rotation field in [Equation 3](simathe-c-axiasymmshells.md#simathe-c-axiasymmshells-t-Interpolations-sma-topic2__simathe-c-axiasymmshells-eq3):  Δ⁢ϕ⁢(S,θ)={Δ⁢ϕr⁢(S,θ)Δ⁢ϕz⁢(S,θ)Δ⁢ϕθ⁢(S,θ)}=∑m=1MHm⁢(S)⁢(∑p=1P+1Rp⁢(θ)⁢{00-Δ⁢ϕθm⁢p}+∑p=1Psin⁡(p⁢θ)⁢{Δ⁢ϕrm⁢pΔ⁢ϕzm⁢p0}).  This incremental rotation vector corresponds to a finite rotation, characterized by quaternion parameters as  Δ⁢q0=cos⁡∥Δ⁢ϕ/2∥    and    Δ⁢q=sin⁡∥Δ⁢ϕ/2∥∥Δ⁢ϕ∥⁢Δ⁢ϕ.  The total rotation quaternion parameter can be updated by the update formula  qk+1=(q0k+1,qk+1)=(Δ⁢ q0⁢q0k-Δ⁢ q⋅qk,Δ⁢ q0⁢qk+q0k⁢Δ⁢ q+Δ⁢ q×qk).  Similarly, the deformed unit director field can be updated from the incremental rotation field as  t3k+1=(2⁢(Δ⁢q0)2-1)⁢t3k+2⁢Δ⁢q0⁢Δ⁢q×t3k+2⁢(Δ⁢q⋅t3k)⁢Δ⁢q⁢=def⁢(Δ⁢q0,Δ⁢q)∘t3k.  Here we have used the notation (q0,q)∘v to denote the rotation of the vector v by the quaternion (q0,q). The curvatures are calculated from the gradient of the director field, which is updated by  t3,αk+1=(Δ⁢q0,Δ⁢q)∘t3,αk+Δ⁢Rα×t3k+1,  where  Δ⁢Rα=H⁢(Δ⁢ϕ)⋅Δ⁢ϕ,α,H⁢(Δ⁢ϕ)=sin⁡∥Δ⁢ϕ∥∥Δ⁢ϕ∥⁢I+1∥Δ⁢ϕ∥2⁢(1-sin⁡∥Δ⁢ϕ∥∥Δ⁢ϕ∥)⁢Δ⁢ϕ⁢Δ⁢ϕ+(1-cos⁡∥Δ⁢ϕ∥)∥Δ⁢ϕ∥2⁢Δ⁢ϕ^.  For completeness, we record the values of Δ⁢ϕ,α. First, along the generator lines we have  Δ⁢ϕ,S=∑m=1MH,Sm⁢(S)⁢(∑p=1P+1Rp⁢(θ)⁢{00Δ⁢ϕθm⁢p}+∑p=1Psin⁡(p⁢θ)⁢{-Δ⁢ϕrm⁢pΔ⁢ϕzm⁢p0}).  For the circumferential derivative we must account for the derivative of the basis vectors in the θ-direction: er,θ=eθ and eθ,θ=-er. Hence, Δ⁢ϕ,θ=(Δ⁢ϕr,θ-Δ⁢ϕθ)⁢er+Δ⁢ϕz,θ⁢ez+(Δ⁢ϕθ,θ+Δ⁢ϕr)⁢eθ. Introducing the interpolation function, we have  Δ⁢ϕ,θ={-Δ⁢ϕθ0Δ⁢ϕr}+∑m=1MHm⁢(S)⁢(∑p=1P+1R,θp⁢(θ)⁢{00-Δ⁢ϕθm⁢p}+∑p=1Pp⁢cos⁡(p⁢θ)⁢{Δ⁢ϕrm⁢pΔ⁢ϕzm⁢p0}),  where R,θp⁢(θ) are computed from the definitions of the interpolation functions Rp⁢(θ) as given above and Δ⁢ϕθ and Δ⁢ϕr are given by the interpolation for the incremental rotation field as given in the Rotation Field Update.  Strain increment and stress resultant update Following the formulation of the finite-strain shell element formulation in [Finite-strain shell element formulation](simathe-c-finitestrainshells.md), the three-dimensional (finite) strain increment is calculated as  Δ⁢Ea⁢b=Δ⁢ϵa⁢b+S3⁢f¯33t+Δ⁢t⁢Δ⁢κa⁢b.  Here the increment in the membrane strain components Δ⁢ϵa⁢b is given by the Hughes-Winget second-order approximation to the logarithmic membrane strain increment  Δ⁢ϵa⁢b=2⁢(Δ⁢f¯a⁢c-δa⁢c)⁢(Δ⁢f¯c⁢b+δc⁢b)-1,  and the increment in the bending strain components Δ⁢κa⁢b is given by the expression  Δ⁢κa⁢b=sym⁢[eac⁢nct+Δ⁢t⋅Δ⁢rb],  where  Δ⁢rb=h¯bα⁢Δ⁢Rα.  As an example of the stress update procedure, consider the simple case of a Saint Venant-Kirchhoff material model. In this case,  σ(t+Δ⁢t)⁢a⁢b=Δ⁢f¯ca⁢σ(t)⁢c⁢d⁢Δ⁢f¯db+Δ⁢f¯ea⁢Δ⁢f¯fb⁢C(t)⁢e⁢f⁢g⁢h⁢Δ⁢f¯gc⁢Δ⁢f¯hd⁢Δ⁢Ec⁢d,  where C(0)⁢e⁢f⁢g⁢h are the plane stress elastic coefficients given by  C(0)⁢e⁢f⁢g⁢h=E(1-ν2)⁢{ν⁢δe⁢f⁢δg⁢h+(1-ν)2⁢(δe⁢g⁢δf⁢h+δe⁢h⁢δf⁢g)}.  Note that a,b,c,d,e,f,h∈{1,2}, and the components σ(t+Δ⁢t)⁢a⁢b are relative to the current orthonormal basis {1t+Δ⁢t,n2t+Δ⁢t}. For geometrically nonlinear problems, however, asymmetric deformations must be taken into consideration. Recall that the current position of a point can be expressed in terms of the axial interpolator Hm⁢(S) and the circumferential interpolators Rp⁢(θ) by  (7){rzuθ}=∑m=1MHm⁢(S)⁢(∑p=1P+1Rp⁢(θ)⁢{rm⁢pzm⁢p0}+∑p=1Psin⁡p⁢θ⁢{00uθm⁢p}). Penalty constraints: transverse shear and drill rotation It is necessary to enforce rotation constraints at selected points on the element surface to prevent singular modes of deformation. One axial transverse shear constraint is enforced on the ϕθ rotation field between each pair of nodes within each nodal plane. One circumferential transverse shear constraint and one drill rotation constraint on the rotation fields ϕr and ϕz are enforced between each pair of nodes on a circumferential line of nodes. In each instance the rotation field is constrained to follow the nodal displacements. To summarize, for element SAXAMN:   * Axial transverse shear: M⁢(N+1) * Circumferential transverse shear: (M+1)⁢N * Drill rotation: (M+1)⁢N   constraints are enforced, where M∈{1,2} is the order of integration in the axial direction and N∈{1,2,3,4} is the number of Fourier modes.  Transverse shear The transverse shear strain is the measure of the amount the director field t3 has rotated relative to the normal to the shell surface. We define the transverse shear strain as  γ3⁢c⁢=def⁢t3⋅t¯c,    where    t¯c⁢=def⁢x¯,ξc/∥x¯,ξc∥,  with no sum on c and force this quantity to be zero with a penalty constraint. Note that t¯c is a unit vector tangent to the shell surface defined by the displacement field along a parametric coordinate line. Recall that ξ1=S and ξ2=θ. Hence, γ31 is the axial transverse shear strain and γ32 is the circumferential transverse shear strain.  For convenience, record the variation of the unit vector t¯c:  δt¯c=1∥x¯,ξc∥δx¯,ξc-x¯,ξc⋅δ⁢x¯,ξc∥x¯,ξc∥3x¯,ξc    ,  with no sum on c. Equivalently, the definition of t¯c can be used to write  δ⁢t¯c=1∥x¯,ξc∥⁢[δ⁢x¯,ξc-(t¯c⋅δ⁢x¯,ξc)⁢tc].  The linearized transverse shear strain is calculated as  δ⁢γ3⁢c=δ⁢t3⋅t¯c+t3⋅δ⁢t¯c.  Since by definition δ⁢t3=δ⁢ϕ×t3, it follows that  δ⁢γ3⁢c=δ⁢ϕ⋅(t3×t¯c)+1∥x¯,ξc∥⁢(t3-γ3⁢c⁢t¯c)⋅δ⁢x¯,ξc,  with no sum on c.  For completeness, the second variation of the transverse shear strain is  d⁢(δ⁢γ3⁢c)​=δ⁢ϕ⋅12⁢[t3⁢t¯c+t¯c⁢t3]⋅d⁢ϕ-δ⁢x¯,ξc⋅1∥x¯,ξc∥2⁢[t3⁢t¯c+t¯c⁢t3]⋅d⁢x¯,ξc+δ⁢ϕ⋅1∥x¯,ξc∥⁢[t^3-(t3×t¯c)⁢t¯c]⋅d⁢x¯,ξc+δ⁢x¯,ξc⋅1∥x¯,ξc∥⁢[-t^3-t¯c⁢(t3×t¯c)]⋅d⁢ϕ,  where terms proportional to γ3⁢c have been neglected and the coupling between δ⁢ϕ and Δ⁢ϕ has been symmetrized.  Drill rotation Mathematically, the equations governing the deformation of the shell are invariant with respect to drill rotations; that is, a rotation of the director field with axis of rotation parallel to the director. It is necessary then to assign a kinematic definition to this rotation. We define the drill strain as the difference between the rotation of the circumferential tangent vector as measured by the displacement field and that measured by the rotation field. Accordingly, we define the drill strain by  γd=a⋅b.  Here, a is the rotated reference axial tangent vector and b is the deformed (unit) circumferential tangent vector, defined by  a=exp⁡[ϕ^]⁢A    and    b=x¯,θ∥x¯,θ∥.  In the above A is a linear approximation to the axial tangent vector in the reference configuration given by A1=(XK-XN)/∥XK-XN∥, where XK and XN are the position vectors to two adjacent nodes in an axial plane. The drill rotation constraint then requires that the component of rotation about the normal to the surface match the in-plane rotation of the surface as measured by the displacement field.  The linearized drill strain calculation is similar to the transverse shear linearized strain calculation. Without repeating the calculation,  δ⁢γd=δ⁢ϕ⋅(a×b)+1∥x¯,θ∥⁢(a-γd⁢b)⋅δ⁢x¯,θ.  Similarly, the second variation of the drill strain  d⁢(δ⁢γd)​=δ⁢ϕ⋅12⁢[ab+ba]⋅d⁢ϕ-δ⁢x¯,θ⋅1∥x¯,θ∥2⁢[ab+ba]⋅d⁢x¯,θ+δ⁢ϕ⋅1∥x¯,θ∥⁢[a^-(a×b)⁢b]⋅d⁢x¯,θ+δ⁢x¯,θ⋅1∥x¯,θ∥⁢[-a^-b⁢(a×b)]⋅d⁢ϕ,  where terms proportional to γd have been neglected and the coupling between δ⁢ϕ and Δ⁢ϕ has been symmetrized.  Zero radius: collapsed edge For the case when the reference radius of any point on the shell surface goes to zero, all of the offset nodes collapse to the same point and the edge constraints along that circumferential edge become redundant. It is, therefore, necessary to treat the zero radius case separately.  For the zero radius case all redundant degrees of freedom are constrained to follow the average motion of the nodes at θ=​0° and θ=​ 180°. The edge constraints are broken into two parts: First, a circumferential transverse shear strain is defined that requires that the rotation in the radial direction follow the circumferential rotations at the first and last nodal plane:  γ320=ϕr+12⁢(ϕθ1+ϕθP+1)⁢sin⁡θ.  Introducing the interpolations, the linearized strain is  δ⁢γ320=∑p=1Psin⁡p⁢θ⁢δ⁢ϕrp+12⁢sin⁡θ⁢(δ⁢ϕθ+δ⁢ϕθP+1).  Note that d⁢(δ⁢γ320)=0. Second, a drill rotation strain is defined that requires that the rotation about the Z-axis be zero:  γd0=ϕz.  This leads to a linearized strain given by  δ⁢γd0=∑p=1Psin⁡p⁢θ⁢δ⁢ϕzp.  Note that d⁢(δ⁢γd0)=0.  Mass matrix At each material point the displacement components in the three directions (radial, axial, circumferential) are dependent only on the corresponding nodal displacement components. Hence, the mass matrix does not involve any coupling between the radial, axial, and circumferential degrees of freedom, and we can write the mass matrix in the form of three separate expressions:  Murm⁢n⁢p⁢q​=∫zρ⁢d⁢z⁢∫ANrm⁢p⁢Nrn⁢q⁢d⁢AMuzm⁢n⁢p⁢q​=∫zρ⁢d⁢z⁢∫ANzm⁢p⁢Nzn⁢q⁢d⁢AMuθm⁢n⁢p⁢q​=∫zρ⁢d⁢z⁢∫ANθm⁢p⁢Nθn⁢q⁢d⁢A.  Similarly, we can write the terms associated with the rotational degrees of freedom as:  Mϕrm⁢n⁢p⁢q​=∫zρ⁢z2⁢d⁢z⁢∫ANθm⁢p⁢Nθn⁢q⁢d⁢AMϕzm⁢n⁢p⁢q​=∫zρ⁢z2⁢d⁢z⁢∫ANθm⁢p⁢Nθn⁢q⁢d⁢AMϕθm⁢n⁢p⁢q​=∫zρ⁢z2⁢d⁢z⁢∫ANrm⁢p⁢Nrn⁢q⁢d⁢A.  Here the superscripts m and n refer to a particular node in the r–z plane, and the superscripts p and q refer to a particular position along the circumference. The interpolation functions Nrm⁢p, Nzm⁢p, and Nθm⁢p are the product of interpolation functions Hm⁢(S) in the r–z plane and interpolation functions in the θ-direction:  Nrm⁢p=Hm(S)Rp(θ)=Nzm⁢pNθm⁢p​=Hm⁢(S)⁢sin⁡p⁢θ.  The area integral used to form the mass matrix can be split then into an integral along the length of the element in the r–z plane and an integral around the circumference. For the r–r component of the mass matrix this yields  Murm⁢n⁢p⁢q=∫zρ⁢d⁢z⁢∫SHm⁢(S)⁢Hn⁢(S)⁢ 2⁢π⁢R⁢d⁢S⁢12⁢π⁢∫02⁢πRp⁢(θ)⁢Rq⁢(θ)⁢d⁢θ,  and for the ϕr component of the mass matrix this yields:  Mϕrm⁢n⁢p⁢q=∫zρ⁢z2⁢d⁢z⁢∫SHm⁢(S)⁢Hn⁢(S)⁢ 2⁢π⁢R⁢d⁢S⁢12⁢π⁢∫02⁢πRp⁢(θ)⁢Rq⁢(θ)⁢d⁢θ.  The matrix can be written in a convenient form by defining the primitive mass matrix as  Mp⁢r⁢i⁢mm⁢n=∫zρ⁢d⁢z⁢∫SHm⁢(S)⁢Hn⁢(S)⁢ 2⁢π⁢R⁢d⁢S,  or for the rotational components as  M¯p⁢r⁢i⁢mm⁢n=∫zρ⁢z2⁢d⁢z⁢∫SHm⁢(S)⁢Hn⁢(S)⁢ 2⁢π⁢R⁢d⁢S.  These primitive mass matrices are the same mass matrices that are used for the regular axisymmetric shell elements. We can also define the circumferential distribution matrices  f1p⁢q​=12⁢π⁢∫02⁢πRp⁢(θ)⁢Rq⁢(θ)⁢d⁢θ        andf2p⁢q​=12⁢π⁢∫02⁢πsin⁡p⁢θ⁢sin⁡q⁢θ⁢d⁢θ.  The various components of the mass matrix then take the form  Murm⁢n⁢p⁢q​=Mp⁢r⁢i⁢mm⁢n⁢f1p⁢qMuzm⁢n⁢p⁢q​=Mp⁢r⁢i⁢mm⁢n⁢f1p⁢qMuθm⁢n⁢p⁢q​=Mp⁢r⁢i⁢mm⁢n⁢f2p⁢qMϕrm⁢n⁢p⁢q​=M¯p⁢r⁢i⁢mm⁢n⁢f2p⁢qMϕzm⁢n⁢p⁢q​=M¯p⁢r⁢i⁢mm⁢n⁢f2p⁢qMϕθm⁢n⁢p⁢q​=M¯p⁢r⁢i⁢mm⁢n⁢f1p⁢q.
