With this formulation the contacting surfaces can undergo only relatively small sliding relative to each other, but arbitrary rotation of the bodies is permitted. Small-sliding contact is computationally less expensive than finite-sliding contact. With this approach one surface definition provides the “main” surface and the other surface definition provides the “secondary” surface. A kinematic constraint that the secondary surface nodes do not penetrate the main surface is then enforced. The contacting surfaces need not have matching meshes; however, the best accuracy is obtained when the meshes are initially matching. For initially nonmatching meshes, accuracy can be improved by judiciously specifying initial adjustments to ensure that all secondary nodes that should initially be in contact are located on the main surface.  The small-sliding contact capability is implemented by means of four internal contact elements designed to handle the following kinematic constraints:   1. two-dimensional contact between a secondary node and a deformable main surface, 2. two-dimensional contact between a secondary node and a rigid main surface, 3. three-dimensional contact between a secondary node and a deformable main surface, and 4. three-dimensional contact between a secondary node and a rigid main surface.   These elements are not accessible to the user, and Abaqus will automatically cover a secondary surface with the appropriate element type, based on the nature of the corresponding main surface.    Identification of tangent plane based on nearest neighbor interaction Although four internal element types are used to model the various types of small-sliding contact interactions supported by Abaqus/Standard, all four formulations are based on the notion that a given secondary node always interacts with the same subset of main surface nodes. This nodal subset is initially determined by the Abaqusanalysis input file processor from the undeformed model definition, thus avoiding the need to “track” the secondary node during the course of the analysis. This set of nearest-neighbor nodes to the point on the main surface closest to the secondary node is used to parametrize a contact plane with which the secondary node will interact during the analysis. This concept is illustrated next for the case of a two-dimensional secondary node interacting with a first-order main surface. This formulation can be generalized to second order as well as three-dimensional situations, but this generalization will not be discussed here.  Consider the contact interaction of three nodes—102, 103, and 104—on the secondary surface with a main surface made up of first-order element faces described by nodes 1, 2, and 3, as shown in [Figure 1](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-IdentificationOfTangentPlaneBasedOnNearestNeighborInteraction-sma-topic1__simathe-c-stmslave-2d-master). Figure 1. Secondary nodes interacting with a two-dimensional main surface.   Before initiating the search for the nodal subset of the main surface nodes that will interact with each node on the secondary surface, unit normal vectors are computed for all the nodes on the main surface. For example, the unit normal vector    N 2  is computed by averaging the unit normal vectors of segments 1–2 and 2–3. The user can also specify the normal vector for each node on the main surface. Additional unit normal vectors are computed for each segment a distance    ε ⁢ L  from each end of the segment, where   ε  is a fraction and   L  is the length of the segment; e.g.,    N ε . Currently the value of   ε  is set to 0.5, and the user cannot change this value. The unit normals computed are then used to define a smooth varying normal vector,    N ⁢  ( X ) , at any point,   X , on the main surface.  An “anchor” point on the main surface,    X 0 , is computed for each secondary node so that the vector formed by the secondary node and    X 0  coincides with the normal vector    N ⁢  (  X 0 ) . Suppose that a search for the anchor point,    X 0 , of secondary node 103 reveals that    X 0  is on segment 1–2. Then, we find that  X0=X⁢(u0)=(1-u0)⁢X1+u0⁢X2,  where X1 and X2 are the coordinates of nodes 1 and 2, respectively, and u0 is calculated so that X0-X103 coincides with N⁢(X0). Moreover, the contact plane tangent direction, v0, at X0 is chosen so that it is perpendicular to N⁢(X0); i.e.,  v0=N⁢(X0)×ez=T⋅∂⁡X⁢(u0)∂⁡u=T⋅(X2-X1),  where T is a (constant) rotation matrix.  The small-sliding contact constraint is achieved by requiring that secondary node 103 interact with the tangent plane whose current anchor point coordinates are, at any time, given by  x0=N1⁢(u0)⁢x1+N2⁢(u0)⁢x2,  where N1⁢(u0)=1-u0 and N2⁢(u0)=u0, and whose current tangent direction is given by  v=T⋅(N1u⁢(u0)⁢x1+N2u⁢(u0)⁢x2),  where N1u⁢(u0)=-1 and N2u⁢(u0)=1. Since the above expressions for the point x0 and the vector v resulted from barycentric (affine) combinations of the points x1 and x2—that is,  N1⁢(u0)+N2⁢(u0)​=1,N1u⁢(u0)+N2u⁢(u0)​=0,  the contact plane will be mapped properly under affine transformations such as translation, scaling (stretching), and rotation.  Next, suppose that a search for the anchor point of secondary node 104 reveals that the anchor point is coincident to the main node 2. In this case the anchor point is chosen to be    X 2 , or in terms of the coordinates of the three main nodes 1, 2, and 3,  X0=N1⁢(u0)⁢X1+N2⁢(u0)⁢X2+N3⁢(u0)⁢X3,  where N1⁢(u0)=0, N2⁢(u0)=1, and N3⁢(u0)=0. The contact tangent direction at X2 is simply  v0=N2×ez.  However, we want to express v0 in terms of the coordinates of the three nodes 1, 2, and 3 to be able to track the evolution of the tangent plane. To this end, we solve for the Niu from the equation  N1u⁢(u0)⁢X1+N2u⁢(u0)⁢X2+N3u⁢(u0)⁢X3=v0,  subject to the barycentric constraint  N1u⁢(u0)+N2u⁢(u0)+N3u⁢(u0)=0 .  The barycentric constraint ensures that the resulting expression for the contact plane tangent direction behaves properly under affine transformations such as translations and rotations.  Contact formulation as a constrained variational principle At each secondary node that can come into contact with a main surface we construct a measure of overclosure   h  (penetration of the node into the main surface) and measures of relative slip    s i . These kinematic measures are then used, together with appropriate Lagrange multiplier techniques, to introduce surface interaction theories for contact and friction, as described in [Contact pressure definition](simathe-c-contactpress.md) and [Coulomb friction](simathe-c-coulombfric.md).  In two dimensions the overclosure   h  along the unit contact normal   n  between a secondary point    x  N + 1  and a main line    p ⁢  ( ξ ) , where   ξ  parametrizes the line, is determined by finding the vector    (  p -  x  N + 1 )  from the secondary node to the line that is perpendicular to the tangent vector   v  at   p . Mathematically, we express the required condition as  (1)h⁢n=p⁢(ξ)-xN+1,  when  v⋅(p⁢(ξ)-xN+1)=0 .  Similarly, in three dimensions the overclosure   h  along the unit contact normal   n  between a secondary point    x  N + 1  and a main plane    p ⁢  (   ξ 1 ,  ξ 2 ) , where    ξ i  parametrize the plane, is determined by finding the vector    (  p -  x  N + 1 )  from the secondary node to the plane that is perpendicular to the tangent vectors    v 1  and    v 2  at   p . Mathematically, we express the required condition as  (2)h⁢n=p⁢(ξ1,ξ2)-xN+1,  when  v1⋅(p⁢(ξ1,ξ2)-xN+1)​=0,v2⋅(p⁢(ξ1,ξ2)-xN+1)​=0 .  If at a given secondary node    h < 0 , there is no contact between the surfaces at that node, and no further surface interaction calculations are needed. If    h ≥ 0 , the surfaces are in contact. The contact constraint    h = 0  is enforced by introducing a Lagrange multiplier,    p ~ , whose value provides the contact pressure at the point. To enforce the contact constraint, we need the first variation    δ ⁢ h ; and for the Newton iterations, we need the second variation,    d ⁢ δ ⁢ h . Likewise, if frictional forces are to be transmitted across the contacting surfaces, the first variations of relative slip,    δ ⁢  s i , and the second variations,    d ⁢ δ ⁢  s i , are needed in the formulation. The derivation of some of these quantities is described next for all four small-sliding contact formulations.  Formulation for two-dimensional small-sliding deformable contact For the case of two-dimensional small-sliding deformable contact, a point on the contact line associated with a secondary node    n  N + 1  is represented by the vector  (3)p⁢(ξ)=x0+ξ⁢v,  where, as described previously, the line's anchor point—   x 0 —and its tangent vector—  v —are functions of the current main node coordinates,     x 1 ⁢ … ⁢  x N . Hence, the vector   v  is, in general, a nonunit vector. Linearization of [Equation 1](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-ContactFormulationAsAConstrainedVariationalPrinciple-sma-topic2__simathe-c-smslidcontact-eq1) yields  (4)δ⁢h⁢n+h⁢δ⁢n=δ⁢x0+δ⁢ξ⁢v+ξ⁢δ⁢v-δ⁢uN+1  where δ⁢uN+1=δ⁢(XN+1+uN+1)=δ⁢xN+1, δ⁢x0=Ni⁢(u0)⁢δ⁢xi, and δ⁢v=R⋅Niu⁢(u0)⁢δ⁢xi.  Taking the dot product of [Equation 4](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingDeformableContact-sma-topic3__simathe-c-smslidcontact-eq4) with n results in the following expression for δ⁢h:  (5)δ⁢h=-n⋅(δ⁢uN+1-δ⁢x0-ξ⁢δ⁢v).  Likewise, taking the dot product of [Equation 4](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingDeformableContact-sma-topic3__simathe-c-smslidcontact-eq4) with the normalized tangent vector t=v/∥v∥ and setting h=0 results in the following expression for the variation in slip:  (6)δ⁢s⁢=def⁢δ⁢ξ⁢v⋅t=t⋅(δ⁢uN+1-δ⁢x0-ξ⁢δ⁢v).  Suitable expressions for d⁢δ⁢h and d⁢δ⁢s can be derived by linearizing [Equation 4](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingDeformableContact-sma-topic3__simathe-c-smslidcontact-eq4) and applying the techniques highlighted above. Since the resulting expressions do not provide additional insight into the understanding of this capability, they will not be presented here.  Formulation for three-dimensional small-sliding deformable contact The three-dimensional small-sliding deformable contact formulation is a straightforward generalization of the previous two-dimensional formulation. A point on the contact plane associated with a secondary node    n  N + 1  is represented by the vector  p⁢(ξ1,ξ2)=x0+ξ1⁢v1+ξ2⁢v2,  where the plane's anchor point—   x 0 —and its two tangent vectors—   v 1  and    v 2 —are functions of the current main node coordinates     x 1 , … ,  x N . Linearization of [Equation 2](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-ContactFormulationAsAConstrainedVariationalPrinciple-sma-topic2__simathe-c-smslidcontact-eq2) yields  (7)δ⁢h⁢n+h⁢δ⁢n=δ⁢x0+δ⁢ξ1⁢v1+ξ1⁢δ⁢v1+δ⁢ξ2⁢v2+ξ2⁢δ⁢v2-δ⁢uN+1,  where δ⁢x0=f⁢(δ⁢x1,…,δ⁢xN) and δ⁢vi=gi⁢(δ⁢x1,…,δ⁢xN).  Taking the dot product of [Equation 7](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForThreedimensionalSmallslidingDeformableContact-sma-topic4__simathe-c-smslidcontact-eq7) with n results in the following expression for δ⁢h:  (8)δ⁢h=-n⋅(δ⁢uN+1-δ⁢x0-ξ1⁢δ⁢v1-ξ2⁢δ⁢v2).  Likewise, taking the dot product of [Equation 7](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForThreedimensionalSmallslidingDeformableContact-sma-topic4__simathe-c-smslidcontact-eq7) with t1=v1/∥v1∥ and setting h=0 results in the following expression for the variation of the first slip component:  (9)δ⁢s1⁢=def⁢δ⁢ξ1⁢v1⋅t1=t1⋅(δ⁢uN+1-δ⁢x0-ξ1⁢δ⁢v1-ξ2⁢δ⁢v2).  Similarly, taking the dot product of [Equation 7](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForThreedimensionalSmallslidingDeformableContact-sma-topic4__simathe-c-smslidcontact-eq7) with t2=v2/∥v2∥ and setting h=0 results in the following expression for the variation of the second slip component:  (10)δ⁢s2⁢=def⁢δ⁢ξ2⁢v2⋅t2=t2⋅(δ⁢uN+1-δ⁢x0-ξ1⁢δ⁢v1-ξ2⁢δ⁢v2).  Formulation for two-dimensional small-sliding rigid contact The formulation for two-dimensional small-sliding rigid contact follows from its deformable counterpart by exploiting the fact that the evolution of the contact plane is fully determined by the motion of the rigid body's reference node. [Figure 2](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingRigidContact-sma-topic5__simathe-c-stmrigid-body-ref-geom) shows how the undeformed coordinates X0 of the contact plane's anchor point are related vectorially to the undeformed coordinates of the rigid reference node, Xr⁢s, and the relative position vector R.We can express this relationship as  X0=Xr⁢s+R. Figure 2. Rigid body reference geometry.   Suppose the rigid reference node undergoes a motion described by the displacement vector ur⁢s and the rotation vector ϕr⁢s⁢ez, then the current coordinates of the contact plane's anchor point are given by  (11)x0​=Xr⁢s+ur⁢s+C⁢(ϕr⁢s⁢ez)⋅R,​=xr⁢s+r,  where C is the orthogonal matrix that produces the rotation ϕr⁢s⁢ez (see [Rotation variables](simathe-c-rotationvars.md)) and r is the current position vector from the rigid reference node to the anchor point. The rotation matrix is also used to obtain the contact plane's current tangent and current normal as follows:  (12)t​=C⁢(ϕr⁢s⁢ez)⋅t0,n​=C⁢(ϕr⁢s⁢ez)⋅n0,  where    t 0  and    n 0  are the initial contact tangent and normal at    X 0 , respectively, as shown in [Figure 2](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingRigidContact-sma-topic5__simathe-c-stmrigid-body-ref-geom). By definition, a rigid surface cannot stretch; therefore, a point on the rigid contact line associated with a secondary node    n  N + 1  is represented by the vector  p⁢(ξ)=x0+ξ⁢t,  where—unlike the vector v in [Equation 3](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingDeformableContact-sma-topic3__simathe-c-smslidcontact-eq3)—the tangent t is always a unit vector.  Linearization of [Equation 11](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingRigidContact-sma-topic5__simathe-c-smslidcontact-eq11) and [Equation 12](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingRigidContact-sma-topic5__simathe-c-smslidcontact-eq12) results in the following expressions for the first variations of the anchor coordinates and the contact plane's tangent:  (13)δ⁢x0​=δ⁢ur⁢s+(-ry⁢ex+rx⁢ey)⁢δ⁢ϕr⁢s,δ⁢t​=(-ty⁢ex+tx⁢ey)⁢δ⁢ϕr⁢s.  Replacing v by t in [Equation 5](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingDeformableContact-sma-topic3__simathe-c-smslidcontact-eq5), noting that t⋅δ⁢t=0, and substituting for δ⁢x0 and δ⁢t from [Equation 13](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingRigidContact-sma-topic5__simathe-c-smslidcontact-eq13) results in the following expression for δ⁢h:  (14)δ⁢h=-n⋅[δ⁢uN+1-δ⁢ur⁢s+((ry+ξ⁢ty)⁢ex-(rx+ξ⁢tx)⁢ey)⁢δ⁢ϕr⁢s].  Similar manipulation of [Equation 6](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingDeformableContact-sma-topic3__simathe-c-smslidcontact-eq6) yields the following expression for δ⁢s:  (15)δ⁢s⁢=def⁢δ⁢ξ=t⋅[δ⁢uN+1-δ⁢ur⁢s+(ry⁢ex-rx⁢ey)⁢δ⁢ϕr⁢s].  Formulation for three-dimensional small-sliding rigid contact The three-dimensional small-sliding rigid contact formulation can also be derived from its deformable counterpart by generalizing some of the expressions that were introduced in the previous section. In particular, in this formulation the rigid reference node can undergo an arbitrary finite rotation described by the rotation vector ϕr⁢s. Consequently, [Equation 13](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForTwodimensionalSmallslidingRigidContact-sma-topic5__simathe-c-smslidcontact-eq13) for the variations of the anchor point coordinates and the contact plane's tangent generalize to  δ⁢x0​=δ⁢ur⁢s+δ⁢θ^r⁢s⋅r,δ⁢ti=δ⁢θ^r⁢s⋅ti,i=1,2,  where δ⁢θ^r⁢s is the skew-symmetric matrix associated with the linearized rotation δ⁢θr⁢s, as explained in [Rotation variables](simathe-c-rotationvars.md).  Replacing vi by ti in [Equation 8](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForThreedimensionalSmallslidingDeformableContact-sma-topic4__simathe-c-smslidcontact-eq8) through [Equation 10](simathe-c-smslidcontact.md#simathe-c-smslidcontact-t-FormulationForThreedimensionalSmallslidingDeformableContact-sma-topic4__simathe-c-smslidcontact-eq10) and substituting for δ⁢x0 and δ⁢ti from above results in the following expressions for δ⁢h, δ⁢s1, and δ⁢s2:  (16)δ⁢h=-n⋅[δ⁢uN+1-δ⁢ur⁢s-δ⁢θ^r⁢s⋅(r+ξ1⁢t1+ξ2⁢t2)],  (17)δ⁢s1⁢=def⁢δ⁢ξ1=t1⋅[δ⁢uN+1-δ⁢ur⁢s-δ⁢θ^r⁢s⋅(r+ξ2⁢t2)],  (18)δ⁢s2⁢=def⁢δ⁢ξ2=t2⋅[δ⁢uN+1-δ⁢ur⁢s-δ⁢θ^r⁢s⋅(r+ξ1⁢t1)]. |
