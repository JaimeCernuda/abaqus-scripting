| |  |  | | --- | --- | | Steady-state transport analysis | | |  | | | |  | | --- | | Abaqus/Standard provides a specialized analysis capability to model the steady-state behavior of a cylindrical deformable body rolling along a flat rigid surface. The capability uses a reference frame that removes the explicit time dependence from the problem so that a purely spatially dependent analysis can be performed.  For an axisymmetric body traveling at a constant ground velocity and constant angular rolling velocity, a steady state is possible in a frame that moves at the speed of the ground velocity but does not spin with the body in the rolling motion. This choice of reference frame allows the finite element mesh to remain stationary so that only the part of the body in the contact zone requires fine meshing. In this moving frame the rigid body rotation is described in a spatial or Eulerian manner and the deformation in a material or Lagrangian manner. It is this kinematic description that converts the steady moving contact field problem into a purely spatially dependent simulation.  We consider the case shown in [Figure 1](simathe-c-steadystatetransport.md#simathe-c-steadystatetransport-t-KinematicsOfSteadystateRolling-sma-topic1__simathe-c-corneringrolling), where the ground velocity of the body is described in terms of a constant cornering motion. Figure 1. Constant cornering motion.     The body is rotating with a constant angular rolling velocity ω around a rigid axle T at X0, which in turn rotates with constant angular velocity Ω around the fixed cornering axis n through point Xc. Hence, the motion of a particle X at time t consists of a rigid rolling rotation to position Y, described by  Y=Rs⋅(X-X0)+X0,  followed by a deformation to point x, and a subsequent cornering rotation (or precession) around n to position y so that  y=Rc⋅(x-Xc)+Xc,  where Rc is the cornering rotation given by Rc=exp⁡(Ω^⁢t) and Ω^ is the skew-symmetric matrix associated with the rotation vector Ω=Ω⁢n. Similarly, Rs is the spinning rotation matrix defined as Rs=exp⁡(ω^⁢t) and ω^ is the skew-symmetric matrix associated with the rotation vector ω=ω⁢T. The velocity of the particle then becomes  v=y˙=R˙c⋅(x-Xc)+Rc⋅x˙.  To describe the deformation of the body, we define a map χ⁢(Y,t), which gives the position of point X at time t as a function of its location Y at time t so that x=χ⁢(Y,t). It follows that  x˙=∂⁡χ∂⁡Y⋅∂⁡Y∂⁡t+∂⁡χ∂⁡t,  where  ∂⁡Y∂⁡t=R˙s⋅(X-X0)=ω⁢T×(Y-X0).  Noting that R˙s=ω^⋅Rs=ω⁢T^⋅Rs, and introducing the circumferential direction S=T×(Y-X0)/R, where R=|Y-X0| is the radius of a point on the reference body, the velocity of the reference body can be written as ∂⁡Y/∂⁡t=ω⁢R⁢S, so that  x˙=ω⁢R⁢∂⁡χ∂⁡Y⋅S+∂⁡χ∂⁡t=ω⁢R⁢∂⁡χ∂⁡S+∂⁡χ∂⁡t,  where S is the distance-measuring coordinate along the streamline. Using this result, together with R˙c=Ω^⋅Rc=Ω⁢n^⋅Rc, the velocity of the particle can be written as  v=Ω⁢n×(x-Xc)+ω⁢R⁢Rc⋅∂⁡χ∂⁡S+Rc⋅∂⁡χ∂⁡t.  The acceleration is obtained by a second differentiation and some manipulation:  a=Ω2(nn-I)⋅(x-Xc)+ 2⁢ω⁢Ω⁢R⁢n×Rc⋅∂⁡χ∂⁡S+ 2⁢Ω⁢n×Rc⋅∂⁡χ∂⁡t+ω2⁢R2⁢Rc⋅∂2⁡χ∂⁡S2+ 2⁢ω⁢R⁢Rc⋅∂2⁡χ∂⁡S⁢∂⁡t+Rc⋅∂2⁡χ∂⁡t2.  To obtain expressions for the velocity and acceleration in the reference frame tied to the body, we use the transformations  vr=RcT⋅v    and    ar=RcT⋅a  so that we obtain  vr=Ω⁢n×(x-Xc)+ω⁢R⁢∂⁡χ∂⁡S+∂⁡χ∂⁡t  and  ar=Ω2(nn-I)⋅(x-Xc)+ 2⁢ω⁢Ω⁢R⁢n×∂⁡χ∂⁡S+ 2⁢Ω⁢n×∂⁡χ∂⁡t+ω2⁢R2⁢∂2⁡χ∂⁡S2+ 2⁢ω⁢R⁢∂2⁡χ∂⁡S⁢∂⁡t+∂2⁡χ∂⁡t2.  For steady-state conditions these expressions reduce to  vr=Ω⁢n×(x-Xc)+ω⁢R⁢∂⁡χ∂⁡S  and  ar=Ω2⁢(nn-I)⋅(x-Xc)+ 2⁢ω⁢Ω⁢R⁢n×∂⁡χ∂⁡S+ω2⁢R2⁢∂2⁡χ∂⁡S2.  The first term in the last expression can be identified as the acceleration that gives rise to centrifugal forces resulting from rotation about n. Noting that ω⁢R⁢∂⁡χ/∂⁡S is a measure of velocity, the second term can be identified as the acceleration that gives rise to Coriolis forces. The last term combines the acceleration that gives rise to Coriolis and centrifugal forces resulting from rotation about T. When the deformation is uniform along the circumferential direction, this Coriolis effect vanishes so that the acceleration gives rise to centrifugal forces only.  The velocity of the center of the body X0 (which must lie on the axis T) is  v0=Ω⁢n×(X0-Xc)  since the motions due to rolling and deformation vanish on the axis.  To obtain the expression for straight line motion, as shown in [Figure 2](simathe-c-steadystatetransport.md#simathe-c-steadystatetransport-t-KinematicsOfSteadystateRolling-sma-topic1__simathe-c-straightlinerolling), we move Xc far away from the center of the body x0 but keep v0 the same. In that case Ω→0 and, hence, in the limit  v=v0+vr=v0+ω⁢R⁢∂⁡χ∂⁡S,  a=ar=ω2⁢R2⁢∂2⁡χ∂⁡S2,  which corresponds to straight line rolling. Figure 2. Straight line rolling.  Inertia The virtual work contribution from the d'Alembert forces is  δ⁢Π=-∫Vρ⁢a⋅δ⁢v⁢d⁢V.  Using the divergence theorem, the virtual work contribution becomes  δ⁢Π​=-Ω2⁢∫Vρ⁢(x-Xc)⋅(nn-I)⋅δ⁢v⁢d⁢V- 2⁢ω⁢Ω⁢∫Vρ⁢R⁢n×∂⁡χ∂⁡S⋅δ⁢v⁢d⁢V+ω2⁢∫Vρ⁢R2⁢∂⁡χ∂⁡S⋅∂⁡δ⁢v∂⁡S⁢d⁢V  and the rate of virtual work becomes  d⁢δ⁢Π​=-Ω2⁢∫Vρ⁢d⁢x⋅(nn-I)⋅δ⁢v⁢d⁢V- 2⁢ω⁢Ω⁢∫Vρ⁢R⁢n×∂⁡d⁢χ∂⁡S⋅δ⁢v⁢d⁢V+ω2⁢∫Vρ⁢R2⁢∂⁡d⁢χ∂⁡S⋅∂⁡δ⁢v∂⁡S⁢d⁢V.  For straight line rolling only the last term in each expression needs to be taken into account.  Performing a harmonic analysis about a nonlinear base state To perform a steady-state dynamic or frequency analysis on a rolling tire, it is necessary to linearize the virtual work expressions about the base state. Assuming a harmonic solution of the form u⁢(Y)⁢ej⁢ψ⁢t, it can be shown that, for the case of straight line rolling, the linearized rate of virtual work is  d⁢δ⁢Π=∫Vρ⁢[ω2⁢R2⁢∂⁡d⁢u∂⁡S⋅∂⁡δ⁢v∂⁡S+j⁢ψ⁢ω⁢R⁢(d⁢u⋅∂⁡δ⁢v∂⁡S-∂⁡d⁢u∂⁡S⋅δ⁢v)+ψ2⁢d⁢u⋅δ⁢v]⁢d⁢V.  The first term is the load stiffness contribution due to the spinning motion about the axle. The second term is an imaginary antisymmetric gyroscopic operator. The third term is the standard mass operator.  Contact conditions To obtain the contact conditions, we start with the expressions for velocity derived in the previous section. For points on the surface of the deformable body  vD=Ω⁢n×(x-Xc)+ω⁢R⁢∂⁡χ∂⁡S+∂⁡χ∂⁡t,  where n is the cornering axis (which must be normal to the rigid surface) and Ω is the cornering angular velocity around n. Assuming that the velocity of a point on the foundation (or rigid surface) is vR, the relative motion becomes  v=vD-vR=Ω⁢n×r+ω⁢R⁢∂⁡χ∂⁡S+∂⁡χ∂⁡t-vR,  where r=x-Xc. This equation can be split into normal and tangential components. The rate of penetration is  h˙=-n⋅v=n⋅vR-ω⁢R⁢n⋅∂⁡χ∂⁡S-n⋅∂⁡χ∂⁡t.  For any point in contact n⋅∂⁡χ/∂⁡S=0; hence,  h˙=n⋅vR-n⋅∂⁡χ∂⁡t,  which in incremental form reduces to the standard contact condition  Δ⁢h=n⋅(Δ⁢xR-Δ⁢xD).  For steady-state conditions n⋅Δ⁢xR=0 and Δ⁢xD=0.  Similarly, the rate of slip is  γ˙α=tα⋅v=Ω⁢tα⋅(n×r)+ω⁢R⁢tα⋅∂⁡χ∂⁡S+tα⋅∂⁡χ∂⁡t-tα⋅vR,  where tα    (α=1,2) are two orthogonal unit vectors tangent to the contact surface so that n=t1×t2. For steady-state conditions ∂⁡χ/∂⁡t=0, so  γ˙α=tα⋅v=Ω⁢tα⋅(n×r)+ω⁢R⁢tα⋅∂⁡χ∂⁡S-tα⋅vR.  Variations in γ˙α yield  δ⁢γ˙α=Ω⁢tα⋅(n×δ⁢r)+ω⁢R⁢tα⋅∂⁡δ⁢χ∂⁡S-tα⋅δ⁢vR.  For straight line rolling we can replace Ω⁢n×r by v0 so that we obtain  γ˙α=tα⋅v0+ω⁢R⁢tα⋅∂⁡χ∂⁡S-tα⋅vR  and  δ⁢γ˙α=ω⁢R⁢tα⋅∂⁡δ⁢χ∂⁡S-tα⋅δ⁢vR.  To complete the formulation, a relationship between frictional stress and slip velocity must be developed. A Coulomb friction law is provided for steady-state rolling. The law assumes that slip occurs if the frictional stress,  τe⁢q=τ12+τ22,  is equal to the critical stress, τc⁢r⁢i⁢t=μ⁢p, where τ1 and τ2 are shear stresses along tα, μ is the friction coefficient, and p is the contact pressure. On the other hand, when τe⁢q<τc⁢r⁢i⁢t, no relative motion occurs. The condition of no relative motion is approximated in Abaqus by stiff viscous behavior  τα=κs⁢γ˙αv,  where γ˙α is the tangential slip velocity and κs is the “stick viscosity,” which follows from the relation  κs=τc⁢r⁢i⁢tγ˙c⁢r⁢i⁢t.  The allowable viscous slip velocity is defined as a fraction of the circumferential velocity  γ˙c⁢r⁢i⁢t=2⁢Ff⁢ω⁢R,  where Ff is a user-defined slip tolerance.  These expressions contribute to the standard virtual work contribution for slip,  δ⁢Π=∫Aτα⁢δ⁢γα⁢d⁢A,  and rate of virtual work for slip,  d⁢δ⁢Π=∫A(d⁢τα⁢δ⁢γα+τα⁢d⁢δ⁢γα)⁢d⁢A. |
