| |  |  | | --- | --- | | Response spectrum analysis | | |  | | | |  | | --- | | Response spectrum analysis is an inexpensive approach to estimate the peak response of a model (usually a model of a structure) subjected to “base motion”: the simultaneous motion of all nodes fixed with boundary conditions. The approach assumes that the system's response is linear, so it can be analyzed in the frequency domain using its lowest eigenmodes—Φα—and eigenfrequencies ωα—extracted in a previous eigenfrequency step. The method is not appropriate if the excitation is so severe that nonlinear effects in the system are important. In such a case the time history of the base excitation must be known and used with a dynamic analysis step to obtain the system's response.  Even for a linear system the response spectrum method provides only estimates of the peak response. If more precise values are required, a modal dynamic analysis step can be used to integrate the system through time and, thus, develop its response to the given base excitation.  In response spectrum analysis the estimates of peak values are obtained by combining the peak responses of the participating modes corresponding to user-specified spectra definitions. Several approximations are introduced by response spectrum analysis. The conversion from a time history of excitation into an equivalent frequency domain spectrum is based on the behavior of a single degree of freedom system. Different spectra are often applied in different excitation directions. Once the spectra are known, the peak modal responses can be calculated. The manner in which these peak modal responses are combined to estimate the peak physical response, together with the manner in which multidirectional excitations are combined, introduces approximations. Since no one method gives good approximations for all cases, several methods are offered. These methods are discussed in the [Regulatory Guide 1.92 (1976)](simathe-c-references.md#simathe-c-references__simathe-c-ref-atomic-192) of the U.S. Nuclear Regulatory Commission, in the papers by [Anagnastopoulos (1981)](simathe-c-references.md#simathe-c-references__simathe-c-ref-anagnastopoulos), [Der Kiureghian (1981)](simathe-c-references.md#simathe-c-references__simathe-c-ref-derkiureghian), and [Smeby (1984)](simathe-c-references.md#simathe-c-references__simathe-c-ref-smeby) and in the book by [A. K. Gupta (1990)](simathe-c-references.md#simathe-c-references__simathe-c-ref-gupta). The choice of the summation rules depends on the particular case and is a matter of the user's judgment.  Since response spectrum analysis is commonly used as a basic design tool, spectra are defined in many design codes for such applications as seismic analysis of buildings. In such cases the user works from the given spectra. In other cases the time history of a known base excitation must first be converted into a response spectrum by considering the response of a single degree of freedom system excited by the known base motion. For this purpose the single degree of freedom system is characterized by its undamped natural frequency, ω, and the fraction of critical damping present in the system, ξ. The equation of motion of the system is integrated through time to find peak values of relative displacement, relative velocity, and absolute acceleration. The integration described in [Modal dynamic analysis](simathe-c-modaldynamic.md) can be used for this purpose, since it is exact when the base motion record varies linearly with time. Thus, the maximum values of displacement, velocity, and acceleration are found for the linear, one degree of freedom system. This process is repeated for all frequency and damping values in the range of interest to construct displacement, velocity, and acceleration spectra, SD⁢(ω,ξ), SV⁢(ω,ξ), and SA⁢(ω,ξ). A Fortran program to build spectra in this way from an acceleration record is given in [Analysis of a cantilever subject to earthquake motion](.._SIMACAEBMKRefMap_simabmk-c-cantilever.md) (file [cantilever\_spectradata.f](../SIMAINPRefResources/cantilever_spectradata.f).)  If there is no damping, the relationship between SD, SV, and SA is given by  SD=1ω⁢SV=1ω2⁢SA.  In Abaqus/Standard it is assumed that the damping is always small, so these relationships are used whenever a conversion is needed.  A response spectrum is defined by giving a table of values of S at increasing values of frequency, ω, for increasing values of damping, ξ. Linear interpolation on a logarithmic scale is used to compute the response for any required frequency and damping factor. Any number of spectra can be defined.  The response spectrum procedure allows up to three spectra, which we denote by k, k=1,2,3, to be applied to the model in orthogonal physical directions defined by their direction cosines, tk. These spectra can come from different excitations (with a certain level of correlation between them), or they can be components of a single base excitation acting in an arbitrary direction.  When modal methods are used to define a model's response, the value of any physical variable is defined from the amplitudes of the modal responses (the “generalized coordinates”), qα. The first stage in the response spectrum procedure is to estimate the peak values of these modal responses. For mode α and spectrum k this is  (qαmax)k=ck⁢SkD⁢∑jtjk⁢Γα⁢j,  where ck is a user-defined scaling parameter, SkD⁢(ω,ξ) is the kth displacement spectrum, tjk is the jth direction cosine for the kth spectrum, and Γα⁢j is the participation factor for mode α in direction j (see [Variables associated with the natural modes of a model](simathe-c-modalvars.md) for the definition of Γα⁢j). Similar expressions for (q˙αmax)k and (q¨αmax)k are obtained by using velocity or acceleration spectra in the above formula.  We now have estimates of the peak responses of the “generalized coordinates”—the amplitudes of the responses of the natural modes of the system for excitation in each direction. If the input spectra in the different directions are components of a single base excitation acting in an arbitrary direction, for each mode we can combine these peak responses into a single value by specifying algebraic summation of the values for the different spatial directions:  qαmax=∑k(qαmax)k.  In this case the modal combinations discussed below still apply, but the subscript k is no longer relevant and should be ignored.  Let us denote by (Rαi⁢(ω,ξ))kmax the peak response of some physical variable Ri (a component of displacement, stress, section force, reaction force, etc.) caused by motion in the natural mode α excited by the response spectrum in excitation direction k at frequency ω and with damping ξ. Denote the component of the eigenvector α associated with Rαi by Φαi. Then  (Rαi)kmax=Φαi⁢(qαmax)k,  (R˙αi)kmax=Φαi⁢(q˙αmax)k,  and  (R¨αi)kmax=Φαi⁢(q¨αmax)k.  We need to combine these estimates of the peak physical responses in the individual modes into estimates of the total peak response of the particular physical variable to the given spectrum, (Ri⁢(ω,ξ))kmax. Since the peak responses in the different modes will not in general occur at the same time, this combination is only an estimate, so several formulæ are offered, as follows:  Summation of the absolute values of the modal peak responses estimates  (Ri)kmax=∑α|(Rαi)kmax|.  This provides the most conservative estimate of the peak response, since it assumes that all modes provide peak response in phase at the same time.  Square root of the summation of the squares (SRSS) estimates  (Ri)kmax=∑α((Rαi)kmax)2.  This summation usually provides a reasonable estimate if the natural frequencies of the modes are well separated.  The Naval Research Laboratory method distinguishes the mode, β, in which the physical variable has its maximum response, and adds the square root of the sum of squares of the peak responses in all other modes to the absolute value of the peak response of that mode. This gives the estimate  (Ri)kmax=|(Rβi)kmax|+∑α≠β((Rαi)kmax)2.  Again, the modes must be reasonably well-spaced in the frequency domain to obtain an accurate estimate with this method.  A variety of methods are available that aim to improve the estimation for structures with closely spaced frequencies. Abaqus/Standard provides two of them: the Ten Percent Method recommended by [Regulatory Guide 1.92 (1976)](simathe-c-references.md#simathe-c-references__simathe-c-ref-atomic-192) of the U.S. Nuclear Regulatory Commission and the Complete Quadratic Combination Method, which was first introduced by [Der Kiureghian (1981)](simathe-c-references.md#simathe-c-references__simathe-c-ref-derkiureghian) and developed by [Smeby and Der Kiureghian (1984)](simathe-c-references.md#simathe-c-references__simathe-c-ref-smeby). Both methods reduce to the SRSS method if the modes are well separated with no coupling among them.  Two additional methods, the Grouping Method and the Double Sum Combination Method, are also available to satisfy [Regulatory Guide 1.92](simathe-c-references.md#simathe-c-references__simathe-c-ref-atomic-192).    Ten Percent Method The Ten Percent Method described in [Regulatory Guide 1.92](simathe-c-references.md#simathe-c-references__simathe-c-ref-atomic-192) modifies the SRSS Method by adding a contribution from all pairs of modes α and β whose frequencies are within 10% of each other, giving the estimate  (Ri)kmax=∑α((Rαi)kmax)2+2⁢∑α<β|(Rαi)kmax⁢(Rβi)kmax|.  The frequencies of modes α and β are considered to be within 10% whenever  ωβ-ωαωβ≤0.1,    α<β.  Complete Quadratic Combination Method The Complete Quadratic Combination Method (CQC) combines the modal response with the formula  (Ri)kmax=∑α∑β(Rαi)kmax⁢ρα⁢β⁢(Rβi)kmax,  where ρα⁢β are cross-correlation coefficients between modes α and β, which depend on the ratio of frequencies and modal damping between the two modes:  ρα⁢β=8⁢ξα⁢ξβ⁢(ξα+rβ⁢α⁢ξβ)⁢rβ⁢α32(1-rβ⁢α2)2+4⁢ξα⁢ξβ⁢rβ⁢α⁢(1+rβ⁢α2)+4⁢(ξα2+ξβ2)⁢rβ⁢α2,  where  rβ⁢α=ωβωα.  If double eigenvalues occur with the same damping coefficient, their correlation coefficient will be ρα⁢β=1. If modes are well-spaced, their cross-correlation coefficient will be small (ρα⁢β≪1) and the method will give the same results as the SRSS method. This method is usually recommended for asymmetrical building systems, since, in such cases, other methods can underestimate the response in the direction of motion and overestimate the response in the transverse direction (see [Response spectra of a three-dimensional frame building](.._SIMACAEEXARefMap_simaexa-c-3dframeresponsespect.md)).  For the case of different base excitations acting along orthogonal directions, we still need to sum over the directions indicated by the subscript k. [Regulatory Guide 1.92](simathe-c-references.md#simathe-c-references__simathe-c-ref-atomic-192) specifies that this directional summation be based on the square root of the sum of the squares summation rule:  (Ri)max=∑k((Ri)kmax)2.  This rule is appropriate when the base motions in different directions are statistically independent (uncorrelated)—when they are acting along “principal directions.” The existence of a set of directions along which the ground motions can be considered uncorrelated is discussed by [Penzien and Watabe (1975)](simathe-c-references.md#simathe-c-references__simathe-c-ref-penzien). Such considerations are especially important when the CQC modal combination method is used. In the Abaqus implementation of the CQC method it is assumed that the horizontal components act along the principal directions and are of equal intensity. For details on the CQC method applied to more general cases, see [Smeby and Der Kiureghian (1984)](simathe-c-references.md#simathe-c-references__simathe-c-ref-smeby).  Grouping Method The Grouping Method, also known as the NRC Grouping Method, improves the response estimation for structures with closely spaced eigenvalues. The modal responses are grouped such that the lowest and highest frequency modes in a group are within 10% and no mode is in more than one group. The modal responses are summed absolutely within groups before performing a SRSS combination of the groups. Within the group responses are summed as  (Rg⁢ri)km⁢a⁢x=|(R1i)km⁢a⁢x|+|(R2i)km⁢a⁢x|⁢…+|(Rni)km⁢a⁢x|,  for n frequencies within any g⁢r group and then performing:  (Ri)km⁢a⁢x=∑g⁢r=1g⁢r=n((Rg⁢ri)kmax)2.  The above expression includes all the groups, and the group can consist of just one frequency response if the frequency does not have another member that is within the 10% limit. The Ten Percent Method, by comparison, will always produce results higher in value than the grouping method.  Double Sum Combination Method The Double Sum Combination Method, also known as Rosenblueth's Double Sum Combination, is the first attempt to evaluate modal correlation based on random vibration theory. The method utilizes the time duration tD of strong earthquake motion. The mode correlation coefficients cα⁢β that also depend on frequencies and damping coefficient ξ lead to the following mode combination:  (Ri)km⁢a⁢x=∑α∑β(Rαi)km⁢a⁢x⁢cα⁢β⁢(Rβi)km⁢a⁢x,  where  cα⁢β=11+(ωα′-ωβ′ξα′⁢ωα+ξβ′⁢ωβ)2,  where  ωα′=ωα⁢1-ξα2,  ξα′=ξα+2tD⁢ωα.  Treating rigid and periodic response within the spectrum Each spectrum can be divided into low-, medium-, and high-frequency regions. Modes are usually uncorrelated for low-frequency regions, partially correlated in the mid range, and correlated with the input data and, hence, between themselves in high-frequency regions. Each of these regions may, therefore, require special consideration. These considerations are addressed by the Gupta and Lindley-Yow methods, where the spectrum frequency range is divided into the periodic and rigid ranges with the respective response called Rp and Rr.  Chapter 3.2.7 from [ASCE4-98](simathe-c-references.md#simathe-c-references__simathe-c-reference-asce-seismicanal) offers an overview of the modal summation methods including methods that recognize the periodic and rigid responses of a given spectrum. [Gupta (1990)](simathe-c-references.md#simathe-c-references__simathe-c-ref-gupta) gives further details on the method. Abaqus uses both references in implementing this idea. The correlation between modes can be done only using the CQC or DSC methods. Both parts of the responses are then combined using the SRSS rule. We split the region in a given spectrum for a periodic and a rigid response. Responses in those regions will be calculated as follows:  Rαr=ηαRα⁢        and⁢         Rαp⁢= (1−ηα2)Rα,  where ηα is a rigid coefficient differently defined for the Gupta and Lindley-Yow methods and Rα denotes a modal response of mode α.  For the Gupta method we define ηα⁢ =log⁡(fαF1)log⁡(F2F1),  where F1 and F2 are user-specified values of frequencies, defining the range of frequencies for the periodic region, with the second value often equivalent to the zero period acceleration (ZPA) frequency, fα is the frequency for the current mode, and ηα⁢= 0⁢   for⁢    fα⁢ ≤F1⁢                 ηα⁢= 1       for⁢    fα⁢ ≥F2⁢.  For the Lindley-Yow method ηα⁢= ZPASaα,  where Saα is a spectrum acceleration value at frequency fα.  Periodic responses are treated using the CQC or DSC combination method with its respective correlation coefficient, cαβ: (Rp)2=∑α∑βcαβRαpRβp=∑α∑βcαβ(1−ηα2)(1−ηβ2)⋅RαRβ.  Since rigid responses are in-phase with external excitation and between themselves, they are summed algebraically across modes: Rr=∑αRαr=∑αηαRα  (Rr)2=(∑αηαRα)(∑βηβRβ)=∑α∑βηαηβRαRβ.  Periodic and rigid responses are summed using the SRSS method for total response: R2=(Rr)2+(Rp)2=∑α∑β[ηαηβ+cαβ(1−ηα2)(1−ηβ2)]RαRβ=∑α∑βc¯αβRαRβ, with c¯αβ=ηαηβ+cαβ(1−ηα2)(1−ηβ2).  The above expression can be rewritten as R2=(Rr)2+(Rp)2=∑α∑βc¯αβRαRβ=∑αRα2+∑α≠βc¯αβRαRβ=∑αRα2+2∑α∑β>αc¯αβRαRβ.  The Lindley-Yow method is known to give in-phase modes correlation for frequencies below the value of ZPA in the low-frequency range since ZPA is the only divider for splitting the regions. Therefore, we use the following logic to alleviate the disadvantage of this method: the maximum value of the response for the particular acceleration spectrum is found together with its frequency value. The correlation factor is set to zero for all modes below this frequency point. If you do not want to use this modification, use modes that are higher than this frequency point.  Missing Mass Method As with any modal superposition technique, response spectrum analysis cannot include a sufficient number of eigenmodes to accurately represent the response. Instead of adding more eigenmodes for superposition, you can use the missing mass method to augment the missing inertia from the higher mode range. This higher mode range usually contributes to the rigid body response and, thus, is well suited for summation methods that split the frequency range into periodic and rigid phases. In this implementation, you can use the missing mass method for any modal summation type available, which is a matter of judgment on your part.  When using this approach, we assume that the total response (for example, the displacement field) can be split into two parts: one that represents the response carried by a selected number of eigenmodes, u, and the remaining one, ur, which corresponds to the missing eigenmodes and relates to missing kinetic energy. The total displacement consists of the sum of the above: ut⁢ = u⁢  + ur. For the particular use case of loading consisting of inertia loads due to an acceleration earthquake record equal to M⁢ag , after substituting these relations into the equation of motion, we get a pseudostatic relation for the additional vector. This relation plays a role as a residual vector acting in the direction of the user-supplied direction of the earthquake: Kur⁢ = −M(Ud⁢⁢− ∑α=1nΦα⁢Γα) ag⁢, where Ud represents unit, static displacement of the base in the direction of the base motion acceleration record (earthquake acceleration) ag. The residual static vector ur  is normalized and is orthogonalized against all eigenmodes used for modal superposition. This vector is used as an additional vector taking part in modal superposition with its own generalized coordinate based on the eigenvalue associated with it. Each spectrum used in the response spectrum analysis has its own residual vector acting in the direction of this spectrum. As a result, a maximum of three residual vectors can be calculated. |
