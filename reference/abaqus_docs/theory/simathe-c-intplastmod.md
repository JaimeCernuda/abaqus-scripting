The only rate equations are the evolutionary rule for the hardening, the flow rule, and the strain rate decomposition.  The simplest operator that provides unconditional stability for integration of rate equations is the backward Euler method: applying this method to the flow rule ([Equation 5](simathe-c-plastoverview.md#simathe-c-plastoverview__simathe-c-plastoverview-eq5)) gives  (1)Δ⁢εp⁢l=∑iΔ⁢λi⁢∂⁡gi∂⁡σ,  and applying it to the hardening evolution equations, [Equation 6](simathe-c-plastoverview.md#simathe-c-plastoverview__simathe-c-plastoverview-eq6), gives  (2)Δ⁢Hi,α=Δ⁢λi⁢hi,α.  In these equations and throughout the remainder of this section any quantity not specifically associated with a time point is taken at the end of the increment (at time t+Δ⁢t). The strain rate decomposition, [Equation 2](simathe-c-plastoverview.md#simathe-c-plastoverview__simathe-c-plastoverview-eq2), is integrated over a time increment as  Δ⁢ε=Δ⁢εe⁢l+Δ⁢εp⁢l,  where Δ⁢ε is defined by the central difference operator:  Δ⁢ε=sym⁢[∂⁡Δ⁢x∂⁡(xt+12⁢Δ⁢x)].  We integrate the total values of each strain measure as the sum of the value of that strain at the start of the increment, rotated to account for rigid body motion during the increment, and the strain increment. The rotation to account for rigid body motion during the increment is defined approximately using the algorithm of [Hughes and Winget (1980)](simathe-c-references.md#simathe-c-references__simathe-c-ref-hughes-winget). This integration allows the strain rate decomposition to be integrated into  (3)ε=εe⁢l+εp⁢l.  From a computational viewpoint the problem is now algebraic: we must solve the integrated equations of the constitutive model for the state at the end of the increment. The set of equations that define the algebraic problem are the strain decomposition, [Equation 3](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq3); the elasticity, [Equation 3](simathe-c-plastoverview.md#simathe-c-plastoverview__simathe-c-plastoverview-eq3); the integrated flow rule, [Equation 1](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq1); the integrated hardening laws, [Equation 2](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq2); and for rate independent models, the yield constraints  (4)fi=0,  for active systems (systems in which fi<0 have Δ⁢λi=0).  We assume that the flow surface is sufficiently smooth so that its (second) derivatives with respect to stress and the hardening parameters are well-defined. This is generally true for the models in Abaqus: the exceptions occur at corners or vertices of the surfaces. These special cases are handled individually when they arise.  For some plasticity models the algebraic problem can be solved in closed form. For other models it is possible to reduce the problem to a one variable or a two variable problem that can then be solved to give the entire solution. For example, the Mises yield surface—which is generally used for isotropic metals, together with linear, isotropic elasticity—is a case for which the integrated problem can be solved exactly or in one variable (see [Isotropic elasto-plasticity](simathe-c-isoelastoplast.md)).  For other rate-independent models with a single yield system the algebraic problem is considered to be a problem in the components of Δ⁢εp⁢l. Once these have been found—the elasticity—together with the integrated strain rate decomposition—define the stress. The flow rule then defines Δ⁢λ and the hardening laws define the increments in the hardening variables.  We now derive the equations for the Newton solution of the integrated problem for the case of rate-independent plasticity with a single yield system. The rate-dependent problem with a single yield system is solved in a similar way. For the particular cases of multiple, independent, yield systems (concrete and jointed material) particular techniques are used for this algebraic solution, taking advantage of the simplifications available in those particular models. The concrete model and its integration are described in [An inelastic constitutive model for concrete](simathe-c-concrete.md), and the jointed material model is described in [Constitutive model for jointed materials](simathe-c-jointedmat.md).  During the solution, the elasticity relationship and the integrated strain rate decomposition are satisfied exactly, so that  (5)cσ=-De⁢l:cε,  where cσ is the correction to the stress, cε is the correction to the plastic strain increments, and  De⁢l=∂2⁡U∂⁡εe⁢l⁢∂⁡εe⁢l  is the tangent elasticity matrix.  The hardening laws are also satisfied exactly (because the increments of the hardening parameters are defined from these laws) so that  cα=hαcλ+Δλ(∂⁡hα∂⁡σ:cσ+∂⁡hα∂⁡Hβcβ),  where cα is the correction to Δ⁢Hα and cλ is the correction to Δ⁢λ.  This set of equations can be rewritten  (6)cα=H^α⁢cλ+w^α:cσ,  where  H^α=[δα⁢β-Δ⁢λ⁢∂⁡hβ∂⁡Hα]-1⁢hβ  and  w^α=Δ⁢λ⁢[δα⁢β-Δ⁢λ⁢∂hβ∂Hα]-1⁢∂hβ∂σ.  The flow rule is not satisfied exactly until the solution has been found, so it gives the Newton equations  cε-cλ∂⁡g∂⁡σ-Δλ(∂2⁡g∂⁡σ⁢∂⁡σ:cσ+∂2⁡g∂⁡σ⁢∂⁡Hαcα)=Δλ∂⁡g∂⁡σ-Δεp⁢l.  Using [Equation 5](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq5) and [Equation 6](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq6) allows these equations to be rewritten as  (7)[I+ΔλN^:De⁢l]:cε-n^cλ=Δλ∂⁡g∂⁡σ-Δεp⁢l,  where  N^=∂2⁡g∂⁡σ⁢∂⁡σ+∂2⁡g∂⁡σ⁢∂⁡Hα⁢w^α,  and  n^=∂⁡g∂⁡σ+Δ⁢λ⁢∂2⁡g∂⁡σ⁢∂⁡Hα⁢H^α.  Likewise, the yield condition is not satisfied exactly during the Newton iteration, so  ∂⁡f∂⁡σ:cσ+∂⁡f∂⁡Hα⁢cα=-f.  Using [Equation 5](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq5) and [Equation 6](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq6) in this equation gives  (8)m^:De⁢l:cε-∂⁡f∂⁡Hα⁢H^α⁢cλ=f,  where  m^=∂⁡f∂⁡σ+∂⁡f∂⁡Hα⁢w^α.  We now eliminate cλ between [Equation 7](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq7) and [Equation 8](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq8). Taking [Equation 7](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq7) along m^:De⁢l and using [Equation 8](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq8) gives  cλ=1d⁢Δ⁢λ⁢m^:De⁢l:N^:De⁢l:cε-1d⁢m^:De⁢l:(Δ⁢λ⁢∂⁡g∂⁡σ-Δ⁢εp⁢l)+1d⁢f,  where  d=m^:De⁢l:n^-∂f∂Hα⁢H^α.  Using this equation in [Equation 7](simathe-c-intplastmod.md#simathe-c-intplastmod__simathe-c-intplastmod-eq7) then gives  [I+ΔλZ:N^:De⁢l]:cε=Z:(Δλ∂⁡g∂⁡σ-Δεp⁢l)+1dfn^,  where  Z=I-1d⁢n^⁢m^:De⁢l,  which is a set of linear equations solved for the cε. The solution is then updated and the Newton loop continued until the flow equation and yield constraint are satisfied.  The solution for rate-dependent plasticity models with a single yield function is developed in the same way, the only differences being the lack of a yield constraint and the identification of Δ⁢λ with time.    Tangent matrix The tangent matrix for the material, ∂⁡σ/∂⁡ε, is required when Abaqus/Standard is being used for implicit time integration and Newton's method is being used to solve the equilibrium equations. The matrix is obtained directly by taking variations of the integrated equations with respect to all solution parameters, and then solving for the relationship between σ and ε. The procedure closely follows the derivation used above for the Newton solution: the result is the tangent matrix  σ=D:ε,  where  D=[I+ΔλDe⁢l:Z:N^]-1:De⁢l:Z. |
