Benefits: The user subroutine makes it easier for you to compute, create, and elaborate user-defined element output variables and provides you the flexibility to implement a broad variety of data consolidation schemes that can reduce the amount of results that must be stored in the output database.  User subroutine UVAREL gives you a method to define variables at the element level to reduce the amount of output data if the results at every material point are not needed. The reduction of output data can be significant, especially for composite elements with many layers.  The user-defined element output variables that are defined in user subroutine UVAREL usually depend on other Abaqus output variables such as stresses, strains, and section forces. You can access these output quantities by calling the new utility routines getElMPtVar and getSecVar.  You can invoke the following new utility routines from user subroutine UVAREL:  * getElMPtVar returns material point information * getSecVar returns integration point information * getUVarElOrientationName returns the name of the element   orientation * getUVarElMaterialName returns the name of the material  Related topics:  [UVAREL](.._SIMACAESUBRefMap_simasub-c-uvarel.md), [\*ELEMENT USER OUTPUT VARIABLES](.._SIMACAEKEYRefMap_simakey-r-elementuseroutputvariables.md), [Obtaining Material Point Information from User Subroutine UVAREL](.._SIMACAESUBRefMap_simasub-c-getelmptvar.md), [Obtaining the Element Orientation Name from User Subroutine UVAREL](.._SIMACAESUBRefMap_simasub-c-getuvarelorientationname.md), [Obtaining the Material Name from User Subroutine UVAREL](.._SIMACAESUBRefMap_simasub-c-getuvarelmaterialname.md), [Obtaining Element Section Information from User Subroutine UVAREL](.._SIMACAESUBRefMap_simasub-c-getsecvar.md), and [UVAREL](.._SIMACAEVERRefMap_simaver-c-uvarel.md). Benefits: Accessing the displacements and accelerations information in the user subroutine is useful when the distributed loads are a function of the displacements and accelerations.  The array velocity available in earlier releases in the VDLOAD argument list is now named vua. It is also extended to include velocities, displacements, and accelerations, giving you the option to define distributed loads as function of these quantities with user subroutine VDLOAD. This change does not affect existing VDLOAD implementations based on the interface available in earlier releases.  Related topics:  [VDLOAD](.._SIMACAESUBRefMap_simasub-c-vdload.md).  2024 FD01 UEXPAN You can now define field expansion strains and, in a porous medium, pore fluid field expansion strains directly in user subroutine UEXPAN.  Benefits: Defining the values in the user subroutine is particularly useful when the field expansion strains are complicated functions of temperature, field variables, or state variables.  The argument list of user subroutine UEXPAN has been enhanced to provide additional information that you can use to discern if the call corresponds to a thermal or a field expansion definition, the field number and, in the case of a porous medium, if the call corresponds to the expansion definition for the pore fluid. This change does not affect existing UEXPAN implementations based on the interface available in earlier releases.  Related topics:  [UEXPAN](.._SIMACAESUBRefMap_simasub-c-uexpan.md) and [UEXPAN](.._SIMACAEVERRefMap_simaver-c-uexpan.md). |
