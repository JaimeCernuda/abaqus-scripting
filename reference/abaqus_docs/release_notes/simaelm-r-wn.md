| |  |  | | --- | --- | | Elements | | |  | | | |  | | --- | | This page describes recent changes in Abaqus Elements.   * [2024 FD03](#simaelm-r-wn__rs-R2024x-FD03) * [2024 FD01](#simaelm-r-wn__rs-R2024x-FD01) | | |   2024 FD03 Bending Stabilization for Full-Integration Linear Elements You can now control the activation and the level of bending stabilization for full-integration linear elements.  Benefits: Bending stabilization improves robustness for models using full-integration linear elements modeled with hyperelastic, hyperfoam, low-density foam, or user-defined materials and subjected to large bending deformations.  For full-integration linear elements modeled with hyperelastic, hyperfoam, low-density foam, or user-defined materials, spurious unstable patterns might develop in some situations due to excessively soft bending behavior. The formulation for this class of problems includes a bending stabilization term to improve the element performance. In earlier releases, the bending stabilization was active by default for built-in hyperelastic, hyperfoam, and low-density foam materials, but it was not active for user-defined materials. This could lead to different outcomes (convergence behavior and results) when you modeled the same material behavior using either a built-in material model or a user-defined material model. In addition, you had no control over the activation/deactivation of the stabilization algorithm or on the degree (magnitude) of stabilization.  The example below shows a two-dimensional rubber ring compressed by a rigid plate against a base that is also made out of rubber. [Figure 1](#simaelm-r-wn__fig_k1w_dcp_cbc) shows the results from a simulation that does not make use of the bending stabilization term. The analysis runs into convergence difficulties and fails to converge following the initiation of self-contact in the ring. Conversely, [Figure 2](#simaelm-r-wn__fig_ljd_sbp_cbc) shows the results from a simulation that utilizes bending stabilization. In this situation, the analysis completes. [Figure 3](#simaelm-r-wn__fig_dfh_wl1_jbc) shows the force-displacement behavior of the rigid plate’s reference node for the two models. The two responses are in close agreement until convergence is lost in the model without stabilization, demonstrating that apart from improving convergence, the bending stabilization’s impact on overall model response is small. The bending stabilization term is very important for problems involving a relatively soft material subjected to large bending deformations. Figure 1. Related topics:  [Using Section Controls for Bending Stabilization](.._SIMACAEELMRefMap_simaelm-c-sectioncontrol.md#sma-topic_scx_mxz_y1c).  2024 FD01 Varying Contact Angles for SLIPRING Connectors You can now request that Abaqus/Standard compute the contact angle of a SLIPRING connector at the beginning of the analysis and update it through the analysis.  Benefits: If the slipring connector models a belt-pulley assembly, basing the calculations on the current value of the contact angle more accurately calculates the frictional force between the pulley and the belt.  In earlier releases, Abaqus/Standard assumed the SLIPRING contact angle to be either a constant (specified) value or zero (the default).  [Figure 4](#simaelm-r-wn__fig_zgc_nnn_lzb) shows a belt-pulley system between nodes 1, 2, and 3. The belt is modeled using two slipring connector elements and passes over a pulley at node 2. The frictional force between the belt and the pulley depends on the contact angle between them. In this example, the contact angle changes as nodes 1 and 3 are displaced from their original positions. Abaqus/Standard now accounts for the change in this contact angle for the friction calculations. Figure 4. SLIPRING connection type with varying contact angle.
