| |  |  | | --- | --- | | \*EPJOINT | | |  | | | |  | | --- | | Define properties for elastic-plastic joint elements. This option is used to define the properties for elastic-plastic joint elements. The [JOINT ELASTICITY](simakey-r-jointelasticity.md#simakey-r-jointelasticity) and, if plasticity is to be defined, [JOINT PLASTICITY](simakey-r-jointplasticity.md#simakey-r-jointplasticity) options must immediately follow this option.  This page discusses:   * [Required parameters](#simakey-r-epjoint__simakey-r-epjoint-s-paramsrequired1) * [Optional parameters](#simakey-r-epjoint__simakey-r-epjoint-s-paramsoptional1) * [Data line to define spud can geometry with SECTION=SPUD CAN](#simakey-r-epjoint__simakey-r-epjoint-s-datadesc1) | | |  | | --- | | See Also | | [\*JOINT ELASTICITY](simakey-r-jointelasticity.md#simakey-r-jointelasticity) | | [\*JOINT PLASTICITY](simakey-r-jointplasticity.md#simakey-r-jointplasticity) |  |  | | --- | |  | | In Other Guides | | [Elastic-Plastic Joints](.._SIMACAEELMRefMap_simaelm-c-epjoint.md) | |   ProductsAbaqus/Standard  TypeModel data  LevelPartPart instance  Required parameters ELSET  Set this parameter equal to the name of the element set containing the elastic-plastic joint elements for which properties are being defined.  ORIENTATION  Set this parameter equal to the name given to the [ORIENTATION](simakey-r-orientation.md#simakey-r-orientation) definition ([Orientations](.._SIMACAEMODRefMap_simamod-c-orientation.md)) that gives the orientation of the local system in the joint.  Optional parameters SECTION  Set this parameter equal to SPUD CAN if the joint models a spud can. If the joint does not model a spud can, this parameter is not needed.  Data line to define spud can geometry with SECTION=SPUD CAN First (and only) line  1. Do, diameter of spud can cylindrical portion. 2. θ, conical spud can cone angle in degrees. Enter a blank, zero, or 180 for a cylindrical spud can.   Include the [JOINT ELASTICITY](simakey-r-jointelasticity.md#simakey-r-jointelasticity) and [JOINT PLASTICITY](simakey-r-jointplasticity.md#simakey-r-jointplasticity) options as needed to define the joint behavior. |
