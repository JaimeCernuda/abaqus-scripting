Data line to define the bulk viscosity parameters First (and only) line  1. Linear bulk viscosity parameter, b1. If the [BULK VISCOSITY](simakey-r-bulkviscosity.md#simakey-r-bulkviscosity) option is omitted or is specified without the data line, the default value is 0.06. If the data line is given and the value of b1 is omitted, the default value is 0.0. 2. Quadratic bulk viscosity parameter, b2. If the [BULK VISCOSITY](simakey-r-bulkviscosity.md#simakey-r-bulkviscosity) option is omitted or is specified without the data line, the default value is 1.2. If the data line is given and the value of b2 is omitted, the default value is 0.0. |
