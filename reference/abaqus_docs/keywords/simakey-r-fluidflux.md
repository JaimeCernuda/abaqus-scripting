If this parameter is omitted, the reference magnitude is applied immediately at the beginning of the step, regardless of the procedure being used in the step.  OP  Set OP=MOD (default) for existing fluid fluxes to remain, with this option defining fluid fluxes to be added (to cavities with no fluid flux loading) or modified (to cavities with fluid flux loading).  Set OP=NEW if all existing fluid fluxes applied to the model should be removed.  Data line to define the fluid mass flow rate First (and only) line  1.
