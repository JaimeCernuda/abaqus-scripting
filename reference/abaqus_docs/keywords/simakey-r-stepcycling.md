| |  |  | | --- | --- | | \*STEP CYCLING | | |  | | | |  | | --- | | Define a step or series of steps to be repeated. This option is used to specify a step or series of steps to be repeated over a set number of cycles. Early termination of step cycling might be triggered from within a step using step cycling controls with sensor-based or wear-based criteria.
