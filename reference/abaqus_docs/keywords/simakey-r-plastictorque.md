| |  |  | | --- | --- | | \*PLASTIC TORQUE | | |  | | | |  | | --- | | Define the plastic torsional moment behavior for frame elements. This option can be used only in conjunction with the [FRAME SECTION](simakey-r-framesection.md#simakey-r-framesection) option and is available only for FRAME3D elements. It describes the torsional moment in a frame element as a function of the plastic rotation about the element's axis.
