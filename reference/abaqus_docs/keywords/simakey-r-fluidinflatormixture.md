Optional parameters TYPE  Set TYPE=MASS FRACTION (default) to use the mass fraction for a mixture of ideal gases.  Set TYPE=MOLAR FRACTION to use the molar fraction for a mixture of ideal gases.  Data lines to define gas species for a fluid inflator First line  1. Fluid behavior name. 2. Etc., up to eight fluid behavior names per line.   Repeat this data line as often as necessary to define all gas species for this inflator.  Next line  1. Inflation time. 2. Mass fraction or molar fraction for the first entry of fluid behavior. 3. Mass fraction or molar fraction for the second entry of fluid behavior. 4. Etc., mass fraction or molar fraction up to the seventh entry of fluid    behavior.  Subsequent lines (only needed if the NUMBER SPECIES parameter has a value greater than seven)  1. Mass fraction or molar fraction for the eighth entry of fluid behavior. 2. Etc., mass fraction or molar fraction for up to eight entries of fluid    behavior per line.  Repeat this set of data lines as often as necessary to define the mass fraction or molar fraction as a function of inflation time. |
