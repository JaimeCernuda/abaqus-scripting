| |  |  | | --- | --- | | \*INCIDENT WAVE | | |  | | | |  | | --- | | Define incident wave loading for a blast or scattering load on a boundary. The preferred interface for applying incident wave loading is the [INCIDENT WAVE INTERACTION](simakey-r-incidentwaveinteraction.md#simakey-r-incidentwaveinteraction) option used in conjunction with the [INCIDENT WAVE INTERACTION PROPERTY](simakey-r-incidentwaveinteractionproperty.md#simakey-r-incidentwaveinteractionproperty) option. The alternative interface uses the [INCIDENT WAVE](simakey-r-incidentwave.md#simakey-r-incidentwave) option to apply incident wave loading.  The [INCIDENT WAVE PROPERTY](simakey-r-incidentwaveproperty.md#simakey-r-incidentwaveproperty) option must be used in conjunction with the [INCIDENT WAVE](simakey-r-incidentwave.md#simakey-r-incidentwave) option. If the incident wave field includes a reflection off a plane outside the boundaries of the mesh, this effect can be modeled with the [INCIDENT WAVE REFLECTION](simakey-r-incidentwavereflection.md#simakey-r-incidentwavereflection) option. Required parameters PROPERTY  Set this parameter equal to the name of the [INCIDENT WAVE PROPERTY](simakey-r-incidentwaveproperty.md#simakey-r-incidentwaveproperty) option defining the incident wave field.  Required, mutually exclusive parameters ACCELERATION AMPLITUDE  Set this parameter equal to the name of the amplitude curve defining the fluid particle acceleration time history at the standoff point ([Amplitude Curves](.._SIMACAEPRCRefMap_simaprc-c-amplitude.md)). This amplitude curve will be used to compute the fluid traction only: a solid surface requiring a pressure load cannot be specified on the data line of an [INCIDENT WAVE](simakey-r-incidentwave.md#simakey-r-incidentwave) option if the ACCELERATION AMPLITUDE parameter is used.  This parameter is valid only for planar incident waves using the [INCIDENT WAVE PROPERTY](simakey-r-incidentwaveproperty.md#simakey-r-incidentwaveproperty), TYPE=PLANE option. Reflected loads, using the [INCIDENT WAVE REFLECTION](simakey-r-incidentwavereflection.md#simakey-r-incidentwavereflection) option, are not permitted in this case.  PRESSURE AMPLITUDE  Set this parameter equal to the name of the amplitude curve defining the fluid pressure time history at the standoff point ([Amplitude Curves](.._SIMACAEPRCRefMap_simaprc-c-amplitude.md)). The corresponding fluid traction, if required, will be computed from the pressure amplitude reference.  Data lines to define an incident wave First line  1. Surface name. 2. Reference magnitude.   Repeat this data line as often as necessary to describe the loading on the surfaces due to the incident wave. In problems involving fluid-solid boundaries, both the fluid surface and the solid surface comprising the boundary must have an incident wave load specified, using the appropriate load type. |
