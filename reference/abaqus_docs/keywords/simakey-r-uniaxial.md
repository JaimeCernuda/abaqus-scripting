| |  |  | | --- | --- | | \*UNIAXIAL | | |  | | | |  | | --- | | Characterize fabric materials through loading and unloading test data. This option is used to indicate the start of shear or uniaxial test data along a particular direction to define the behavior of a fabric material. It must be used in conjunction with the [FABRIC](simakey-r-fabric.md#simakey-r-fabric) option.
