PROGRAM  Set PROGRAM=MULTIPHYSICS for exchange of data between Abaqus and the SIMULIA Co-Simulation Engine, which in turn can exchange data with third-party analysis programs that support the SIMULIA Co-Simulation Engine.  Set PROGRAM=ABAQUS for exchange of data with another Abaqus analysis in an Abaqus/Standard to Abaqus/Explicit co-simulation.  Optional parameters CONTROLS  This parameter is required when PROGRAM=ABAQUS.  Set this parameter equal to the name of the co-simulation controls to be used to define the coupling and rendezvousing scheme.  There are no data lines associated with this option. |
