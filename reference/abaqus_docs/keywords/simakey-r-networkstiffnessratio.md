| |  |  | | --- | --- | | \*NETWORK STIFFNESS RATIO | | |  | | | |  | | --- | | Specify stiffness ratios for viscoelastic networks. This option is used to specify the stiffness ratios for viscoelastic networks for a material model defined using the parallel rheological framework.  This page discusses:   * [Required parameters](#simakey-r-networkstiffnessratio__simakey-r-networkstiffnessratio-s-paramsrequired1) * [Optional parameters](#simakey-r-networkstiffnessratio__simakey-r-networkstiffnessratio-s-paramsoptional1) * [Data lines to define the stiffness ratio if N=1](#simakey-r-networkstiffnessratio__simakey-r-networkstiffnessratio-s-datadesc1) * [Data lines to define the stiffness ratio if N=2](#simakey-r-networkstiffnessratio__simakey-r-networkstiffnessratio-s-datadesc2) * [Data lines to define the stiffness ratio for higher values of N](#simakey-r-networkstiffnessratio__simakey-r-networkstiffnessratio-s-datadesc3) | | |  | | --- | | See Also | | [\*VISCOELASTIC](simakey-r-viscoelastic.md#simakey-r-viscoelastic) |  |  | | --- | |  | | In Other Guides | | [Parallel Rheological Framework](.._SIMACAEMATRefMap_simamat-c-nonlinvisco.md) | |   ProductsAbaqus/StandardAbaqus/Explicit  TypeModel data  LevelModel  Required parameters N  Set this parameter equal to the number of viscoelastic networks in the model.  Optional parameters DEPENDENCIES  Set this parameter equal to the number of field variable dependencies included in the definition of the stiffness ratios, in addition to temperature. If this parameter is omitted, the hardening behavior does not depend on field variables. See [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md#simamat-c-materialdata) for more information.  Data lines to define the stiffness ratio if N=1 First line  1. Stiffness ratio for the viscoelastic network 1, r1. 2. Temperature. 3. First field variable. 4. Etc., up to eight entries per line.  Subsequent lines (only needed if the number of entries is greater than eight)  1. Seventh field variable. 2. Etc., up to eight entries per line.   Repeat this set of data lines as often as necessary to define the dependence of the stiffness ratios on temperature and other predefined field variables.  Data lines to define the stiffness ratio if N=2 First line  1. Stiffness ratio for the viscoelastic network 1, r1. 2. Stiffness ratio for the viscoelastic network 2, r2. 3. Temperature. 4. First field variable. 5. Etc., up to eight entries per line.  Subsequent lines (only needed if the number of entries is greater than eight)  1. Sixth field variable. 2. Etc., up to eight entries per line.   Repeat this set of data lines as often as necessary to define the dependence of the stiffness ratios on temperature and other predefined field variables.  Data lines to define the stiffness ratio for higher values of N Data lines  1. The data lines for higher values of N follow the same pattern. First, give ri for i from 1 to N. Then, give the temperature. Finally, give the values of the field variables. Exactly eight data values should be given on each line. |
