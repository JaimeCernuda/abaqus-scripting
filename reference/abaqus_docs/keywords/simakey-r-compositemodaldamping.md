| |  |  | | --- | --- | | \*COMPOSITE MODAL DAMPING | | |  | | | |  | | --- | | Specify composite modal damping for modal analyses based on the SIM architecture. This option can be used only with the SIM architecture and can be used only with the [FREQUENCY](simakey-r-frequency.md#simakey-r-frequency) option. It specifies the composite modal damping data that enable calculation of the weighted mass and stiffness composite damping per each of the extracted eigenmodes during an eigenvalue extraction analysis. The damping data are requested for the mass proportional fraction of critical damping and for the stiffness proportional fraction of critical damping for specified element sets. This option can also be used to assign critical damping fractions to both mass and stiffness matrix input.
