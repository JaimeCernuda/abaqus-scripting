If this parameter is omitted, the inflation time will be equal to the actual time elapsed since activation.  MASS FLOW AMPLITUDE  Set this parameter equal to the name of the amplitude curve by which to modify the mass flow rate. This parameter is valid only if the mass flow rate is prescribed directly in the inflator property definition. It will be ignored if the mass flow rate is calculated by using tank test data or the dual pressure method.
