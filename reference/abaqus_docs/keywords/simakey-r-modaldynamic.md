This option is used to provide dynamic time history response as a linear perturbation procedure using modal superposition. In this case the initial displacements are zero, and the initial velocities are taken from the [INITIAL CONDITIONS](simakey-r-initialconditions.md#simakey-r-initialconditions), TYPE=VELOCITY option if it is used; otherwise, they are zero. Step time begins at zero.  Set CONTINUE=YES to specify that this step is to carry over the initial conditions from the end of the immediately preceding [MODAL DYNAMIC](simakey-r-modaldynamic.md#simakey-r-modaldynamic) step or static perturbation step. If this preceding step is a [MODAL DYNAMIC](simakey-r-modaldynamic.md#simakey-r-modaldynamic) step, both the velocities and the displacements from the end of this step are used as the initial conditions for the current step. If this preceding step is a static perturbation step, the displacements from this step are used as the initial displacements for the current step and the initial velocities are taken from the [INITIAL CONDITIONS](simakey-r-initialconditions.md#simakey-r-initialconditions), TYPE=VELOCITY option if it is used; otherwise, they are zero. Step time is continued from the immediately preceding [MODAL DYNAMIC](simakey-r-modaldynamic.md#simakey-r-modaldynamic) or static perturbation step.  SOLVER  Set SOLVER=STATE SPACE (default) to use the state space solver.  Set SOLVER=CONVENTIONAL to use the conventional solver.  Data line for a transient modal dynamic analysis First (and only) line  1. Time increment to be used. 2. Time period. |
