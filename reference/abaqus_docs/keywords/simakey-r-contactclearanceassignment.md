This option is used to define initial contact clearances between contact surfaces and to control how initial contact overclosures are resolved in the general contact algorithm. Data lines to define nondefault contact clearances First line  1. The name of the first (single-sided) surface. 2. The name of the second (single-sided) surface. 3. The name of the model data [CONTACT CLEARANCE](simakey-r-contactclearance.md#simakey-r-contactclearance) definition to be used. 4. Optional data item when a [CONTACT CLEARANCE](simakey-r-contactclearance.md#simakey-r-contactclearance) definition specified with ADJUST=YES is referenced: 5. Blank, the “word” MAIN, or the “word”    SECONDARY to indicate how    the surfaces will be treated while adjusting the surface nodes    to resolve contact clearance violations. A blank entry indicates    that the interaction will be treated as balanced main-secondary.    A setting of MAIN or    SECONDARY specifies the    behavior of the first surface in a pure main-secondary    interaction.   Repeat this data line as often as necessary. If the contact clearance assignments overlap, the last assignment applies in the overlap region. |
