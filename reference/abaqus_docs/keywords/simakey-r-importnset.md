| |  |  | | --- | --- | | \*IMPORT NSET | | |  | | | |  | | --- | | Import node set definitions from a previous Abaqus/Explicit or Abaqus/Standard analysis. This option is used to import node set definitions that were defined in a previous Abaqus/Explicit or Abaqus/Standard analysis. If the [IMPORT NSET](simakey-r-importnset.md#simakey-r-importnset) option is used, it must appear after the [IMPORT](simakey-r-import.md#simakey-r-import) option.  If the [IMPORT NSET](simakey-r-importnset.md#simakey-r-importnset) option is used with the RENAME parameter, it must appear after an [IMPORT](simakey-r-import.md#simakey-r-import) option with active RENAME and NOFFSET parameters.  If this option is omitted or is specified without any data lines and all [IMPORT](simakey-r-import.md#simakey-r-import) options that reference a previous analysis do not include the RENAME parameter, all the node sets relevant to the analysis are imported. References to nodes that are not imported are removed from imported sets.  This option is ignored if you specify the full-model input format in the [\*IMPORT CONTROLS](simakey-r-importcontrols.md#simakey-r-importcontrols) option because data for all imported node sets are given in the input.
