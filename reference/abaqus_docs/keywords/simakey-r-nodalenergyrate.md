| |  |  | | --- | --- | | \*NODAL ENERGY RATE | | |  | | | |  | | --- | | Define critical energy release rates at nodes. This option is used to define variable critical energy release rates on a nodal basis. The critical energy release rate data defined with this option is ignored unless the NODAL ENERGY RATE parameter is included on the [FRACTURE CRITERION](simakey-r-fracturecriterion.md#simakey-r-fracturecriterion), TYPE=VCCT option or the [FRACTURE CRITERION](simakey-r-fracturecriterion.md#simakey-r-fracturecriterion), TYPE=FATIGUE option. The critical energy release rates for the bounding nodes or node sets must have been defined earlier. If the node sets do not have the same number of nodes, the extra nodes in the longer set are ignored.  INPUT  Set this parameter equal to the name of the alternate input file containing the data lines for this option. See [Input Syntax Rules](.._SIMACAEMODRefMap_simamod-c-inputsyntax.md) for the syntax of such file names. If this parameter is omitted, it is assumed that the data follow the keyword line. GI⁢I⁢I⁢C,    Mode III critical energy release rate.   Repeat this data line as often as necessary to define the variation in critical energy release rates.  Data lines when the GENERATE parameter is included First line  1. Node number or node set label that defines the first bound for the generate    operation. 2. Node number or node set label that defines the second bound for the generate    operation. 3. Number of intervals between the bounding nodes or node sets. 4.
