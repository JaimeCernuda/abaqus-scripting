| |  |  | | --- | --- | | \*CONCRETE TENSION STIFFENING | | |  | | | |  | | --- | | Define postcracking properties for the concrete damaged plasticity model. This option is used to define cracking and postcracking properties for the concrete damaged plasticity material model. The [CONCRETE TENSION STIFFENING](simakey-r-concretetensionstiffening.md#simakey-r-concretetensionstiffening) option must be used in conjunction with the [CONCRETE DAMAGED PLASTICITY](simakey-r-concretedamagedplasticity.md#simakey-r-concretedamagedplasticity) and [CONCRETE COMPRESSION HARDENING](simakey-r-concretecompressionhardening.md#simakey-r-concretecompressionhardening) options. In addition, the option can be used with the [CONCRETE TENSION DAMAGE](simakey-r-concretetensiondamage.md#simakey-r-concretetensiondamage) and/or [CONCRETE COMPRESSION DAMAGE](simakey-r-concretecompressiondamage.md#simakey-r-concretecompressiondamage) options to specify tensile and/or compressive stiffness degradation damage and the [CONCRETE FAILURE](simakey-r-concretefailure.md#simakey-r-concretefailure) option to define material failure criteria. If this parameter is omitted, the postcracking stress depends only on the cracking strain, the strain rate, and, possibly, on temperature. See [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md#simamat-c-materialdata) for more information.  TYPE  Set TYPE=STRAIN (default) to specify the postcracking behavior by entering the postfailure stress/cracking-strain relationship.  Set TYPE=DISPLACEMENT to define the postcracking behavior by entering the postfailure stress/cracking-displacement relationship.  Set TYPE=GFI to define the postcracking behavior by entering the failure stress, σt⁢0, and the fracture energy, Gf.  Data lines if the TYPE=STRAIN parameter is included (default) First line  1.
