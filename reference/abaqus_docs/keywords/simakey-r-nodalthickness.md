| |  |  | | --- | --- | | \*NODAL THICKNESS | | |  | | | |  | | --- | | Define shell or membrane thickness at nodes. This option is used to define variable shell or membrane thicknesses on a nodal basis. The thickness data defined with this option will be ignored unless the NODAL THICKNESS parameter is included on either the [SHELL GENERAL SECTION](simakey-r-shellgeneralsection.md#simakey-r-shellgeneralsection) or the [SHELL SECTION](simakey-r-shellsection.md#simakey-r-shellsection) options for shell elements or on the [MEMBRANE SECTION](simakey-r-membranesection.md#simakey-r-membranesection) option for membrane elements.
