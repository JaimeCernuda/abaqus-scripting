| |  |  | | --- | --- | | \*SURFACE SECTION | | |  | | | |  | | --- | | Specify section properties for surface elements. This option is used to specify a surface element cross-section. It must be used in conjunction with the [REBAR LAYER](simakey-r-rebarlayer.md#simakey-r-rebarlayer) option. In an Abaqus/Aqua analysis the surface section can be used to visualize the behavior of the water surface under gravity waves. Optional, mutually exclusive parameters AQUAVISUALIZATION  This parameter applies only to Abaqus/Aqua analyses.
