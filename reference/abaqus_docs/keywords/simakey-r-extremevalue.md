| |  |  | | --- | --- | | \*EXTREME VALUE | | |  | | | |  | | --- | | Define element and nodal variables to be monitored. This option is used in conjunction with the [EXTREME ELEMENT VALUE](simakey-r-extremeelementvalue.md#simakey-r-extremeelementvalue) and/or the [EXTREME NODE VALUE](simakey-r-extremenodevalue.md#simakey-r-extremenodevalue) options to indicate that nodal and element variables are to be monitored in the current step and compared with user-specified values. For each variable specified with these options, the maximum, minimum, or absolute maximum value attained during the course of the analysis and the associated element or node number will be written to the status (`.sta`) file at the end of the step. Use the [EXTREME VALUE](simakey-r-extremevalue.md#simakey-r-extremevalue) option without the [EXTREME ELEMENT VALUE](simakey-r-extremeelementvalue.md#simakey-r-extremeelementvalue) or [EXTREME NODE VALUE](simakey-r-extremenodevalue.md#simakey-r-extremenodevalue) options and without any parameters to stop monitoring variables in a new step.
