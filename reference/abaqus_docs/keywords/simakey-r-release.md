| |  |  | | --- | --- | | \*RELEASE | | |  | | | |  | | --- | | Release rotational degrees of freedom at one or both ends of a beam element. This option is used to release a rotational degree of freedom or a combination of rotational degrees of freedom at one or both ends of a beam element.  This page discusses:   * [Optional parameters](#simakey-r-release__simakey-r-release-s-paramsoptional1) * [Data lines to   prescribe the released degrees of freedom](#simakey-r-release__simakey-r-release-s-datadesc1) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Kinematic Coupling Constraints](.._SIMACAECSTRefMap_simacst-c-kinematiccoupling.md) | | [Element End Release](.._SIMACAECSTRefMap_simacst-c-release.md) | |   ProductsAbaqus/Standard  TypeModel data  LevelPartPart instance  Optional parameters INPUT  Set this parameter equal to the name of the alternate input file containing the data lines for this option. See [Input Syntax Rules](.._SIMACAEMODRefMap_simamod-c-inputsyntax.md) for the syntax of such file names. If this parameter is omitted, it is assumed that the data follow the keyword line.  Data lines to prescribe the released degrees of freedom First line  1. Element number or element set label. 2. Element end identifier (S1 or    S2). 3. Release combination code at the end of the element    (M1, M2,    T, M1-M2,    M1-T, M2-T,    ALLM). See    [Element End Release](.._SIMACAECSTRefMap_simacst-c-release.md)    for a definition of the release combination codes in    Abaqus/Standard.    This field can be left blank if none of the rotational degrees of freedom are    released at this end of the element.   Repeat this data line as often as necessary to specify the rotational degrees of freedom to be released for different elements and element ends. |
