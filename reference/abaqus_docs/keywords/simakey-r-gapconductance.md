| |  |  | | --- | --- | | \*GAP CONDUCTANCE | | |  | | | |  | | --- | | Introduce heat conductance between interface surfaces. This option is used to provide conductive heat transfer between closely adjacent (or contacting) surfaces. It must be used in conjunction with the [SURFACE INTERACTION](simakey-r-surfaceinteraction.md#simakey-r-surfaceinteraction) option or in an Abaqus/Standard analysis with the [GAP](simakey-r-gap.md#simakey-r-gap) option.  For coupled temperature-displacement gasket elements, this option must be used in conjunction with:  * the   [MATERIAL](simakey-r-material.md#simakey-r-material) option if the gasket behavior is defined by a material   model, or * the   [GASKET BEHAVIOR](simakey-r-gasketbehavior.md#simakey-r-gasketbehavior) option if the gasket behavior is defined by a gasket   behavior model (using   [GASKET SECTION](simakey-r-gasketsection.md#simakey-r-gasketsection)).  For coupled temperature-displacement cohesive elements, this option must be used in conjunction with the [MATERIAL](simakey-r-material.md#simakey-r-material) option. Repeat this data line as often as necessary to define the dependence of gap conductance on gap clearance, gap pressure, closure, average surface temperature, average mass flow rate, and any predefined field variables. At least two data lines must be specified for each combination of average surface temperature, average mass flow rate, and any predefined field variables. When gap conductance is defined as a function of clearance or closure, the value of the conductance drops to zero when the clearance or closure is greater than the value corresponding to the data point.  There are no data lines when the USER parameter is used. Instead, define the gap conductance in user subroutine GAPCON |
