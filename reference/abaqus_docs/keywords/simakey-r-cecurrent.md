| |  |  | | --- | --- | | \*CECURRENT | | |  | | | |  | | --- | | Specify concentrated current in an electric conduction analysis. This option is used to apply concentrated current to any node of a model in coupled thermal-electrical, coupled thermal-electrical-structural, coupled thermal-electrochemical, coupled thermal-electrochemical-structural, and coupled thermal-electrochemical-structural-pore pressure analyses.
