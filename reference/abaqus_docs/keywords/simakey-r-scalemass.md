| |  |  | | --- | --- | | \*SCALE MASS | | |  | | | |  | | --- | | Specify scale factors and, for adjoint design sensitivity analysis, quantities that represent the derivatives of the scale factors divided by the scale factors for material mass. This option is used to specify scale factors using a distribution for material mass. In addition, in an adjoint design sensitivity analysis, you can specify quantities that represent the derivatives of the scale factors divided by the scale factors. In the latter case, the scale factors and their derivatives are used in the computation of design responses and topology sensitivities.
