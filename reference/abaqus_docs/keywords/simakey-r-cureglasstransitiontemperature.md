Set DEFINITION=TABULAR to define the glass transition temperature in tabular form.  Optional parameters DEPENDENCIES  This parameter is relevant only for DEFINITION=TABULAR.  Set this parameter equal to the number of field variables included in the specification of the glass transition temperature.  If this parameter is omitted, it is assumed that the glass transition temperature depends only on the degree of cure and, optionally, on temperature. For more information, see [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md).
