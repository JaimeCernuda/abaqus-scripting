| |  |  | | --- | --- | | \*TRANSPORT VELOCITY | | |  | | | |  | | --- | | Specify angular transport velocity. This option is used to define the angular velocity of material transported through the mesh of a deformable body or the transport of material relative to the reference node of a rigid body during a steady-state transport analysis.  This page discusses:   * [Optional parameters](#simakey-r-transportvelocity__simakey-r-transportvelocity-s-paramsoptional1) * [Data lines to define rotational motion](#simakey-r-transportvelocity__simakey-r-transportvelocity-s-datadesc1) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Steady-State Transport Analysis](.._SIMACAEANLRefMap_simaanl-c-steadystatetransport.md) | | [Symmetric Model Generation](.._SIMACAEANLRefMap_simaanl-c-aximodelgen.md) | | [UMOTION](.._SIMACAESUBRefMap_simasub-c-umotion.md) | |   ProductsAbaqus/Standard  TypeHistory data  LevelStep  Optional parameters AMPLITUDE  Set this parameter equal to the name of the amplitude curve (defined in the [AMPLITUDE](simakey-r-amplitude.md#simakey-r-amplitude) option) that gives the time variation of the velocity throughout the step ([Amplitude Curves](.._SIMACAEPRCRefMap_simaprc-c-amplitude.md)).  If this parameter is omitted, the reference magnitude is applied immediately at the beginning of the step or linearly over the step, depending on the value assigned to the AMPLITUDE parameter on the [STEP](simakey-r-step.md#simakey-r-step) option (see [Defining an Analysis](.._SIMACAEANLRefMap_simaanl-c-over.md)).  USER  Include this parameter to indicate that the magnitude of the rotational velocity will be defined in user subroutine [UMOTION](.._SIMACAESUBRefMap_simasub-c-umotion.md#simasub-c-umotion). If this parameter is used, any magnitudes defined by the data lines can be redefined in the user subroutine.  Data lines to define rotational motion First line  1. Node set label or node number. 2. Magnitude of the rotational velocity (in radians/time). This magnitude will be modified by the [AMPLITUDE](simakey-r-amplitude.md#simakey-r-amplitude) specification if the AMPLITUDE parameter is used. For a deformable body the rotation is assumed to be about the axis defined on the [SYMMETRIC MODEL GENERATION](simakey-r-symmetricmodelgeneration.md#simakey-r-symmetricmodelgeneration) option. For a rigid body of type REVOLUTION the rotation is assumed to be about the axis of revolution of the body.   Repeat this data line as often as necessary to define rotational motion on nodes of different parts of the model. |
