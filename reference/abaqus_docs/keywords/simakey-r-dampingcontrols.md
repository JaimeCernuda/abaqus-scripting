This option is used to control the type (viscous, structural) and source of damping (material, global) within the step definition for the following types of analyses in Abaqus/Standard:   * [STEADY STATE DYNAMICS](simakey-r-steadystatedynamics.md#simakey-r-steadystatedynamics), DIRECT * [STEADY STATE DYNAMICS](simakey-r-steadystatedynamics.md#simakey-r-steadystatedynamics), SUBSPACE PROJECTION * [STEADY STATE DYNAMICS](simakey-r-steadystatedynamics.md#simakey-r-steadystatedynamics) that supports nondiagonal damping * [MODAL DYNAMIC](simakey-r-modaldynamic.md#simakey-r-modaldynamic) that supports nondiagonal damping * [MATRIX GENERATE](simakey-r-matrixgenerate.md#simakey-r-matrixgenerate) * [SUBSTRUCTURE GENERATE](simakey-r-substructuregenerate.md#simakey-r-substructuregenerate)   Damping can be defined at the material level using visco-elastic behavior or using the [DAMPING](simakey-r-damping.md#simakey-r-damping) option; at the element level using [SPRING](simakey-r-spring.md#simakey-r-spring), COMPLEX STIFFNESS or [CONNECTOR DAMPING](simakey-r-connectordamping.md#simakey-r-connectordamping) options; for acoustic elements using [ACOUSTIC MEDIUM](simakey-r-acousticmedium.md#simakey-r-acousticmedium), VOLUMETRIC DRAG; or using the acoustic impedance definitions ([IMPEDANCE](simakey-r-impedance.md#simakey-r-impedance) and [SIMPEDANCE](simakey-r-simpedance.md#simakey-r-simpedance)). Damping is defined at the global level using [GLOBAL DAMPING](simakey-r-globaldamping.md#simakey-r-globaldamping). The [DAMPING CONTROLS](simakey-r-dampingcontrols.md#simakey-r-dampingcontrols) option controls which of the supplied damping options will participate in the current step or within a substructure.  Use the [SUBSTRUCTURE DAMPING CONTROLS](simakey-r-substructuredampingcontrols.md#simakey-r-substructuredampingcontrols) option to control damping for substructure elements (see [Defining Substructure Damping](.._SIMACAEANLRefMap_simaanl-c-superelements.md#simaanl-c-superelements-damping) for details). Optional parameters LOW FREQUENCY CUTOFF  This parameter is relevant for transient modal analysis only.  Set this parameter equal to the frequency value below which the eigenmodes will not be damped even if damping is requested at the material, element, and/or modal level. This parameter is useful for free structures or for models with secondary base motions.  If this parameter is omitted, the default value is used. The default value is six orders of magnitude smaller than the frequency of the first deformable eigenmode.  If this parameter is included but no value is given, the low frequency cutoff value is given as the square root of the platform precision value.  A negative value can be assigned to allow damping at the low frequency modes.  The parameter units are cycles/time.  STRUCTURAL  Set this parameter equal to ELEMENT to request the structural damping matrix that includes material and/or element damping properties only.  Set this parameter equal to FACTOR to request the structural damping matrix that includes the global damping factor only.  Set this parameter equal to COMBINED to request the structural damping matrix that includes the combination of both ELEMENT and FACTOR.  Set this parameter equal to NONE to exclude the structural damping matrix at this step.  If this parameter is omitted or the option is not used within the step definition, the default uses all structural damping specified at the model and step levels. If both material and global structural damping are specified, the COMBINED damping is used.  If this parameter is omitted or the option is not used as a suboption of [SUBSTRUCTURE PROPERTY](simakey-r-substructureproperty.md#simakey-r-substructureproperty), the substructure property uses COMBINED as the default with the structural factor specified under the [DAMPING](simakey-r-damping.md#simakey-r-damping), STRUCTURAL option.  VISCOUS  Set this parameter equal to ELEMENT to request a viscous damping matrix that includes material and/or element damping properties only.  Set this parameter equal to FACTOR to request a viscous damping matrix that includes the global damping factor only.  Set this parameter equal to COMBINED to request a viscous damping matrix that includes a combination of ELEMENT and FACTOR.  Set this parameter equal to NONE to exclude the viscous damping matrix in this step.  If this parameter is omitted or the option is not used within the step definition, the default uses all viscous damping specified at the model and step levels. If both material and global damping are specified, the COMBINED damping is used.  If this parameter is omitted or the option is not used as a suboption of [SUBSTRUCTURE PROPERTY](simakey-r-substructureproperty.md#simakey-r-substructureproperty), the substructure property uses COMBINED as the default with the mass and stiffness proportional Rayleigh damping factors specified under the [DAMPING](simakey-r-damping.md#simakey-r-damping), ALPHA or BETA option.  There are no data lines associated with this option. |
