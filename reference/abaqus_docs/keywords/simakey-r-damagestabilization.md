This option is used to specify viscosity coefficients used in the viscous regularization scheme for the damage model for fiber-reinforced materials, surface-based traction-separation behavior in contact or cohesive behavior in enriched elements.   * For fiber-reinforced materials, you can use this option in conjunction with the   [DAMAGE INITIATION](simakey-r-damageinitiation.md#simakey-r-damageinitiation),   CRITERION=HASHIN   and [DAMAGE EVOLUTION](simakey-r-damageevolution.md#simakey-r-damageevolution)   options. * For surface-based traction-separation behavior, you can use this option in   conjunction with the [DAMAGE INITIATION](simakey-r-damageinitiation.md#simakey-r-damageinitiation),   CRITERION=MAXS,   MAXU,   QUADS, or   QUADU and [DAMAGE EVOLUTION](simakey-r-damageevolution.md#simakey-r-damageevolution)   options. * For XFEM, you can use this option in conjunction with the [DAMAGE INITIATION](simakey-r-damageinitiation.md#simakey-r-damageinitiation),   CRITERION=LARC05,   MAXE,   MAXS,   MAXPE,   MAXPS,   QUADE, or   QUADS and [DAMAGE EVOLUTION](simakey-r-damageevolution.md#simakey-r-damageevolution)   options.
