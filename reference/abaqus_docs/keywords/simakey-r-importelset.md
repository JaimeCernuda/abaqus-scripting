| |  |  | | --- | --- | | \*IMPORT ELSET | | |  | | | |  | | --- | | Import element set definitions from a previous Abaqus/Explicit or Abaqus/Standard analysis. This option is used to import element set definitions that were defined in a previous Abaqus/Explicit or Abaqus/Standard analysis. If the [IMPORT ELSET](simakey-r-importelset.md#simakey-r-importelset) option is used, it must appear after the [IMPORT](simakey-r-import.md#simakey-r-import) option.  If the [IMPORT ELSET](simakey-r-importelset.md#simakey-r-importelset) option is used with the RENAME parameter, it must appear after an [IMPORT](simakey-r-import.md#simakey-r-import) option with active RENAME and EOFFSET parameters.  If this option is omitted or is specified without any data lines and all [IMPORT](simakey-r-import.md#simakey-r-import) options that reference a previous analysis do not include the RENAME parameter, all the element sets relevant to the analysis are imported. References to elements that are not imported are removed from imported sets.  This option is ignored if you specify the full-model input format in the [\*IMPORT CONTROLS](simakey-r-importcontrols.md#simakey-r-importcontrols) option because data for all imported element sets are given in the input.
