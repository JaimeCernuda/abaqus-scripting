| |  |  | | --- | --- | | \*CENTROID | | |  | | | |  | | --- | | Define the position of the centroid of the beam section. This option can be used only in conjunction with the [BEAM GENERAL SECTION](simakey-r-beamgeneralsection.md#simakey-r-beamgeneralsection), SECTION=GENERAL or the [BEAM GENERAL SECTION](simakey-r-beamgeneralsection.md#simakey-r-beamgeneralsection), SECTION=MESHED option. It cannot be used if you include the FULL COUPLING parameter for the [SECTION STIFFNESS](simakey-r-sectionstiffness.md#simakey-r-sectionstiffness) option.  It is used to define the position of the centroid of the section with respect to the local (1, 2) axis system.
