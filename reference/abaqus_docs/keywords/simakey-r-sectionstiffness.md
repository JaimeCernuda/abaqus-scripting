| |  |  | | --- | --- | | \*SECTION STIFFNESS | | |  | | | |  | | --- | | Define stiffness properties for meshed general beam sections. This option must be used in conjunction with the [BEAM GENERAL SECTION](simakey-r-beamgeneralsection.md#simakey-r-beamgeneralsection), SECTION=MESHED option to assign the beam section stiffness properties that result from the two-dimensional meshed cross-section generation procedure. The properties are written to the jobname.bsp file during the cross-section generation and are typically read into a subsequent beam analysis using the [INCLUDE](simakey-r-include.md#simakey-r-include) option.  The [SECTION STIFFNESS](simakey-r-sectionstiffness.md#simakey-r-sectionstiffness) and [SECTION INERTIA](simakey-r-sectioninertia.md#simakey-r-sectioninertia) options are mutually exclusive with the second and third data lines of the [BEAM GENERAL SECTION](simakey-r-beamgeneralsection.md#simakey-r-beamgeneralsection) option. The [SECTION STIFFNESS](simakey-r-sectionstiffness.md#simakey-r-sectionstiffness), FULL COUPLING option is also mutually exclusive with the [TRANSVERSE SHEAR STIFFNESS](simakey-r-transverseshearstiffness.md#simakey-r-transverseshearstiffness), [\*CENTROID](simakey-r-centroid.md#simakey-r-centroid), and [\*SHEAR CENTER](simakey-r-shearcenter.md#simakey-r-shearcenter) options. See [Meshed Beam Cross-Sections](.._SIMACAEANLRefMap_simaanl-c-meshedsection.md) for details. This includes all coupling effects that might otherwise be defined with the [TRANSVERSE SHEAR STIFFNESS](simakey-r-transverseshearstiffness.md#simakey-r-transverseshearstiffness), [\*CENTROID](simakey-r-centroid.md#simakey-r-centroid), and [\*SHEAR CENTER](simakey-r-shearcenter.md#simakey-r-shearcenter) options.
