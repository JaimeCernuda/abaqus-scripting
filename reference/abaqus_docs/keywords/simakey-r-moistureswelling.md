| |  |  | | --- | --- | | \*MOISTURE SWELLING | | |  | | | |  | | --- | | Define moisture-driven swelling. This option is used to define the moisture-driven swelling of the solid skeleton in a partially saturated porous medium. It can be used in the analysis of coupled wetting liquid flow and porous medium stress. Data lines to define moisture-driven swelling First line  1. Volumetric moisture swelling strain, εm⁢s. 2. Saturation, s. This value must lie in the range 0.0≤s≤1.0.   Repeat this data line as often as necessary to define the εm⁢s–s relationship from s=0.0 to s=1.0 in increasing values of s. |
