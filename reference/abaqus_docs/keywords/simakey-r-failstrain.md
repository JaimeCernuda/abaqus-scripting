If this parameter is omitted, it is assumed that the failure criteria depend only on temperature. See [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md#simamat-c-materialdata) for more information.  Data lines to define strain-based failure criteria First line  1. Subsequent lines (only needed if the DEPENDENCIES parameter has a value greater than two.)  1. Third field variable. 2. Fourth field variable. 3. Etc., up to eight field variables per line.
