| |  |  | | --- | --- | | \*ELECTRIC MACHINE PROPERTY | | |  | | | |  | | --- | | Define electric machine properties (or parameters) needed to apply electric machine loads.  This option is used to define electric machine properties (or parameters) that are needed to apply electric machine loads in the step data. These geometry properties include the name of the stator surface, the number of electric machine teeth, the number of two-dimensional electromagnetic slices, and the stator orientation.
