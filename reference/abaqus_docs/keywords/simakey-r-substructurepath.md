At least one of the following parameters is required ENTER ELEMENT  Include this parameter if output requests within a substructure are to follow. Set this parameter equal to the element number used for the substructure at the usage level at which Abaqus/Standard is operating before the appearance of this option.  LEAVE  Include this parameter to leave a substructure and go back up to its usage level.  There are no data lines associated with this option. |
