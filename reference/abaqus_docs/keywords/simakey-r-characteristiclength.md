| |  |  | | --- | --- | | \*CHARACTERISTIC LENGTH | | |  | | | |  | | --- | | Define characteristic element length at a material point. This option is used to define the characteristic element length to be used by Abaqus for the regularization of models that exhibit strain softening or to be passed to user subroutines that are called at the material point. If used, it must appear within a [MATERIAL](simakey-r-material.md#simakey-r-material) definition ([Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md)). If this option is not specified, Abaqus computes the characteristic element length using the geometric mean–based definition.
