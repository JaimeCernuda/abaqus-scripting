Required parameter for load cases that include nodal pressure loading GENERATE  Include this parameter to generate multiple load cases.  This parameter applies only to a load case definition that refers to the nodal pressure distributed load type label (NP) in the [DSLOAD](simakey-r-dsload.md#simakey-r-dsload) option.  Nodal pressure load cases are generated for each node of the referenced surface. The label that is used to refer to the individual load case is formatted using the specified load case name, the referenced surface name, and the node number as follows:  ``` name-surface_name-node_number ```  There are no data lines associated with this option. |
