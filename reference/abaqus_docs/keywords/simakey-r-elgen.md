Optional parameters ALL NODES  Include this parameter to increment the node numbers of rigid body reference nodes for IRS-type and drag chain elements and nodes used to define the direction of the first cross-section axis for beams in space. By default, these node numbers will not be incremented.  ELSET  Set this parameter equal to the name of the element set to which the elements, including the main element, will be assigned.  Data lines to generate elements incrementally First line  1. Main element number. 2. Number of elements to be defined in the first row generated, including the main    element. 3. Increment in node numbers of corresponding nodes from element to element in    the row. The default is 1. 4. Increment in element numbers in the row. The default is 1. 5. If necessary, copy this newly created main row to define a layer of    elements. 6. Number of rows to be defined, including the main row. The default is 1. 7. Increment in node numbers of corresponding nodes from row to row. 8. Increment in element numbers of corresponding elements from row to row. 9. If necessary, copy this newly created main layer to define a block of    elements. 10. Number of layers to be defined, including the main layer. The default is 1. 11. Increment in node numbers of corresponding nodes from layer to layer. 12. Increment in element numbers of corresponding elements from layer to layer.  Repeat this data line as often as necessary. Each line will generate N1 × N2 × N3 elements, where N1 is the number of elements in a row, N2 is the number of rows in a layer, and N3 is the number of layers. |
