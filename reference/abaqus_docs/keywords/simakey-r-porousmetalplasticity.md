| |  |  | | --- | --- | | \*POROUS METAL PLASTICITY | | |  | | | |  | | --- | | Specify a porous metal plasticity model. This option is used to specify the porous part of the porous metal plasticity model.  The [POROUS METAL PLASTICITY](simakey-r-porousmetalplasticity.md#simakey-r-porousmetalplasticity) option can be used in conjunction with the [VOID NUCLEATION](simakey-r-voidnucleation.md#simakey-r-voidnucleation) option to define the nucleation of voids. In an Abaqus/Explicit analysis it can also be used in conjunction with the [POROUS FAILURE CRITERIA](simakey-r-porousfailurecriteria.md#simakey-r-porousfailurecriteria) option to specify the material failure criteria. If this parameter is omitted, q1, q2, and q3 may depend only on temperature. See [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md#simamat-c-materialdata) for more information.  RELATIVE DENSITY  Set this parameter equal to r0, the initial relative density of the material. If this parameter is omitted, the initial relative density is interpolated from the values given in the [INITIAL CONDITIONS](simakey-r-initialconditions.md#simakey-r-initialconditions), TYPE=RELATIVE DENSITY option.  Data lines to define porous metal plasticity First line  1. q1. 2. q2. 3. q3. 4. Temperature. 5. First field variable. 6. Second field variable. 7. Etc., up to four field variables.  Subsequent lines (only needed if the DEPENDENCIES parameter has a value greater than four)  1. Fifth field variable. 2. Etc., up to eight field variables per line.   Repeat this set of data lines as often as necessary to define the dependence of q1, q2, and q3 on temperature and other predefined field variables. |
