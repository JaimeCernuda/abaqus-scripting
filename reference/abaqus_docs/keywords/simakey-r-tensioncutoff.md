| |  |  | | --- | --- | | \*TENSION CUTOFF | | |  | | | |  | | --- | | Specify tension cutoff data for the Mohr-Coulomb plasticity model. This option is used to specify tension cutoff data to limit the load-carrying capacity of the Mohr-Coulomb plasticity model near the tensile region. This option must be used in conjunction with [MOHR COULOMB](simakey-r-mohrcoulomb.md#simakey-r-mohrcoulomb) and [MOHR COULOMB HARDENING](simakey-r-mohrcoulombhardening.md#simakey-r-mohrcoulombhardening) options.
