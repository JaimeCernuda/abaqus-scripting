| |  |  | | --- | --- | | \*CONCRETE DAMAGED PLASTICITY | | |  | | | |  | | --- | | Define flow potential, yield surface, and viscosity parameters for the concrete damaged plasticity model. This option is used to define flow potential, yield surface, and viscosity parameters for the concrete damaged plasticity material model. The [CONCRETE DAMAGED PLASTICITY](simakey-r-concretedamagedplasticity.md#simakey-r-concretedamagedplasticity) option must be used in conjunction with the [CONCRETE TENSION STIFFENING](simakey-r-concretetensionstiffening.md#simakey-r-concretetensionstiffening) and the [CONCRETE COMPRESSION HARDENING](simakey-r-concretecompressionhardening.md#simakey-r-concretecompressionhardening) options. In addition, the option can be used with the [CONCRETE TENSION DAMAGE](simakey-r-concretetensiondamage.md#simakey-r-concretetensiondamage) and/or the [CONCRETE COMPRESSION DAMAGE](simakey-r-concretecompressiondamage.md#simakey-r-concretecompressiondamage) options to specify tensile and/or compressive stiffness degradation damage and the [CONCRETE FAILURE](simakey-r-concretefailure.md#simakey-r-concretefailure) option to define material failure criteria.
