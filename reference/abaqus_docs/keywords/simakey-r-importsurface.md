| |  |  | | --- | --- | | \*IMPORT SURFACE | | |  | | | |  | | --- | | Import surface definitions from a previous Abaqus/Explicit or Abaqus/Standard analysis. This option is used to import surface definitions that were defined in a previous Abaqus/Explicit or Abaqus/Standard analysis. If the [IMPORT SURFACE](simakey-r-importsurface.md#simakey-r-importsurface) option is used, it must appear after the [IMPORT](simakey-r-import.md#simakey-r-import) or the [INSTANCE](simakey-r-import.md#simakey-r-import) option.  If this option is specified after an [IMPORT](simakey-r-importelset.md#simakey-r-importelset) option without the RENAME parameter and with no data lines, all surfaces relevant to the analysis are imported. If this option is omitted in an Abaqus/Standard to Abaqus/Standard import analysis and the [INSTANCE](simakey-r-import.md#simakey-r-import) option is not used, all surfaces relevant to the analysis are imported.  If this option is specified with the RENAME parameter, it must appear after an [IMPORT](simakey-r-import.md#simakey-r-import) option with the RENAME parameter specified. The values of the EOFFSET and NOFFSET parameters of the [IMPORT](simakey-r-import.md#simakey-r-import) option apply to the [IMPORT SURFACE](simakey-r-importsurface.md#simakey-r-importsurface) option.  If this option is specified without any data lines, all surfaces relevant to the analysis are imported.  This option is ignored if you specify the full-model input format in the [\*IMPORT CONTROLS](simakey-r-importcontrols.md#simakey-r-importcontrols) option because data for all imported surfaces are given in the input.
