| |  |  | | --- | --- | | \*USER OUTPUT VARIABLES | | |  | | | |  | | --- | | Specify number of user variables. This option is used to allow Abaqus to allocate space at each material calculation point for user-defined output variables defined in user subroutine [UVARM](.._SIMACAESUBRefMap_simasub-c-uvarm.md#simasub-c-uvarm). If the [USER OUTPUT VARIABLES](simakey-r-useroutputvariables.md#simakey-r-useroutputvariables) option is used, it must appear within each of the relevant material or gasket behavior definitions.
