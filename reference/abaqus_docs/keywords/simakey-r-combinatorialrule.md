This option is used to define controls associated with combinatorial rules that are used to determine interaction properties as functions of surface properties.  This page discusses:   * [Optional parameters](#simakey-r-combinatorialrule__simakey-r-combinatorialrule-optionalparams) * [There are no data lines associated with this option.](#simakey-r-combinatorialrule__simakey-r-combinatorialrule-nodata) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Deriving Friction Coefficients from Quantities Specified as Surface Properties](.._SIMACAEITNRefMap_simaitn-c-friction.md#smaitn-c-friction-surfprop) | | [Frictional Behavior](.._SIMACAEITNRefMap_simaitn-c-friction.md#simaitn-c-friction) | | [Surface-Based Friction Coefficients](.._SIMACAEITNRefMap_simaitn-c-surfacepropassign.md#simaitn-c-surfacepropassign-surfbasedfriccoef) | |   ProductsAbaqus/Explicit  Type Model data  LevelStep  Optional parameters ALPHA  Set this parameter equal to α  in the equation μAB=[1+α(1−μAμB)]μA, where μA≤μB, to compute a friction coefficient for contact, μAB, based on friction coefficients μA  and μB  specified as surface properties.  ANISOTROPY WEIGHTING  This parameter applies only if friction anisotropy is specified as a surface property. Set ANISOTROPY WEIGHTING=BALANCED to specify a balanced weighting method for combining surface-based directional preferences for the anisotropic friction model.  Set ANISOTROPY WEIGHTING=PROPORTIONAL to specify an epsilon-proportional weighting method for combining surface-based directional preferences for the anisotropic friction model.  Set ANISOTROPY WEIGHTING=DOMINANT to specify the maximum-epsilon-dominant weighting method for combining surface-based directional preferences for the anisotropic friction model.  There are no data lines associated with this option. |
