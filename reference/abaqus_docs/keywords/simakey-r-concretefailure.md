| |  |  | | --- | --- | | \*CONCRETE FAILURE | | |  | | | |  | | --- | | Specify material failure criteria and allow element deletion for the concrete damaged plasticity material model. This option is used to define material failure criteria for the concrete damaged plasticity material model. The [CONCRETE FAILURE](simakey-r-concretefailure.md#simakey-r-concretefailure) option must be used in conjunction with the [CONCRETE DAMAGED PLASTICITY](simakey-r-concretedamagedplasticity.md#simakey-r-concretedamagedplasticity), [CONCRETE TENSION STIFFENING](simakey-r-concretetensionstiffening.md#simakey-r-concretetensionstiffening), and [CONCRETE COMPRESSION HARDENING](simakey-r-concretecompressionhardening.md#simakey-r-concretecompressionhardening) options. In addition, the option can be used with the [CONCRETE TENSION DAMAGE](simakey-r-concretetensiondamage.md#simakey-r-concretetensiondamage) and/or [CONCRETE COMPRESSION DAMAGE](simakey-r-concretecompressiondamage.md#simakey-r-concretecompressiondamage) option to specify material failure criteria based on tensile and/or compressive stiffness degradation damage, respectively.
