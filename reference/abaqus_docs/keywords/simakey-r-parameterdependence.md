This option is used to define the dependence table that specifies the relationship between tabularly dependent and independent parameters. This number must be equal to the sum of the number of dependent and the number of independent parameters for which this table is used.  TABLE  Set this keyword parameter equal to the name of the table being defined in this option.  Data lines to define the parameter dependence table First line  1. Values in the first row of the dependence table. Give the dependent and independent parameter data values that are to be interpolated. The dependent parameter values must precede the independent parameter values. The total number of entries in the row must equal the value of the NUMBER VALUES parameter.   Repeat this data line as often as necessary to define additional rows of the parameter dependence table. The data given on this data line cannot be parameterized. |
