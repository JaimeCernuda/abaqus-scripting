| |  |  | | --- | --- | | \*SFILM | | |  | | | |  | | --- | | Define film coefficients and associated sink temperatures over a surface. This option is used to provide film coefficients and sink temperatures over a specified surface for all procedures that solve for nodal temperature degrees of freedom.  This page discusses:   * [Optional parameters](#simakey-r-sfilm__simakey-r-sfilm-s-paramsoptional1) * [Data lines to define sink temperatures and film coefficients](#simakey-r-sfilm__simakey-r-sfilm-s-datadesc1) | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [Thermal Loads](.._SIMACAEPRCRefMap_simaprc-c-thermal.md) | | [FILM](.._SIMACAESUBRefMap_simasub-c-film.md) | |   Products Abaqus/Standard Abaqus/Explicit Abaqus/CAE  Type History data  LevelStep  Abaqus/CAE Interaction module  Optional parameters FILM AMPLITUDE  This parameter applies only to Abaqus/Standard and Abaqus/Explicit analyses.  Set this parameter equal to the name of the [AMPLITUDE](simakey-r-amplitude.md#simakey-r-amplitude) option that gives the variation of the film coefficient, h, with time.  If this parameter is omitted in an Abaqus/Standard analysis, the reference film coefficient is applied immediately at the beginning of the step and kept constant over the step, independent of the value assigned to the AMPLITUDE parameter on the [STEP](simakey-r-step.md#simakey-r-step) option. If this parameter is omitted in an Abaqus/Explicit analysis, the reference sink temperature given on the data lines is applied throughout the step.  The FILM AMPLITUDE parameter is ignored if a film coefficient is defined to be a function of temperature and field variables using the [FILM PROPERTY](simakey-r-filmproperty.md#simakey-r-filmproperty) option.  For nonuniform films of type FNU, the film coefficient amplitude is defined in user subroutine [FILM](.._SIMACAESUBRefMap_simasub-c-film.md#simasub-c-film) in Abaqus/Standard or user subroutine [VFILM](.._SIMACAESUBRefMap_simasub-c-vfilm.md#simasub-c-vfilm) in Abaqus/Explicit; and FILM AMPLITUDE references are used only to modify the film coefficient passed into the user subroutine.  OP  Set OP=MOD (default) to modify existing films or to define additional films.  Set OP=NEW if all existing [SFILM](simakey-r-sfilm.md#simakey-r-sfilm)s applied to the model should be removed.  SINK AMPLITUDE  Set this parameter equal to the name of the [AMPLITUDE](simakey-r-amplitude.md#simakey-r-amplitude) option that gives the variation of the sink temperature,    θ 0 , with time.  If this parameter is omitted in an Abaqus/Standard analysis, the reference sink temperature is applied immediately at the beginning of the step or linearly over the step, depending on the value assigned to the AMPLITUDE parameter on the [STEP](simakey-r-step.md#simakey-r-step) option ([Defining an Analysis](.._SIMACAEANLRefMap_simaanl-c-over.md)). If this parameter is omitted in an Abaqus/Explicit analysis, the reference sink temperature is applied immediately at the beginning of the step.  For nonuniform films of type FNU, the sink temperature amplitude is defined in user subroutine [FILM](.._SIMACAESUBRefMap_simasub-c-film.md#simasub-c-film) in Abaqus/Standard or user subroutine [VFILM](.._SIMACAESUBRefMap_simasub-c-vfilm.md#simasub-c-vfilm) in Abaqus/Explicit; and SINK AMPLITUDE references are used only to modify the sink temperature passed into the user subroutine.
