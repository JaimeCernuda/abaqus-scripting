| |  |  | | --- | --- | | \*DESIGN PARAMETER | | |  | | | |  | | --- | | Specify design parameters with respect to which sensitivities are calculated. This option is used to specify design parameters for design sensitivity analysis. Sensitivities of responses specified under the [DESIGN RESPONSE](simakey-r-designresponse.md#simakey-r-designresponse) option will be calculated with respect to these design parameters. The design parameters must be chosen from an existing set of parameters defined on the [PARAMETER](simakey-r-parameter.md#simakey-r-parameter) option.
