| |  |  | | --- | --- | | \*SURFACE PROPERTY | | |  | | | |  | | --- | | Define named surface properties for cavity radiation or contact-based wear. This option is used to define surface properties for cavity radiation analysis or contact-based wear modeling.  In the case of cavity radiation, this option must immediately precede the [EMISSIVITY](simakey-r-emissivity.md#simakey-r-emissivity) option. For contact based wear, this option must precede the [WEAR SURFACE PROPERTIES](simakey-r-wearsurfaceproperties.md#simakey-r-wearsurfaceproperties) option.
