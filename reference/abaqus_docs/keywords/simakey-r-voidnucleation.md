Data lines to define void nucleation First line  1. εN, mean value of the nucleation-strain normal distribution. 2. sN, standard deviation of the nucleation-strain normal distribution. 3. fN, volume fraction of nucleating voids. 4. Temperature. 5. First field variable. 6. Second field variable. 7. Etc., up to four field variables.  Subsequent lines (only needed if the DEPENDENCIES parameter has a value greater than four)  1. Fifth field variable. 2. Etc., up to eight field variables per line.   Repeat this set of data lines as often as necessary to define the dependence of εN, sN, and fN on temperature and other predefined field variables. |
