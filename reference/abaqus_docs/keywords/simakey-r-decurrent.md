| |  |  | | --- | --- | | \*DECURRENT | | |  | | | |  | | --- | | Specify distributed current densities in an electromagnetic analysis. This option is used to input distributed current densities in coupled thermal-electrical, coupled thermal-electrical-structural, coupled thermal-electrochemical, coupled thermal-electrochemical-structural, and coupled thermal-electrochemical-structural-pore pressure analyses or to input volume current densities in an eddy current and magnetostatic analyses. If this parameter is omitted, the reference magnitude is applied immediately at the beginning of the step or linearly over the step, depending on the value assigned to the AMPLITUDE parameter on the [STEP](simakey-r-step.md#simakey-r-step) option ([Defining an Analysis](.._SIMACAEANLRefMap_simaanl-c-over.md)).  OP  Set OP=MOD (default) for existing [DECURRENT](simakey-r-decurrent.md#simakey-r-decurrent)s to remain, with this option defining distributed current densities to be added or modified.  Set OP=NEW if all existing [DECURRENT](simakey-r-decurrent.md#simakey-r-decurrent)s applied to the model should be removed.  Optional, mutually exclusive parameters for time-harmonic eddy current analyses IMAGINARY  Include this parameter to define the imaginary (out-of-phase) part of the volume current density.  REAL  Include this parameter (default) to define the real (in-phase) part of the volume current density.  Data lines to define distributed electrical current densities in coupled thermal-electrical, coupled thermal-electrical-structural, coupled thermal-electrochemical, coupled thermal-electrochemical-structural, or coupled thermal-electrochemical-structural-pore pressure analyses First line  1. Element number or element set label. 2. Distributed current density type label (see [About the Element Library](.._SIMACAEELMRefMap_simaelm-c-general.md)). 3. Reference current density magnitude. (Units of    CL−2T−1 for surface current    densities and CL−3T−1 for    body current sources.)   Repeat this data line as often as necessary to define current densities for various elements or element sets.  Data lines to define volume current densities in eddy current or magnetostatic analyses First line  1. Element number or element set label. 2. Volume current density type label    CJ (uniform) or    CJNU (nonuniform). 3. Reference volume current density magnitude. (Units of    CL−2T−1.) 4. 1-component of the volume current density vector direction. 5. 2-component of the volume current density vector direction. 6. 3-component of the volume current density vector direction. 7. For nonuniform loads the magnitude and direction must be    defined in user subroutine [UDECURRENT](.._SIMACAESUBRefMap_simasub-c-udecurrent.md#simasub-c-udecurrent). If    given, the magnitude and direction will be passed into the user    subroutine. 8. Name of the orientation option ([Orientations](.._SIMACAEMODRefMap_simamod-c-orientation.md)) that defines the local coordinate    system in which the volume current density vector is    specified.   Repeat this data line as often as necessary to define volume current densities for various elements or element sets. |
