Data lines to specify contact exclusions First line  1. The name of the first surface. If the first surface name is omitted, the default all-inclusive, element-based surface defined by Abaqus is assumed. 2. The name of the second surface. If the second surface name is omitted or is the same as the first surface name, Abaqus assumes that self-contact is being excluded. Self-contact means contact of a surface with itself, without consideration of whether a surface contains disconnected regions. If different names are specified for the first and second surfaces, self-contact is not excluded except in any overlap between the two surfaces.   Repeat this data line as often as necessary. |
