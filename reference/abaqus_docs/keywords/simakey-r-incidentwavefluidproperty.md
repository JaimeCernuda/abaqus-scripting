| |  |  | | --- | --- | | \*INCIDENT WAVE FLUID PROPERTY | | |  | | | |  | | --- | | Define the fluid properties associated with an incident wave. The preferred interface for defining the fluid properties for an incident wave is the [INCIDENT WAVE INTERACTION PROPERTY](simakey-r-incidentwaveinteractionproperty.md#simakey-r-incidentwaveinteractionproperty) option used in conjunction with the [INCIDENT WAVE INTERACTION](simakey-r-incidentwaveinteraction.md#simakey-r-incidentwaveinteraction) option. The alternative interface uses the [INCIDENT WAVE FLUID PROPERTY](simakey-r-incidentwavefluidproperty.md#simakey-r-incidentwavefluidproperty) option to define the fluid properties used to define an incident wave.  The [INCIDENT WAVE FLUID PROPERTY](simakey-r-incidentwavefluidproperty.md#simakey-r-incidentwavefluidproperty) must be used in conjunction with the [INCIDENT WAVE PROPERTY](simakey-r-incidentwaveproperty.md#simakey-r-incidentwaveproperty) option.
