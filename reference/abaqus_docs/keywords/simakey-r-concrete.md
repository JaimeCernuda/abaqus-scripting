It is important to be familiar with the issues relating to concrete modeling and rebar definition by referring to [Concrete Smeared Cracking](.._SIMACAEMATRefMap_simamat-c-concrete.md), [Defining Rebar as an Element Property](.._SIMACAEMODRefMap_simamod-c-rebar.md), and the appropriate sections in the [Abaqus Theory Guide](.._SIMACAETHERefMap_simathe-c-ov.md#simathe-c-ov) and the [Abaqus Example Problems Guide](.._SIMACAEEXARefMap_simaexa-c-ov.md#simaexa-c-ov). |   The [CONCRETE](simakey-r-concrete.md#simakey-r-concrete) option is used to define the properties of plain concrete outside the elastic range in an Abaqus/Standard analysis. It must be used in conjunction with the [TENSION STIFFENING](simakey-r-tensionstiffening.md#simakey-r-tensionstiffening) option and may also appear with the [SHEAR RETENTION](simakey-r-shearretention.md#simakey-r-shearretention) and [FAILURE RATIOS](simakey-r-failureratios.md#simakey-r-failureratios) options. The [BRITTLE CRACKING](simakey-r-brittlecracking.md#simakey-r-brittlecracking) option is used to analyze concrete in an Abaqus/Explicit analysis (see [Cracking Model for Concrete](.._SIMACAEMATRefMap_simamat-c-cracking.md)). If this parameter is omitted, it is assumed that the compressive yield stress depends only on the plastic strain and, possibly, on temperature. See [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md#simamat-c-materialdata) for more information.  Data lines to define the concrete properties First line  1. Sixth field variable. 2. Etc., up to eight field variables per line.
