Set this parameter equal to the number of field variable dependencies in the definition of material parameters, in addition to temperature. If this parameter is omitted, it is assumed that the rate-dependent material behavior depends only on temperature. See [Material Data Definition](.._SIMACAEMATRefMap_simamat-c-materialdata.md#simamat-c-materialdata) for more information.  TYPE  Set TYPE=POWER LAW (default) to specify the Cowper-Symonds overstress power law.  Set TYPE=CHABOCHE to specify Chaboche rate dependence.  Set TYPE=JOHNSON COOK to specify Johnson-Cook rate dependence (this option cannot be used with the crushable foam plasticity model).  Set TYPE=YIELD RATIO to enter yield stress ratios.  If this option is used in conjunction with the [CRUSHABLE FOAM](simakey-r-crushablefoam.md#simakey-r-crushablefoam) option, the static hardening relation must be defined on the [CRUSHABLE FOAM HARDENING](simakey-r-crushablefoamhardening.md#simakey-r-crushablefoamhardening) option.
