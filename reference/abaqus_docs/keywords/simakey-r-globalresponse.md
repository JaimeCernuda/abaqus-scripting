| |  |  | | --- | --- | | \*GLOBAL RESPONSE | | |  | | | |  | | --- | | Specify global design response. This option is used in an adjoint sensitivity analysis to write a global design response and its corresponding sensitivities with respect to the appropriate design variables to the output database. It must be used in conjunction with the [DESIGN RESPONSE](simakey-r-designresponse.md#simakey-r-designresponse) option. That is, if the value of the design response value is below the specified lower bound, then only the design response value is written to the output database, but not the corresponding adjoint sensitivities.  This parameter is not supported in an eigenfrequency sensitivity analysis.  UPPER BOUND  This parameter is used to specify an upper bound on the design response value above which adjoint sensitivities are not calculated. That is, if the value of the design response value is above the specified upper bound, then only the design response value is written to the output database, but not the corresponding adjoint sensitivities.  This parameter is not supported in an eigenfrequency sensitivity analysis.  Data lines First line  1. Specify an identifying key for the global response whose sensitivities are to be written    to the output database. The valid keys are listed in [Adjoint Design Sensitivity Analysis](.._SIMACAEANLRefMap_simaanl-c-adjointsensitivities.md#simaanl-c-adjointsensitivities). Only one identifying key can    be specified for each use of this option.  Second line  1. Mode number for eigenfrequency    sensitivity. |
