| |  |  | | --- | --- | | \*UEL PROPERTY | | |  | | | |  | | --- | | Define property values to be used with a user element type. This option is required to define the properties of a user element, where the element set must be provided. User element properties provided on the data line are relevant only for nonlinear user elements. The damping parameters provided via parameters on this option are relevant for all procedure types except for nonlinear user elements given by the user subroutine in direct-integration transient dynamic analyses.
