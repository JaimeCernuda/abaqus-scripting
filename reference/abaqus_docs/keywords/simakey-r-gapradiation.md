| |  |  | | --- | --- | | \*GAP RADIATION | | |  | | | |  | | --- | | Introduce heat radiation between surfaces. This option is used to provide radiative heat transfer between closely adjacent surfaces. It must be used in conjunction with the [SURFACE INTERACTION](simakey-r-surfaceinteraction.md#simakey-r-surfaceinteraction) option or in an Abaqus/Standard analysis with the [GAP](simakey-r-gap.md#simakey-r-gap) option.  For coupled temperature-displacement cohesive elements, this option must be used in conjunction with the [MATERIAL](simakey-r-material.md#simakey-r-material) option.
