| |  |  | | --- | --- | | \*MOHR COULOMB HARDENING | | |  | | | |  | | --- | | Specify hardening for the Mohr-Coulomb plasticity model. This option is used to define piecewise linear hardening/softening behavior for a material defined by the Mohr-Coulomb plasticity model. It must be used in conjunction with the [MOHR COULOMB](simakey-r-mohrcoulomb.md#simakey-r-mohrcoulomb) option. If this parameter is omitted, it is assumed that the cohesion yield stress depends only on the plastic strain and, possibly, on temperature.
