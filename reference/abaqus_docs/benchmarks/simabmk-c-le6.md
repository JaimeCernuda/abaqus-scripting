Mesh: A coarse (2 × 2) and a fine (4 × 4) are tested for each element. In addition, a very fine (8 × 8) mesh is tested for each element in the explicit dynamic analysis.  Material: Linear elastic, Young's modulus = 210 GPa, Poisson's ratio = 0.3, density = 7800 kg/m3.  Boundary conditions: uz=0 along edges AB, BC, CD, and AD. ux=uy=​ 0 at point A and uy=0 at point B to prevent rigid body motion.  Loading: Uniform pressure of −7.0 kPa in the vertical z-direction. In the explicit dynamic analysis the loading is applied such that a quasi-static solution is obtained.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test LE6 from NAFEMS Publication TNSB, Rev. 3, “The Standard NAFEMS Benchmarks,” October 1990.  Target solution: Maximum principal stress = 0.802 MPa on the lower surface at point E.
