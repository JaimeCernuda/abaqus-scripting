Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test 3DNLG-5 from NAFEMS Publication R0024 “A Review of Benchmark Problems for Geometric Non-linear Behaviour of 3D Beams and Shells (SUMMARY).”  The published results of this problem were obtained with Abaqus. The NAFEMS study includes results from other sources for comparison that may provide a basis for verification of this problem.  Results and discussion All elements are tested with meshes using the same nodal spacing.  The results vary slightly between different element types. The maximum difference in the reported displacement components is 1.3%. The hybrid element results are identical to their non-hybrid counterparts to the precision reported here.
