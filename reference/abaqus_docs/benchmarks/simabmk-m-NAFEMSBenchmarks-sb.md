| |  |  | | --- | --- | | NAFEMS Benchmarks | | |  | | | |  | | --- | | This chapter defines some of the finite element benchmarks that are recommended by the National Agency for Finite Element Methods and Standards (UK). The first three categories of benchmarks documented here are the Linear Elastic, Temperature, and Free Vibration tests described in NAFEMS publication TNSB, Rev. 3, “The Standard NAFEMS Benchmarks,” October 1990. Proposed benchmarks from the draft documents “Selected Benchmarks for Forced Vibration,” R0016, March 1993, and “NAFEMS Non-linear Benchmarks,” October 1989, are also included here.
