Half of the axisymmetric test geometry is modeled.  Material: Young's modulus = 207 GPa, Poisson's ratio = 0.3.  Boundary conditions: ur=0 along edge AB, uz=0 along edge AE.  Loading: Uniform stress, σy⁢y = 100 N/mm2.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test 5 from NAFEMS publication “2D Test Cases in Linear Elastic Fracture Mechanics,” R0020.  Target solution: KI/K​0 = 0.475, K​0 = σ⁢R2⁢π⁢bb2  Results and discussion The results are shown in the following table.
