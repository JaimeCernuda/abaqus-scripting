Boundary conditions: A quarter-section is modeled with the symmetry conditions uy=​ 0 along y=​ 0 and ux=​ 0 along x=​ 0.  Loading: Within the hot-spot, thermal strain (α⁢T) = 1.0 × 10−3. Outside the hot-spot, thermal strain (α⁢T) = 0.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test T1 from NAFEMS publication TNSB, Rev. 3, “The Standard NAFEMS Benchmarks,” October 1990.  Target solution: σy⁢y at point D (outside the hot-spot) = 50.0 MPa.  Results and discussion The results are shown in the following table.
