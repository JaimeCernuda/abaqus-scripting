Half of the test geometry is modeled.  Material: Young's modulus = 207 GPa, Poisson's ratio = 0.3.  Boundary conditions: ux=0 at point A, uy=0 along edge BA.  Loading: Concentrated force, P = 1000 N.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test 6 from NAFEMS publication “2D Test Cases in Linear Elastic Fracture Mechanics,” R0020.  Target solution: KI/K​0 = 9.659, K0 = Pt⁢w  Results and discussion The results are shown in the following table.
