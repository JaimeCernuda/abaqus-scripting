Forcing function Steady-state harmonic.  F=F0 sin⁡(ω⁢t)  F0=​ 100 N/m2 over whole plate.  ω=2⁢π⁢f  f=​ 0 to 4.16 Hz  Damping ζ=​ 2%  Response uz and σ11 at center of plate.  General: Gauss integration is used for the shell cross-section in input file [nfh1368x.inp](../SIMAINPRefResources/nfh1368x.inp).  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test 13H from NAFEMS “Selected Benchmarks for Forced Vibration,” R0016, March 1993.
