Mesh: A coarse mesh and a fine mesh are tested in the Abaqus/Explicit analyses.  Forcing function Suddenly applied step load, transverse to the beam.  F0=​ 1 MN/m over whole length of beam.  Damping ζ=​ 2% [2% of critical damping in the dominant first mode with analytical frequency value f=​ 42.650 (Hz) or ω=2⁢π⁢f=​ 267.98 (sec−1)].  The damping factors are chosen as αR=​ 5.36 (sec−1) and βR=​ 7.46 × 10−5 (sec) so that  ζ=αR2⁢ω+βR⁢ω2=0.01+0.01=0.02.  Response uy and extreme fiber bending stress.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test 5T from NAFEMS “Selected Benchmarks for Forced Vibration,” R0016, March 1993.
