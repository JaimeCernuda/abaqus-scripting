The full test geometry is modeled.  Material: Young's modulus = 207 GPa, Poisson's ratio = 0.3.  Boundary conditions: ux=0 along edge AB and CD, uy=0 along edge CD.  Loading: Uniform stress, σy⁢y = 100 N/mm2.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test 7.1 from NAFEMS publication “2D Test Cases in Linear Elastic Fracture Mechanics,” R0020.  Target solution: KI/K​0 = 1.317, K​0 = σ⁢π⁢a  Results and discussion The results are shown in the following table.
