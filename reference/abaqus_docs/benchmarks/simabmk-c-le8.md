Mesh: A coarse and a fine mesh are tested.  Material: Linear elastic, Young's modulus = 210 GPa, Poisson's ratio = 0.3, density = 7800 kg/m3.  Boundary conditions: uz=​ 0 at point A. ur=ϕ=​ 0 at point F.  Loading: Uniform internal pressure of 1.0 MPa. In the explicit dynamic analysis the loading is applied such that a quasi-static solution is obtained.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test LE8 from NAFEMS Publication TNSB, Rev. 3, “The Standard NAFEMS Benchmarks,” October 1990.
