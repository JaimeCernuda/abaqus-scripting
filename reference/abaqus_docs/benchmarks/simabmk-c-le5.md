Material: Linear elastic, Young's modulus = 210 GPa, Poisson's ratio = 0.3, density = 7800 kg/m3.  Boundary conditions: All displacements are zero along the edge at x=​ 0.  Loading: Torque of 1.2 MN-m applied at x=​ 10. The torque is applied by two uniformly distributed edge shears of 0.6 MN at each flange when shell elements are used. In the explicit dynamic analysis the loading rate is applied such that a quasi-static solution is obtained.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test LE5 from NAFEMS publication TNSB, Rev. 3, “The Standard NAFEMS Benchmarks,” October 1990.  Target solution: Axial stress, σx⁢x=​ −108 MPa at midsurface, point A.
