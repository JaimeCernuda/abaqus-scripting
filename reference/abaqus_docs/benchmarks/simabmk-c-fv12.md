Material: Young's modulus = 200 GPa, Poisson's ratio = 0.3, density = 8000 kg/m3.  Boundary conditions: ux=uy=ϕz=0 at all nodes. The continuum shell meshes use equation constraints to provide equivalent midsurface kinematic constraints.  Reference solution This is a test recommended by the National Agency for Finite Element Methods and Standards (U.K.): Test FV12 from NAFEMS publication TNSB, Rev. 3, “The Standard NAFEMS Benchmarks,” October 1990.  Mode shapes predicted by Abaqus (for element type S4R5) The contour plots were generated by setting the maximum and minimum contour levels close to zero. Where contour levels coincided with the element boundaries, the maximum contour level was increased and the minimum contour level was decreased appropriately.
