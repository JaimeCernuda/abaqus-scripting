| |  |  | | --- | --- | | Accessing the C++ interface from an existing application | | |  | | | |  | | --- | | This section provides information that may be helpful to users who need to access results in an output database from an existing application.  Most users should find that the abaqus make utility is sufficient for their postprocessing needs. Since linking and executing with dynamically linked runtime libraries is highly system dependent, the information in this section is intended for users who have an advanced working knowledge of compilation and linking with runtime libraries. It is important to ensure that the compiler used to compile and link the existing application is consistent with the compilers used to generate the Abaqus release. The “System Requirements” document lists the name and version of the compiler used for the Abaqus release on each supported platform. You can access this document through the System Information section of the Support page at [www.3ds.com/simulia](http://www.3ds.com/simulia).
