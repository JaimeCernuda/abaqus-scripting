|  |  |  |  |  |  |  |  |

| |  |  | | --- | --- | | Editing files in the Abaqus PDE | | |  | | | |  | | --- | | You can use the Edit menu to edit scripts in the Abaqus PDE. The Edit menu contains common editing tools, including Undo, Redo, Copy, Cut, Paste, Find, and Replace. It also contains the following tools for editing scripts: | | |   * Indent Region > * Unindent Region < * Comment Region ## * Uncomment Region   To use these tools, highlight one or more lines of code in the main window and select the desired option from the Edit menu. The Edit menu also contains a keyboard shortcut for each of the editing tools. |
