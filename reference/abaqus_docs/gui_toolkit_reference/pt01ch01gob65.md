| |  |  | | --- | --- | | AFXVerticalAligner | | |  | | |  |   This class is used to automatically vertically align its children "container" widgets (e.g. AFXTextField or AFXComboBox). The width of the first widget in the container of each child of the vertical aligner is set to the width of the widest first widget of all the vertical aligner's children.
