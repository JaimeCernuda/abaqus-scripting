| |  |  | | --- | --- | | FXTabItem | | |  | | |  |   A tab item is placed in a tab bar or tab book. When selected, the tab item sends a message to its parent, and causes itself to become the active tab, and raised slightly above the other tabs. In the tab book, activating a tab item also causes the corresponding panel to be raised to the top. Reimplemented from FXWindow.
