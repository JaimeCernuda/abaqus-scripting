| |  |  | | --- | --- | | Message dialogs | | |  | | |  |   The following methods provide access to the standard message dialogs.  showAFXDismissableWarningDialog  showAFXDismissableWarningDialog(owner, message, tgt=None, sel=0)  Posts a modal dismissable warning dialog box that has a "Show this dialog next time" check button, via which the user can request not to see a specific type of messages in the future. The dialog box has a getCheckButtonState method that can be called to get the state of the check button in the dialog box.   |  |  |  |  | | --- | --- | --- | --- | | **Argument** | **Type** |
