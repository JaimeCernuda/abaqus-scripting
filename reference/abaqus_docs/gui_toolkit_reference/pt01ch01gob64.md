| |  |  | | --- | --- | | AFXTupleKeyword | | |  | | |  |   This class manages values which are sent as tuples in a command.  Widgets used to edit the whole tuple should have their message ID set to 0. It is also possible to edit individual elements of the tuple. In order to edit the N-th tuple element, the widget's message ID should be set to N (N is 1-based).
