| |  |  | | --- | --- | | Getting started with Abaqus | | |  | | | |  | | --- | | This guide is an introductory text designed to give new users guidance in creating solid, shell, beam, and truss models with Abaqus/CAE, analyzing these models with Abaqus/Standard and Abaqus/Explicit, and viewing the results in the Visualization module. You do not need any previous knowledge of Abaqus to benefit from this guide, although some previous exposure to the finite element method is recommended. If you are already familiar with the Abaqus solver products (Abaqus/Standard or Abaqus/Explicit) but would like an introduction to the Abaqus/CAE interface, three tutorials are provided in the appendices of this guide to lead you through the modeling process in Abaqus/CAE. This document covers primarily stress/displacement simulations, concentrating on both linear and nonlinear static analyses as well as dynamic analyses.
