| |  |  | | --- | --- | | Running the analysis in Abaqus/Explicit | | |  | | | |  | | --- | | As an optional exercise, you can modify the model and run a dynamic analysis of the skew plate in Abaqus/Explicit. To do so, you must add a density of 7800 kg/m3 to the material definition, replace the existing step with an explicit dynamic step, and change the element library to Explicit. After making the appropriate model changes, you can create and run a new job to examine the transient dynamic effects in the plate under a suddenly applied load. | | | |
