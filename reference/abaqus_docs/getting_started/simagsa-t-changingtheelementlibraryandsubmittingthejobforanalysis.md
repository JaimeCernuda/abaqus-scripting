| |  |  | | --- | --- | | Changing the element library and submitting the job for analysis | | |  | | | |  | | --- | | The elements available in Abaqus/Explicit are a subset of those available in Abaqus/Standard, so you must change the element library from which the elements are selected to the explicit element library. After changing the element library, you will create and run a new job for the Abaqus/Explicit analysis. To ensure that you are using a valid element type in your analysis, Abaqus/CAE automatically filters the available element types according to the selected element library.  This task shows you how to:   * [Change the element library](#simagsa-t-simagsa-t-changingtheelementlibraryandsubmittingthejobforanalysis-subtask0) * [Create and run the new job](#simagsa-t-simagsa-t-changingtheelementlibraryandsubmittingthejobforanalysis-subtask1) | | |  | | --- | | See Also | | [Finite Elements and Rigid Bodies](simagsa-m-Elementintro-sb.md#simagsa-m-Elementintro-sb) | |       Change the element library 1. In the    Model Tree,    expand the Frame item underneath the    Parts container. Then double-click    Mesh in the list that appears. Abaqus/CAE    switches to the    Mesh module. 2. From the main menu bar, select    MeshElement    Type, select the set all (or    pick the entire frame in the viewport), and change the Element    Library selection to Explicit. 3. Click OK to accept the new element type.  Create and run the new job 1. In the    Model Tree,    double-click the Jobs container. 2.
