| |  |  | | --- | --- | | How to use this guide | | |  | | | |  | | --- | | The different sections of this guide are addressed to different types of users. | | |   Tutorials for new Abaqus users  If you are completely new to Abaqus, we recommend that you follow each of the self-paced tutorials in this guide. Each of the sections in this guide introduces one or more topics relevant to using Abaqus/Standard and Abaqus/Explicit. Throughout the guide the term Abaqus is used to refer to both of these analysis products; the individual product names are used when information applies to only one product. Most sections contain a short discussion of the topic or topics being considered and one or two tutorial examples. You should work through the examples carefully since they contain a great deal of practical advice on using Abaqus.  The capabilities of Abaqus/CAE are introduced gradually in these examples. It is assumed that you will use Abaqus/CAE to create the models used in the examples. You can also generate the model for any example using a script that replicates the complete analysis model for the problem. A model created from a script may differ slightly from that created by following the steps in this guide. These differences, such as material names or node numbers, are minor and can be ignored. Scripts are available in two locations:   * A Python script is provided for each example in   [Example Files](simagsa-m-Appendix-sb.md).   The same section also provides instructions on how to fetch the script and run   it within   Abaqus/CAE. * Abaqus/CAE   plug-in scripts are provided for each example in the Getting Started   Examples dialog box of the   Abaqus/CAE   Plug-in toolset. For more information about running these scripts, see   [Running the Getting Started with Abaqus examples](.._SIMACAECAERefMap_simacae-c-plgexamplegst.md).   This section is a short introduction to Abaqus and this guide. [Abaqus Basics](simagsa-m-Abasics-sb.md), which is centered around a simple example, covers the basics of using Abaqus. By the end of [Abaqus Basics](simagsa-m-Abasics-sb.md), you will know the fundamentals of how to prepare a model for an Abaqus simulation, check the data, run the analysis job, and view the results.  [Finite Elements and Rigid Bodies](simagsa-m-Elementintro-sb.md) presents an overview of the main element families available in Abaqus. The use of continuum (solid) elements, shell elements, and beam elements is discussed in [Using Continuum Elements](simagsa-m-Continuumelem-sb.md), [Using Shell Elements](simagsa-m-Shell-sb.md), and [Using Beam Elements](simagsa-m-Beamelem-sb.md), respectively.  Linear dynamic analyses are discussed in [Linear Dynamics](simagsa-m-Stddynamics-sb.md). [Nonlinearity](simagsa-m-Intrononlin-sb.md) introduces the concept of nonlinearity in general, and geometric nonlinearity in particular, and contains the first nonlinear Abaqus simulation. Nonlinear dynamic analyses are discussed in [Nonlinear Explicit Dynamics](simagsa-m-Expdynamics-sb.md), and material nonlinearity is introduced in [Materials](simagsa-m-Materials-sb.md). [Multiple Step Analysis](simagsa-m-Multistep-sb.md) introduces the concept of multistep simulations, and [Contact](simagsa-m-Contact-sb.md) discusses the many issues that arise in contact analyses. Using Abaqus/Explicit to solve quasi-static problems is presented in [Quasi-Static Analysis with Abaqus/Explicit](simagsa-m-Quasi-sb.md). The illustrative example is a sheet metal forming simulation, which requires importing between Abaqus/Explicit and Abaqus/Standard to perform the forming and springback analyses efficiently.  Abaqus/CAE tutorials for experienced Abaqus users  Several tutorials are provided to introduce users familiar with the Abaqus analysis products to the Abaqus/CAE interface. In [Creating and Analyzing a Simple Model in Abaqus/CAE](simagsa-m-Caebeam-sb.md), you create a simple model, analyze it, and then view the results. The second tutorial, [Using Additional Techniques to Create and Analyze a Model in Abaqus/CAE](simagsa-m-Caehinge-sb.md) is more complex and illustrates how parts, sketches, datum geometry, and partitions work together and how you assemble part instances. [Viewing the Output from Your Analysis](simagsa-m-Caevismod-sb.md) demonstrates how you can use the Visualization module (also licensed separately as Abaqus/Viewer) to display your results in a variety of formats and how you can customize the display. |
