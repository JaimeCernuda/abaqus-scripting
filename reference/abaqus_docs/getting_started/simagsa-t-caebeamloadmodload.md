# Applying a load to the top of the cantilever beam

| |  |  | | --- | --- | | Applying a load to the top of the cantilever beam | | |  | | | |  | | --- | | Now that you have fixed one end of the cantilever beam, you can apply a distributed load to the top face of the beam. The load is applied during the general, static step you created earlier. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [The Load module](.._SIMACAECAERefMap_simacae-m-Lbi-sb.md) | | [What are step-dependent managers?](.._SIMACAECAERefMap_simacae-c-intstepmanager.md) | |   1. In the Model Tree, double-click the Loads container. The Create Load dialog box appears. 2. In the Create Load dialog box:    1. Name the load `Pressure`.    2. From the list of steps, select `BeamLoad` as the step in which the load will be applied.    3. In the Category list, accept Mechanical as the default category selection.    4. In the Types for Selected Step list, select Pressure, and click Continue. Abaqus/CAE displays prompts       in the prompt area to guide you through the procedure. 3. In the viewport, select the top face of the beam as the surface to which the load will be applied. The desired face is shown by the gridded face in [Figure 1](simagsa-t-caebeamloadmodload.md#simagsa-t-caebeamloadmodload__simagsa-t-gst-load). Figure 1. Selecting the region on which to apply a pressure load. 4. Click mouse button 2 in the viewport or click Done in the prompt area to indicate that you have finished selecting regions. The Edit Load dialog box appears. 5. In the dialog box:    1. Enter a magnitude of `0.5` MPa for the load.    2. Accept the default Distribution selection—Abaqus will apply the load uniformly over the face.    3. Accept the default Amplitude selection—Abaqus will ramp up the load during the step.    4. Click OK to create the load and to close the dialog box. Abaqus/CAE displays downward-pointing arrows along the top face of the beam to indicate the load applied in the negative 2-direction. 6. Examine the Load Manager and note that the new load is Created (activated) in the general analysis step `BeamLoad`. 7. Click Dismiss to close the Load Manager. |
