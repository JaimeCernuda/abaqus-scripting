| |  |  | | --- | --- | | Creating assembly-level sets | | |  | | | |  | | --- | | We now focus on assembling the model. | | |   Since the parts are already aligned with the global Cartesian coordinate system shown in [Figure 1](simagsa-c-creatingassemblylevelsets.md#simagsa-c-creatingassemblylevelsets__simagsa-c-creatingassemblylevelsets-dimensions-cargo-crane-fig), no further manipulations of the parts are necessary. Figure 1. Dimensions (in m) of the cargo crane.     At this point, however, it is convenient to define assembly-level geometry sets that will be used later. In the Model Tree, expand the Assembly container and double-click Sets. Define a geometry set containing the vertices corresponding to points A through D (refer to [Figure 2](simagsa-c-creatingassemblylevelsets.md#simagsa-c-creatingassemblylevelsets__simagsa-c-creatingassemblylevelset-cargo-crane-fig) for the exact locations), and name the set `Attach`. When defining this set, be sure to select the vertices of the truss and not reference points. You may need to use the Selection toolbar to aid in your selection. Figure 2. Sketch of a light-service cargo crane.     In addition, create sets at the vertices located at the tips of the trusses (location E in [Figure 2](simagsa-c-creatingassemblylevelsets.md#simagsa-c-creatingassemblylevelsets__simagsa-c-creatingassemblylevelset-cargo-crane-fig)). Name the sets `Tip-a` and `Tip-b`, with `Tip-a` being the geometry set associated with truss A (see [Figure 3](simagsa-c-creatingassemblylevelsets.md#simagsa-c-creatingassemblylevelsets__simagsa-c-creatingassemblylevelsets-final-geom-fig)). Finally, create a set for each region where beam normals will be specified, referring to [Figure 3](simagsa-c-creatingassemblylevelsets.md#simagsa-c-creatingassemblylevelsets__simagsa-c-creatingassemblylevelsets-final-geom-fig). For truss A, create a set named `Inner-a` for the region indicated by R2 and a set named `Leg-a` for the region indicated by R5; create corresponding sets `Inner-b` and `Leg-b` for truss B. Figure 3. Final geometry of the truss structures; highlighted vertices indicate the locations of the pin joints. |
