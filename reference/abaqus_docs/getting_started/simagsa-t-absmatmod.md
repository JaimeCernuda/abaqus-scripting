| |  |  | | --- | --- | | Creating a material | | |  | | | |  | | --- | | In this problem all the members of the frame are made of steel and assumed to be linear elastic with Young's modulus of 200 GPa and Poisson's ratio of 0.3. Thus, you will create a single linear elastic material with these properties. | | |   1. In the    Model Tree,    double-click the Materials container to create a new    material. Abaqus/CAE    switches to the    Property module,    and the Edit Material dialog box appears. 2. Name the material `Steel`. 3. Use the menu bar under the browser area of the material editor to    reveal menus containing all the available material options. Some of the menu    items contain submenus; for example,    [Figure 1](simagsa-t-absmatmod.md#simagsa-t-absmatmod__simagsa-t-buttons)    shows the options available under the    MechanicalElasticity    menu item. When you select a material option, the appropriate data entry form    appears below the menu. Figure 1. Submenus available under the    MechanicalElasticity    menu. 4. From the material editor's menu bar, select    MechanicalElasticityElastic. Abaqus/CAE    displays the Elastic data form. 5. Type a value of `200.0E9` for Young's    modulus and a value of `0.3` for Poisson's ratio    in the respective fields. Use Tab or move the cursor to a new    cell and click to move between cells. 6. Click OK to exit the material editor. |
