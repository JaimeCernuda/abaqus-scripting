| |  |  | | --- | --- | | Customizing an undeformed shape plot | | |  | | | |  | | --- | | You will now use the plot options to enable the display of node and element numbering. Plot options that are common to all plot types (undeformed, deformed, contour, symbol, and material orientation) are set in a single dialog box. The contour, symbol, and material orientation plot types have additional options, each specific to the given plot type.  This task shows you how to:   * [Display node numbers](#simagsa-t-simagsa-t-customizinganundeformedshapeplot-subtask0) * [Display element numbers](#simagsa-t-simagsa-t-customizinganundeformedshapeplot-subtask1) | | |     Display node numbers 1. From the main menu bar, select    OptionsCommon;    or use the     tool in the toolbox. The Common Plot Options dialog box appears. 2. Click the Labels tab. 3. Toggle on Show node labels. 4. Click Apply. Abaqus/CAE    applies the change and keeps the dialog box open.  The customized undeformed plot is shown in    [Figure 1](simagsa-t-customizinganundeformedshapeplot.md#simagsa-t-simagsa-t-customizinganundeformedshapeplot-subtask0__simagsa-nodeplot)    (your node numbers may be different).  Figure 1. Node number plot.  Display element numbers 1. In the Labels tabbed page of the Common    Plot Options dialog box, toggle on Show element    labels. 2. Click OK. Abaqus/CAE    applies the change and closes the dialog box.  The resulting plot is shown in    [Figure 2](simagsa-t-customizinganundeformedshapeplot.md#simagsa-t-simagsa-t-customizinganundeformedshapeplot-subtask1__simagsa-nodeelem)    (your element numbers may be different).  Figure 2. Node and element number plot.  Remove the node and element labels before proceeding. To disable the    display of node and element numbers, repeat the above procedure and, under    Labels, toggle off Show node labels    and Show element labels. |
