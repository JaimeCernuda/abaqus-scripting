# Customizing a model plot

| |  |  | | --- | --- | | Customizing a model plot | | |  | | | |  | | --- | | You will now use the plot options to request element numbering. | | |   Context: A common set of plot options for all plot states—undeformed, deformed, contour, etc.—is provided to allow you to customize the appearance of a plot. Regardless of the plot state, customization options apply only to the current viewport and are not saved between sessions.  1. From the main menu bar, select    OptionsCommon. Abaqus    displays the Common Plot Options dialog box. 2. By default,    Abaqus    fills the model in green and hides element labels. You will change the color of    the element labels from cyan to red and display them. From the Common    Plot Options dialog box, click the Labels tab    and do the following:    1. Toggle on Show element labels.    2. Click Apply. Abaqus       displays the element numbering using cyan text.    3. Click the color sample       for the element labels. Abaqus       displays the Select Color dialog box.    4. Click the       RGB tab and set the red,       green, and blue values to 255, 0, and 0, respectively. |  |       | --- |       | Tip: You can also select red from the colors near the bottom of the dialog box or use any of the other available selection methods. |    5. Click OK to accept your selection. Abaqus       closes the Select Color dialog box and updates the color       sample to red.    6. Click OK. The color of the element labels changes from cyan to red, and the       Common Plot Options dialog box closes. |
