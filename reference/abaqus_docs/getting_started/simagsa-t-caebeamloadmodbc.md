# Applying a boundary condition to one end of the cantilever beam

| |  |  | | --- | --- | | Applying a boundary condition to one end of the cantilever beam | | |  | | | |  | | --- | | Create a boundary condition that constrains the cantilever beam to be built-in at one end of the beam. | | |  | | --- | | See Also |  |  | | --- | |  | | In Other Guides | | [The Load module](.._SIMACAECAERefMap_simacae-m-Lbi-sb.md) | |   1. In the Model Tree, double-click the BCs container. Abaqus/CAE switches to the Load module, and the Create Boundary Condition dialog box appears. 2. In the Create Boundary Condition dialog box:    1. Name the boundary condition `Fixed`.    2. From the list of steps, select `Initial` as the step in which the boundary condition will be activated.    3. In the Category list, accept Mechanical as the default category selection.    4. In the Types for Selected Step list, accept Symmetry/Antisymmetry/Encastre as the default type selection, and click Continue. Abaqus/CAE displays prompts       in the prompt area to guide you through the procedure. 3. You will fix the face at the left end of the cantilever beam; the desired face is shown in [Figure 1](simagsa-t-caebeamloadmodbc.md#simagsa-t-caebeamloadmodbc__simagsa-t-gst-ambig2). Figure 1. Selecting the region on which to apply a boundary condition.  Rotate the view in order to select the face. Click OK to confirm your choice. 4. Click mouse button 2 in the viewport or click Done in the prompt area to indicate that you have finished selecting. The Edit Boundary Condition dialog box appears. 5. In the dialog box:    1. Toggle on ENCASTRE.    2. Click OK to create the boundary condition and to close the dialog box. Abaqus/CAE displays arrows at each corner and midpoint on the selected face to indicate the constrained degrees of freedom. Single-headed arrows represent a constraint that is applied to a translational degree of freedom. Double-headed arrows represent a constraint that is applied to a rotational degree of freedom. An ENCASTRE boundary condition constrains all available degrees of freedom. 6. In the Model Tree, click mouse button 3 on the BCs container and select Manager from the menu that appears. Abaqus/CAE displays the Boundary Condition Manager. The manager indicates that the boundary condition is `Created` (activated) in the initial step and is `Propagated` (continues to be active) in the general analysis step `BeamLoad`. 7. Click Dismiss to close the Boundary Condition Manager. |
