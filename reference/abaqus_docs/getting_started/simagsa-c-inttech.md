| |  |  | | --- | --- | | Technical support | | |  | | | |  | | --- | | SIMULIA technical support engineers are available to assist in clarifying Dassault Systèmes product features and checking errors by giving both general information on using Dassault Systèmes products and information on their application to specific analyses. If you have concerns about a model, analysis, or workflow, we suggest that you contact us at an early stage since it is usually easier to solve problems at the beginning of a project rather than trying to correct them at the end. | | |   To access support, you can select the Submit a request link at [http://www.3ds.com/support](http://www.3ds.com/support) to see the online support tool or obtain support office contact information from the LOCATION DIRECTORY at [http://www.3ds.com/products-services/simulia/locations](http://www.3ds.com/products-services/simulia/locations) to request support by telephone.  Please have the following information ready before calling the technical software support hotline, and include it in any written contacts:  * Your site identifier. * The release of the Dassault Systèmes product that you are using. * The type of computer and operating system that you are using. If you are using a   cluster, make sure you included relevant details of the compute cluster. If you are having   problems with servers when running the 3DEXPERIENCE platform, make sure you have the details about these servers. * The symptoms of any problems, including the exact error messages, if any. * Workarounds or tests that you have already tried and the results of these tests.  When calling for support about a specific problem, any available files or messages may be helpful in answering questions that the support engineer may ask you.  The support engineer will try to diagnose your problem from the model description and a description of the difficulties you are having. The more detailed information you provide, the easier it will be for the support engineer to understand and solve your problem.  If the support engineer cannot diagnose your problem from this information, you may be asked to supply the model information data. The data can be attached to a support request in the online system. It can also be sent by means of email, or the support engineer can determine how you can transfer the data electronically to Dassault Systèmes.  If you are contacting us via telephone to discuss an existing problem, please give the receptionist the support engineer's name. If you are contacting us via email, please include the support engineer's name at the top of any email correspondence. If you are contacting us online (preferred for written communication), update the existing support request for the problem. |
