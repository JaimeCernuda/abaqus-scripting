# Customizing the symbol plot

|  |  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Customizing the symbol plot | | |  | | | |  | | --- | | You will now customize your symbol plot by changing the visible edges and the arrow size and color. | | |   1. From the main menu bar, select OptionsCommon. The Common Plot Options dialog box appears. 2. In the Common Plot Options dialog box, click the Basic tab if it is not already selected. Choose Wireframe for the render style and Feature edges for the visible edges. 3. From the main menu bar, select OptionsSymbol. The Symbol Plot Options dialog box appears. 4. In the Color & Style tabbed page, do the following:    1. Click the Vector tab.    2. Set the color type to Uniform.    3. Click the color sample . Abaqus/CAE displays the Select Color dialog box.    4. Click the RGB tab and set the red, green, and blue values to 0, 255 and 255, respectively. |  |       | --- |       | Tip: You can also select cyan from the colors near the bottom of the dialog box or use any of the other available selection methods. |    5. Click OK to accept your selection and to close the Select Color dialog box.    6. Drag the Size slider to select `12` as the maximum length of the vector. 5. Click OK to apply your changes and to close the Symbol Plot Options dialog box. The customized symbol plot appears, as shown in [Figure 1](simagsa-t-vismodvectorcustom.md#simagsa-t-vismodvectorcustom__simagsa-t-gst-tut3-sym2). Figure 1. Customized symbol plot. |
