| |  |  | | --- | --- | | Units | | |  | | | |  | | --- | | Before starting to define this or any model, you need to decide which system of units you will use. Abaqus has no built-in system of units. Do not include unit names or labels when entering data in Abaqus. All input data must be specified in consistent units.
