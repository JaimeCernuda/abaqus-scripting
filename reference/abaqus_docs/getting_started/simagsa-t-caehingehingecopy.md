# Copying the hinge

|  |  |  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- | --- | --- |
| |  |  | | --- | --- | | Copying the hinge | | |  | | | |  | | --- | | First you will create an exact copy of the hinge piece. | | |   1. In the Model Tree, click mouse button 3 on Hinge-hole underneath the Parts container and select Copy from the menu that appears. Abaqus/CAE displays the Part Copy dialog box. 2. In the text box in the Part Copy dialog box, type `Hinge-solid`, and click OK. Abaqus/CAE creates a copy of the hinge piece and names the copy Hinge-solid. The copy of the hinge piece includes the section from the original hinge piece. |
