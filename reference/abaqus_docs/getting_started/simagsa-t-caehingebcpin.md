| |  |  | | --- | --- | | Constraining the pin | | |  | | | |  | | --- | | In the first general step of the analysis you will establish contact between the two hinge pieces and between the hinge pieces and the pin. To fix the pin during this step, you must apply a boundary condition to the pin that constrains all its degrees of freedom. | | |   1. In the Boundary Condition Manager, click Create. The Create Boundary Condition dialog box appears. 2. In the Create Boundary Condition dialog box:    1. Name the boundary condition `NoSlip`.    2. Accept `Initial` in the Step text field.    3. Accept Mechanical as the default Category selection.    4. Select Displacement/Rotation as the type of boundary condition for the selected step.    5. Click Continue. 3. In the viewport, select the rigid body reference point on the pin as the region where the boundary condition will be applied. 4. Click mouse button 2 to indicate that you have finished selecting regions. The Edit Boundary Condition dialog box appears. 5. In the dialog box:    1. Toggle on all the buttons to constrain all the degrees of freedom of the pin.    2. Click OK. The new boundary condition appears in the Boundary Condition Manager. |
