| |  |  | | --- | --- | | Checking the model with Abaqus/CAE | | |  | | | |  | | --- | | You can use Abaqus/CAE to check that the model is correct before running the simulation. You have already learned how to draw plots of the model and to display the node and element numbers. These are useful tools for checking that Abaqus is using the correct mesh. | | |   Context:  The boundary conditions applied to the overhead hoist model can also be displayed and checked in the Visualization module.  1. Click the  tool in the toolbox to disable multiple plot states in the viewport. 2. Display the undeformed model shape, if it is not displayed already. 3. From the main menu bar, select ViewODB Display Options. 4. In the ODB Display Options dialog box, click the Entity Display tab. 5. Toggle on Show boundary conditions. 6. Click OK. Abaqus/CAE displays symbols to indicate the applied boundary conditions, as shown in [Figure 1](simagsa-t-checkingthemodelwithabaquscae.md#simagsa-t-checkingthemodelwithabaquscae__simagsa-overheadhoist).
