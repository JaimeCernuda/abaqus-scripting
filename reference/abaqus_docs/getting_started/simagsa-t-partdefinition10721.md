| |  |  | | --- | --- | | Part definition | | |  | | | |  | | --- | | Create an axisymmetric, deformable, shell part. Name the part `Mount`, and specify an approximate part size of `0.3`. Because of symmetry considerations, only the bottom half of the mount will be modeled. You can use the following suggested approach to create the part geometry. When you first enter the sketcher, the axis of revolution is displayed as a green dashed line with a fixed position constraint; your sketch cannot cross this axis. | | |   1. Draw an arbitrary rectangle to the right of the axis of symmetry. Dimension it as follows:    1. Set the horizontal distance between the axis of symmetry and the left edge of the rectangle to 0.01 m.    2. Set the vertical height of the rectangle to 0.030 m and its horizontal span to 0.050 m. 2. Sketch a circle using the Create Circle: Center and Perimeter tool . Select any point to the right of the rectangle as the center, and snap the perimeter point to any point along the right edge of the rectangle. Dimension the circle as follows:    1. Set the horizontal distance between the axis of symmetry and the center of the circle to 0.1 m.    2. Set the vertical distance between the center of the circle and the top-right vertex of the rectangle to 0 m.    3. Set the vertical distance between the perimeter point (where the circle snaps to the rectangle) and the bottom-right vertex of the rectangle to 0.005 m.
