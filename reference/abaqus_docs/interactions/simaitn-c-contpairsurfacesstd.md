The finite-sliding, node-to-surface formulation will not account for surface thickness. Node-based surfaces have no thickness, regardless of which element types are connected to the surface nodes. Accounting for element thicknesses in contact calculations is generally desirable, but you can avoid having thickness considered if it is not desired.  Input File Usage   ``` [CONTACT PAIR](.._SIMACAEKEYRefMap_simakey-r-contactpair.md#simakey-r-contactpair), NO THICKNESS ```   Abaqus/CAE Usage   ``` Interaction module: interaction editor: Sliding formulation: Small sliding or Finite sliding, Discretization method: Surface to surface or Node to surface, toggle on Exclude shell/membrane element thickness ```  Example Consider the case of a shell pinched between two rigid surfaces, as shown in [Figure 1](simaitn-c-contpairsurfacesstd.md#simaitn-c-contpairsurfacesstd-t-Example-sma-topic1__simaitn-c-pinchedshellcontact). Figure 1. Shell pinched between two rigid bodies.   In this example contact pairs using the small-sliding, node-to-surface formulation are defined between the top surface of the shell and the top rigid surface and between the bottom surface of the shell and the bottom rigid surface. Although the shell surfaces are defined at the shell reference location, the contact interactions account for the thickness of the shell and are offset from the reference surface. The penalty constraint enforcement method (see [Contact Pressure-Overclosure Relationships](simaitn-c-normalinteraction.md)) is used to avoid overconstraining secondary nodes. The use of a faceted surface geometry rather than the true surface geometry can significantly contribute to contact stress inaccuracy in contact pairs, especially when the magnitude of the differences between the faceted and true surface is not small with respect to the deformation of the components in contact. Methods for overcoming convergence and accuracy difficulties associated with faceted surfaces in contact interactions are discussed in [Contact Formulations in Abaqus/Standard](simaitn-c-contactpairform.md) and [Smoothing Contact Surfaces in Abaqus/Standard](simaitn-c-smoothsurfaces.md). |
