Multiple contact pairs can refer to the same contact property definition.  Input File Usage  Use both of the following options:   ``` [CONTACT PAIR](.._SIMACAEKEYRefMap_simakey-r-contactpair.md#simakey-r-contactpair), INTERACTION=interaction_property_name surface_1, surface_2 [SURFACE INTERACTION](.._SIMACAEKEYRefMap_simakey-r-surfaceinteraction.md#simakey-r-surfaceinteraction), NAME=interaction_property_name ```   Abaqus/CAE Usage   ``` Interaction module: ```  ``` Create Interaction Property: Name: interaction_property_name, Contact ```  ``` Interaction editor: Contact interaction property: interaction_property_name ```  Example [Figure 1](simaitn-c-contactpairpropassign.md#simaitn-c-contactpairpropassign-t-Example-sma-topic1__simaitn-c-acontactmech-exp-fric) shows the mesh used in this example. For purposes of this example, a balanced main-secondary contact pair is used. The property definition for the contact pair (`GRATING`) uses a friction model where   μ =0.4. Figure 1. Surface interaction with friction.     ``` [HEADING](.._SIMACAEKEYRefMap_simakey-r-heading.md#simakey-r-heading) … [SURFACE](.._SIMACAEKEYRefMap_simakey-r-surface.md#simakey-r-surface), NAME=ASURF ESETA, [SURFACE](.._SIMACAEKEYRefMap_simakey-r-surface.md#simakey-r-surface), NAME=BSURF ESETB, … [STEP](.._SIMACAEKEYRefMap_simakey-r-step.md#simakey-r-step) Step1 [DYNAMIC](.._SIMACAEKEYRefMap_simakey-r-dynamic.md#simakey-r-dynamic), EXPLICIT … [CONTACT PAIR](.._SIMACAEKEYRefMap_simakey-r-contactpair.md#simakey-r-contactpair), INTERACTION=GRATING ASURF, BSURF [SURFACE INTERACTION](.._SIMACAEKEYRefMap_simakey-r-surfaceinteraction.md#simakey-r-surfaceinteraction), NAME=GRATING [FRICTION](.._SIMACAEKEYRefMap_simakey-r-friction.md#simakey-r-friction) 0.4 ```  Changing Contact Properties Contact property models are defined as model or history data for a contact pair analysis. You can modify the contact properties from step to step; however, the old contact pair should be deleted and redefined using the new interaction.  Example For example, the following input could be used to change the friction coefficient used for contact between `ASURF` and `BSURF` in the second step of the analysis started in the previous example:   ``` [STEP](.._SIMACAEKEYRefMap_simakey-r-step.md#simakey-r-step) Step2 [DYNAMIC](.._SIMACAEKEYRefMap_simakey-r-dynamic.md#simakey-r-dynamic), EXPLICIT … [CONTACT PAIR](.._SIMACAEKEYRefMap_simakey-r-contactpair.md#simakey-r-contactpair), INTERACTION=GRATING,OP=DELETE ASURF, BSURF [SURFACE INTERACTION](.._SIMACAEKEYRefMap_simakey-r-surfaceinteraction.md#simakey-r-surfaceinteraction), NAME=GRATING_NEW [FRICTION](.._SIMACAEKEYRefMap_simakey-r-friction.md#simakey-r-friction) 0.5 [CONTACT PAIR](.._SIMACAEKEYRefMap_simakey-r-contactpair.md#simakey-r-contactpair), INTERACTION=GRATING_NEW ASURF, BSURF ``` |
