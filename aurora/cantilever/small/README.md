# Aurora — cantilever (small) — CPU+OpenMP run

Smoke-test / verification of the Plato Engine CPU+OpenMP build on Aurora (ALCF).

## Problem

3D cantilever beam, 100×20×10 mm, fixed at one face, point load at the opposite face. Compliance minimization with a 30 % volume constraint, SIMP penalty exponent 3, Helmholtz filter radius 15 mm. ROL trust-region solver, 50 iterations.

## Mesh

- 356 nodes, 1029 tet4 elements (`mesh.exo`, generated by `generate_mesh_simple.py` via gmsh)
- Side sets: `fixed_support` (face at x=0), `load_surface` (face at x=100)

## Run

| Item | Value |
|---|---|
| Cluster | Aurora (ALCF) |
| Build | `~/plato/spack/...` (CPU+OpenMP) |
| Compiler | gcc 13.4.0 |
| MPI | mpich 5.0.0.aurora_test |
| Scheduler | PBS Pro, queue `gpu_hack` |
| Ranks × OMP threads | 1 × 208 (single node) |
| Wall time | ~2 min total (mesh + 50 ROL iterations + viz) |
| ROL convergence | compliance 3658 → 1498 (-59 %) |
| Termination | `Iteration Limit Exceeded` (max_iterations=50, expected) |

## Files

| File | Purpose |
|---|---|
| `input.i` | Plato input deck — topology + filter + objective + constraint + ROL |
| `analyze_compliance.xml` | Plato Analyze problem (mechanical, internal elastic energy criterion) |
| `analyze_volume.xml` | Plato Analyze volume criterion |
| `generate_mesh_simple.py` | gmsh mesh generation, exports Exodus II with side sets |
| `extract_results.py` | netCDF4-based density extraction + ASCII topology |
| `render_matplotlib.py` | matplotlib viz (no GPU/X needed) |
| `run-aurora.sh` | PBS launcher for Aurora |
| `result.exo`, `restart_result.exo` | Optimized density field, exodus II |
| `ROL_Optimizer.txt` | Per-iteration convergence log |
| `topology_side_view.png` | Density heat-map projection |
| `topology_thresholded.png` | Solid shape (density > 0.3), classic two-flange topology |
| `run.log` | Full PBS job log |

## Reproduction

```bash
qsub /home/jcernuda/plato-runs/cantilever/run-aurora.sh
```

To open the result in ParaView locally: copy `result.exo` to your workstation and `File → Open` (ParaView reads Exodus natively, no conversion needed).
