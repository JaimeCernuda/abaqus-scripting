# Tosca .par File Syntax Reference

Complete block-by-block reference for the Tosca Structure parameter file format.

## General Syntax Rules

| Rule | Detail |
|------|--------|
| File encoding | UTF-8 |
| Max line length | **160 characters** (lines are silently truncated -- no error) |
| Comments | `!` or `#` at start of line, or `!`/`#` after a value on the same line |
| Block terminator | Every block must end with `END_` on its own line |
| Case sensitivity | **Keywords are case-insensitive**; ID_NAME values are case-sensitive |
| Whitespace | Free-form; spaces and tabs for alignment are ignored |
| String quoting | ID_NAMEs with spaces must be quoted: `ID_NAME = "My Group"` |
| List syntax | Use `LIST_BEGIN` ... `END_` for element/node lists in GROUP_DEF |
| Range notation | `1-100` (elements 1 through 100), `1-100:5` (1,6,11,...,96) |
| Separator | Comma `,` separates list items and multi-value parameters |
| Continuation | No explicit continuation character; each parameter on its own line |

## Block Reference

### OPTIONS -- Global Options

Controls global behavior of the Tosca optimization run. Must appear before all other blocks.

```
OPTIONS
  DRESP_GROUP_OPER_AGGREGATION = ON | OFF   ! Default: OFF. Aggregate DRESP group operations
END_
```

**Required fields:** None (all are optional)

**Key parameters:**

| Parameter | Default | Description |
|-----------|---------|-------------|
| `DRESP_GROUP_OPER_AGGREGATION` | OFF | When ON, aggregates element-level design responses using GROUP_OPER before evaluation. Recommended for production runs. |

**Example:**
```
OPTIONS
  DRESP_GROUP_OPER_AGGREGATION = ON
END_
```

**Important:** The OPTIONS block is optional but recommended. When Abaqus CAE generates .par files, it always includes this block.

### DRIVER -- Solver Configuration (Auto-Generated)

The DRIVER block configures how Tosca calls the FEA solver and manages file saving. It is **auto-generated by Abaqus CAE** when using `OptimizationProcess.submit()` — do not hand-write this block.

```
DRIVER
driver.Solver.AddCallArgs = ['message', 'memory=90%', ...]
config.registerSaveRule(UpdateRules.MOVE, CheckPoints.CYCLE_COMPLETE, ...)
config.registerSaveRule(UpdateRules.COPY, CheckPoints.CYCLE_COMPLETE, ...)
driver.registerCheckPointHook(CheckPoints.ITER_COMPLETE, ...)
driver.Solver.RemoveUserRequests = False
END_
```

**Key elements:**
- `driver.Solver.AddCallArgs` — Extra arguments passed to the Abaqus solver command
- `config.registerSaveRule` — Rules for saving/moving ODB, MSG, DAT, STA files between cycles
- `driver.registerCheckPointHook` — Post-iteration hooks (e.g., writing ONF to ODB)
- `driver.Solver.RemoveUserRequests` — Whether to strip user output requests

**When you see it:** In .par files generated by Abaqus CAE via `OptimizationProcess`. Never needed in hand-written .par files for Tosca CLI.

### FEM_INPUT -- Finite Element Model

Points Tosca to the Abaqus .inp file(s) to optimize.

```
FEM_INPUT
  ID_NAME       = <unique_name>
  FILE          = <filename.inp>           ! Required. Path to Abaqus input file
  FILE          = <filename2.inp>          ! Optional. Additional input files (multi-step)
  FILE_ADD_CALL = cpus=4                   ! Optional. Extra solver arguments
  ADD_FILE      = <restriction_elems.inp>  ! Optional. Elements for manufacturing constraints
  COPY_FILE     = <auxiliary_file>         ! Optional. Copied to working directory
END_
```

**Required fields:** `ID_NAME`, `FILE`

**Key rules:**
- The first `FILE` is the main model; its mesh configuration is read
- All `FILE` entries must have different base names (without extension)
- `FILE` names must not contain `=`, `!`, or `#`
- Multiple `FILE` entries create multi-step analyses (load cases)

**Example (single model):**
```
FEM_INPUT
  ID_NAME  = FEA_MODEL
  FILE     = Block_flat.inp
END_
```

**Example (multi-step with extra CPUs):**
```
FEM_INPUT
  ID_NAME       = model
  FILE          = preload.inp
  FILE_ADD_CALL = cpus=24
  FILE          = service_load.inp
  FILE_ADD_CALL = cpus=12 globalmodel=preload.inp
END_
```

### GROUP_DEF -- Element and Node Groups

Defines groups of elements or nodes for use in DV_TOPO, DVCON_TOPO, and DRESP blocks. Groups can reference element/node IDs directly, materials, properties, or other groups.

```
GROUP_DEF
  ID_NAME    = <unique_name>
  TYPE       = ELEM | NODE | GENERIC
  FORMAT     = LIST | LIST_MAT | LIST_PROP | LIST_GROUP | LIST_SUBTRACT_GROUP
               | LIST_NODE_ALL | LIST_NODE_ANY | LIST_NDGR_ALL | LIST_NDGR_ANY
               | LIST_ELEM | LIST_ELGR | LIST_POINTS | SELECTED
  LIST_BEGIN
  <entries>
END_
```

**Required fields:** `ID_NAME`, `TYPE`, `FORMAT`, and `LIST_BEGIN` (for LIST* formats)

**FORMAT options:**

| FORMAT | TYPE | Entries contain |
|--------|------|-----------------|
| `LIST` | ELEM/NODE | Element or node IDs (ranges allowed: `1-100`, `1-100:5`) |
| `LIST_MAT` | ELEM | Material names/IDs -- selects all elements with those materials |
| `LIST_PROP` | ELEM | Property names/IDs |
| `LIST_GROUP` | ELEM/NODE | Other group names -- creates union (A + B + C) |
| `LIST_SUBTRACT_GROUP` | ELEM/NODE | First group minus subsequent groups (A - B - C) |
| `LIST_NODE_ALL` | ELEM | Node IDs -- selects elements whose ALL nodes are in the list |
| `LIST_NODE_ANY` | ELEM | Node IDs -- selects elements with at least one listed node |

**Example (element list with ranges):**
```
GROUP_DEF
  ID_NAME = design_elements
  TYPE    = ELEM
  FORMAT  = LIST
  LIST_BEGIN
  1-5000, 5100-6000
END_
```

**Example (combine groups):**
```
GROUP_DEF
  ID_NAME = ALL_FROZEN
  TYPE    = ELEM
  FORMAT  = LIST_GROUP
LIST_BEGIN
FrozenUpper, FrozenLowerLeft, FrozenLowerRight
END_
```

**Example (subtract groups):**
```
GROUP_DEF
  ID_NAME = STRESS_EVAL_ELEMENTS
  TYPE    = ELEM
  FORMAT  = LIST_SUBTRACT_GROUP
  LIST_BEGIN
  ALL_ELEMENTS, LoadedElements, BCElements
END_
```

**Important:** If the Abaqus .inp file already defines element sets (e.g., `*ELSET, ELSET=FrozenElems`), Tosca can reference them directly in DV_TOPO and DVCON_TOPO without needing GROUP_DEF. Tosca reads Abaqus set definitions from the .inp file.

### DV_TOPO -- Design Variables (Topology)

Defines which elements participate in the topology optimization (the design space).

```
DV_TOPO
  ID_NAME           = <unique_name>
  EL_GROUP          = <element_group_name>    ! Required. Design space elements
  INITIAL_DV_FIELD  = <filename.onf>          ! Optional. Initial density distribution
END_
```

**Required fields:** `ID_NAME`, `EL_GROUP`

**Key rules:**
- Only certain element types are valid (hex8, hex20, tet4, tet10, pent6, pent15)
- Invalid elements are silently removed from the group
- `INITIAL_DV_FIELD` must be an ONF file in the working directory; rename from `TP_XXX.onf` to avoid name conflicts with output files

**Example:**
```
DV_TOPO
  ID_NAME  = design_variables
  EL_GROUP = ALL_ELEMENTS
END_
```

### DVCON_TOPO -- Design Variable Constraints (Topology)

Defines manufacturing constraints and frozen regions for topology optimization.

```
DVCON_TOPO
  ID_NAME       = <unique_name>
  EL_GROUP      = <element_group_name>
  CHECK_TYPE    = FROZEN | CAST | MILLING | OVERHANG | MIN_MEMBER
                  | MAX_MEMBER | RIB_DESIGN | LINK_TOPO | CLUSTER_GROUPS
  ! Additional parameters depend on CHECK_TYPE (see below)
END_
```

**Required fields:** `ID_NAME`, `EL_GROUP`, `CHECK_TYPE`

**CHECK_TYPE options:**

| CHECK_TYPE | Purpose | Key Extra Parameters |
|------------|---------|---------------------|
| `FROZEN` | Elements remain solid (never removed) | None |
| `MIN_MEMBER` | Minimum structural thickness | `THICKNESS = <value>` |
| `MAX_MEMBER` | Maximum structural thickness | `THICKNESS = <value>`, `DISTANCE`, `MIN_THICKNESS` |
| `CAST` | Demolding constraint | `PULL_DIR = x,y,z`, `MID_PLANE`, `CHECK_GROUP` |
| `MILLING` | Milling accessibility | `MILLING_DIR = x,y,z` (repeatable) |
| `OVERHANG` | Additive manufacturing | `PRINT_DIR = x,y,z`, `ANGLE = 45` |
| `RIB_DESIGN` | Enforce rib patterns | `RIB_DIRECTION`, `RIB_THICKNESS`, `RIB_DISTANCE` |
| `LINK_TOPO` | Symmetry/pattern repetition | `CHECK_LINK = <link_topo_name>`, `RADIUS` |
| `CLUSTER_GROUPS` | Same density for element groups | Multiple `EL_GROUP` entries |

**Example (frozen region):**
```
DVCON_TOPO
  ID_NAME    = dvcon_frozen
  EL_GROUP   = FrozenElems
  CHECK_TYPE = FROZEN
END_
```

**Example (minimum member size):**
```
DVCON_TOPO
  ID_NAME    = dvcon_min_member
  EL_GROUP   = ALL_ELEMENTS
  CHECK_TYPE = MIN_MEMBER
  THICKNESS  = 5.0
END_
```

**Example (casting with draw direction):**
```
DVCON_TOPO
  ID_NAME     = dvcon_cast
  EL_GROUP    = ALL_ELEMENTS
  CHECK_TYPE  = CAST
  PULL_DIR    = 0.,0.,1.
  MID_PLANE   = AUTO
  CHECK_GROUP = ALL_ELEMENTS
END_
```

**Example (additive manufacturing overhang):**
```
DVCON_TOPO
  ID_NAME    = dvcon_overhang
  EL_GROUP   = ALL_ELEMENTS
  CHECK_TYPE = OVERHANG
  PRINT_DIR  = 0.,1.,0.
  ANGLE      = 45
END_
```

### DRESP -- Design Response

Defines a measurable quantity from the FEA results. Design responses are referenced by OBJ_FUNC and CONSTRAINT blocks.

See `design-responses.md` for the complete TYPE catalog.

```
DRESP
  ID_NAME    = <unique_name>
  DEF_TYPE   = SYSTEM | OPER
  TYPE       = <response_type>         ! e.g., VOLUME, STRAIN_ENERGY, SIG_SENS_MISES
  EL_GROUP   = <element_group>         ! For element-based responses
  ND_GROUP   = <node_group>            ! For node-based responses
  NODE       = <node_number>           ! Alternative to ND_GROUP (single node)
  ELEM       = <element_number>        ! Alternative to EL_GROUP (single element)
  GROUP_OPER = MAX | MIN | SUM | AVERAGE   ! How to aggregate over the group
  CS_REF     = <coordinate_system>     ! Default: CS_0 (global)
  LC_SET     = <approach>,<loadcase>,<substep>  ! Load case selection
  LIST       = LIST | NO_LIST          ! Output verbosity
END_
```

**Required fields:** `ID_NAME`, `DEF_TYPE`, `TYPE`

**DEF_TYPE = SYSTEM:** Response computed directly from FEA results.
**DEF_TYPE = OPER:** Response derived from other DRESPs (e.g., subtraction, combination).

For `DEF_TYPE = OPER`:
```
DRESP
  ID_NAME  = relative_displacement
  DEF_TYPE = OPER
  VAR_A    = disp_node_1
  VAR_B    = disp_node_2
  VAR_OPER = SUB_ABS
END_
```

**LC_SET syntax:**
```
LC_SET = <approach>, <loadcase>, <substep>
```
- `<approach>`: ALL, STATIC, MODAL, NONLINEAR, DAMAGE
- `<loadcase>`: ALL or specific number (1, 2, etc.)
- `<substep>`: ALL or specific number

If `LC_SET` is omitted, defaults to `ALL, ALL, ALL`.

For multi-file setups, load case numbering: file 1 uses numbers as-is; file 2 adds 10000; file 3 adds 20000.

### OBJ_FUNC -- Objective Function

Defines what the optimizer minimizes or maximizes.

```
OBJ_FUNC
  ID_NAME = <unique_name>
  DRESP   = <dresp_name>                          ! Single DRESP
  DRESP   = <dresp_name>, <weight>, <ref_value>   ! Weighted (optional)
  TARGET  = MIN | MAX | MINMAX | MAXMIN
END_
```

**Required fields:** `ID_NAME`, `DRESP` (at least one), `TARGET`

**TARGET options:**

| TARGET | Meaning |
|--------|---------|
| `MIN` | Minimize the (weighted sum of) DRESP(s) |
| `MAX` | Maximize the (weighted sum of) DRESP(s) |
| `MINMAX` | Minimize the maximum deviation from reference values |
| `MAXMIN` | Maximize the minimum deviation from reference values |

**Key rules:**
- `DRESP` can be repeated for multi-objective formulation
- Weight factor defaults to 1.0; reference value defaults to 0.0
- For `SIG_SENS_MISES`, the reference value acts as the reference stress for scaling
- `MINMAX`/`MAXMIN` require reference values to be meaningful

**Example (minimize volume):**
```
OBJ_FUNC
  ID_NAME = min_volume
  DRESP   = DRESP_VOLUME
  TARGET  = MIN
END_
```

**Example (minimize compliance -- equivalent to maximize stiffness):**
```
OBJ_FUNC
  ID_NAME = min_compliance
  DRESP   = DRESP_STRAIN_ENERGY
  TARGET  = MIN
END_
```

### CONSTRAINT -- Optimization Constraint

Defines an inequality or equality constraint on a design response.

```
CONSTRAINT
  ID_NAME   = <unique_name>
  DRESP     = <dresp_name>
  MAGNITUDE = ABS | REL
  LE_VALUE  = <value>      ! Less than or equal (use ONE of LE/GE/EQ)
  GE_VALUE  = <value>      ! Greater than or equal
  EQ_VALUE  = <value>      ! Equal to (controller-based only)
END_
```

**Required fields:** `ID_NAME`, `DRESP`, `MAGNITUDE`, and exactly one of `LE_VALUE`/`GE_VALUE`/`EQ_VALUE`

**MAGNITUDE:**
- `ABS`: Value is in absolute units (e.g., `LE_VALUE = 800.0` means 800 MPa)
- `REL`: Value is relative to the start model response (e.g., `LE_VALUE = 0.3` means 30% of initial)

**Key rules:**
- Only ONE of `LE_VALUE`, `GE_VALUE`, `EQ_VALUE` per constraint
- `EQ_VALUE` is only for controller-based optimization
- Inequality constraints are for sensitivity-based optimization
- Be careful with `REL` when start model value is negative (inequality direction flips)
- For topology, the "start model" has densities set by `DENSITY_INITIAL` (default 0.5 without volume constraint)

**Example (volume fraction <= 30%):**
```
CONSTRAINT
  ID_NAME   = vol_constraint
  DRESP     = DRESP_VOLUME
  MAGNITUDE = REL
  LE_VALUE  = 0.3
END_
```

**Example (absolute stress limit):**
```
CONSTRAINT
  ID_NAME   = stress_constraint
  DRESP     = DRESP_STRESS
  MAGNITUDE = ABS
  LE_VALUE  = 800.0
END_
```

### OPTIMIZE -- Optimization Task Definition

Ties together all components into a single optimization problem.

```
OPTIMIZE
  ID_NAME    = <unique_name>
  DV         = <dv_topo_name>
  OBJ_FUNC   = <obj_func_name>
  DVCON      = <dvcon_name>              ! Repeatable
  CONSTRAINT = <constraint_name>         ! Repeatable
  STRATEGY   = TOPO_SENSITIVITY | TOPO_CONTROLLER
               | SHAPE_SENSITIVITY | SHAPE_CONTROLLER
               | BEAD_SENSITIVITY | BEAD_CONTROLLER
               | SIZING_SENSITIVITY
END_
```

**Required fields:** `ID_NAME`, `DV`, `OBJ_FUNC`, `STRATEGY`

**STRATEGY selection:**

| Strategy | When to use |
|----------|-------------|
| `TOPO_SENSITIVITY` | Topology with any constraints (stress, displacement, multiple) |
| `TOPO_CONTROLLER` | Topology with only compliance obj + volume constraint (faster) |
| `SHAPE_SENSITIVITY` | Shape optimization with constraints |
| `SHAPE_CONTROLLER` | Shape optimization (stress minimization) |
| `BEAD_SENSITIVITY` | Bead optimization with constraints |
| `SIZING_SENSITIVITY` | Shell thickness optimization |

**Key rules:**
- Multiple `DVCON` entries allowed; can use wildcard: `DVCON = dvcon_*`
- Multiple `CONSTRAINT` entries allowed for sensitivity-based strategies
- Controller-based topology only supports one constraint (volume)
- You can switch between TOPO_SENSITIVITY and TOPO_CONTROLLER by just changing STRATEGY (if the problem is compatible)

**Example:**
```
OPTIMIZE
  ID_NAME    = TOPOLOGY_OPT
  DV         = design_variables
  OBJ_FUNC   = min_volume
  DVCON      = dvcon_frozen
  CONSTRAINT = stress_constraint
  STRATEGY   = TOPO_SENSITIVITY
END_
```

### OPT_PARAM -- Optimization Parameters

Tuning knobs for the optimization algorithm. All parameters have defaults; only include what you want to override.

```
OPT_PARAM
  ID_NAME              = <unique_name>
  OPTIMIZE             = <optimize_name>         ! Required. Which OPTIMIZE block to control
  ! Topology-specific parameters:
  MAT_INTERPOLATION    = SIMP | RAMP | PEDE | MIMP | 4_TH
  MAT_PENALTY          = <real>                  ! Default: 3.0
  TOPO_FILTER_RADIUS   = <real>                  ! Default: 1.3 * avg edge length
  FILTER_TYPE          = AUTO | SENS | DV | DV_LEGACY
  DENSITY_INITIAL      = <real>                  ! Default: 0.5 (or from volume constraint)
  DENSITY_MOVE         = <real>                  ! Default: 0.25 (move limit per iteration)
  DENSITY_LOWER        = <real>                  ! Default: 0.001
  DENSITY_UPPER        = <real>                  ! Default: 1.0
  DENSITY_UPDATE       = NORMAL | CONSERVATIVE | AGGRESSIVE
  DV_UPDATE_STRATEGY   = CSA | MMA              ! Update algorithm
  AUTO_FROZEN          = OFF | LOAD | SPC | ALL  ! Auto-freeze loaded/BC elements
  STRESS_DRESP_OPT     = ON | OFF               ! Auto-tune for stress (ON = conservative)
  STRESS_DRESP_ITER    = <int>                   ! Default: 4 (precise stress sensitivity iters)
  STABILIZATION        = YES | NO               ! For min-volume problems
  ! Convergence stop criteria (also settable here):
  STOP_CRITERION_CONVERGENCE = AUTO | YES | NO
  STOP_CRITERION_OBJ        = <real>            ! Default: 0.001
  STOP_CRITERION_DENSITY    = <real>            ! Default: 0.005
  STOP_CRITERION_ITER       = <int>             ! Default: 4
  STOP_CRITERION_LEVEL      = BOTH | SINGLE
END_
```

**Required fields:** `ID_NAME`, `OPTIMIZE`

**Material interpolation guide:**

| Scheme | When to use | Penalty default |
|--------|-------------|-----------------|
| `SIMP` | Compliance minimization, general use | 3.0 |
| `RAMP` | Dynamic/frequency problems | 3.0 |
| `PEDE` | Auto-selected when body loads or dynamic LCs present | proprietary |
| `MIMP` | **Stress-constrained optimization** (recommended) | proprietary |
| `4_TH` | Expert use only; custom polynomial | user-defined |

**Filter radius:**
- Controls minimum member size in the result
- Larger radius = thicker members, smoother topology
- Too small = checkerboard patterns
- Good starting point: 2-3x element edge length

**Example (compliance optimization, standard):**
```
OPT_PARAM
  ID_NAME            = OPT_PARAMS
  OPTIMIZE           = TOPOLOGY_OPT
  TOPO_FILTER_RADIUS = 10.0
END_
```

**Example (stress-constrained, tuned):**
```
OPT_PARAM
  ID_NAME            = OPT_PARAMS
  OPTIMIZE           = TOPOLOGY_OPT
  TOPO_FILTER_RADIUS = 3.0
  MAT_INTERPOLATION  = MIMP
  DENSITY_MOVE       = 0.10
  DENSITY_UPDATE     = CONSERVATIVE
  STRESS_DRESP_OPT   = ON
  STABILIZATION      = YES
END_
```

### STOP -- Stopping Criteria

Defines when the optimization terminates.

```
STOP
  ID_NAME  = <unique_name>
  ITER_MAX = <integer>        ! Maximum iterations
END_
```

**Required fields:** `ID_NAME`, `ITER_MAX`

**Default ITER_MAX values:**

| Context | Default |
|---------|---------|
| Topology/sizing sensitivity | 50 |
| Topology/sizing with stress DRESP | 80 (automatic) |
| Shape controller/sensitivity | 50 |
| Topology controller | 15 |
| Bead sensitivity | 20 |
| Bead controller | 3 |

**Advanced: Logical stop conditions** (separate STOP block):
```
STOP
  ID_NAME  = stop_stress
  MOD_NDGR = ALL_NODES
  MOD_TYPE = MAX, CTRL_INP_SHAPE
  MOD_OPER = LE
  MOD_REF  = 0.01, MULT, FIRST
  OPTIMIZE = TOPOLOGY_OPT
END_
```

**Key rule:** A global STOP (with ITER_MAX) cannot have other parameters. Define additional logical stop conditions in separate STOP blocks.

### SMOOTH -- Isosurface Extraction and Export

Post-processes the optimization result to generate a smoothed geometry (STL, IGES, etc.).

```
SMOOTH
  ID_NAME                 = <unique_name>
  TASK                    = ISO | SURFACE | SURFACE_INITIAL | ALL_ITERATIONS
  ISO_VALUE               = <real>       ! Default: 0.3. Threshold (0-1); higher = less material
  TARGET_VOLUME           = <real>       ! Alternative to ISO_VALUE; iterates to find matching iso
  SMOOTH_CYCLES           = <int>        ! Default: 5. Laplacian smoothing passes
  SHRINKAGE_CORRECTION    = YES | NO     ! Compensate for smoothing shrinkage
  REDUCTION_RATE          = <real>       ! Default: 0. Percent of faces to reduce (0-100)
  REDUCTION_ANGLE         = <real>       ! Default: 15. Max angle for face removal (degrees)
  SELF_INTERSECTION_CHECK = OFF | CHECK | RUNTIME | ITERATIVE
  FORMAT                  = stl | inp | vtfx | onf | iges1 | iges2 | iges3
                            | bdf | cdb | out | obj   ! Repeatable for multiple formats
  OUTPUT_FILE             = <base_name>  ! Default: ID_NAME value
  OUTPUT_SURFACE          = ORIGINAL | NEW | BOTH
  DATABASE                = opt_res_database   ! Read from results database
  DESIGN_CYCLE            = ALL | LAST | <int>
  GROUP_EXCLUDE           = <group_name>       ! Exclude elements from output
  GROUP_INCLUDE           = <group_name>       ! Force-include elements
  GROUP_SURFACE           = <group_name>       ! Always show surface of these elements
END_
```

**Required fields:** `ID_NAME`, `TASK`, `FORMAT`

**ISO_VALUE guidance:**

| ISO_VALUE | Effect |
|-----------|--------|
| 0.2 | More material retained (conservative) |
| 0.3 | Balanced (common default) |
| 0.5 | Moderate material removal |
| 0.7 | Aggressive -- only high-density elements kept |

**Example (STL export):**
```
SMOOTH
  ID_NAME                 = ISO_SMOOTHING
  TASK                    = iso
  ISO_VALUE               = 0.3
  SELF_INTERSECTION_CHECK = runtime
  SMOOTH_CYCLES           = 10
  REDUCTION_RATE          = 60
  REDUCTION_ANGLE         = 5.0
  FORMAT                  = stl
END_
```

**Example (target volume + multiple formats):**
```
SMOOTH
  ID_NAME        = VOLUME_SMOOTHING
  TASK           = iso
  TARGET_VOLUME  = 0.4
  SMOOTH_CYCLES  = 10
  FORMAT         = vtfx
  FORMAT         = stl
  FORMAT         = onf
END_
```

## Complete Minimal .par File Template

```
! Topology optimization parameter file
! Objective: Minimize strain energy (maximize stiffness)
! Constraint: Volume <= 30% of original

OPTIONS
  DRESP_GROUP_OPER_AGGREGATION = ON
END_

FEM_INPUT
  ID_NAME  = FEA_MODEL
  FILE     = model.inp
END_

DV_TOPO
  ID_NAME  = design_variables
  EL_GROUP = ALL_ELEMENTS
END_

DVCON_TOPO
  ID_NAME    = dvcon_frozen
  EL_GROUP   = FrozenElems
  CHECK_TYPE = FROZEN
END_

DRESP
  ID_NAME    = DRESP_STRAIN_ENERGY
  LIST       = NO_LIST
  DEF_TYPE   = SYSTEM
  TYPE       = STRAIN_ENERGY
  EL_GROUP   = ALL_ELEMENTS
  GROUP_OPER = SUM
  LC_SET     = ALL, 1, ALL
END_

DRESP
  ID_NAME    = DRESP_VOLUME
  LIST       = NO_LIST
  DEF_TYPE   = SYSTEM
  TYPE       = VOLUME
  EL_GROUP   = ALL_ELEMENTS
  GROUP_OPER = SUM
END_

OBJ_FUNC
  ID_NAME = min_compliance
  DRESP   = DRESP_STRAIN_ENERGY, 1.
  TARGET  = MIN
END_

CONSTRAINT
  ID_NAME   = vol_constraint
  DRESP     = DRESP_VOLUME
  MAGNITUDE = REL
  LE_VALUE  = 0.3
END_

OPTIMIZE
  ID_NAME    = TOPOLOGY_OPT
  DV         = design_variables
  OBJ_FUNC   = min_compliance
  DVCON      = dvcon_frozen
  CONSTRAINT = vol_constraint
  STRATEGY   = TOPO_SENSITIVITY
END_

OPT_PARAM
  ID_NAME                = OPT_PARAMS
  OPTIMIZE               = TOPOLOGY_OPT
  AUTO_FROZEN            = BOTH
  DENSITY_UPDATE         = NORMAL
  DENSITY_LOWER          = 0.001
  DENSITY_UPPER          = 1.
  DENSITY_MOVE           = 0.25
  MAT_INTERPOLATION      = SIMP
  MAT_PENALTY            = 3.
  TOPO_FILTER_RADIUS     = 3.0
  STOP_CRITERION_LEVEL   = BOTH
  STOP_CRITERION_OBJ     = 0.001
  STOP_CRITERION_DENSITY = 0.005
  STOP_CRITERION_ITER    = 4
  SUM_Q_FACTOR           = 6.
END_

STOP
  ID_NAME  = global_stop
  ITER_MAX = 50
END_

SMOOTH
  ID_NAME                 = ISO_SMOOTHING
  TASK                    = iso
  ISO_VALUE               = 0.3
  SELF_INTERSECTION_CHECK = runtime
  SMOOTH_CYCLES           = 10
  REDUCTION_RATE          = 60
  REDUCTION_ANGLE         = 5.0
  FORMAT                  = stl
END_
```
