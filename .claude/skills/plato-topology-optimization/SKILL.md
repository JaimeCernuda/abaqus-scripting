# Plato Topology Optimization — Complete Workflow

End-to-end topology optimization using Plato Engine (open-source, Sandia National Labs).

## When to Use

- User wants to optimize a structural design for minimum weight or maximum stiffness
- User mentions topology optimization, material removal, lightweight design, generative design
- User has a design envelope with loads and supports defined

## When NOT to Use

- FEA only, no optimization → use `plato-static-analysis`
- Shape optimization (parametric) → not yet supported in this skill set
- Modal/dynamic analysis → not yet supported

## What to Ask User

### Required
1. **Design envelope**: Shape and dimensions (e.g., "100×20×10 mm box")
2. **Supports**: Where is the structure fixed? Which face/edge?
3. **Loads**: What forces/pressures? Magnitude, direction, where applied?
4. **Objective**: Minimize weight (with stress constraint) OR maximize stiffness (with volume constraint)?

### Optional (with defaults)
5. **Material**: Default steel (E=210 GPa, nu=0.3, rho=7850 kg/m³)
6. **Volume fraction**: Default 0.3 (30% of design domain retained)
7. **Mesh size**: Default auto (design domain / 30)
8. **Max iterations**: Default 50
9. **Frozen regions**: Regions that must stay solid (near supports/loads)
10. **Symmetry**: Reflection/revolution symmetry constraints

## Workflow

### Phase 1: Generate Mesh
Invoke `plato-mesh` skill to create Exodus mesh with named sidesets/nodesets.

### Phase 2: Generate Physics XML
Invoke `plato-material`, `plato-bc`, `plato-load`, then `plato-physics` to assemble the complete Plato Analyze XML file(s).

For compliance minimization: one XML file with `Internal Elastic Energy` criterion.
For stress-constrained: one XML file with `Stress P-Norm` criterion, plus volume criterion.

### Phase 3: Generate Input Deck (.i file)

Assemble the `.i` file with all blocks. Template for **compliance minimization with volume constraint**:

```
// Plato Topology Optimization Input Deck
// Generated by Claude Code

begin service 1
  code platomain
  number_processors 1
end service

begin service 2
  code plato_analyze
  number_processors 1
end service

begin material 1
  material_model isotropic_linear_elastic
  youngs_modulus 210e9
  poissons_ratio 0.3
  mass_density 7850
end material

begin block 1
  material 1
  name design_domain
end block

begin criterion 1
  type mechanical_compliance
end criterion

begin criterion 2
  type volume
end criterion

begin load 1
  type traction
  location_type sideset
  location_name load_surface
  value 0 -1e6 0
end load

begin boundary_condition 1
  type fixed_value
  location_type sideset
  location_name fixed_support
  degree_of_freedom dispx dispy dispz
  value 0 0 0
end boundary_condition

begin scenario 1
  physics steady_state_mechanics
  dimensions 3
  loads 1
  boundary_conditions 1
  material 1
  minimum_ersatz_material_value 1e-3
end scenario

begin objective
  type weighted_sum
  services 2
  criteria 1
  scenarios 1
  weights 1.0
end objective

begin constraint 1
  service 1
  criterion 2
  scenario 1
  relative_target 0.3
end constraint

begin optimization_parameters
  optimization_algorithm rol_linear_constraint
  discretization density
  initial_density_value 0.5
  filter_radius_scale 1.75
  filter_type kernel
  max_iterations 50
  output_frequency 5
  material_penalty_exponent 3.0
end optimization_parameters

begin output
  service 2
  data vonmises dispx dispy dispz
end output

begin mesh
  name mesh.exo
end mesh
```

### Phase 4: Submit Job
Invoke `plato-job` to submit via SLURM on Delta.

### Phase 5: Post-Process
Invoke `plato-results` to extract topology, stress, displacement.
Invoke `plato-export` to generate STL.

## Key Decisions

| User Goal | Objective | Constraint | Algorithm |
|---|---|---|---|
| Lightest structure meeting stress limit | min volume | stress ≤ σ_allow | rol_augmented_lagrangian |
| Stiffest structure at target weight | min compliance | volume ≤ V_frac | rol_linear_constraint |
| Stiffest structure (simple) | min compliance | volume ≤ 0.3 | rol_linear_constraint |
| Multi-load stiffness | min weighted compliance | volume ≤ V_frac | rol_linear_constraint |

| Parameter | Default | When to Change |
|---|---|---|
| Volume fraction | 0.3 | User specifies different target |
| Filter radius scale | 1.75 | Increase for smoother results (2.0-3.0) |
| SIMP exponent | 3.0 | Increase to 4.0 for sharper 0/1 boundary |
| Initial density | 0.5 | Equal to volume fraction for faster convergence |
| Max iterations | 50 | Increase for complex problems (100-200) |
| filter_type | kernel | Use helmholtz for complex domains |
| MPI ranks | 4 | Scale with mesh size (1 rank per ~50k elements) |

## Multi-Load Case

For multiple load cases, create multiple scenarios and list them in the objective:

```
begin scenario 1
  physics steady_state_mechanics
  dimensions 3
  loads 1
  boundary_conditions 1
  material 1
end scenario

begin scenario 2
  physics steady_state_mechanics
  dimensions 3
  loads 2
  boundary_conditions 1
  material 1
end scenario

begin objective
  type weighted_sum
  services 2 2
  criteria 1 1
  scenarios 1 2
  weights 0.5 0.5
end objective
```

## Frozen Regions

To keep material near supports or load application points:

```
begin optimization_parameters
  ...
  fixed_block_ids 2 3
  fixed_sideset_ids fixed_support load_surface
end optimization_parameters
```

Or define separate element blocks in the mesh for frozen vs design regions.

## Symmetry

```
begin optimization_parameters
  ...
  symmetry_plane_normal 1 0 0
  symmetry_plane_origin 0 0 0
end optimization_parameters
```

## Validation Checklist

- [ ] Mesh has named sidesets matching BC/load location_names
- [ ] Mesh has named element block matching block name
- [ ] Material properties are physically reasonable
- [ ] Volume fraction is between 0.1 and 0.9
- [ ] Filter radius > 1.5× element edge length
- [ ] Loads and BCs fully constrain rigid body motion
- [ ] Job submitted via SLURM (never on login node)
- [ ] Convergence: objective value stabilized in last 10 iterations
- [ ] Final volume fraction matches target (within 1%)
- [ ] No disconnected floating material regions
- [ ] Stress in optimized design ≤ allowable (if stress-constrained)

## Troubleshooting

| Issue | Cause | Fix |
|---|---|---|
| "Cannot find mesh" | Wrong mesh path in `begin mesh` | Use relative path, ensure .exo is in working dir |
| "Sideset not found" | Name mismatch between .exo and .i | Check `ncdump -h mesh.exo` for sideset names |
| Checkerboard pattern | No filter or filter too small | Increase filter_radius_scale to 2.0+ |
| All material removed | No volume constraint | Add volume constraint with relative_target |
| Optimization diverges | Step size too large | Reduce initial_search_radius in ROL params |
| Disconnected regions | Filter radius too small | Increase filter_radius_scale |
| Uniform gray (no 0/1) | Too few iterations or low penalty | Increase max_iterations and/or penalty exponent |
| MPI error on startup | Wrong number of services | Ensure ntasks matches total service processors |
| Job killed (OOM) | Mesh too fine for memory | Increase --mem or coarsen mesh |
